Quasiconvex: only the sublevel sets need to be convex. Log-concave: $\log f$ is concave, i.e. $f(\theta\mathbf x+(1-\theta)\mathbf y)\ge f(\mathbf x)^\theta f(\mathbf y)^{1-\theta}$. Both are weaker than convexity/concavity and both are closed under fewer operations — but they cover ratios, densities, ranks and cardinalities. Quasiconvex functions: definition and examples (§3.4.1)

$f$ is quasiconvex if $\dom f$ and every sublevel set $S_\alpha=\{\mathbf x\in\dom f\mid f(\mathbf x)\le\alpha\}$ are convex. Quasiconcave: $-f$ quasiconvex (superlevel sets convex). Quasilinear: both. Equivalent inequality (modified Jensen): $$f(\theta\mathbf x+(1-\theta)\mathbf y)\le\max\{f(\mathbf x),f(\mathbf y)\}.$$ On $\mathbf R$: quasiconvex iff nondecreasing, nonincreasing, or nonincreasing then nondecreasing (unimodal).

 A quasiconvex function on $\mathbf R$ that is not convex.

Example 3.29. $\log x$ on $\mathbf R_{++}$ is quasilinear. $\lceil x\rceil$ is quasilinear. Example 3.30. The length of a vector (index of its last nonzero component) is quasiconvex on $\mathbf R^n$: $\{\mathbf x\mid f(\mathbf x)\le\alpha\}$ is a subspace. Example 3.31. $f(x_1,x_2)=x_1x_2$ on $\mathbf R^2_+$ is quasiconcave (superlevel sets $x_1x_2\ge\alpha$ are convex) but neither convex nor concave (Hessian $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ indefinite).

Example 3.32 (linear-fractional). $f(\mathbf x)=\dfrac{\mathbf a^T\mathbf x+b}{\mathbf c^T\mathbf x+d}$ on $\mathbf c^T\mathbf x+d\gt0$ is quasilinear: $S_\alpha=\{\mathbf c^T\mathbf x+d\gt0,\ \mathbf a^T\mathbf x+b\le\alpha(\mathbf c^T\mathbf x+d)\}$ is the intersection of an open halfspace and a closed halfspace.

Example 3.33 (distance ratio). $\|\mathbf x-\mathbf a\|_2/\|\mathbf x-\mathbf b\|_2$ is quasiconvex on the halfspace $\{\|\mathbf x-\mathbf a\|_2\le\|\mathbf x-\mathbf b\|_2\}$: for $\alpha\le1$, $S_\alpha$ is a Euclidean ball.

Example 3.34 (internal rate of return). The IRR of a cash flow (the smallest $r$ at which the present value $\sum x_i(1+r)^{-i}$ is zero) is quasiconcave: $\{\mathbf x\mid\mathbf{IRR}(\mathbf x)\ge R\}=\{\mathbf x\mid PV(\mathbf x,r)\gt0,\ 0\le r\lt R\}$, an intersection of open halfspaces.

Properties of quasiconvex functions (§3.4.2–3.4.5)

Examples 3.35–3.36. The cardinality $\mathbf{card}(\mathbf x)$ is quasiconcave on $\mathbf R^n_+$; $\rank X$ is quasiconcave on $\mathbf S^n_+$ (since $\rank(X+Y)\ge\min\{\rank X,\rank Y\}$ for PSD matrices).

First-order condition (differentiable $f$, convex domain): $f$ quasiconvex iff $f(\mathbf y)\le f(\mathbf x)$ ⇒ $\nabla f(\mathbf x)^T(\mathbf y-\mathbf x)\le0$. So $\nabla f(\mathbf x)$ defines a supporting hyperplane to the sublevel set $\{\mathbf y\mid f(\mathbf y)\le f(\mathbf x)\}$. Warning: $\nabla f(\mathbf x)=\mathbf 0$ does not imply a global minimum for quasiconvex $f$.
Second-order condition: if $f$ is quasiconvex then $\mathbf y^T\nabla f(\mathbf x)=0$ ⇒ $\mathbf y^T\nabla^2f(\mathbf x)\mathbf y\ge0$ (on $\mathbf R$: $f'(x)=0$ ⇒ $f''(x)\ge0$). Conversely, strict $\gt0$ for nonzero $\mathbf y\perp\nabla f(\mathbf x)$ is sufficient.

Operations. Nonnegative weighted maximum $\max_iw_if_i$ ($w_i\ge0$) and $\sup_{\mathbf y}w(\mathbf y)g(\mathbf x,\mathbf y)$ preserve quasiconvexity. Composition: $h$ nondecreasing and $g$ quasiconvex ⇒ $h\circ g$ quasiconvex; composition with affine or linear-fractional maps preserves it; minimisation over $\mathbf y$ of a jointly quasiconvex function over a convex set preserves it. Sums do not: the sum of two quasiconvex functions need not be quasiconvex. Example 3.37. The maximum generalised eigenvalue $\lambda_{\max}(X,Y)=\sup_{\mathbf u\ne0}\mathbf u^TX\mathbf u/\mathbf u^TY\mathbf u$ ($Y\succ0$) is quasiconvex.

Representation (§3.4.5). A quasiconvex $f$ can be written through a family of convex functions $\phi_t$: $f(\mathbf x)\le t\iff\phi_t(\mathbf x)\le0$, with $\phi_s\le\phi_t$ for $s\ge t$. Example 3.38. $f=p/q$ with $p$ convex $\ge0$, $q$ concave $\gt0$: $\phi_t(\mathbf x)=p(\mathbf x)-tq(\mathbf x)$ is convex for $t\ge0$. Used in bisection (Module III).

Log-concave and log-convex functions (§3.5)

$f\gt0$ on its convex domain is log-concave if $\log f$ is concave: $$f(\theta\mathbf x+(1-\theta)\mathbf y)\ge f(\mathbf x)^\theta f(\mathbf y)^{1-\theta}.$$ Log-convex if $\log f$ is convex. A log-convex function is convex ($f=e^{\log f}$, convex increasing of convex); a concave positive function is log-concave. Twice differentiable: $f$ log-concave iff $f(\mathbf x)\nabla^2f(\mathbf x)\preceq\nabla f(\mathbf x)\nabla f(\mathbf x)^T$.

Example 3.39. Affine $\mathbf a^T\mathbf x+b$ on its positive part: log-concave. $x^a$ on $\mathbf R_{++}$: log-convex for $a\le0$, log-concave for $a\ge0$. $e^{ax}$: both. The cumulative Gaussian $\Phi(x)$: log-concave. $\Gamma(x)$: log-convex for $x\ge1$. $\det X$ on $\mathbf S^n_{++}$: log-concave. $\det X/\tr X$: log-concave. Example 3.40. Many densities are log-concave: the Gaussian $\dfrac{1}{\sqrt{(2\pi)^n\det\Sigma}}e^{-\frac12(\mathbf x-\bar{\mathbf x})^T\Sigma^{-1}(\mathbf x-\bar{\mathbf x})}$, the exponential, the uniform on a convex set, the Wishart.

Properties (§3.5.2). Products of log-concave functions are log-concave; sums are not (in general). Log-convexity is preserved by sums and products. Integration: if $f(\mathbf x,\mathbf y)$ is log-concave in $(\mathbf x,\mathbf y)$, then $g(\mathbf x)=\int f(\mathbf x,\mathbf y)\,d\mathbf y$ is log-concave. Consequences: marginals of log-concave densities are log-concave; the convolution $f*g$ of log-concave functions is log-concave.

Example 3.41. The Laplace transform $P(\mathbf z)=\int p(\mathbf x)e^{-\mathbf z^T\mathbf x}d\mathbf x$ of $p\ge0$ is log-convex, so the cumulant generating function $\log\mathbf E e^{\mathbf z^T\mathbf x}$ is convex. Example 3.42. The CDF of a log-concave density is log-concave. Example 3.43. Yield function $Y(\mathbf x)=\mathbf{prob}(\mathbf x+\mathbf w\in S)$ with $\mathbf w$ log-concave and $S$ convex is log-concave, so $\{\mathbf x\mid Y(\mathbf x)\ge\alpha\}$ is convex. Example 3.44. The volume of the polyhedron $\{\mathbf x\mid A\mathbf x\preceq\mathbf b\}$ is a log-concave function of $\mathbf b$.

Show $f(x)=e^{-x^2}$ is log-concave but not concave.

$\log f=-x^2$ is concave. $f''=(4x^2-2)e^{-x^2}\gt0$ for $|x|\gt1/\sqrt2$, so $f$ is not concave.

 Prove that a nondecreasing function on $\mathbf R$ is quasiconvex.

If $f$ is nondecreasing, $\{x\mid f(x)\le\alpha\}$ is an interval of the form $(-\infty,c)$, $(-\infty,c]$, $\emptyset$ or $\mathbf R$: always convex.

 Give two quasiconvex functions whose sum is not quasiconvex.

$f_1=x^3$ (monotone) and $f_2=-x$ (monotone). $x^3-x$ has sublevel set $\{x^3-x\le0\}=(-\infty,-1]\cup[0,1]$, not convex.
