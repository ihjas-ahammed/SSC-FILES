Replace $\le$ by $\preceq_K$ throughout: $K$-nondecreasing functions, $K$-convex vector functions, matrix monotone and matrix convex functions. Everything reduces to ordinary convexity of the scalar functions $\mathbf w^Tf$, $\mathbf w\succeq_{K^*}0$. Monotonicity (§3.6.1)

$f:\mathbf R^n\to\mathbf R$ is $K$-nondecreasing if $\mathbf x\preceq_K\mathbf y$ ⇒ $f(\mathbf x)\le f(\mathbf y)$. For differentiable $f$ on a convex domain: $K$-nondecreasing iff $\nabla f(\mathbf x)\succeq_{K^*}0$ for all $\mathbf x$ (the gradient lies in the dual cone). Strictly: $\nabla f(\mathbf x)\succ_{K^*}0$ ⇒ $K$-increasing.

Example 3.45. For $K=\mathbf R^n_+$: $f$ is nondecreasing iff each partial derivative is $\ge0$. Example 3.46. On $\mathbf S^n$ with $K=\mathbf S^n_+$: $\tr(WX)$ with $W\succeq0$ is matrix nondecreasing; $\tr X^{-1}$ is matrix decreasing on $\mathbf S^n_{++}$; $\det X$ is matrix increasing on $\mathbf S^n_{++}$ and nondecreasing on $\mathbf S^n_+$.

Proof of the gradient condition (⇐). If $\mathbf x\preceq_K\mathbf y$, let $h(t)=f(\mathbf x+t(\mathbf y-\mathbf x))$. Then $h'(t)=\nabla f(\cdot)^T(\mathbf y-\mathbf x)\ge0$ because $\mathbf y-\mathbf x\in K$ and $\nabla f\in K^*$. So $h(1)\ge h(0)$.

$K$-convexity (§3.6.2)

$f:\mathbf R^n\to\mathbf R^m$ is $K$-convex if $f(\theta\mathbf x+(1-\theta)\mathbf y)\preceq_K\theta f(\mathbf x)+(1-\theta)f(\mathbf y)$. Dual characterisation: $f$ is $K$-convex iff $\mathbf w^Tf$ is convex for every $\mathbf w\succeq_{K^*}0$. Differentiable $f$: $K$-convex iff $f(\mathbf y)\succeq_Kf(\mathbf x)+Df(\mathbf x)(\mathbf y-\mathbf x)$. Composition: $g$ convex, $h$ convex and $K$-nondecreasing ⇒ $h\circ g$ convex when $g$ is $K$-convex.

Example 3.47. $K=\mathbf R^m_+$: $f$ is $K$-convex iff each component $f_i$ is convex. Example 3.48 (matrix convexity). $f:\mathbf R^n\to\mathbf S^m$ is matrix convex iff $\mathbf z^Tf(\mathbf x)\mathbf z$ is convex for every $\mathbf z$. Examples: $f(X)=XX^T$ ($X\in\mathbf R^{n\times m}$) is matrix convex since $\mathbf z^TXX^T\mathbf z=\|X^T\mathbf z\|_2^2$; $X^p$ is matrix convex on $\mathbf S^n_{++}$ for $1\le p\le2$ and $-1\le p\le0$, matrix concave for $0\le p\le1$; $e^X$ is not matrix convex for $n\ge2$.

Show that $f(X)=XX^T$ is matrix convex.

For each $\mathbf z$, $\mathbf z^TXX^T\mathbf z=\|X^T\mathbf z\|_2^2$, a convex quadratic of the linear function $X\mapsto X^T\mathbf z$. Hence $XX^T$ is $\mathbf S^n_+$-convex.

 When is a differentiable $f$ nondecreasing with respect to $\mathbf S^n_+$?

When $\nabla f(X)\succeq0$ for all $X$ (the dual of $\mathbf S^n_+$ is itself).
