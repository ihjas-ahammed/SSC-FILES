Every formula and proof the paper can ask for, on one screen. If you can write each line from memory, you are ready. Module I — formulas
  • $D_{\mathbf u}f(\boldsymbol\xi)=\lim_{t\to0}\frac{f(\boldsymbol\xi+t\mathbf u)-f(\boldsymbol\xi)}{t}=f'(\boldsymbol\xi)\mathbf u$, $\|\mathbf u\|=1$.
  • Differentiable: $f(\boldsymbol\xi+\mathbf h)-f(\boldsymbol\xi)-L\mathbf h=o(\mathbf h)$; $f'(\boldsymbol\xi)=L=(\partial y_i/\partial x_j)$; tangent flat $\mathbf y=f(\boldsymbol\xi)+f'(\boldsymbol\xi)(\mathbf x-\boldsymbol\xi)$.
  • $\nabla f$ normal to contours, steepest slope $\|\nabla f\|$. $\frac{d}{d\mathbf x}\mathbf x^TA\mathbf x=\mathbf x^T(A+A^T)$.
  • Chain rule $(f\circ g)'=f'(g(\boldsymbol\xi))g'(\boldsymbol\xi)$; Jacobian $\det f'$; inverse $(f^{-1})'=(f')^{-1}$.
  • Least squares $A^TA\mathbf x=A^T\mathbf b$. MVT $f(\mathbf b)-f(\mathbf a)=f'(\boldsymbol\xi)(\mathbf b-\mathbf a)$ (scalar $f$ only). Taylor 2.
  • Classification ($n=2$): $\det\gt0,f_{11}\gt0$ min; $\det\gt0,f_{11}\lt0$ max; $\det\lt0$ saddle; $\det=0$ no conclusion.
Module II — definitions and proofs
  • Affine / convex / conic combinations; hulls; relative interior.
  • Hyperplane, halfspace, ball, ellipsoid $(\mathbf x-\mathbf x_c)^TP^{-1}(\mathbf x-\mathbf x_c)\le1$, norm cone, polyhedron, simplex, $\mathbf S^n_+$.
  • Preserved: intersection, affine image/pre-image, perspective, linear-fractional.
  • Proper cone; $\preceq_K$; minimum vs minimal. Separating and supporting hyperplane theorems (proof!).
  • $K^*=\{\mathbf y\mid\mathbf x^T\mathbf y\ge0\ \forall\mathbf x\in K\}$; $(\mathbf R^n_+)^*=\mathbf R^n_+$, $(\mathbf S^n_+)^*=\mathbf S^n_+$, norm cone dual = dual-norm cone.
  • Convex function: definition, first-order $f(\mathbf y)\ge f(\mathbf x)+\nabla f^T(\mathbf y-\mathbf x)$, second-order $\nabla^2f\succeq0$, epigraph, sublevel sets, Jensen.
  • Operations: weighted sums, affine composition, max/sup, composition rules, partial minimisation, perspective. Conjugate $f^*$, Fenchel.
  • Quasiconvex (sublevel sets), log-concave ($f(\theta\mathbf x+(1-\theta)\mathbf y)\ge f(\mathbf x)^\theta f(\mathbf y)^{1-\theta}$), $K$-convex.
Module III — problem classes
  • Standard form; convex problem; local = global; optimality criterion $\nabla f_0(\mathbf x)^T(\mathbf y-\mathbf x)\ge0$.
  • LP (standard, inequality forms), Chebyshev centre, linear-fractional → LP. QP, QCQP, SOCP, robust LP.
  • GP: monomial, posynomial, convex form via $y=\log x$. Conic form, SDP. Vector optimization: optimal, Pareto, scalarization.
Module IV — duality
  • $L$, $g=\inf_{\mathbf x}L$ (concave), $g\le p^\star$ for $\boldsymbol\lambda\succeq0$. Dual problem; weak duality; strong duality; Slater.
  • LP dual pair; least-norm dual; $g$ via conjugates; geometric picture $\mathcal G$, $\mathcal A$; max–min inequality; saddle point.
  • KKT: primal feasibility, $\boldsymbol\lambda\succeq0$, $\lambda_if_i=0$, $\nabla_{\mathbf x}L=0$. Water-filling. Farkas. Generalized inequalities: $\boldsymbol\lambda\succeq_{K^*}0$; SDP dual.
