Cognitive Science Guide: Why Active Recall Beats Subjective Sliders
Metacognitive Calibration
▾
1. Beware the "Fluency Illusion" When you simply read a topic name (e.g. \multicolumn) and pick a number, your brain mistakes passive recognition for procedural competence. You feel you know it until an exam forces you to write the exact 3-argument syntax from memory.
2. Use the "Test My Recall" Button First Before rating each card, click "⚡ Test My Recall". Attempt to solve the prompt mentally or on scratch paper. If you fail, the true score is 1 or 2, regardless of how familiar the topic looked!
3. Calibrated Behavioral Rubric • 1 (Novice): Blank / never used.
• 2 (Familiar): Recognize it when seen, but cannot write from scratch.
• 3 (Functional): Can write standard syntax with minor reference checks.
• 4 (Proficient): Flawless code from memory under time pressure.
• 5 (Mastered): Deep grasp, can troubleshoot obscure compile errors.
