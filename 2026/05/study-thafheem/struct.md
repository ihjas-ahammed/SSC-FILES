# Tafheem ul Quran — Full Study Hierarchy

> **Structure:**
> - **Module** = A Surah
> - **Section** = A thematic group of Ayat within the Surah (set of 2–5 units)
> - **Unit** = A single Ayah
> - **Lessons per Unit** = TR (Translation) + WM (Word Meanings) + TF (Tafheem Questions) + optional CTX/RFL/REL
> - **Estimated lessons** shown per unit block; each unit ≈ 3 base lessons + extras where needed
> - Each Section ends with a **Section Summary Unit**
> - Each Module ends with a **Surah Summary**
