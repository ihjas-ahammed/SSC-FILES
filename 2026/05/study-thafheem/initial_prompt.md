Module    = A Surah (e.g., Al-Baqarah)
Section   = A group of Ayat from the same thematic/contextual set within the Surah
Unit      = A single Ayah (verse)

Each unit is given separate files due to the depth of content required per Ayah.

LESSON TYPES PER UNIT

  Ayah 6:  TR2 WL2 WM2 TF2
  Ayah 7:  TR3 WL3 WM3 TF3

LESSON STRUCTURE (SLIDE-BASED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

─── TR: Translation Lesson ───────────────
Designed for reading comprehension and TTS (text-to-speech) playback.

  Slide 0: Warm-up — 2 conceptual objective questions about this Ayah
            so the student begins thinking before the lesson
  Slide 1+: The Arabic text of the Ayah split into meaningful phrases,
            each phrase on its own slide with:
              - Arabic text (large, right-to-left)
              - Translation of that phrase
              - TTS-ready text
  Final Slide: The full Ayah + full translation together

─── WL: Word Learn Lesson ────────────────
Designed for deep learning of individual non-common Arabic words.

  Slide 0: Word Card (Type: 'word_card') — First give context, then show a card with the word, English translation, an Arabic example sentence, and morphology (root letters and forms that can be used to make new words).
  Slide 1: Fill in the Blank / MCQ — A question where the user can choose the correct application or meaning of that specific word.
  (Repeat Slides 0 and 1 for 2-3 key words in the Ayah)

─── WM: Word Meaning Lesson ──────────────
Designed for vocabulary memorization using retrieval practice.

  Slide 0+: Match the Following (Type: 'match_the_following') — Arabic word → English meaning. Group 4-5 words per slide. Create enough slides so EVERY SINGLE ARABIC WORD in the Ayah is tested.
  Slide[Next]: Fill in the Blank — "The word _____ means _____" (with word bank)
  Slide[Next]: Reverse match — English → Arabic
  Slide [Final]: Timed challenge round (all words, quick-fire objective)

─── TF: Tafheem Questions Lesson ─────────
Designed to test understanding of every fact mentioned in Maududi's
Tafheem ul Quran commentary for this Ayah.

  Slide 0: Fill in the Blank — key fact from Tafheem
  Slide 1: Match the Following — concept → explanation (from Tafheem)
  Slide 2+: More fill in blank / match the following for every
             significant fact, background detail, linguistic note,
             and historical context from the commentary
  Final Slide: Summary of all Tafheem points for this Ayah

─── Optional Lesson Types ────────────────
Add these when the content demands:

  CTX = Context Lesson — historical background, revelation context (Asbab al-Nuzul)
        Use when Tafheem has significant background for the Ayah
        Slides: Background story → objective questions about the story

  RFL = Reflection Lesson — practical life application
        Use for Ayat with strong moral/spiritual lessons
        Slides: The lesson → "How does this apply to your life?" open prompt
                + objective questions linking principle to real scenarios

  REL = Related Ayat Lesson — cross-reference with other Ayat or Hadith
        Use when Tafheem references other verses or Hadith
        Slides: Related reference → what connects them → objective question

SLIDE DESIGN PRINCIPLES
(Based on cognitive science of learning)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Apply these principles across all slides:

1. SPACED RETRIEVAL — every lesson ends with a quick recall question
   about the previous Ayah (not just the current one)

2. INTERLEAVING — mix word meanings with translation questions within
   the same session occasionally (not always isolated)

3. ELABORATIVE INTERROGATION — for TF lessons, don't just ask "what"
   but also "why did Maududi note this?" as objective choices

4. DESIRABLE DIFFICULTY — warm-up slides should be slightly hard;
   the student should feel a productive struggle before the lesson

5. CHUNKING — translation slides break the Ayah into the smallest
   meaningful units (2-4 words per phrase), not full sentences

6. DUAL CODING — where possible, add a visual/symbolic cue alongside
   Arabic text (e.g., an icon or color representing the theme)

7. GAMIFICATION — word meaning lessons should feel game-like:
   timed rounds, streak counters, visual feedback for correct answers
