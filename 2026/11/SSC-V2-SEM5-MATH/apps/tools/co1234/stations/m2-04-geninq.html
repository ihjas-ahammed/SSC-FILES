A proper cone $K$ turns $\mathbf y-\mathbf x\in K$ into a partial order $\mathbf x\preceq_K\mathbf y$ that behaves like $\le$ in most ways, except that two vectors need not be comparable. That is why a set can have many minimal elements but at most one minimum. Proper cones (§2.4.1)

A cone $K\subseteq\mathbf R^n$ is proper if it is convex, closed, solid (non-empty interior) and pointed (contains no line: $\mathbf x\in K$, $-\mathbf x\in K$ ⇒ $\mathbf x=\mathbf 0$). It defines $$\mathbf x\preceq_K\mathbf y\iff\mathbf y-\mathbf x\in K,\qquad\mathbf x\prec_K\mathbf y\iff\mathbf y-\mathbf x\in\intr K.$$

Example 2.14. $K=\mathbf R^n_+$: componentwise inequality, written $\preceq$. Example 2.15. $K=\mathbf S^n_+$: the matrix inequality $X\preceq Y$ ($Y-X$ PSD). Example 2.16. $K=\{\mathbf c\in\mathbf R^n\mid c_1+c_2t+\dots+c_nt^{n-1}\ge0\text{ for }t\in[0,1]\}$, polynomials nonnegative on $[0,1]$, a proper cone; $\mathbf c\preceq_K\mathbf d$ means $p_{\mathbf c}(t)\le p_{\mathbf d}(t)$ on $[0,1]$.

Properties of $\preceq_K$ (each from the cone properties): preserved under addition ($\mathbf x\preceq\mathbf y$, $\mathbf u\preceq\mathbf v$ ⇒ $\mathbf x+\mathbf u\preceq\mathbf y+\mathbf v$; convexity); transitive; preserved under nonnegative scaling; reflexive; antisymmetric ($\mathbf x\preceq\mathbf y\preceq\mathbf x$ ⇒ $\mathbf x=\mathbf y$; pointedness); preserved under limits (closedness). The strict version: $\mathbf x\prec\mathbf y$ ⇒ $\mathbf x\preceq\mathbf y$; $\mathbf x\prec\mathbf y$, $\mathbf u\preceq\mathbf v$ ⇒ $\mathbf x+\mathbf u\prec\mathbf y+\mathbf v$; $\mathbf x\prec\mathbf y$, $\alpha\gt0$ ⇒ $\alpha\mathbf x\prec\alpha\mathbf y$; $\mathbf x\not\prec\mathbf x$; small perturbations keep strict inequality.

$\preceq_K$ is not a linear order: for $\mathbf R^2_+$, neither $(1,0)\preceq(0,1)$ nor $(0,1)\preceq(1,0)$. Statements true for $\le$ that use comparability (every finite set has a minimum) fail.

 Minimum and minimal elements (§2.4.2)

$\mathbf x\in S$ is the minimum element of $S$ if $\mathbf x\preceq_K\mathbf y$ for every $\mathbf y\in S$; equivalently $S\subseteq\mathbf x+K$. $\mathbf x\in S$ is a minimal element if $\mathbf y\in S$, $\mathbf y\preceq_K\mathbf x$ ⇒ $\mathbf y=\mathbf x$; equivalently $(\mathbf x-K)\cap S=\{\mathbf x\}$. A minimum, if it exists, is unique and is minimal; a set may have many minimal elements and no minimum.

 Minimum versus minimal for $K=\mathbf R^2_+$ (step 3 is the dual characterisation of §2.6.3).

Example 2.17. With $K=\mathbf R^2_+$: $\mathbf x$ is the minimum of $S$ when every point of $S$ is above and to the right of it; $\mathbf x$ is minimal when no other point of $S$ is below and to the left of it.

Example 2.18. For $K=\mathbf S^n_+$ and the set of ellipsoids $\mathcal E_A=\{\mathbf x\mid\mathbf x^TA^{-1}\mathbf x\le1\}$, $A\preceq B$ iff $\mathcal E_A\subseteq\mathcal E_B$. So for a set of such ellipsoids (say, all centred ellipsoids containing given points), a minimal element is an ellipsoid inside which no other member of the set fits; there can be many, and a minimum (one inside all the others) usually does not exist.

Find the minimal elements of $S=\{(x_1,x_2)\mid x_1+x_2\ge1,\ x_1,x_2\ge0\}$ with respect to $\mathbf R^2_+$. Is there a minimum?

Minimal: every point of the segment $x_1+x_2=1$, $x_1,x_2\ge0$. No minimum: it would have to be $\preceq(1,0)$ and $\preceq(0,1)$, i.e. $\preceq(0,0)$, but $(0,0)\notin S$.

 Which property of a proper cone makes $\preceq_K$ antisymmetric?

Pointedness: $\mathbf y-\mathbf x\in K$ and $\mathbf x-\mathbf y\in K$ force $\mathbf y-\mathbf x=\mathbf 0$.
