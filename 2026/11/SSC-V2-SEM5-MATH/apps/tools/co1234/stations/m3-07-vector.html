With a vector objective $f_0(\mathbf x)\in\mathbf R^q$ compared by a proper cone $K$, a single best point (optimal) rarely exists. The useful notion is Pareto optimality: no other feasible point is at least as good in every objective and better in one. Scalarization, minimising $\boldsymbol\lambda^Tf_0$ with $\boldsymbol\lambda\succ_{K^*}0$, finds Pareto optimal points. Vector optimization problems (§4.7.1)

Minimise (w.r.t. $K$) $f_0(\mathbf x)$ s.t. $f_i(\mathbf x)\le0$, $h_i(\mathbf x)=0$, with $f_0:\mathbf R^n\to\mathbf R^q$. It is a convex vector problem if $f_0$ is $K$-convex, the $f_i$ are convex and the $h_i$ affine. The set of achievable objective values is $\mathcal O=\{f_0(\mathbf x)\mid\mathbf x\text{ feasible}\}$.

 Optimal and Pareto optimal points (§4.7.2–4.7.3)

$\mathbf x^\star$ is optimal if $f_0(\mathbf x^\star)$ is the minimum element of $\mathcal O$: $\mathcal O\subseteq f_0(\mathbf x^\star)+K$. $\mathbf x^{\mathrm{po}}$ is Pareto optimal if $f_0(\mathbf x^{\mathrm{po}})$ is a minimal element: $(f_0(\mathbf x^{\mathrm{po}})-K)\cap\mathcal O=\{f_0(\mathbf x^{\mathrm{po}})\}$. The Pareto optimal values lie on the boundary of $\mathcal O$; there are usually many.

Example 4.9 (best linear unbiased estimator). $\mathbf y=A\mathbf x+\mathbf v$, $\mathbf v$ zero mean with covariance $I$. Linear unbiased estimators $\hat{\mathbf x}=F\mathbf y$ need $FA=I$; the error covariance is $FF^T$. Minimise $FF^T$ with respect to $\mathbf S^n_+$ s.t. $FA=I$. This problem has an optimal point: $F^\star=A^\dagger=(A^TA)^{-1}A^T$, since $FF^T-F^\star F^{\star T}=(F-F^\star)(F-F^\star)^T\succeq0$ for every feasible $F$.

Scalarization (§4.7.4)

For $\boldsymbol\lambda\succ_{K^*}0$, a minimiser of the scalar problem "minimise $\boldsymbol\lambda^Tf_0(\mathbf x)$ s.t. constraints" is Pareto optimal. For a convex vector problem, conversely, every Pareto optimal point minimises $\boldsymbol\lambda^Tf_0$ for some nonzero $\boldsymbol\lambda\succeq_{K^*}0$ (by the dual characterisation of minimal elements applied to the convex set $\mathcal A=\mathcal O+K$).

 Each weight vector $\boldsymbol\lambda$ gives a supporting line of $\mathcal O$ and a Pareto point. Changing $\boldsymbol\lambda$ slides the point along the trade-off curve.

Proof of the first statement. If $\mathbf x$ minimises $\boldsymbol\lambda^Tf_0$ but is not Pareto optimal, some feasible $\mathbf y$ has $f_0(\mathbf y)\preceq_Kf_0(\mathbf x)$, $f_0(\mathbf y)\ne f_0(\mathbf x)$. Then $f_0(\mathbf x)-f_0(\mathbf y)\in K\setminus\{\mathbf 0\}$ and $\boldsymbol\lambda\succ_{K^*}0$ give $\boldsymbol\lambda^T(f_0(\mathbf x)-f_0(\mathbf y))\gt0$: contradiction.

Example 4.10 (minimal upper bound on a set of matrices). Minimise $X$ w.r.t. $\mathbf S^n_+$ s.t. $X\succeq A_i$, $i=1,\dots,m$. Scalarize with $W\succ0$: minimise $\tr(WX)$ s.t. $X\succeq A_i$, an SDP. Geometrically: the smallest ellipsoid (in the $W$-weighted sense) containing the ellipsoids $\mathcal E_{A_i}$.

Multicriterion optimization (§4.7.5–4.7.6)

$K=\mathbf R^q_+$: $q$ objectives $F_1,\dots,F_q$ all to be small. Pareto optimal: no feasible $\mathbf y$ with $F_i(\mathbf y)\le F_i(\mathbf x)$ for all $i$ and strict for one. The boundary of Pareto values is the optimal trade-off surface (curve for $q=2$). Scalarization: minimise $\lambda_1F_1+\dots+\lambda_qF_q$, $\lambda_i\gt0$.

Regularised least squares ($q=2$): minimise $(\|A\mathbf x-\mathbf b\|_2^2,\ \|\mathbf x\|_2^2)$. Scalarized with $\boldsymbol\lambda=(1,\gamma)$: $\mathbf x(\gamma)=(A^TA+\gamma I)^{-1}A^T\mathbf b$, tracing the whole trade-off curve as $\gamma$ runs over $(0,\infty)$. Risk–return trade-off in portfolio optimization: minimise $(-\bar{\mathbf p}^T\mathbf x,\ \mathbf x^T\Sigma\mathbf x)$ s.t. $\mathbf 1^T\mathbf x=1$, $\mathbf x\succeq0$.

A scalarization with $\boldsymbol\lambda$ on the boundary of $K^*$ (some $\lambda_i=0$) can return a point that is not Pareto optimal. Non-convex problems can have Pareto points that no $\boldsymbol\lambda$ reaches.

 Two criteria: $F_1=x^2$, $F_2=(x-2)^2$ on $\mathbf R$. Find the Pareto optimal points.

Minimise $\lambda_1x^2+\lambda_2(x-2)^2$: $x=2\lambda_2/(\lambda_1+\lambda_2)$, which runs over $(0,2)$ for $\lambda\succ0$; the endpoints $0$ and $2$ are also Pareto optimal. Pareto set: $[0,2]$.

 Distinguish an optimal point from a Pareto optimal point.

Optimal: its objective value is $\preceq_K$ every achievable value (the minimum of $\mathcal O$). Pareto optimal: no achievable value is $\preceq_K$ it except itself (a minimal element). Optimal ⇒ Pareto optimal, not conversely.
