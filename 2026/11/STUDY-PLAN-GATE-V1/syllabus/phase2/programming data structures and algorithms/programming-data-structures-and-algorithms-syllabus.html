📖 Winning Textbook Benchmarking & Subject Architecture

Programming, Data Structures, and Algorithms is the second highest weightage subject in GATE DA (48 total marks across 31 questions). A dual-textbook strategy wins decisively because GATE DA combines intricate Python language runtime behaviors with rigorous mathematical algorithm proofs.

Primary Choice 1: Python & Data Structures

Michael T. Goodrich, Roberto Tamassia, Michael H. Goldwasser

Data Structures and Algorithms in Python (John Wiley & Sons)

  • Python Primer (Ch 1): Unlocks mutable default parameter traps (def f(lst=[])), scoping rules (LEGB), nonlocal closures, and shallow copying vs aliasing.
  • Recursion (Ch 4): Visualizes call-stack frames, binary recursion trees, and in-place sequence inversions.
  • Abstract Data Types (Ch 6 & 7): Pure ADT contracts for Stacks, Queues, Deques, and Singly/Doubly Linked Lists.
  • Trees & Priority Queues (Ch 8, 9, 11): Full structural proofs ($n_E = n_I + 1$), complete binary tree properties, array heaps, and traversal reconstruction.
Primary Choice 2: Algorithms & Complexity

Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, Clifford Stein

Introduction to Algorithms (CLRS 3rd Edition, MIT Press)

  • Asymptotic Complexity (Ch 3): Formal set-theoretic bounds ($O, \Omega, \Theta$) and function growth comparisons.
  • Recurrences (Ch 4): Recursion tree method, substitution method, and Master Theorem conditions.
  • Quicksort (Ch 7): Lomuto partition step tracking, in-place swaps count, and unbalanced split recurrence ($T(n) = T(n/4) + T(3n/4) + cn = \Theta(n \log n)$).
  • Dynamic Programming (Ch 15): Subproblem DAG path counting and Fibonacci recurrences.
  • Graph Algorithms (Ch 22): BFS, DFS discovery/finish timestamps, edge classification (tree, back, forward, cross), topological sorting, and strongly connected components (SCC).
