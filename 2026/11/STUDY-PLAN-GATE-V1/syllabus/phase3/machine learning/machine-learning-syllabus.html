📖 Winning Textbook Benchmarking & Subject Architecture

With Linear Algebra (SVD, projections, eigenvalues), Calculus (gradient descent, Hessians), and Probability (Bayes theorem, Gaussian densities) completed in Phase 1, Machine Learning unlocks effortlessly. Three complementary textbooks provide complete mastery:

Primary Choice 1: Core Mathematical ML

Christopher M. Bishop

Pattern Recognition and Machine Learning (PRML, Springer)

  • Linear Regression (Ch 3): Least squares derivation, normal equations, Ridge regularization analytical solution $w = (X^T X + \lambda I)^{-1} X^T y$, and bias-variance tradeoff.
  • Linear Classification (Ch 4): Separating hyperplanes, Fisher's Linear Discriminant ($S_W^{-1} S_B w = \lambda w$), Perceptron criterion, Generative Gaussian models, and Multiclass Softmax parameter counting.
  • Neural Networks (Ch 5): MLP parameter counting (weights + biases), ReLU activation functions, and backpropagation via the chain rule of calculus.
  • Support Vector Machines (Ch 7): Maximum margin formulation, support vectors on margin hyperplanes ($y_i(w^T x_i + b) = 1$), and soft-margin slack variables.
  • Clustering (Ch 9): k-Means distortion measure $J$ and proof of Voronoi cell convexity.
Primary Choice 2: Algorithmic ML & Trees

Tom M. Mitchell & Marc Peter Deisenroth

Machine Learning (Mitchell) & Mathematics for Machine Learning (Deisenroth)

  • Decision Trees (Mitchell Ch 3): Shannon entropy $H(S)$, Information Gain $Gain(S, A)$, ID3 greedy tree growth, and overfitting avoidance.
  • Bayesian Learning (Mitchell Ch 6): Naive Bayes conditional independence assumption, independent parameter counting ($2K+1$ for $K$ binary features), and posterior odds.
  • Instance-Based Learning (Mitchell Ch 8): k-Nearest Neighbor classifier, distance metrics, and 1-NN Voronoi decision boundaries.
  • Principal Component Analysis (Deisenroth Ch 10): Maximum variance formulation, covariance matrix $S u_i = \lambda_i u_i$, and exact ratio of variance explained $\frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i}$.
