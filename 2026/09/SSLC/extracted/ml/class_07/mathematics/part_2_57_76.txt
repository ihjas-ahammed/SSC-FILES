12 ബീജഗണിതം
സംഖ്യകളും ബീജഗണിതവും
അളവുകളെയും സംഖ്യകളെയും കുറിച്ചുള്ള കാര്യങ്ങൾ അക്ഷരങ്ങൾ ഉപയോോഗിച്ചു ചുരുക്കി
യെഴുതുന്ന ബീജഗണിതരീതി കുറച്ചചൊക്കെ മനസ്സിലാക്കിയല്ലലോ.
ഇനി ബീജഗണിതം ഉപയോോഗിക്കുന്ന മറ്റു ചില സന്ദർഭങ്ങൾ നോോക്കാം.
സംഖ്യകളിൽനിന്നു തുടങ്ങാം. അടുത്തടുത്ത രണ്ട് എണ്ണൽസംഖ്യകൾ കൂട്ടിയാൽ ഇങ്ങനെ
കിട്ടും:
1+2 = 3
2+3 = 5
3+4 = 7
4+5 = 9

അപ്പപോൾ നമുക്ക് ഇങ്ങനെ തുടങ്ങാം:
(i) x ഒരു എണ്ണൽസംഖ്യ
(ii) അടുത്ത എണ്ണൽസംഖ്യ x + 1
(iii) ഇവ രണ്ടും കൂട്ടിയാൽ കിട്ടുന്ന സംഖ്യ x + (x + 1)

അടുത്തതായി, ചെറിയ സംഖ്യയുടെ രണ്ടു മടങ്ങിനോോട് ഒന്നു കൂട്ടിയ സംഖ്യ നോോക്കാം:
(i) ചെറിയ സംഖ്യ x
(ii) അതിന്റെ രണ്ടു മടങ്ങ് 2x
(iii) അതിനോോട് 1 കൂട്ടിയത് 2x + 1

ഇനി മുകളിൽ എഴുതിയ തത്വത്തിന്റെ ബീജഗണിതരൂപം എഴുതാമല്ലലോ:
x ഏത് എണ്ണൽസംഖ്യ ആയാലും x + (x + 1) = 2x + 1

ഇതിൽ ഒരു കാര്യയം ശ്രദ്ധിച്ചചോ ? കണക്കിലെ ചുരുക്കെഴുത്ത് എന്ന പാഠത്തിൽ കണ്ട ഒരു
കാര്യയം:
x, y, z ഏതു സംഖ്യകളായാലും (x + y) + z = x + (y + z)

ഈ സമവാക്യയം തിരിച്ചു വായിച്ചാൽ
x + (y + z) = (x + y) + z

ഇതിൽ, y, z എന്നിവ ഏതെങ്കിലും സംഖ്യകളായി എടുക്കുന്നതിനു പകരം x ഉം 1 ഉം ആയി
എടുത്താലോോ ?
x + (x + 1) = (x + x) + 1
x + x = 2x ആണല്ലലോ. മുകളിലെ സമവാക്യത്തിൽ ഇത് എഴുതിയാൽ,
x + (x + 1) = 2x + 1

ഇതല്ലേ ഇപ്പപോൾ കണ്ട പൊൊതുതത്വത്തിലെ സമവാക്യയം ?
ഇങ്ങനെ നോോക്കുമ്പപോൾ, മറ്ററൊരു കാര്യയം കൂടി കാണാം: x, y, z എന്നീ മൂന്നു സംഖ്യകളുടെ
തുകയെക്കുറിച്ചുള്ള സമവാക്യയം, എണ്ണൽസംഖ്യകൾക്കു മാത്രമല്ല ഭിന്നസംഖ്യകൾക്കും ശരിയാ
ണല്ലലോ.

ബീജഗണിതം

ഇങ്ങനെ പ്രത്യയേക സ്വഭാവമുള്ള സംഖ്യകളെ പൊൊതുവായി ബീജഗണിതരൂപത്തിൽ എഴുതു
ന്നത്, അവയുടെ മറ്റു സവിശേഷതകൾ മനസ്സിലാക്കാൻ സഹായിക്കും.
ഉദാഹരണമായി, ഏതു രണ്ട് ഇരട്ടസംഖ്യകൾ തമ്മിൽ കൂട്ടിക്കിട്ടുന്നതും ഇരട്ടസംഖ്യതന്നെയാ
ണെന്ന് ഉദാഹരണങ്ങളിലൂടെ കാണാം.
ഇത് എന്തുകൊൊണ്ടാണ് എന്നു മനസ്സിലാക്കാൻ ബീജഗണിതം ഉപയോോഗിക്കാം.
അതിന് ഏതെങ്കിലും രണ്ട് ഇരട്ടസംഖ്യകൾ എടുക്കാം. നേരത്തെ കണ്ടതനുസരിച്ച്, ഇവയെ
2m, 2n എന്ന രൂപത്തിൽ എഴുതാമല്ലലോ. ഇതിൽ, m, n ഇവ പൂജ്യമോോ, ഏതെങ്കിലും എണ്ണൽ
സംഖ്യകളോോ ആകാം.
ഇവ കൂട്ടിയാലോോ ?
2m + 2n = 2(m + n)

ഇതിലെ m + n എന്ന തുകയെ p എന്ന ഒരക്ഷരംകൊൊണ്ടു സൂചിപ്പിച്ചാൽ, ആദ്യമെടുത്ത ഇരട്ട
സംഖ്യകൾ കൂട്ടിക്കിട്ടിയ സംഖ്യയെ 2p എന്നെഴുതാം; m, n ഇവ പൂജ്യമോോ എണ്ണൽസംഖ്യകളോോ
ആയതിനാൽ, അവയുടെ തുകയായ p യും അത്തരം ഒരു സംഖ്യയാണ്.
അപ്പപോൾ തുകയായ 2p യും ഇരട്ടസംഖ്യതന്നെ.
ഇനി ഏതെങ്കിലും രണ്ട് ഒറ്റസംഖ്യകൾ കൂട്ടിയാലോോ ?
എന്തുകൊൊണ്ടാണ് തുക ഇരട്ടസംഖ്യ ആകുന്നത് ?
രണ്ട് ഒറ്റസംഖ്യകൾ 2m + 1, 2n + 1 എന്നെടുക്കാം; m, n ഇവ പൂജ്യമോോ, ഏതെങ്കിലും എണ്ണൽ
സംഖ്യകളോോ ആണ്.
ഇവ കൂട്ടിയാൽ
(2m + 1) + (2n + 1) = 2m + 2n + 2
= 2(m + n + 1)

ഇതിലും m + n + 1 എന്ന സംഖ്യയെ p എന്നെഴുതിയാൽ, ഒറ്റസംഖ്യകളുടെ തുക 2p എന്ന രൂപ
ത്തിലാകും; ഇതിൽ p ഒരു എണ്ണൽസംഖ്യയാണ്.
അപ്പപോൾ തുക ഇരട്ടസംഖ്യ ആണല്ലലോ.
ഇതുപോോലെ ഒരു ഇരട്ടസംഖ്യയും ഒരു ഒറ്റസംഖ്യയും കൂട്ടിയാൽ ഒറ്റസംഖ്യ കിട്ടുന്നത് എന്തു
കൊൊണ്ടാണെന്ന് ബീജഗണിതം ഉപയോോഗിച്ചു വിശദീകരിക്കാമോോ ?
സംഖ്യകളെ 2 കൊൊണ്ടു ഹരിക്കുമ്പപോൾ കിട്ടുന്ന മിച്ചത്തിന്റെ അടിസ്ഥാനത്തിലാണ് ഇരട്ട
സംഖ്യകൾ, ഒറ്റസംഖ്യകൾ എന്ന രണ്ടു കൂട്ടങ്ങളായി പിരിച്ചത്.
