# Associativity

**One-line meaning:** Grouping three additions or multiplications does not change the result.

**Formal definition:** An operation is associative if $(a+b)+c=a+(b+c)$; for multiplication, $(ab)c=a(bc)$.

**Why it matters here:** Supports 32 Module 3 questions.

**Tiny example:** $(1+2)+3=1+(2+3)=6$.
