# Momentum Representation

**One-line meaning:** Describe a quantum state using momentum as the input variable.

**Formal definition:** $\phi(p)=\langle p|\psi\rangle$; $|\phi(p)|^2dp$ is the [[Probability|probability]] in a small momentum interval.

**Why it matters here:** Supports 6 Module 3 questions.

**Tiny example:** A narrow momentum density describes a state with nearly definite momentum.
