# Normalization

**One-line meaning:** Scaling a nonzero vector so its length is one.

**Formal definition:** For nonzero $v$, the normalized [[Vector|vector]] is $v/\|v\|$.

**Why it matters here:** Supports 29 Module 3 questions.

**Tiny example:** $(3,4)/5=(3/5,4/5)$.
