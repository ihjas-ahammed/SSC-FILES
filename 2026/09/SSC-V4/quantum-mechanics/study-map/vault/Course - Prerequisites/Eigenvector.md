# Eigenvector

**One-line meaning:** A nonzero vector whose direction stays the same under an operator.

**Formal definition:** $A|v\rangle=\lambda|v\rangle$ with $|v\rangle\ne0$ makes $|v\rangle$ an eigenvector.

**Why it matters here:** Supports 12 Module 3 questions.

**Tiny example:** For $A=\operatorname{diag}(2,3)$, $\begin{pmatrix}1\\0\end{pmatrix}$ is an eigenvector.
