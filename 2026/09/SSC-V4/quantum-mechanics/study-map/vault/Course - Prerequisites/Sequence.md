# Sequence

**One-line meaning:** An ordered list indexed by counting numbers.

**Formal definition:** A sequence is a [[Function|function]] assigning an object $v_n$ to each positive [[Integer|integer]] $n$.

**Why it matters here:** Supports 30 Module 3 questions.

**Tiny example:** $1,1/2,1/3,\ldots$ is a sequence.
