# Spectrum

**One-line meaning:** The set of values where subtracting that value times identity does not have a suitable inverse.

**Formal definition:** For a finite [[Matrix|matrix]], the spectrum is its [[Set|set]] of [[Eigenvalue|eigenvalues]]. In infinite dimensions, the spectrum includes [[Continuity|continuous]] values where the [[Inverse Matrix|inverse]] fails to be a bounded [[Linear Operator|operator]] defined on the whole [[Mathematical Space|space]]; bounded means the output [[Norm|norm]] is at most a fixed constant times the input [[Norm|norm]].

**Why it matters here:** Supports 7 Module 3 questions.

**Tiny example:** Position on the real line has continuous spectrum, not a discrete normalizable eigenbasis.
