# Function of an Operator

**One-line meaning:** A function evaluated with an operator in place of its input.

**Formal definition:** For a [[Polynomial|polynomial]], $f(A)=\sum_{n=0}^{N}c_nA^n$ with $A^0=I$. A power series requires [[Convergence|convergence]]; more general definitions need a suitable spectral construction.

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** If $f(t)=t^2+2$, then $f(A)=A^2+2I$.
