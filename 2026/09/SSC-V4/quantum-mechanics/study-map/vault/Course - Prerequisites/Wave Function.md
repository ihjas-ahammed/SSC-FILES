# Wave Function

**One-line meaning:** The coefficients of a state expressed using a continuous coordinate.

**Formal definition:** For a [[Normalization|normalized]] [[Quantum State|state]], $\psi(x)=\langle x|\psi\rangle$ and $|\psi(x)|^2$ is its position [[Probability Density|probability density]]. The [[Phase|overall phase]] does not change that density.

**Why it matters here:** Supports 18 Module 3 questions.

**Tiny example:** $\psi(x)=\sqrt a\,e^{-a|x|}$ with $a>0$ is normalized on the line.
