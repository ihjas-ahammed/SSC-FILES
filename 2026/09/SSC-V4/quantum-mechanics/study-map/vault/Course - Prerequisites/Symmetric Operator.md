# Symmetric Operator

**One-line meaning:** An operator whose action can move across an inner product on its own domain.

**Formal definition:** $\langle u|Av\rangle=\langle Au|v\rangle$ for all $u,v\in D(A)$. For [[Operator Domain|unbounded]] operators this need not imply $D(A)=D(A^\dagger)$, so it need not imply [[Self-adjoint Operator|self-adjointness]].

**Why it matters here:** Supports 10 Module 3 questions.

**Tiny example:** A derivative can satisfy the symmetry identity on a restricted domain without being self-adjoint.
