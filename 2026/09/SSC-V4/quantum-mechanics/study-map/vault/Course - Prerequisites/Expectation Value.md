# Expectation Value

**One-line meaning:** The average predicted measurement result over many identical preparations.

**Formal definition:** For a [[Normalization|normalized]] [[Quantum State|state]], $\langle A\rangle=\langle\psi|A|\psi\rangle$. For an unnormalized [[Vector|vector]] divide by $\langle\psi|\psi\rangle$.

**Why it matters here:** Supports 6 Module 3 questions.

**Tiny example:** For $A=\operatorname{diag}(2,3)$ and $\psi=\begin{pmatrix}1\\1\end{pmatrix}/\sqrt2$, $\langle A\rangle=5/2$.
