# Theta Symbol

**One-line meaning:** θ is the real angle used to describe a complex phase.

**Formal definition:** $e^{i\theta}$ is a [[Phase]] factor of [[Absolute Value]] one for [[Real Number|real]] $\theta$. An overall phase does not change [[Probability|probabilities]].

**Why it matters here:** Supports 1 Module 3 questions.

**Tiny example:** $\theta=0$ gives $e^{i\theta}=1$.
