# Kronecker Delta

**One-line meaning:** An indexed δ is 1 when the labels match and 0 when they differ.

**Formal definition:** $\delta_{mn}=1$ if the [[Integer]] labels $m=n$, and $0$ otherwise. An [[Orthonormal Basis]] satisfies $\langle e_m|e_n\rangle=\delta_{mn}$. This is distinct from the [[Delta Function]] $\delta(x-x')$.

**Why it matters here:** Supports 1 Module 3 questions.

**Tiny example:** $\delta_{22}=1$, while $\delta_{23}=0$.
