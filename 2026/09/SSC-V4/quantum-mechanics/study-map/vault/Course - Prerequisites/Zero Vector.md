# Zero Vector

**One-line meaning:** The vector that leaves another vector unchanged when added.

**Formal definition:** $v+0=v$ for every [[Vector|vector]] $v$.

**Why it matters here:** Supports 32 Module 3 questions.

**Tiny example:** In two coordinates the zero vector is $(0,0)$.
