# Operator Hat

**One-line meaning:** A hat distinguishes an operation from an ordinary number.

**Formal definition:** $\hat A$ marks a [[Linear Operator]], while an [[Eigenvalue]] such as $a$ is a [[Scalar]]. Authors sometimes omit the hat when context is clear.

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** $\hat p\psi(x)=-i\hbar\,d\psi/dx$.
