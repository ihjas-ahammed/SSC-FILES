# Operator Restriction

**One-line meaning:** Use the same operation while allowing only inputs from a chosen smaller collection.

**Formal definition:** The restriction $A|_W$ uses a [[Linear Operator]] $A$ only on inputs from an [[Invariant Subspace]] $W$. Its [[Operator Domain]] and outputs lie in $W$.

**Why it matters here:** Supports 1 Module 3 questions.

**Tiny example:** Restrict $\operatorname{diag}(2,3)$ to vectors $(x,0)$: the action is multiplication by 2.
