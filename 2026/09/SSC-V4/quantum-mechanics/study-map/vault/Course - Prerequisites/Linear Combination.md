# Linear Combination

**One-line meaning:** A sum of vectors after multiplying each by a number.

**Formal definition:** $a_1v_1+\cdots+a_nv_n$ is a linear combination with [[Scalar|scalar]] coefficients $a_i$.

**Why it matters here:** Supports 30 Module 3 questions.

**Tiny example:** $2(1,0)+3(0,1)=(2,3)$.
