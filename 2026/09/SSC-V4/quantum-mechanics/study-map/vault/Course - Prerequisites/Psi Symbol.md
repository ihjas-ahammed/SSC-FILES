# Psi Symbol

**One-line meaning:** ψ is a common name for the state being studied.

**Formal definition:** $|\psi\rangle$ labels a [[Ket]]; $\psi(x)=\langle x|\psi\rangle$ is its position [[Wave Function]]. The letter alone is a label, not an extra operation.

**Why it matters here:** Supports 16 Module 3 questions.

**Tiny example:** $\psi(x)=Ae^{-a|x|}$ is one possible function.
