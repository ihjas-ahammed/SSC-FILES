# Position Representation

**One-line meaning:** Describe a quantum state using position as the input variable.

**Formal definition:** $\psi(x)=\langle x|\psi\rangle$. For a [[Normalization|normalized]] [[Quantum State|state]], $\int|\psi(x)|^2dx=1$.

**Why it matters here:** Supports 8 Module 3 questions.

**Tiny example:** A localized packet has a density concentrated in a small position interval.
