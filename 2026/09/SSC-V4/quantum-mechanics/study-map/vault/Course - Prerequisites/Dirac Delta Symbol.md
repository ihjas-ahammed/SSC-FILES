# Dirac Delta Symbol

**One-line meaning:** δ with a continuous input picks out the value at a point when integrated.

**Formal definition:** $\delta(x-a)$ is the [[Delta Function]] notation defined by $\int\delta(x-a)f(x)\,dx=f(a)$ for suitable [[Test Function|test functions]]. It is a [[Distribution]], not an ordinary peaked function.

**Why it matters here:** Supports 1 Module 3 questions.

**Tiny example:** $\int\delta(x-2)x^2\,dx=4$.
