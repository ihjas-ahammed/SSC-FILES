# Coordinate

**One-line meaning:** A number specifying a location relative to a chosen reference.

**Formal definition:** The coordinates $(x_1,x_2)$ locate a point using two chosen directions.

**Why it matters here:** Supports 32 Module 3 questions.

**Tiny example:** $(2,3)$ is two units across and three units up.
