# Position Operator

**One-line meaning:** The operator that multiplies a position wave function by its coordinate.

**Formal definition:** $(\hat x\psi)(x)=x\psi(x)$ on the domain with $x\psi\in L^2$.

**Why it matters here:** Supports 3 Module 3 questions.

**Tiny example:** Applied to $e^{-x^2}$ it gives $xe^{-x^2}$.
