# Limit

**One-line meaning:** A value that a sequence approaches arbitrarily closely.

**Formal definition:** $x_n\to L$ means for every real $\epsilon>0$, some [[Integer|integer]] $N$ has $|x_n-L|<\epsilon$ for all $n>N$.

**Why it matters here:** Supports 30 Module 3 questions.

**Tiny example:** $1/n\to0$.
