# Derivative

**One-line meaning:** The rate at which a function changes.

**Formal definition:** The derivative $df/dx$ measures local change of the output with input $x$.

**Why it matters here:** Supports 29 Module 3 questions.

**Tiny example:** $d(x^2)/dx=2x$.
