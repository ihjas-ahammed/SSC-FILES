# Axiom

**One-line meaning:** A starting rule accepted in a mathematical definition.

**Formal definition:** An axiom states a rule assumed for the objects under discussion; other conclusions follow from those rules.

**Why it matters here:** Supports 32 Module 3 questions.

**Tiny example:** One rule for addition is $u+v=v+u$.
