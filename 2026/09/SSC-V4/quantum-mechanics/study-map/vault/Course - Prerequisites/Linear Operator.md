# Linear Operator

**One-line meaning:** A rule taking vectors to vectors while respecting addition and scaling.

**Formal definition:** $A(a|u\rangle+b|v\rangle)=aA|u\rangle+bA|v\rangle$. The input [[Vector|vectors]] must belong to the [[Operator Domain|operator domain]].

**Why it matters here:** Supports 25 Module 3 questions.

**Tiny example:** $A(x,y)=(2x,3y)$ is linear. $A(x)=x^2$ is not linear over real numbers.
