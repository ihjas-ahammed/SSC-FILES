# Delta Function

**One-line meaning:** An idealized point selector inside an integral.

**Formal definition:** The Dirac delta is a [[Distribution|distribution]] defined by $\int\delta(x-a)f(x)dx=f(a)$ for suitable [[Test Function|smooth test functions]]. It is not an ordinary finite-valued [[Function|function]].

**Why it matters here:** Supports 9 Module 3 questions.

**Tiny example:** $\int\delta(x-2)(x+1)dx=3$.
