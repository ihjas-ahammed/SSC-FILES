# Delta Symbol

**One-line meaning:** A capital Δ beside an observable means its spread in a specified state.

**Formal definition:** In an [[Uncertainty Relation]], $\Delta A=\sqrt{\langle A^2\rangle-\langle A\rangle^2}$ is a [[Standard Deviation]], not an [[Eigenvalue]].

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** If every result is 3, $\Delta A=0$.
