# Matrix

**One-line meaning:** A rectangular array of numbers.

**Formal definition:** A matrix $A$ has entries $A_{ij}$, with row $i$ and column $j$. Products satisfy $(AB)_{ij}=\sum_k A_{ik}B_{kj}$.

**Why it matters here:** Supports 15 Module 3 questions.

**Tiny example:** $\begin{pmatrix}2&0\\0&3\end{pmatrix}\begin{pmatrix}a\\b\end{pmatrix}=\begin{pmatrix}2a\\3b\end{pmatrix}$.
