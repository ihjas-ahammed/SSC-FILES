# Exponential Function

**One-line meaning:** A function whose rate of change equals itself.

**Formal definition:** $d(e^x)/dx=e^x$, $e^{a+b}=e^ae^b$, and $e^{i\theta}=\cos\theta+i\sin\theta$.

**Why it matters here:** Supports 29 Module 3 questions.

**Tiny example:** $|e^{i\theta}|=1$ for real $\theta$.
