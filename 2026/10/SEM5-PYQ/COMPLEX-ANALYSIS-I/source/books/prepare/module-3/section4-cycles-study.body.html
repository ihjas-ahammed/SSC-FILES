Before you start

  • The group axioms (Module 1, Definition 2.1) and the notion of isomorphism (Section 2).
  • Functions: composition, one-to-one and onto maps, and inverse functions. A permutation of a set $A$ is a one-to-one function from $A$ onto $A$; the product of two permutations is their composition.
  • Two-row notation for a permutation: the top row lists the elements of $A$ and the bottom row lists where each one goes. The examples below use it. The book introduces it in Section 4 (printed pages 39–42), which is not reproduced here.

1. Permutations form a group

Theorem 4.8 Let $A$ be a nonempty set, and let $S_A$ be the collection of all permutations of $A$. Then $S_A$ is a group under permutation multiplication.

Why. Composing two permutations gives a permutation, so $S_A$ is closed. Permutation multiplication is function composition, which is associative. The identity map $\iota$ with $\iota(a) = a$ is the identity. A permutation $\sigma$ is one-to-one and onto, so it has an inverse function $\sigma^{-1}$, which is again a permutation, and $\sigma^{-1}\sigma = \sigma\sigma^{-1} = \iota$. ◆

Warning. Some texts multiply permutations from left to right, so that $(\sigma\mu)(a) = \mu(\sigma(a))$. Their product $\sigma\mu$ is the one we get by computing $\mu\sigma$. Check the order used in any other text. Exercise 34 asks you to check that both orders still give a group. Its text is printed directly below.

Exercise 34. (See the warning following Theorem 4.8.) Let $G$ be a group with binary operation $\ast$. Let $G'$ be the same set as $G$, and define a binary operation $\ast'$ on $G'$ by $x \ast' y = y \ast x$ for all $x, y \in G'$.

a. (Intuitive argument that $G'$ under $\ast'$ is a group.) Suppose the front wall of your classroom were made of transparent glass, and that all possible products $a \ast b = c$ and all possible instances $a \ast (b \ast c) = (a \ast b) \ast c$ of the associative property for $G$ under $\ast$ were written on the wall with a magic marker. What would a person see when looking at the other side of the wall from the next room in front of yours?
b. Show from the mathematical definition of $\ast'$ that $G'$ is a group under $\ast'$.

The structure of $S_A$ depends only on how many elements $A$ has. If $A$ and $B$ have the same number of elements, then $S_A \simeq S_B$. To see this, take a one-to-one map $f$ of $A$ onto $B$. For a permutation $\sigma$ of $A$, define $\bar\sigma$ on $B$ by $\bar\sigma(f(a)) = f(\sigma(a))$. Then $\sigma \mapsto \bar\sigma$ is an isomorphism. Renaming the elements of $A$ by elements of $B$ in two-row notation is exactly this map. So $\{1, 2, \dots, n\}$ can stand for any finite set of $n$ elements.

Example in the book: with $A = \{1, 2, 3\}$, $B = \{\#, \$, \%\}$, $f(1) = \#$, $f(2) = \$$, $f(3) = \%$, the permutation $\begin{pmatrix}1&2&3\\3&2&1\end{pmatrix}$ of $A$ becomes $\begin{pmatrix}\#&\$&\%\\\%&\$&\#\end{pmatrix}$ of $B$.

Definition 4.9 Let $A = \{1, 2, \dots, n\}$. The group of all permutations of $A$ is the symmetric group on $n$ letters, written $S_n$.

$S_n$ has $n!$ elements, where $n! = n(n-1)(n-2)\cdots(3)(2)(1)$.

$S_3$ is not abelian. Take $\sigma = \begin{pmatrix}1&2&3\\2&1&3\end{pmatrix}$ and $\tau = \begin{pmatrix}1&2&3\\1&3&2\end{pmatrix}$. Then $\sigma\tau(1) = \sigma(1) = 2$, but $\tau\sigma(1) = \tau(2) = 3$. Groups with at most four elements are abelian, and the abelian group $\mathbb{Z}_5$ is the only group of order $5$ up to isomorphism. So $S_3$ is the smallest group that is not abelian.

Example 4.10. To invert a permutation, swap the top and bottom rows and sort the columns so the top row is in order. For $\sigma = \begin{pmatrix}1&2&3&4&5&6\\3&2&6&1&4&5\end{pmatrix}$:

2. Disjoint cycle notation

Two-row notation lists every number twice. Disjoint cycle notation lists each number once. Take $\sigma = \begin{pmatrix}1&2&3&4&5&6\\3&4&6&2&5&1\end{pmatrix}$. Start with $1$. Since $\sigma(1) = 3$, write $(1, 3$. Since $\sigma(3) = 6$, write $(1, 3, 6$. Since $\sigma(6) = 1$, close the cycle: $(1, 3, 6)$. This is a cycle, and a cycle with $k$ entries is a $k$-cycle. Next, $\sigma(2) = 4$ and $\sigma(4) = 2$, so $(2, 4)$ is a $2$-cycle. The number $5$ is fixed, and 1-cycles are usually left out. So

$$\sigma = (1, 3, 6)(2, 4).$$

A $2$-cycle is also called a transposition. Cycles are disjoint if no entry is in more than one cycle. Disjoint cycles can be written in any order, and each cycle can start at any of its entries, as long as the cyclic order is kept. Every permutation of $S_n$ can be written in disjoint cycle form, and that form is unique up to these choices.

Example 4.11. In $S_9$, $\sigma = (1, 5, 2, 7)(3, 4, 9)$. Reading off the cycles: $\sigma(1) = 5$, $\sigma(5) = 2$, $\sigma(2) = 7$, $\sigma(7) = 1$, $\sigma(3) = 4$, $\sigma(4) = 9$, $\sigma(9) = 3$. Since $6$ and $8$ are not in any cycle, $\sigma(6) = 6$ and $\sigma(8) = 8$. So

$$\sigma = \begin{pmatrix}1&2&3&4&5&6&7&8&9\\5&7&4&9&2&6&1&8&3\end{pmatrix}.$$

Since the operation in $S_n$ is composition, the cycles on the right are applied first. Multiplying in disjoint cycle form is the usual way to work with permutations.

Example 4.12. In $S_6$ let $\sigma = (1, 5, 3, 2, 6)$ and $\tau = (1, 2, 4, 3, 6)$. We find $\sigma\tau$ without two-row notation. Start with $1$: $\tau$ sends $1$ to $2$, and then $\sigma$ sends $2$ to $6$, so $\sigma\tau(1) = 6$. Begin the cycle $(1, 6$. Next $\tau(6) = 1$ and $\sigma(1) = 5$, so the cycle is $(1, 6, 5$. Since $\tau(5) = 5$ and $\sigma(5) = 3$, $\sigma\tau(5) = 3$; the cycle is $(1, 6, 5, 3$. Then $3$ maps to $1$, so the first cycle is $(1, 6, 5, 3)$. The number $2$ has not been placed. Since $\sigma\tau(2) = 4$ and $\sigma\tau(4) = 2$, the second cycle is $(2, 4)$. So

$$\sigma\tau = (1, 5, 3, 2, 6)(1, 2, 4, 3, 6) = (1, 6, 5, 3)(2, 4).$$

Move from right to left between the cycles, and from left to right inside each cycle.

Example 4.13. Compute $\sigma = (1, 5)(2, 4)(1, 4, 3)(2, 5)(4, 2, 1)$ in disjoint cycle form. The first cycle on the right sends $1$ to $4$; then $(2, 5)$ does not move $4$, $(1, 4, 3)$ sends $4$ to $3$, $(2, 4)$ does not move $3$, and $(1, 5)$ does not move $3$. So $\sigma(1) = 3$. Continuing gives $\sigma = (1, 3, 5, 4)(2) = (1, 3, 5, 4)$. The group was never named. The same calculation works in $S_5$, $S_6$, or $S_n$ for any $n \ge 5$.

Example 4.14. Take $\sigma = (1, 5, 7)(3, 8, 2, 4, 6)$. Since $(ab)^{-1} = b^{-1}a^{-1}$, we get $\sigma^{-1} = (3, 8, 2, 4, 6)^{-1}(1, 5, 7)^{-1}$. The inverse of a cycle is the same cycle written backward, so $\sigma^{-1} = (6, 4, 2, 8, 3)(7, 5, 1)$. Because disjoint cycles commute and each can start at any entry, this can also be written $\sigma^{-1} = (1, 7, 5)(2, 8, 3, 6, 4)$.
