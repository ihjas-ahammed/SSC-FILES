9.1.3 Reflection and transmission on a string

Source: book-sources/m3-sec2-bc.html, Griffiths pp. 396–399. Equations 9.21–9.33 in full. This section is background (beyond the syllabus list, which takes items 9–14 from §9.1.1, §9.1.2 and §9.1.4). Problems 9.5–9.7 are not worked.

Before you start

  • Sinusoidal waves and complex amplitudes (Section 9.1.2).
  • Continuity of a function and of its slope at a point (Beyond in Plus Two; pre-math M7).

1. Why the boundary matters

So far the string has been infinitely long. What a wave does at a join depends on how the string is attached. Tie two strings with the same tension $T$ but different mass per unit length $\mu_1$ and $\mu_2$. Then the speeds $v_1=\sqrt{T/\mu_1}$ and $v_2=\sqrt{T/\mu_2}$ are different. Put the knot at $z=0$.

2. The three waves

A sinusoidal wave of frequency $\omega$ comes in from the left on string 1. It gives a reflected wave going back along string 1, and a transmitted wave going on along string 2:

$$\tilde f_I=\tilde A_Ie^{i(k_1z-\omega t)}\quad(z<0)\tag{9.21}$$
$$\tilde f_R=\tilde A_Re^{i(-k_1z-\omega t)}\quad(z<0)\tag{9.22}$$
$$\tilde f_T=\tilde A_Te^{i(k_2z-\omega t)}\quad(z>0)\tag{9.23}$$

The reflected wave has $-k_1$ because it travels to the left. All three have the same $\omega$, which is set by the source. Because the speeds differ, the wave numbers differ:

$$\frac{\lambda_1}{\lambda_2}=\frac{k_2}{k_1}=\frac{v_1}{v_2}\tag{9.24}$$
{{FIG:m3-sec2-pulse}}

A single sinusoid is an idealisation: a finite pulse is made of sinusoids of many frequencies (Eq. 9.20). The book uses sinusoids of infinite extent because only then is there a single frequency.

For $z<0$ the total displacement is $\tilde f_I+\tilde f_R$, and for $z>0$ it is $\tilde f_T$:

$$\tilde f(z,t)=\begin{cases}\tilde A_Ie^{i(k_1z-\omega t)}+\tilde A_Re^{i(-k_1z-\omega t)}, & z<0\\ \tilde A_Te^{i(k_2z-\omega t)}, & z>0\end{cases}\tag{9.25}$$

3. Boundary conditions

There must be no break in the string at the knot, so the displacement is continuous:

$$f(0^-,t)=f(0^+,t)\tag{9.26}$$

If the knot has negligible mass, a net force on it would give it an infinite acceleration. So the slope is continuous too (Fig. 9.6):

$$\left.\frac{\partial f}{\partial z}\right|_{0^-}=\left.\frac{\partial f}{\partial z}\right|_{0^+}\tag{9.27}$$

Because the imaginary part of $\tilde f$ differs from the real part only in cosine replaced by sine, the complex function obeys the same rules:

$$\tilde f(0^-,t)=\tilde f(0^+,t),\qquad\left.\frac{\partial\tilde f}{\partial z}\right|_{0^-}=\left.\frac{\partial\tilde f}{\partial z}\right|_{0^+}\tag{9.28}$$

4. Solving for the amplitudes

Apply Eq. 9.28 to Eq. 9.25. Continuity of $\tilde f$ gives $\tilde A_I+\tilde A_R=\tilde A_T$. Continuity of the slope gives $ik_1(\tilde A_I-\tilde A_R)=ik_2\tilde A_T$, so $k_1(\tilde A_I-\tilde A_R)=k_2\tilde A_T$. Solving the two:

$$\tilde A_R=\frac{k_1-k_2}{k_1+k_2}\tilde A_I,\qquad\tilde A_T=\frac{2k_1}{k_1+k_2}\tilde A_I\tag{9.29}$$

Using $k\propto1/v$ (Eq. 9.24) gives the same result in terms of speeds:

$$\tilde A_R=\frac{v_2-v_1}{v_2+v_1}\tilde A_I,\qquad\tilde A_T=\frac{2v_2}{v_2+v_1}\tilde A_I\tag{9.30}$$

Real amplitudes and phases:

$$A_Re^{i\delta_R}=\frac{v_2-v_1}{v_2+v_1}A_Ie^{i\delta_I},\qquad A_Te^{i\delta_T}=\frac{2v_2}{v_2+v_1}A_Ie^{i\delta_I}\tag{9.31}$$

If the second string is lighter ($v_2>v_1$), all three waves are in phase, and

$$A_R=\frac{v_2-v_1}{v_2+v_1}A_I,\qquad A_T=\frac{2v_2}{v_2+v_1}A_I\tag{9.32}$$

If the second string is heavier ($v_2

$$A_R=\frac{v_1-v_2}{v_2+v_1}A_I,\qquad A_T=\frac{2v_2}{v_2+v_1}A_I\tag{9.33}$$

In the limit where the second string is fixed to an immovable post, the transmitted amplitude is zero and the reflected amplitude equals the incident one: all of the wave comes back.
