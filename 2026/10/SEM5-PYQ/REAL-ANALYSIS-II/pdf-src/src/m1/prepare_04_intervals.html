UNITS 2–3 · BARTLE §5.3

Continuous functions on intervals

T8

Bounded functions; the Boundedness Theorem

The most-asked theorem of the module (PYQ MTS-26 Q16, MAT-22 Q27, MAT-21 Q13, MTS-22 Q2).

Definition 5.3.1 · say it word for wordA function $f : A \to \mathbb R$ is said to be bounded on A if there exists a constant $M>0$ such that $|f(x)| \le M$ for all $x \in A$. Not bounded: for every $M>0$ there is $x_M \in A$ with $|f(x_M)| > M$.
{{fig:unbounded}}
Theorem 5.3.2 · Boundedness TheoremLet $I := [a,b]$ be a closed bounded interval and let $f : I \to \mathbb R$ be continuous on I. Then f is bounded on I.
Knowf continuous at every point of [a, b].Wantsome M with $|f(x)| \le M$ for all x in [a, b].
Proof (by contradiction, pattern M5)
Suppose f is not bounded on I. Then for each $n \in \mathbb N$ there is $x_n \in I$ with $|f(x_n)| > n$.Negation of bounded (M3), with M = n.
I is bounded, so $(x_n)$ is bounded; by Bolzano–Weierstrass a subsequence $(x_{n_r})$ converges to some x."Bounded" is used here (P7).
$a \le x_{n_r} \le b$, so $a \le x \le b$: $x \in I$."Closed" is used here (order theorem 3.2.6).
f is continuous at x, so $f(x_{n_r}) \to f(x)$; a convergent sequence is bounded."Continuous" is used here (T3, P6).
But $|f(x_{n_r})| > n_r \ge r$ for all r, so $(f(x_{n_r}))$ is unbounded. Contradiction. ∎$n_1 < n_2 < \cdots$ gives $n_r \ge r$.
Hypotheses checklist (what fails without each)
  • interval bounded$f(x) = x$ on $[0,\infty)$: continuous, unbounded
  • interval closed$g(x) = 1/x$ on $(0,1]$: continuous, unbounded C2
  • f continuous$h(x) = 1/x$ on (0, 1], $h(0) = 1$: on [0, 1], unbounded N2

In the model paper: Q9 (PYQ MTS-26 Q2), Q10, Q26 (PYQ MTS-26 Q16).

T9

The Maximum–Minimum Theorem

A 10–13 mark question (PYQ MAT-22 Q36a, MAT-21 Q14).

Definition 5.3.3 · absolute max and minf has an absolute maximum on A if there is a point $x^* \in A$ such that $f(x^*) \ge f(x)$ for all $x \in A$, and an absolute minimum if there is $x_* \in A$ with $f(x_*) \le f(x)$ for all $x \in A$.
Theorem 5.3.4 · Maximum–Minimum TheoremLet $I := [a,b]$ be a closed bounded interval and let $f : I \to \mathbb R$ be continuous on I. Then f has an absolute maximum and an absolute minimum on I.
{{fig:maxmin}}
Proof (maximum; Bartle)
$f(I)$ is non-empty and bounded (Theorem 5.3.2), so $s^* := \sup f(I)$ exists.Completeness (P5).
For each n, $s^* - \frac1n$ is not an upper bound, so there is $x_n \in I$ with $s^* - \frac1n < f(x_n) \le s^*$.Property of sup (P5).
By Bolzano–Weierstrass, a subsequence $x_{n_r} \to x^*$, and $x^* \in I$.I bounded (BW), I closed (3.2.6).
f is continuous at $x^*$, so $f(x_{n_r}) \to f(x^*)$.Sequential criterion (T3).
Also $s^* - \frac1{n_r} < f(x_{n_r}) \le s^*$, so $f(x_{n_r}) \to s^*$.Squeeze (P6).
Limits are unique: $f(x^*) = s^* \ge f(x)$ for all $x \in I$. So $x^*$ is an absolute maximum point.$s^*$ is an upper bound of f(I).
Minimum: apply steps 1–6 to $-f$ (or use inf). ∎A maximum of −f is a minimum of f.
Hypotheses checklist
  • closed$f(x) = x$ on (0, 1): sup 1, inf 0, neither reached
  • bounded$x$ on $[0,\infty)$: no maximum
  • continuous$h(x) = x$ ($0 \le x < 1$), $h(1) = 0$: sup 1 never reached

T10

Location of Roots (bisection)

A 10-mark question (PYQ MTS-25 Q24, MAT-21 Q17).

Theorem 5.3.5 · Location of Roots TheoremLet $I = [a,b]$ and let $f : I \to \mathbb R$ be continuous on I. If $f(a) < 0 < f(b)$, or if $f(a) > 0 > f(b)$, then there exists a number $c \in (a,b)$ such that $f(c) = 0$.
{{fig:bisection}}
Proof (case f(a) < 0 < f(b))
$I_1 = [a,b]$, midpoint $p_1$. If $f(p_1) = 0$, take $c = p_1$. If $f(p_1) > 0$ let $I_2 = [a, p_1]$; if $f(p_1)<0$ let $I_2 = [p_1, b]$.Keep a sign change: $f(a_2) < 0 < f(b_2)$ (M7).
Repeat. Either some $f(p_n) = 0$, or we get nested $I_n = [a_n, b_n]$ with $f(a_n) < 0 < f(b_n)$ and $b_n - a_n = \dfrac{b-a}{2^{n-1}}$.Each step halves the length.
By the Nested Intervals Property some c lies in every $I_n$; since $b_n - a_n \to 0$, $a_n \to c$ and $b_n \to c$.P10; $|a_n - c| \le b_n - a_n$.
f is continuous at c, so $f(a_n) \to f(c)$ and $f(b_n) \to f(c)$.Sequential criterion.
$f(a_n) < 0$ gives $f(c) \le 0$; $f(b_n) > 0$ gives $f(c) \ge 0$. So $f(c) = 0$.Order theorem: "<" becomes "≤" in the limit.
$c \ne a, b$ since $f(a) \ne 0 \ne f(b)$, so $c \in (a,b)$. Case $f(a) > 0 > f(b)$: apply this to $-f$. ∎−f changes sign the other way.
Exam trap"$f(a_n) < 0$ so $f(c) < 0$" is wrong: limits of negative numbers can be 0. Always weaken to ≤.

Using it (most common short question)

Skeleton · "show the equation has a root in (a, b)"Let $f(x) = $ ?. f is continuous on [a, b] (polynomial / exponential …). $f(a) = $ ? $< 0$ and $f(b) = $ ? $> 0$. By the Location of Roots Theorem there is $c \in (a, b)$ with $f(c) = 0$. ∎
Worked examples

$xe^x - 2 = 0$ on (0, 1): $f(0) = -2 < 0 < e - 2 \approx 0.718 = f(1)$. Root in (0, 1) (it is ≈ 0.8526). (PYQ MAT-21 Q17)

$6x^3 - 3x^2 + 2$: $f(-1) = -7 < 0 < 2 = f(0)$, so a zero in (−1, 0) ⊂ (−1, 1). (Old MCQ: answer "a zero in (−1, 1)".)

$x = \cos x$: $g(x) = x - \cos x$, $g(0) = -1$, $g(\pi/2) = \pi/2$: root ≈ 0.7391.

In the model paper: Q12 (PYQ MAT-21 Q17, MAT-22 MCQ 12), Q37 (PYQ MTS-25 Q24).

T11

Bolzano's Intermediate Value Theorem

Every value between two values is taken (PYQ MAT-21 Q1, MAT-22 Q13).

Theorem 5.3.7 · Bolzano's Intermediate Value TheoremLet I be an interval and let $f : I \to \mathbb R$ be continuous on I. If $a, b \in I$ and if $k \in \mathbb R$ satisfies $f(a) < k < f(b)$, then there exists a point $c \in I$ between a and b such that $f(c) = k$.
{{fig:ivt}}
ProofIf $a < b$, let $g(x) = f(x) - k$: g is continuous and $g(a) < 0 < g(b)$, so by 5.3.5 some $c \in (a,b)$ has $g(c) = 0$, i.e. $f(c) = k$. If $b < a$, use $h(x) = k - f(x)$ on [b, a]. ∎
Corollary 5.3.8Let $I = [a,b]$ be a closed bounded interval and let $f : I \to \mathbb R$ be continuous on I. If $k \in \mathbb R$ is any number satisfying $\inf f(I) \le k \le \sup f(I)$, then there exists a number $c \in I$ such that $f(c) = k$.
ProofBy Max–Min there are $c_*, c^* \in I$ with $f(c_*) = \inf f(I)$ and $f(c^*) = \sup f(I)$. If k equals one of these, done. Otherwise $f(c_*) < k < f(c^*)$ and Bolzano (on the interval between $c_*$ and $c^*$) gives c with $f(c) = k$. ∎
Hypotheses checklist
  • f continuousa jump skips values N1
  • on an interval$1/x$ on $\mathbb R \setminus \{0\}$ takes −1 and 1 but never 0
{{fig:ivt_fail}}
Exam trap · the converse is false"Takes every intermediate value ⇒ continuous" is false: $\sin(1/x)$ with value 0 at 0 takes every value between any two of its values on [0, 1], yet is discontinuous at 0.

In the model paper: Q13 (PYQ MAT-21 Q1), Q27 (PYQ MAT-22 Q13).

T12

Images of intervals

5.3.9 and Preservation of Intervals (PYQ MAT-21 Q15, MTS-25 Q17, MAT-22 Q14).

Theorem 5.3.9Let I be a closed bounded interval and let $f : I \to \mathbb R$ be continuous on I. Then the set $f(I) := \{f(x) : x \in I\}$ is a closed bounded interval.
ProofLet $m = \inf f(I)$, $M = \sup f(I)$. By Max–Min both are values of f, so $f(I) \subseteq [m, M]$ and m, M ∈ f(I). By Corollary 5.3.8 every $k \in [m, M]$ is a value: $[m, M] \subseteq f(I)$. Hence $f(I) = [m, M]$. ∎
Exam trap$f([a,b])$ is $[m, M]$, not $[f(a), f(b)]$. For $x^3 - 3x$ on [−1.5, 1.5]: $[f(b), f(a)] = [-1.125, 1.125]$ but $f(I) = [-2, 2]$.
Theorem 5.3.10 · Preservation of IntervalsLet I be an interval and let $f : I \to \mathbb R$ be continuous on I. Then the set f(I) is an interval.
Proof
Let $\alpha < \beta$ be in f(I): $\alpha = f(a)$, $\beta = f(b)$ for some $a, b \in I$.Meaning of image.
If $\alpha < k < \beta$, Bolzano gives $c \in I$ between a and b with $f(c) = k$, so $k \in f(I)$.T11; c ∈ I because I is an interval.
So $[\alpha, \beta] \subseteq f(I)$ whenever $\alpha < \beta$ are in f(I). By the characterisation of intervals (2.5.1), f(I) is an interval. ∎P10. (If f is constant, f(I) is a single point, a degenerate interval.)
