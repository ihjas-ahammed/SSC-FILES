P1

Sets, intervals and functions

The language of every statement in this module.

Remind me · Plus One Ch 1–2
  • Intervals: $[a,b]$ closed (ends included), $(a,b)$ open, $[a,\infty)$ unbounded. "Closed bounded interval" means exactly $[a,b]$ with $a \le b$ real numbers.
  • A function $f : A \to \mathbb R$ gives one value $f(x)$ for each x in the domain A. The image of a set B is $f(B) = \{f(x) : x \in B\}$.
  • Piecewise functions, the greatest integer $[x]$ (largest integer ≤ x) and signum: $\operatorname{sgn} x = 1, 0, -1$ for $x>0$, $x = 0$, $x<0$.
Check yourself
Find $f([-1,2])$ for $f(x) = x^2$.
Values run from 0 (at x = 0) to 4 (at x = 2): $f([-1,2]) = [0, 4]$. Not $[f(-1), f(2)] = [1, 4]$.
P2

Modulus (absolute value)

|x − c| is the distance between x and c.

Remind me · Plus One
  • $|x| = x$ if $x \ge 0$, $-x$ if $x<0$. $|ab| = |a||b|$.
  • $|x - c| < \delta \iff c - \delta < x < c + \delta$: "x is within δ of c".
  • Triangle inequality: $|a + b| \le |a| + |b|$; and $\big||a| - |b|\big| \le |a - b|$.

P3

Limits and continuity in Plus Two

What you already know, now made exact.

Remind me · Plus Two Ch 5
  • f is continuous at c if $\lim_{x\to c} f(x) = f(c)$: left limit = right limit = value.
  • Polynomials, $\sin$, $\cos$, $e^x$ are continuous everywhere; $1/x$ is continuous wherever it is defined.
  • Sums, products and quotients (non-zero denominator) of continuous functions are continuous.
What changes nowIn Plus Two "limit" was a feeling ("gets close to"). Here we say exactly how close: given any ε, there is a δ. That precision lets us prove things like "a continuous function on [a, b] has a maximum".
P4

Rationals, irrationals and Archimedes

Needed for Dirichlet and Thomae functions (T6).

Remind me · Real Analysis I, Bartle 2.4
  • Archimedean property: for every $\varepsilon>0$ there is $n \in \mathbb N$ with $1/n < \varepsilon$.
  • Density (2.4.8, 2.4.9): between any two real numbers there is a rational and an irrational. So every real number is the limit of a sequence of rationals and of a sequence of irrationals.
  • Examples: $c + \sqrt2/n$ is irrational when c is rational, and $\to c$. Decimal truncations 1.4, 1.41, 1.414, … are rationals $\to \sqrt2$.
P5

Supremum and infimum

The maximum of f is found as a supremum (T9).

Remind me · Bartle 2.3
  • $\sup S$ is the least upper bound. Completeness: every non-empty set bounded above has a supremum in ℝ.
  • If $s^* = \sup S$ then for each n, $s^* - \frac1n$ is not an upper bound, so some $s_n \in S$ has $s^* - \frac1n < s_n \le s^*$.
  • A supremum need not belong to S: $\sup(0,1) = 1 \notin (0,1)$.
P6

Sequences and their limit theorems

Most proofs in §5.3 are sequence arguments.

Remind me · Bartle 3.1–3.2
  • $x_n \to c$: for every $\varepsilon>0$ there is K with $|x_n - c| < \varepsilon$ for $n \ge K$.
  • A convergent sequence is bounded (3.2.2).
  • Limits of sums and products (3.2.3): $x_n \to x$, $y_n \to y$ ⇒ $x_n + y_n \to x + y$, $x_ny_n \to xy$.
  • Order (3.2.6): if $a \le x_n \le b$ for all n then $a \le \lim x_n \le b$. Strict "<" may become "≤" in the limit.
  • Squeeze (3.2.7): $y_n \le x_n \le z_n$ and $y_n, z_n \to L$ ⇒ $x_n \to L$.
P7

Subsequences and Bolzano–Weierstrass

The engine of the Boundedness, Max–Min and Uniform Continuity Theorems.

Remind me · Bartle 3.4.8

Bolzano–Weierstrass: every bounded sequence of real numbers has a convergent subsequence.

A subsequence $(x_{n_r})$ uses indices $n_1 < n_2 < \cdots$, so $n_r \ge r$.

Why it matters hereIf all $x_n$ lie in [a, b], BW gives a subsequence converging to some x, and by the order theorem x is still in [a, b]. "Bounded" gives the subsequence; "closed" keeps its limit inside. That is why those two words appear in every big theorem of §5.3.
P8

Cauchy sequences

Used in T19 and T20.

Remind me · Bartle 3.5

$(x_n)$ is Cauchy if for every $\varepsilon>0$ there is H with $|x_n - x_m| < \varepsilon$ for all $m, n \ge H$. In ℝ: convergent ⇔ Cauchy (3.5.3, 3.5.5).

P9

Limits of functions

Continuity is "limit = value", so we need limits.

Remind me · Bartle 4.1
  • c is a cluster point of A if every interval round c contains points of A other than c.
  • $\lim_{x\to c} f(x) = L$: for every ε there is δ with $|f(x) - L| < \varepsilon$ when $x \in A$, $0 < |x - c| < \delta$.
  • Sequential criterion for limits (4.1.8): $\lim_{x\to c} f = L$ iff $f(x_n) \to L$ for every sequence $x_n \to c$ with $x_n \ne c$.
P10

Nested intervals and what an interval is

Used in the bisection proof (T10) and Preservation of Intervals (T12).

Remind me · Bartle 2.5
  • Nested Intervals Property (2.5.2): if $I_1 \supseteq I_2 \supseteq \cdots$ are closed bounded intervals, some point c lies in all of them. If their lengths → 0, there is exactly one such c.
  • Characterisation (2.5.1): a set S with at least two points is an interval iff whenever $x < y$ are in S, everything between them is in S.
M1

Inequality gym

The six moves inside every ε–δ proof. Practise until automatic.

Maths tool
  1. Factor: $x^2 - c^2 = (x - c)(x + c)$; $\frac1x - \frac1c = \frac{c - x}{xc}$; $\sqrt x - \sqrt c = \frac{x - c}{\sqrt x + \sqrt c}$.
  2. Bound the other factor by first restricting $|x - c| < 1$: then $|x + c| \le |x - c| + 2|c| < 1 + 2|c|$.
  3. Keep away from 0: if $|x - c| < c/2$ (with $c>0$) then $x > c/2$, so $\frac1x < \frac2c$.
  4. Take the smaller: if you need both $|x - c| < 1$ and $|x - c| < \varepsilon/5$, use $\delta = \min\{1, \varepsilon/5\}$.
  5. Reverse triangle: $\big||x| - |c|\big| \le |x - c|$.
  6. AM–GM: $1 + x^2 \ge 2|x|$, so $\frac{|x|}{1+x^2} \le \frac12$.
Check yourself
If $|x - 3| < 1$, find a bound for $|x + 3|$.
$2 < x < 4$, so $5 < x + 3 < 7$: $|x + 3| < 7$ (= 1 + 2·3).

Negating a statement

"Not continuous", "not uniformly continuous", "not bounded": write each exactly.

Maths tool · flip each word

"for every" ↔ "there is", and the last inequality flips.

Not continuous at cthere is $\varepsilon_0>0$ such that for every δ > 0 some $x \in A$ has $|x - c| < \delta$ but $|f(x) - f(c)| \ge \varepsilon_0$. Not uniformly continuousthere is $\varepsilon_0>0$ such that for every δ some $x, u \in A$ have $|x - u| < \delta$ but $|f(x) - f(u)| \ge \varepsilon_0$. Unboundedfor every $M>0$ some $x_M \in A$ has $|f(x_M)| > M$.
M4

Scratch work, then proof

How to find δ, and how to write the answer.

Scratch · run backwards

Want $|f(x) - f(c)| < \varepsilon$. Factor out $|x - c|$. Bound the rest by a number B (restrict δ ≤ 1 if needed). Then $B|x - c| < \varepsilon \Leftarrow |x - c| < \varepsilon/B$.

Proof · run forwards

Let $\varepsilon>0$. Choose $\delta = \min\{1, \varepsilon/B\}$. Let $x \in A$ with $|x - c| < \delta$. Then … $\le B|x - c| < B\cdot\frac{\varepsilon}{B} = \varepsilon$. ∎

Exam trapNever write a δ containing x (like $\delta = \varepsilon/|x + c|$). δ must be chosen before x is picked. Circle every symbol in your δ: only ε, c and numbers are allowed.
M5

Contradiction, and "one point for each n"

The pattern of the three big proofs in §5.3–5.4.

Maths tool · the pattern
  1. Assume the opposite (e.g. "f is not bounded").
  2. Use the negation with M = n or δ = 1/n to get one point $x_n$ for each $n \in \mathbb N$.
  3. Bolzano–Weierstrass (P7) gives a subsequence converging to some z in [a, b].
  4. Continuity at z (sequential form) gives $f(x_{n_r}) \to f(z)$.
  5. This contradicts step 2. So the assumption was false.

Choosing sequences to break things

One bad sequence disproves continuity; one bad pair disproves uniform continuity.

Maths tool
not continuous at cone $x_n \to c$ with $f(x_n) \not\to f(c)$ (or two sequences giving different limits) not uniformly continuoustwo sequences $x_n, u_n$ with $x_n - u_n \to 0$ but $|f(x_n) - f(u_n)| \ge \varepsilon_0$

Where to look: near a jump, near an open end where f blows up or wiggles, or far out where f gets steep.

M7

Bisection

Halve, keep the half with the sign change, repeat.

Maths tool

Start with $I_1 = [a,b]$ where f changes sign. Look at the midpoint p. If f(p) = 0, done. Otherwise keep the half where the sign still changes. After n steps the interval has length $(b-a)/2^{n-1}$, and the midpoint is within $(b-a)/2^n$ of a root.

Check yourself
How many halvings guarantee a root of a function on [0, 1] to within $10^{-5}$?
Need $1/2^n < 10^{-5}$, i.e. $2^n > 100000$: n = 17 ($2^{17} = 131072$).
