21Bartle Thm 6.1.2related MAT-22 MCQ 4, MAT-21 MCQ 3

Differentiable at c implies continuous at c; the converse is false.

Know firstT02T01P06M04

Theorem 6.1.2. If $f : I \to \mathbb R$ has a derivative at $c \in I$, then f is continuous at c.

Skeleton

Want $f(x) \to f(c)$, i.e. $f(x) - f(c) \to 0$. Write $f(x) - f(c) = \dfrac{f(x) - f(c)}{x - c}\cdot(x - c)$ and use the limit of a product: $f'(c)\cdot 0$ ?

Proof. For $x \in I$, $x \ne c$: $$f(x) - f(c) = \frac{f(x) - f(c)}{x - c}\cdot(x - c).$$ As $x \to c$ the first factor tends to $f'(c)$ (hypothesis) and the second to 0. By the limit theorem for products, $\lim_{x\to c}\big(f(x) - f(c)\big) = f'(c)\cdot0 = 0$, so $\lim_{x\to c} f(x) = f(c)$. This is continuity at c. ∎

Converse false. $f(x) = |x|$ is continuous at 0 ($||x| - 0| = |x - 0|$, so δ = ε). But $\dfrac{|x| - 0}{x - 0} = +1$ for $x > 0$ and $-1$ for $x < 0$: with $x_n = 1/n$ the quotients are $1$, with $y_n = -1/n$ they are $-1$, both $\to0$. The limits differ, so $f'(0)$ does not exist.

Differentiable ⇒ continuous; $|x|$ is continuous at 0 but not differentiable there.

Marks: statement 1 · factor identity 1 · limit product 2 · conclusion 1 · example 1.

23Bartle Thm 6.1.3(c)

State and prove the product rule; deduce $(1/g)'$.

Know firstT03T02T01

Theorem 6.1.3(c). Let $f, g : I \to \mathbb R$ be differentiable at $c \in I$. Then the product $fg$ is differentiable at c and $(fg)'(c) = f'(c)g(c) + f(c)g'(c)$.

Proof. For $x \ne c$, adding and subtracting $f(c)g(x)$: $$\frac{f(x)g(x) - f(c)g(c)}{x - c} = \frac{f(x) - f(c)}{x - c}\,g(x) + f(c)\,\frac{g(x) - g(c)}{x - c}.$$ Since g is differentiable at c it is continuous at c (Thm 6.1.2), so $g(x) \to g(c)$. By the limit laws the right side tends to $f'(c)g(c) + f(c)g'(c)$. ∎

Reciprocal. Let $g(c) \ne 0$. g is continuous at c, so $g \ne 0$ on a neighbourhood of c (local sign, Thm 4.2.9) and $1/g$ is defined there. For x in it, $x \ne c$: $$\frac{1/g(x) - 1/g(c)}{x - c} = \frac{-1}{g(x)g(c)}\cdot\frac{g(x) - g(c)}{x - c} \longrightarrow \frac{-g'(c)}{g(c)^2}.$$

$(1/g)'(c) = -\dfrac{g'(c)}{g(c)^2}$. Check $g = x$, c = 2: $-1/4$, and $(1/x)' = -1/x^2 = -0.25$ ✓.

Marks: statement 1 · add-and-subtract identity 2 · continuity of g 1 · reciprocal 2.

24Bartle Thm 6.1.5

Carathéodory's Theorem; $\varphi$ for $x^3$; none for $|x|$.

Know firstT05T01P06M09

Theorem 6.1.5 (Carathéodory). Let f be defined on an interval I containing the point c. Then f is differentiable at c if and only if there exists a function $\varphi$ on I that is continuous at c and satisfies $f(x) - f(c) = \varphi(x)(x - c)$ for $x \in I$. In this case $\varphi(c) = f'(c)$.

(⇒) Define $\varphi(x) = \dfrac{f(x) - f(c)}{x - c}$ for $x \ne c$, and $\varphi(c) = f'(c)$.The only possible candidate: the difference quotient, completed at c.
$\lim_{x\to c}\varphi(x) = f'(c) = \varphi(c)$, so $\varphi$ is continuous at c.Definition of $f'(c)$.
For $x \ne c$ multiply by $x - c$; for $x = c$ both sides are 0. So $f(x) - f(c) = \varphi(x)(x - c)$ on all of I.Check every x, including c.
(⇐) Given such a $\varphi$: for $x \ne c$, $\dfrac{f(x) - f(c)}{x - c} = \varphi(x)$.Divide by $x - c \ne 0$.
$\varphi$ is continuous at c, so $\lim_{x\to c}\varphi(x) = \varphi(c)$. Hence $f'(c)$ exists and equals $\varphi(c)$. ∎Definition 6.1.1.

$f(x) = x^3$. $x^3 - c^3 = (x^2 + cx + c^2)(x - c)$, so $\varphi(x) = x^2 + cx + c^2$, which is continuous everywhere, and $f'(c) = \varphi(c) = 3c^2$.

$|x|$ at 0. $|x| - 0 = \varphi(x)\cdot x$ forces $\varphi(x) = |x|/x = \operatorname{sgn}x$ for $x \ne 0$; its limits at 0 are $+1$ (right) and $-1$ (left), so no value $\varphi(0)$ makes $\varphi$ continuous. Hence $|x|$ is not differentiable at 0.

26Bartle Thm 6.2.1

Interior Extremum Theorem; "interior", "differentiable", converse.

Know firstT10T22P08

Definition 6.2.1. f has a relative maximum at $c \in I$ if there is a neighbourhood $V = V_\delta(c)$ with $f(x) \le f(c)$ for all $x \in V \cap I$ (relative minimum: $f(c) \le f(x)$).

Theorem 6.2.1. Let c be an interior point of the interval I at which $f : I \to \mathbb R$ has a relative extremum. If the derivative of f at c exists, then $f'(c) = 0$.

Skeleton

Max case; min by applying it to $-f$. Assume $f'(c) \ne 0$ and produce points arbitrarily near c with $f(x) > f(c)$ ? (contradiction).

Proof (relative maximum at c). Suppose $f'(c) > 0$. Put $\varepsilon = f'(c)/2$; there is $\delta_1 > 0$ with $\frac{f(x) - f(c)}{x - c} > \frac{f'(c)}{2} > 0$ for $0 < |x - c| < \delta_1$. Because c is interior we may choose $\delta \le \min\{\delta_1, \delta_0\}$ ($\delta_0$ the radius of the maximum neighbourhood) with $(c - \delta, c + \delta) \subseteq I$. Take x with $c < x < c + \delta$: then $f(x) - f(c) = (x - c)(\text{positive}) > 0$, contradicting $f(x) \le f(c)$.

Suppose $f'(c) < 0$: the quotient is $< 0$ near c, so for $c - \delta < x < c$ we have $(x - c) < 0$ and $f(x) - f(c) > 0$, again a contradiction. Hence $f'(c) = 0$. ∎

Hypotheses. Interior: $f(x) = x$ on $[0, 1]$ has extrema at 0 and 1, but $f' = 1$. Differentiable: $|x|$ on $[-1, 1]$ has a minimum at 0 where $f'(0)$ does not exist. Converse: $f(x) = x^3$ has $f'(0) = 0$ but no extremum at 0 (negative to the left, positive to the right).

Marks: definition and statement 1 · contradiction setup 1 · f′ > 0 2 · f′ < 0 1 · examples 1.

28Bartle Thm 6.2.5, Cor 6.2.6

$f' = 0$ implies constant; equal derivatives differ by a constant.

Know firstT13T12

Theorem 6.2.5. Suppose f is continuous on the closed interval $I = [a, b]$, differentiable on $(a, b)$, and $f'(x) = 0$ for $x \in (a, b)$. Then f is constant on I.

Proof. Fix $x \in (a, b]$. f is continuous on $[a, x]$ and differentiable on $(a, x)$, so by the Mean Value Theorem there is $c \in (a, x)$ with $f(x) - f(a) = f'(c)(x - a) = 0\cdot(x - a) = 0$. So $f(x) = f(a)$ for every $x \in I$. ∎

Corollary 6.2.6. If $f, g$ are continuous on $[a, b]$, differentiable on $(a, b)$ and $f' = g'$ there, then $f = g + C$. Proof. $h = f - g$ is continuous, differentiable, $h' = f' - g' = 0$ on $(a, b)$; by 6.2.5 $h \equiv C$. ∎

Why an interval is needed. On $(0,1) \cup (2,3)$ let $f = 0$ on $(0,1)$ and $f = 1$ on $(2,3)$. Then $f' = 0$ everywhere but f is not constant. The MVT needs the whole segment $[a, x]$ inside the domain; here the segment from $\frac12$ to $\frac52$ leaves it.

Example: $\sin^2x + \cos^2x$ has derivative $2\sin x\cos x - 2\cos x\sin x = 0$ and equals 1 at x = 0, so it equals 1 everywhere.

Marks: statement 1 · MVT application 2 · conclusion 1 · corollary 1 · counterexample 1.

29Bartle Thm 6.2.8

First Derivative Test, part (a); $x^3 - 3x$; $|x|$ at 0.

Know firstT15T12M05

Theorem 6.2.8 (a). Let f be continuous on the interval $I = [a, b]$ and let c be an interior point of I. Assume f is differentiable on $(a, c)$ and $(c, b)$. If there is a neighbourhood $(c - \delta, c + \delta) \subseteq I$ such that $f'(x) \ge 0$ for $c - \delta < x < c$ and $f'(x) \le 0$ for $c < x < c + \delta$, then f has a relative maximum at c.

Proof. Left side. For $c - \delta < x < c$, f is continuous on $[x, c]$ and differentiable on $(x, c)$. MVT: $f(c) - f(x) = f'(\xi)(c - x)$ with $\xi \in (x, c)$, $f'(\xi) \ge 0$, $c - x > 0$; so $f(x) \le f(c)$. Right side. For $c < x < c + \delta$, MVT on $[c, x]$: $f(x) - f(c) = f'(\xi)(x - c)$ with $f'(\xi) \le 0$, $x - c > 0$; so $f(x) \le f(c)$. Thus $f(x) \le f(c)$ on $(c - \delta, c + \delta)$: a relative maximum. ∎ ((b) is the same with signs reversed.)

$f = x^3 - 3x$. $f' = 3(x^2 - 1)$: $\ge0$ on $(-\infty, -1)$, $\le0$ on $(-1, 1)$, $\ge 0$ on $(1, \infty)$. Relative maximum at $-1$ ($f = 2$); relative minimum at 1 ($f = -2$).

$|x|$ at 0. $f' = -1$ for $x < 0$, $+1$ for $x > 0$: part (b) gives a relative minimum at 0, although $f'(0)$ does not exist (so the test does not need $f'(c)$).

35Bartle 6.2.10(d)

$x^\alpha \le \alpha x + (1 - \alpha)$; weighted AM–GM; $\sqrt{ab} \le (a + b)/2$.

Know firstT21T15T20

Let $0 < \alpha < 1$ and $g(x) = \alpha x - x^\alpha$ for $x \ge 0$. Then $g$ is continuous on $[0, \infty)$ and $g'(x) = \alpha(1 - x^{\alpha-1})$ for $x > 0$. Since $\alpha - 1 < 0$: for $0 < x < 1$, $x^{\alpha-1} > 1$ so $g' < 0$; for $x > 1$, $x^{\alpha-1} < 1$ so $g' > 0$.

So g decreases on $[0, 1]$ and increases on $[1, \infty)$ (6.2.7); g has its absolute minimum at 1: $g(x) \ge g(1) = \alpha - 1$. That is $\alpha x - x^\alpha \ge \alpha - 1$, i.e. $$x^\alpha \le \alpha x + (1 - \alpha),\qquad x \ge 0,$$ with equality iff $x = 1$.

Deduction. For $a, b > 0$ put $x = a/b$: $(a/b)^\alpha \le \alpha\frac ab + (1 - \alpha)$. Multiply by $b > 0$: $a^\alpha b^{1-\alpha} \le \alpha a + (1 - \alpha)b$, equality iff $a = b$.

$\alpha = \frac12$: $\sqrt{ab} \le \dfrac{a + b}{2}$. Check $\alpha = \frac13$, a = 8, b = 1: $2 \le \frac83 + \frac23 = \frac{10}{3}$ ✓.

36Bartle Cor 6.2.13, Ex 6.2.12

A function that is not a derivative; two functions with derivative h.

Know firstT24T23

Darboux's Theorem 6.2.12. If f is differentiable on $I = [a, b]$ and k is a number between $f'(a)$ and $f'(b)$, then there is at least one point c in $(a, b)$ with $f'(c) = k$.

g is not a derivative. Suppose $g = f'$ on $[-1, 1]$ for some differentiable f. Then $f'(-1) = -1 < \frac12 < 1 = f'(1)$, so by Darboux there is $c \in (-1, 1)$ with $g(c) = \frac12$. But g takes only the values $-1, 0, 1$. Contradiction.

Two functions. $f_1(x) = \max\{x, 0\}$ ($= 0$ for $x \le 0$, $x$ for $x > 0$) and $f_2(x) = 0$ for $x \le 0$, $f_2(x) = x + 1$ for $x > 0$. For $x < 0$ both have derivative 0; for $x > 0$ both have derivative 1; so both have derivative $h(x)$ at every $x \ne 0$. But $f_2 - f_1 = 0$ on $(-\infty, 0]$ and $= 1$ on $(0, \infty)$: not constant.

Equal derivatives off 0 need not give a constant difference, because $\mathbb R \setminus \{0\}$ is not an interval. (Whatever value h is given at 0, no function has $f' = h$ at every point: $h$ takes 0 and 1 but not $\frac12$, so Darboux fails.)

Marks: Darboux statement 1 · contradiction 2 · $f_1$ 1 · $f_2$ 1 · not constant 1.
