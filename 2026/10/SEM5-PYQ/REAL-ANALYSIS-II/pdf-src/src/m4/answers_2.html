21PYQ MAT-21 Q21

Define pointwise convergence; test $(x^n)$.

Know firstT1T2P1

Definition. $(f_n)$ converges on $A_0$ to f if for each $x \in A_0$, $f_n(x) \to f(x)$ (see Q2).

Test. Let $g_n(x) = x^n$, $x \in \mathbb R$.

$x = 1$$g_n(1) = 1 \to 1$. $|x|<1$$x^n \to 0$. $x = -1$$(-1)^n$ oscillates between −1 and 1: divergent. $|x|>1$$|x|^n \to \infty$: unbounded, divergent.
$(x^n)$ converges exactly on $(-1,1]$, to $g(x) = 0$ ($-1<x<1$), $g(1) = 1$.

The limit is discontinuous at 1 although every $x^n$ is continuous; hence the convergence is not uniform on $(-1,1]$ (Theorem 8.2.2).

Marks: definition 2 · four cases 3 · conclusion 1.

22PYQ MAT-21 Q32

Convergence of $x^n(1-x)$ on [0, 1].

Know firstT7T6M4

Pointwise. At $x = 0$ and $x = 1$, $G_n(x) = 0$. For $0<x<1$, $x^n \to 0$, so $G_n(x) \to 0$. Limit $G = 0$.

Norm. $G_n'(x) = nx^{n-1}(1-x) - x^n = x^{n-1}\big(n - (n+1)x\big)$, zero at $x_n = \frac{n}{n+1}$; $G_n' > 0$ before and $<0$ after, so this is the maximum: $$\lVert G_n\rVert_{[0,1]} = \Big(\frac{n}{n+1}\Big)^n \frac{1}{n+1} = \frac{n^n}{(n+1)^{n+1}} \le \frac{1}{n+1}.$$

(n = 1: ¼; n = 2: 4/27 ≈ 0.148; n = 10: ≈ 0.035.)

$\lVert G_n\rVert \to 0$, so $x^n(1-x) \to 0$ uniformly on [0, 1].

Marks: pointwise 1.5 · derivative and critical point 2 · norm 1.5 · conclusion 1.

23PYQ MAT-22 Q31

Convergence of $\frac{x^n}{x^n+1}$ on [0, 2].

Know firstT2T14T13
$0 \le x < 1$$x^n \to 0$, so $f_n(x) \to 0$. $x = 1$$f_n(1) = \frac12$. $1<x\le2$$f_n(x) = \frac{1}{1+x^{-n}} \to 1$ since $x^{-n} \to 0$.

Not uniform on [0, 2]. Each $f_n$ is continuous (quotient of continuous functions, denominator ≥ 1), but the limit f jumps at 1. By Theorem 8.2.2 the convergence cannot be uniform. Directly: $\sup_{0\le x<1} \frac{x^n}{1+x^n} = \frac12$ (approached as $x\to1^-$), so $\lVert f_n - f\rVert = \frac12$ for all n.

Where it is uniform. On $[0, b]$, $b<1$: $|f_n| \le x^n \le b^n \to 0$. On $[a, 2]$, $a>1$: $|f_n - 1| = \frac{1}{1+x^n} \le \frac{1}{1+a^n} \to 0$.

Pointwise limit: 0 on [0, 1), ½ at 1, 1 on (1, 2]. Not uniform on [0, 2]; uniform on [0, b] (b < 1) and [a, 2] (a > 1).

Marks: limit 2 · non-uniformity 2 · uniform subsets 2.

Prove Lemma 8.1.5; apply to $(x^2+nx)/n$.

Know firstT4M5T3

Lemma. $(f_n)$ does not converge uniformly on $A_0$ to f iff for some $\varepsilon_0>0$ there are a subsequence $(f_{n_k})$ and points $x_k \in A_0$ with $|f_{n_k}(x_k) - f(x_k)| \ge \varepsilon_0$ for all k.

Negating Definition 8.1.4: there is $\varepsilon_0>0$ such that for every K there are $n \ge K$ and $x \in A_0$ with $|f_n(x) - f(x)| \ge \varepsilon_0$.Flip ∀/∃ and the inequality.
K = 1 gives $n_1, x_1$; $K = n_1 + 1$ gives $n_2 > n_1$, $x_2$; inductively $n_1 < n_2 < \cdots$: the required subsequence and points.Construction by induction.
Conversely, if such $n_k, x_k$ exist then for any K some $n_k \ge K$ violates uniformity.$n_k \to \infty$.

Application. $h_n(x) = \frac{x^2+nx}{n} \to h(x) = x$ (Q6). With $x_k = -k$: $h_k(-k) = \frac{k^2 - k^2}{k} = 0$, $h(-k) = -k$, so $|h_k(x_k) - h(x_k)| = k \ge 1 = \varepsilon_0$. Not uniform on ℝ.

Marks: statement 1 · proof 3 · application 2.

25

$x^n$ on [0, 1]: derivatives, limit, why not uniform.

Know firstT11T13

$g_n'(x) = nx^{n-1}$ is a polynomial, hence continuous on [0, 1]. Pointwise: $g_n(1) = 1$, and $g_n(x) \to 0$ for $0 \le x < 1$, so g = 0 on [0, 1), g(1) = 1. Since $\lim_{x\to1^-} g(x) = 0 \ne 1 = g(1)$, g is not continuous at 1, hence not differentiable at 1 (differentiable ⇒ continuous).

Why not uniform: if $g_n \to g$ uniformly, Theorem 8.2.2 would give g continuous, which is false. (Also $\lVert g_n - g\rVert = \sup_{[0,1)} x^n = 1$.)

Marks: derivatives 1 · limit 2 · discontinuity 1 · reason 2.

26

Moving bump $\frac{nx}{1+n^2x^2}$.

Know firstT7T4T9M4

Pointwise. $f_n(0) = 0$. For $x>0$: $0 \le f_n(x) \le \frac{nx}{n^2x^2} = \frac{1}{nx} \to 0$. So f = 0.

Norm. $1 + n^2x^2 - 2nx = (1 - nx)^2 \ge 0$, so $f_n(x) \le \frac12$, with equality at $x = 1/n$. Hence $\lVert f_n\rVert_{[0,\infty)} = \frac12 \not\to 0$: not uniform on $[0,\infty)$.

On $[a, \infty)$. $f_n'(x) = \frac{n(1 - n^2x^2)}{(1+n^2x^2)^2} < 0$ for $x > 1/n$. For $n > 1/a$, $f_n$ is decreasing on $[a,\infty)$, so $\lVert f_n\rVert = f_n(a) = \frac{na}{1+n^2a^2} < \frac{1}{na} \to 0$: uniform.

Marks: pointwise 1.5 · norm ½ 2 · [a, ∞) 2.5.

27

Spikes: $f_n \to 0$, $\int f_n = 1$.

Know firstT12

$f_n(0) = 0$. For $x \in (0,1]$: when $n > 2/x$ we have $x > 2/n$, so $f_n(x) = 0$. Hence $f_n(x) \to 0$ for every x: f = 0. The graph on $[0, 2/n]$ is a triangle with base $2/n$ and height n, so $\int_0^1 f_n = \frac12\cdot\frac2n\cdot n = 1$ for all $n \ge 2$.

$\lim\int_0^1 f_n = 1 \ne 0 = \int_0^1 \lim f_n$.

This shows that the limit of integrals need not be the integral of the limit for pointwise convergence. Here the limit is continuous, yet the convergence is not uniform: $\lVert f_n\rVert = n \to \infty$.

Marks: pointwise 2 · integral 2 · conclusion 2.

31

$(x^n)$ not uniformly Cauchy on [0, 1].

Know firstT10M4

Each $x^n$ is bounded on [0, 1]. Put $t = x^n \in [0,1]$: $x^n - x^{2n} = t - t^2 \le \frac14$, with equality when $t = \frac12$, i.e. $x = 2^{-1/n}$. So $\lVert f_n - f_{2n}\rVert_{[0,1]} = \frac14$ for every n.

Take $\varepsilon = \frac18$. For any H, the choice $m = 2H$, $n = H$ gives $\lVert f_m - f_n\rVert = \frac14 > \varepsilon$. So the Cauchy condition fails and, by Theorem 8.1.10, $(x^n)$ does not converge uniformly on [0, 1] to any bounded function. (The limit function was never used.)

Marks: norm ¼ 3 · failure of Cauchy condition 2 · conclusion 1.

32

$\frac1n\sin nx$: uniform; derivatives diverge.

Know firstT8T11

$|F_n(x)| \le \frac1n$ for all x, so $\lVert F_n\rVert_{\mathbb R} \le \frac1n \to 0$: $F_n \to 0$ uniformly on ℝ. But $F_n'(x) = \cos nx$; at $x = \pi$, $F_n'(\pi) = \cos n\pi = (-1)^n$, which diverges. So $(F_n')$ does not converge (on any set containing π), while the limit F = 0 has $F' = 0$.

This shows: uniform convergence of $f_n$ does not allow differentiating term by term; one needs extra conditions on $f_n'$ (Theorem 8.2.3, practicum).

34

$n^2x^2e^{-nx}$ on $[0,\infty)$ and $[a,\infty)$.

Know firstT4T9M4

Pointwise. x = 0: 0. x > 0: $n^2e^{-nx} \to 0$ (exponentials beat powers), times $x^2$: 0.

Not uniform. The derivative $n^2xe^{-nx}(2 - nx)$ vanishes at $x = 2/n$, where the value is $n^2\cdot\frac{4}{n^2}e^{-2} = \frac{4}{e^2} \approx 0.541$ for every n. With $\varepsilon_0 = 4/e^2$ and $x_n = 2/n$, Lemma 8.1.5 shows non-uniformity.

Uniform on $[a,\infty)$. For $n > 2/a$ the function decreases on $[a,\infty)$, so the norm is $n^2a^2e^{-na} \to 0$.

35

$\frac{nx}{1+nx}$ on [0, 1]: not uniform, yet integrals converge.

Know firstT12T14P6

Limit: f(0) = 0, f = 1 on (0, 1] (Q5). The $f_n$ are continuous and f is not, so not uniform (8.2.2); indeed $|f_n(x) - 1| = \frac{1}{1+nx} \to 1$ as $x \to 0^+$, so $\lVert f_n - f\rVert = 1$.

Integrals: $\frac{nx}{1+nx} = 1 - \frac{1}{1+nx}$, so $$\int_0^1 f_n = 1 - \frac{\ln(1+n)}{n} \to 1 = \int_0^1 f$$ (since $\frac{\ln(1+n)}{n} \to 0$; f differs from 1 only at x = 0).

Moral: uniform convergence is sufficient, but not necessary, for $\lim\int f_n = \int f$.

36

Sums and products of uniformly convergent sequences.

Know firstT15T6M1

Sum. For all x: $|(f_n + g_n)(x) - (f + g)(x)| \le |f_n(x) - f(x)| + |g_n(x) - g(x)| \le \lVert f_n - f\rVert + \lVert g_n - g\rVert \to 0$. So the sum converges uniformly.

Product (all $f_n, g_n$ bounded). Choose N with $\lVert f_n - f\rVert \le 1$ for $n \ge N$. Then f is bounded ($|f| \le \lVert f_N\rVert + 1$), and so is g; also $\lVert f_n\rVert \le \lVert f\rVert + 1 =: M$ for $n \ge N$. Now $$f_ng_n - fg = f_n(g_n - g) + g(f_n - f),$$ so $\lVert f_ng_n - fg\rVert \le M\lVert g_n - g\rVert + \lVert g\rVert\,\lVert f_n - f\rVert \to 0$.

Marks: sum 2 · boundedness 2 · product estimate 2.
