T9

Uniform depends on the set

The same sequence can be uniform on one set and not on another (PYQ MAT-21 Q37b).

The ideaUniformity fails because of a bad place: far out towards ∞, or near a point where the limit jumps. Cut the bad place out of the set and uniformity comes back.
$f_n$uniform onnot uniform on
$x/n$[0, 1]: norm $1/n$; any $[-b, b]$: $b/n$ℝ
$x^n$$[0, b]$, $b<1$: norm $b^n$[0, 1], and even [0, 1)
$(x^2+nx)/n$[0, 8]: norm $64/n$ℝ
$nx/(1+n^2x^2)$$[a, \infty)$, $a>0$$[0, \infty)$
{{fig:parab}}
Worked example · $x^n$ on three sets

On [0, b], b < 1. $x^n$ increases in x, so $\lVert x^n - 0\rVert_{[0,b]} = b^n \to 0$. Uniform. (For $b = \frac12$: norm $2^{-n}$.)

On [0, 1). The limit is 0 (continuous!), but $\sup\{x^n : 0 \le x < 1\} = 1$ for every n. Not uniform C25.

On [0, 1]. Gap $|x^n - g(x)|$ is $x^n$ on [0, 1) and 0 at 1, so the norm is 1. Not uniform.

Exam trap"The limit is continuous, so the convergence is uniform." False: $x^n$ on [0, 1) has the continuous limit 0 and is still not uniform.
Check yourself
Is $x/n \to 0$ uniform on [−5, 5]?
Yes: $|x/n| \le 5/n$ for all $x \in [-5, 5]$, so the norm is $5/n \to 0$.

T10

The Cauchy criterion (Theorem 8.1.10)

A 10–15 mark favourite (PYQ MTS-25 Q26, MAT-21 Q38a).

Theorem 8.1.10 · say it word for wordLet $(f_n)$ be a sequence of bounded functions on $A \subseteq \mathbb R$. Then this sequence converges uniformly on A to a bounded function f if and only if for each $\varepsilon > 0$ there is a number $H(\varepsilon)$ in ℕ such that for all $m, n \ge H(\varepsilon)$, then $\lVert f_m - f_n\rVert_A \le \varepsilon$. In plain words: late frames are uniformly close to each other. Like P4, but for whole graphs. You never need to know f.
KnowLemma 8.1.8 (T6); Cauchy Criterion 3.5.5 for numbers (P4); order limit 3.2.6 (P2); triangle inequality (M1).Want(⇒) uniform ⇒ uniformly Cauchy. (⇐) uniformly Cauchy ⇒ there is a bounded f with $f_n \to f$ uniformly.
Proof (⇒)
Let $\varepsilon>0$. By Lemma 8.1.8 there is $K = K(\varepsilon/2)$ with $\lVert f_n - f\rVert_A \le \varepsilon/2$ for $n \ge K$.Use ε/2 so two pieces add to ε (M1).
For $m, n \ge K$ and every $x \in A$: $|f_m(x) - f_n(x)| \le |f_m(x) - f(x)| + |f(x) - f_n(x)| \le \frac\varepsilon2 + \frac\varepsilon2 = \varepsilon$.Add and subtract f(x); triangle inequality.
Taking sup over x: $\lVert f_m - f_n\rVert_A \le \varepsilon$ for $m, n \ge H(\varepsilon) := K(\varepsilon/2)$.ε bounds every value, so it bounds the sup (T5).
Proof (⇐)
Fix $x \in A$. For $m, n \ge H(\varepsilon)$: $|f_m(x) - f_n(x)| \le \lVert f_m - f_n\rVert_A \le \varepsilon$. So $(f_n(x))$ is a Cauchy sequence of numbers.Each value ≤ the sup; definition of Cauchy (P4).
By the Cauchy Convergence Criterion 3.5.5 it converges. Define $f(x) := \lim_n f_n(x)$ for each $x \in A$.ℝ is complete. This is our candidate f.
In $|f_m(x) - f_n(x)| \le \varepsilon$ (m fixed, $m \ge H$) let $n \to \infty$: $|f_m(x) - f(x)| \le \varepsilon$ for all $x \in A$, $m \ge H(\varepsilon)$.Order limit theorem 3.2.6: limits keep ≤. The same H works for every x: this is the heart of the proof.
f is bounded: with $m = H(1)$, $|f(x)| \le |f_m(x)| + 1 \le \lVert f_m\rVert_A + 1$ for all x.Step 3 with ε = 1; $f_m$ is bounded. (Bartle leaves this line out; write it.)
So $\lVert f_m - f\rVert_A \le \varepsilon$ for $m \ge H(\varepsilon)$, i.e. $f_n \to f$ uniformly. ∎Lemma 8.1.8.
Exam trap"$\lVert f_{n+1} - f_n\rVert \to 0$" is not the Cauchy condition. You need all pairs $m, n \ge H$. (Constant functions $f_n = 1 + \frac12 + \dots + \frac1n$ have neighbours closer and closer, but they never converge.)
Using the criterion · Bartle-styleShow $(x^n)$ is not uniformly convergent on [0, 1] without finding its limit. Put $t = x^n \in [0, 1]$: $$x^n - x^{2n} = t - t^2 \le \tfrac14,$$ with equality at $t = \frac12$, i.e. $x = 2^{-1/n}$. So $\lVert f_n - f_{2n}\rVert = \frac14$ for every n. With $\varepsilon = \frac18$ no H works (take m = H, n = 2H). Not uniformly Cauchy, so not uniform.

T11

Pointwise limits can break continuity

Bartle 8.2.1(a), (b) (PYQ MTS-22 MCQ 11).

The ideaEvery $g_n(x) = x^n$ is continuous (even smooth) on [0, 1]. Their pointwise limit g is 0 on [0, 1) and 1 at x = 1: it jumps. So a pointwise limit of continuous functions need not be continuous, and need not be differentiable.
{{fig:interchange_xn}}
Result · two limits in the wrong order$$\lim_{x \to 1^-}\Big(\lim_{n} x^n\Big) = 0, \qquad \lim_{n}\Big(\lim_{x\to1^-} x^n\Big) = 1.$$ "Continuity of the limit" is exactly the statement that these two orders agree.
Check yourself · past MCQ
$g_n(x) = x^n$. On which of (−1, 1], (−2, 1], (0, 1], (−1, 1) does $(g_n)$ converge to a continuous function?
Only (−1, 1): there the limit is 0. On (−1, 1] and (0, 1] the limit jumps at 1; on (−2, 1] there is no limit at x ≤ −1.
Exam trapDerivatives are worse still: $\frac1n \sin nx \to 0$ uniformly on ℝ, but the derivatives $\cos nx$ do not converge (at $x = \pi$ they are $(-1)^n$). Uniform convergence of $f_n$ alone does not let you differentiate the limit term by term.

In the model paper: Q11 (PYQ MTS-22 MCQ 11), Q25, Q32.

T12

Limits and integrals

$\lim \int f_n$ need not equal $\int \lim f_n$ (Bartle 8.2.1(c), (d); PYQ MTS-22 Q10).

Example 1 · spikes (8.2.1(c))$f_n$ is the triangle with corners (0, 0), (1/n, n), (2/n, 0), and 0 on [2/n, 1]. Area = ½ · (2/n) · n = 1 for every n. At a fixed $x>0$, once $2/n < x$ the spike has passed and $f_n(x) = 0$; also $f_n(0) = 0$. Limit f = 0, $\int_0^1 f = 0 \ne 1$.
{{fig:spikes}}
Example 2 · $h_n(x) = 2nx\,e^{-nx^2}$ on [0, 1] (PYQ MTS-22 Q10)

Integral. $H_n(x) = -e^{-nx^2}$ has $H_n' = h_n$ (P6), so $\int_0^1 h_n = H_n(1) - H_n(0) = 1 - e^{-n} \to 1$.

Limit. $h_n(0) = 0$. For $x > 0$: $e^{nx^2} > \frac{(nx^2)^2}{2}$ (one term of the exponential series), so $0 < h_n(x) < \frac{2nx \cdot 2}{n^2x^4} = \frac{4}{nx^3} \to 0$. So $h = 0$ and $\int_0^1 h = 0$.

$\lim \int h_n = 1 \ne 0 = \int \lim h_n$.

{{fig:hn_fig}}
Exam trapUniform convergence is enough to swap limit and integral (Theorem 8.2.4, practicum), but it is not needed: $\frac{nx}{1+nx}$ on [0, 1] is not uniform, yet $\int_0^1 f_n = 1 - \frac{\ln(1+n)}{n} \to 1 = \int_0^1 f$ C26.

In the model paper: Q10 (PYQ MTS-22 Q10), Q27, Q35.

T13

Uniform limit of continuous functions is continuous

Theorem 8.2.2, the main theorem of §8.2 (PYQ MTS-25 Q20).

Theorem 8.2.2 · say it word for wordLet $(f_n)$ be a sequence of continuous functions on a set $A \subseteq \mathbb R$ and suppose that $(f_n)$ converges uniformly on A to a function $f : A \to \mathbb R$. Then f is continuous on A.
Hypotheses checklist
  • every $f_n$ continuous on Awithout it nothing is inherited: constant step functions converging to a step function.
  • convergence is uniform on Apointwise is not enough: $x^n$ on [0, 1] has a jump limit C12.
{{fig:eps3}}
Knowuniform: one H with $|f_H(x) - f(x)| < \varepsilon/3$ for all x; $f_H$ continuous at c.Wantfor each $c \in A$ and ε > 0, a δ with $|f(x) - f(c)| < \varepsilon$ when $|x - c| < \delta$, $x \in A$.
Proof (Bartle's ε/3 argument)
Let $\varepsilon>0$ and $c \in A$.To show continuity at an arbitrary c (P5).
By uniform convergence there is $H = H(\varepsilon/3)$ with $|f_H(x) - f(x)| < \varepsilon/3$ for all $x \in A$.Definition 8.1.4 with ε/3. Fix this one function $f_H$.
For $x \in A$: $|f(x) - f(c)| \le |f(x) - f_H(x)| + |f_H(x) - f_H(c)| + |f_H(c) - f(c)| < \frac\varepsilon3 + |f_H(x) - f_H(c)| + \frac\varepsilon3$.Add and subtract $f_H(x)$ and $f_H(c)$ (M1). Uniformity is used at two points, x and c.
$f_H$ is continuous at c, so there is $\delta>0$ with $|f_H(x) - f_H(c)| < \varepsilon/3$ when $x \in A$, $|x - c| < \delta$.Continuity of the single function $f_H$.
Then $|f(x) - f(c)| < \frac\varepsilon3 + \frac\varepsilon3 + \frac\varepsilon3 = \varepsilon$ for those x. c was arbitrary, so f is continuous on A. ∎Steps 3 and 4 together.
Where pointwise would failIn step 2 we need one H that works at x and at c, for every x near c. With only pointwise convergence, H would depend on x, and x moves as δ shrinks.

T14

Using Theorem 8.2.2

The quickest proof of "not uniform" (PYQ MAT-22 Q31).

Skeleton · contrapositiveEach $f_n$ is continuous on A (reason). The pointwise limit is f = ?, which is not continuous at c. If $f_n \to f$ uniformly on A, Theorem 8.2.2 would make f continuous. Hence the convergence is not uniform on A. ∎
Worked example · $f_n(x) = \dfrac{x^n}{x^n+1}$ on [0, 2] (PYQ MAT-22 Q31)
$0 \le x < 1$$x^n \to 0$, so $f_n(x) \to 0$ $x = 1$$f_n(1) = \frac12$ $1 < x \le 2$$f_n(x) = \dfrac{1}{1 + x^{-n}} \to 1$

The $f_n$ are continuous; the limit jumps at 1. So not uniform on [0, 2]. (Directly: $\lVert f_n - f\rVert = \frac12$ for every n.) On $[0, b]$ with $b<1$ the norm is $\le b^n \to 0$: uniform there.

Exam trap · the converse is false"The limit is continuous, so the convergence is uniform." No. $x/n \to 0$ on ℝ: limit continuous, convergence not uniform. Theorem 8.2.2 can only disprove uniformity (when the limit is discontinuous); it can never prove it.
Check yourself
Show $\arctan(nx) \to \frac\pi2 \operatorname{sgn} x$ and that the convergence is not uniform on ℝ.
x > 0: $nx \to \infty$, $\arctan \to \pi/2$. x < 0: $-\pi/2$. x = 0: 0. The $f_n$ are continuous but the limit jumps at 0, so not uniform (8.2.2). On $[a, \infty)$, a > 0, it is uniform: gap $\le \frac\pi2 - \arctan(na) \to 0$.

In the model paper: Q15 Q20 Q23 (PYQ MAT-22 Q31) Q30.

T15

Sums and products

Bartle Exercises 8.1.21–23 (PYQ MTS-22 MCQ 13).

ResultIf $f_n \to f$ and $g_n \to g$ uniformly on A, then $f_n + g_n \to f + g$ and $c f_n \to c f$ uniformly. If also every $f_n$ and $g_n$ is bounded, then $f_n g_n \to fg$ uniformly.
Proof idea

Sum: $|(f_n + g_n) - (f + g)| \le |f_n - f| + |g_n - g|$, so $\lVert \cdot\rVert \le \lVert f_n - f\rVert + \lVert g_n - g\rVert \to 0$.

Product: $f_ng_n - fg = f_n(g_n - g) + g(f_n - f)$. With $\lVert f_n\rVert \le M$ for all large n, $\lVert f_ng_n - fg\rVert \le M\lVert g_n - g\rVert + \lVert g\rVert\,\lVert f_n - f\rVert \to 0$.

Without boundedness, products fail$f_n = x + \frac1n \to x$ uniformly on ℝ (norm 1/n). But $f_n^2 - x^2 = \frac{2x}{n} + \frac1{n^2}$; at $x = n$ this is $\ge 2$. So $f_n^2 \not\to x^2$ uniformly on ℝ C23.

In the model paper: Q12 (PYQ MTS-22 MCQ 13), Q29, Q36.
