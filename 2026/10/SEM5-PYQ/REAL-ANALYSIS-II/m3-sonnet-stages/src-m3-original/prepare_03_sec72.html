The Cauchy Criterion for integrability

Testing integrability without knowing the value L in advance (Bartle Theorem 7.2.1; PYQ MAT-21 Q8).

Theorem 7.2.1 · Cauchy Criterion (Bartle p. 208) · say it word for wordA function f : [a,b] \to \mathbb{R} belongs to \mathcal{R}[a,b] if and only if for every \varepsilon > 0 there exists \eta_\varepsilon > 0 such that if \dot P and \dot Q are any tagged partitions of [a,b] with \lVert P\rVert < \eta_\varepsilon and \lVert Q\rVert < \eta_\varepsilon, then \lvert S(f;\dot P) - S(f;\dot Q)\rvert < \varepsilon. In plain words: f is integrable if and only if, whatever \varepsilon > 0 you are handed, you can find a mesh bound \eta_\varepsilon > 0 so that any two Riemann sums with mesh <\eta_\varepsilon are within \varepsilon of each other—without ever naming L.
Hypotheses · Theorem 7.2.1
  • \lvert S(f;\dot P) - S(f;\dot Q)\rvert < \varepsilon holds for all pairs of tagged partitions \dot P, \dot Q with \lVert P\rVert, \lVert Q\rVert < \eta_\varepsilonfor Dirichlet's function C7, two partitions with the same tiny mesh still give \lvert S(f;\dot P) - S(f;\dot Q)\rvert = \lvert 1 - 0\rvert = 1 \not< 1/2
  • completeness of \mathbb{R} (Cauchy Convergence Criterion 3.5.5 for sequences in \mathbb{R})used in the (\Leftarrow) direction to guarantee that the Cauchy sequence of numbers (S(f;\dot P_m)) converges to a real limit A \in \mathbb{R}
Skeleton · use the Cauchy Criterion to prove f \in \mathcal{R}[a,b]Let \varepsilon > 0 be given. Choose \eta_\varepsilon = $ ? $ > 0. Let \dot P, \dot Q be any tagged partitions of [a,b] with \lVert P\rVert < \eta_\varepsilon and \lVert Q\rVert < \eta_\varepsilon. Then \lvert S(f;\dot P) - S(f;\dot Q)\rvert \le $ ? $ < \varepsilon. By the Cauchy Criterion (Theorem 7.2.1), f \in \mathcal{R}[a,b]. ∎
Know(\Rightarrow) f \in \mathcal{R}[a,b] with integral L. (\Leftarrow) For each \varepsilon > 0 there is \eta_\varepsilon > 0 making \lvert S(f;\dot P) - S(f;\dot Q)\rvert < \varepsilon.Want(\Rightarrow) Produce \eta_\varepsilon. (\Leftarrow) Construct the limit A \in \mathbb{R} using \varepsilon = 1/n and prove \int_a^b f = A.
Scratch · how (\Leftarrow) builds the missing number A

Take \varepsilon = 1/n to get mesh bounds \delta_n > 0, forced decreasing (\delta_n \ge \delta_{n+1}). Pick one tagged partition \dot P_n with \lVert P_n\rVert < \delta_n. For m > n, both \dot P_m and \dot P_n have norm < \delta_n, so \lvert S(f;\dot P_m) - S(f;\dot P_n)\rvert < 1/n: the real sequence a_m = S(f;\dot P_m) is Cauchy! Call its limit A. Then any \dot Q with \lVert Q\rVert < \delta_K is within 1/K of S(f;\dot P_K), which is within 1/K of A; choose K > 2/\varepsilon.

Proof of Theorem 7.2.1 (Bartle p. 208)

(\Rightarrow)

If f \in \mathcal{R}[a,b] with integral L, let \eta_\varepsilon := \delta_{\varepsilon/2} > 0 be the number from Definition 7.1.1 corresponding to \varepsilon/2. If \dot P, \dot Q have \lVert P\rVert < \eta_\varepsilon and \lVert Q\rVert < \eta_\varepsilon, then \lvert S(f;\dot P) - L\rvert < \varepsilon/2 and \lvert S(f;\dot Q) - L\rvert < \varepsilon/2.Definition 7.1.1 applied twice with tolerance \varepsilon/2.
By the Triangle Inequality, \lvert S(f;\dot P) - S(f;\dot Q)\rvert = \lvert S(f;\dot P) - L + L - S(f;\dot Q)\rvert \le \lvert S(f;\dot P) - L\rvert + \lvert L - S(f;\dot Q)\rvert < \varepsilon/2 + \varepsilon/2 = \varepsilon. Add and subtract L, then apply the Triangle Inequality (P05).

(\Leftarrow)

For each n \in \mathbb{N}, let \delta_n > 0 be the number \eta_{1/n} such that whenever \dot P and \dot Q have norms <\delta_n, we have \lvert S(f;\dot P) - S(f;\dot Q)\rvert < 1/n. We may assume \delta_n \ge \delta_{n+1} for all n (otherwise replace \delta_n by \delta'_n := \min\{\delta_1,\dots,\delta_n\}).Hypothesis applied with \varepsilon = 1/n; taking running minimums keeps \delta_n decreasing so finer partitions satisfy all earlier bounds.
For each n \in \mathbb{N}, choose a tagged partition \dot P_n with \lVert P_n\rVert < \delta_n. If m > n, then \lVert P_m\rVert < \delta_m \le \delta_n and \lVert P_n\rVert < \delta_n, so \lvert S(f;\dot P_m) - S(f;\dot P_n)\rvert < 1/n. Both \dot P_m and \dot P_n have norm <\delta_n, so Step 1 applies to the pair (\dot P_m, \dot P_n).
Consequently, the sequence (S(f;\dot P_m))_{m=1}^\infty is a Cauchy sequence in \mathbb{R}. By the Cauchy Convergence Criterion for sequences (Theorem 3.5.5, P06), this sequence converges in \mathbb{R}; let A := \lim_m S(f;\dot P_m).Completeness of \mathbb{R} (P06).
Passing to the limit in Step 2 as m \to \infty gives \lvert S(f;\dot P_n) - A\rvert \le 1/n for all n \in \mathbb{N}.Order property of sequence limits (strict < 1/n becomes \le 1/n in the limit).
To see that A is the Riemann integral of f, given \varepsilon > 0, choose K \in \mathbb{N} with K > 2/\varepsilon (so 1/K < \varepsilon/2). If \dot Q is any tagged partition with \lVert Q\rVert < \delta_K, then \lvert S(f;\dot Q) - A\rvert \le \lvert S(f;\dot Q) - S(f;\dot P_K)\rvert + \lvert S(f;\dot P_K) - A\rvert < \frac{1}{K} + \frac{1}{K} = \frac{2}{K} < \varepsilon. Since \varepsilon > 0 is arbitrary, f \in \mathcal{R}[a,b] with \int_a^b f = A. ∎Archimedean property (P13), Step 1 for (\dot Q, \dot P_K), Step 4 for n=K, and Triangle Inequality.
Worked example · Bartle Example 7.2.2(a)

Let g(x) = 2 on [0,1] and 3 on (1,3] as in Example 7.1.4(b). For any \dot P, \dot Q with \lVert P\rVert < \delta and \lVert Q\rVert < \delta, we showed 8 - 5\delta \le S(g;\dot P) \le 8 + 5\delta and 8 - 5\delta \le S(g;\dot Q) \le 8 + 5\delta. Subtracting gives \lvert S(g;\dot P) - S(g;\dot Q)\rvert \le 10\delta. Given \varepsilon > 0, choose \eta_\varepsilon := \varepsilon/20; then \lVert P\rVert, \lVert Q\rVert < \eta_\varepsilon \Rightarrow \lvert S(g;\dot P) - S(g;\dot Q)\rvert \le 10(\varepsilon/20) = \varepsilon/2 < \varepsilon. By Theorem 7.2.1, g \in \mathcal{R}[0,3].

T11

Dirichlet's function (and relatives) are not integrable

Negating the Cauchy Criterion to prove f \notin \mathcal{R}[a,b] (Bartle Example 7.2.2(b), Exercises 7.2.1–7.2.2; PYQ MAT-22 Q4, MAT-22 MCQ 17, MAT-21 MCQ 12, 16).

Negation of Cauchy Criterion (Bartle Ex 7.2.1) & Example 7.2.2(b) C7

Negation of 7.2.1: f \notin \mathcal{R}[a,b] if and only if there exists \varepsilon_0 > 0 such that for every \eta > 0 (or for every n \in \mathbb{N} with \eta = 1/n) there exist tagged partitions \dot P and \dot Q with \lVert P\rVert < \eta and \lVert Q\rVert < \eta such that \lvert S(f;\dot P) - S(f;\dot Q)\rvert \ge \varepsilon_0.

Example 7.2.2(b) (Dirichlet's function): Let f(x) := 1 if x \in [0,1] is rational and f(x) := 0 if x \in [0,1] is irrational. Then f \notin \mathcal{R}[0,1].

In plain words: to disprove integrability, pick one fixed positive gap \varepsilon_0 (like 1/2) and show that no matter how fine the mesh \eta is, you can still find two taggings \dot P, \dot Q whose sums differ by at least \varepsilon_0.

Form \dot P by choosing rational tags t_i \in I_i, giving $S(f;\dot P) = $ ?, and form \dot Q by choosing irrational tags s_i \in I_i, giving $S(f;\dot Q) = $ ?. Then \lvert S(f;\dot P) - S(f;\dot Q)\rvert \ge \varepsilon_0. By the Cauchy Criterion (7.2.1), f \notin \mathcal{R}[a,b]. ∎
Proof that Dirichlet's function is not in \mathcal{R}[0,1] (Bartle p. 209)
Take \varepsilon_0 := \tfrac12 > 0, and let \eta > 0 be arbitrary. Choose any partition P = \{[x_{i-1},x_i]\}_{i=1}^n of [0,1] with \lVert P\rVert < \eta (for instance, an equal partition with n > 1/\eta).Set the fixed gap \varepsilon_0 = 1/2 and let the opponent hand us any \eta > 0.
By the density of \mathbb{Q} in \mathbb{R}, each subinterval [x_{i-1},x_i] contains a rational tag t_i. Let \dot P be P with these rational tags; then f(t_i) = 1 for all i, so S(f;\dot P) = \sum_{i=1}^n 1\cdot(x_i - x_{i-1}) = 1 - 0 = 1. Density of rationals (P14) and telescoping sum (M01).
By the density of \mathbb{R}\setminus\mathbb{Q} in \mathbb{R}, each subinterval [x_{i-1},x_i] contains an irrational tag s_i. Let \dot Q be P with these irrational tags; then f(s_i) = 0 for all i, so S(f;\dot Q) = 0.Density of irrationals (P14).
Both \lVert P\rVert < \eta and \lVert Q\rVert < \eta, yet \lvert S(f;\dot P) - S(f;\dot Q)\rvert = \lvert 1 - 0\rvert = 1 \ge \tfrac12 = \varepsilon_0. Thus the Cauchy Criterion 7.2.1 fails, and f \notin \mathcal{R}[0,1]. ∎Negation of Theorem 7.2.1.
Worked example · h(x) = x + 1 on rationals, 0 on irrationals (Bartle Ex 7.2.2; PYQ MAT-21 MCQ 16)

Let h(x) := x + 1 for x \in [0,1] \cap \mathbb{Q} and h(x) := 0 for x \in [0,1] \setminus \mathbb{Q}. Take \varepsilon_0 := 1. For any \eta > 0, choose a partition P of [0,1] with \lVert P\rVert < \eta. If \dot P has all rational tags t_i \in [x_{i-1},x_i], then h(t_i) = t_i + 1 \ge 1 on [0,1], so S(h;\dot P) = \sum_{i=1}^n (t_i + 1)(x_i - x_{i-1}) \ge \sum_{i=1}^n 1\cdot(x_i x_{i-1}) = 1. If \dot Q has all irrational tags, then S(h;\dot Q) = 0. Hence \lvert S(h;\dot P) S(h;\dot Q)\rvert \ge 1 = \varepsilon_0, so h \notin \mathcal{R}[0,1].

Your intuition will lie to you here

"There are vastly more irrationals than rationals, so Dirichlet's function is 'almost always 0' and its integral should be 0." That is true for the Lebesgue integral (taught in postgraduate Measure Theory), which gives 0. It is false for the Riemann integral, because Riemann sums let an opponent pick rational tags in every subinterval!

The Squeeze Theorem for integrals

Proving f \in \mathcal{R}[a,b] by trapping f between two simpler integrable functions \alpha_\varepsilon \le f \le \omega_\varepsilon (Bartle Theorem 7.2.3, Example 7.2.6(b); PYQ MTS-26 Q18, MTS-22 Q6, MAT-21 Q7).

Theorem 7.2.3 · Squeeze Theorem (Bartle p. 209) · say it word for wordLet f : [a,b] \to \mathbb{R}. Then f \in \mathcal{R}[a,b] if and only if for every \varepsilon > 0 there exist functions \alpha_\varepsilon and \omega_\varepsilon in \mathcal{R}[a,b] with \alpha_\varepsilon(x) \le f(x) \le \omega_\varepsilon(x) \quad \text{for all } x \in [a,b] and such that \int_a^b (\omega_\varepsilon - \alpha_\varepsilon) < \varepsilon. In plain words: instead of wrestling with all possible tags of f, trap f between a floor function \alpha_\varepsilon \in \mathcal{R}[a,b] and a ceiling function \omega_\varepsilon \in \mathcal{R}[a,b] whose integrals are within \varepsilon of each other.
Hypotheses · Theorem 7.2.3
  • \alpha_\varepsilon, \omega_\varepsilon \in \mathcal{R}[a,b] with \alpha_\varepsilon(x) \le f(x) \le \omega_\varepsilon(x) for all x \in [a,b]if \alpha_\varepsilon, \omega_\varepsilon are not themselves integrable, trapping f between them tells us nothing
  • \int_a^b (\omega_\varepsilon - \alpha_\varepsilon) < \varepsilon holds for every \varepsilon > 0 (so \alpha_\varepsilon, \omega_\varepsilon must be adjusted as \varepsilon shrinks)Bartle Ex 7.2.4 trap: one fixed pair like \alpha(x) = -x and \omega(x) = x on [0,1] satisfies -x \le f(x) \le x, but \int_0^1 (\omega - \alpha) = \int_0^1 2x\,dx = 1, which is NOT < \varepsilon for \varepsilon \le 1. Indeed, f(x) = x on \mathbb{Q} and -x on irrationals satisfies -x \le f(x) \le x yet f \notin \mathcal{R}[0,1]!

Then \alpha_\varepsilon(x) \le f(x) \le \omega_\varepsilon(x) on [a,b], and \int_a^b (\omega_\varepsilon - \alpha_\varepsilon) = $ ? $ < \varepsilon. By the Squeeze Theorem (7.2.3), f \in \mathcal{R}[a,b]. ∎
Know(\Leftarrow) For every \varepsilon > 0, \alpha_\varepsilon \le f \le \omega_\varepsilon with \alpha_\varepsilon,\omega_\varepsilon \in \mathcal{R}[a,b] and \int_a^b(\omega_\varepsilon \alpha_\varepsilon) < \varepsilon.WantShow \lvert S(f;\dot P) S(f;\dot Q)\rvert < 3\varepsilon when \lVert P\rVert, \lVert Q\rVert < \delta_\varepsilon, and invoke the Cauchy Criterion 7.2.1.
Proof of Theorem 7.2.3 (Bartle pp. 209–210)

(\Rightarrow)

If f \in \mathcal{R}[a,b], simply take \alpha_\varepsilon := f and \omega_\varepsilon := f for all \varepsilon > 0; then \int_a^b (\omega_\varepsilon \alpha_\varepsilon) = \int_a^b 0 = 0 < \varepsilon.Trivial choice when f is already known to be integrable.

(\Leftarrow)

Let \varepsilon > 0. Since \alpha_\varepsilon, \omega_\varepsilon \in \mathcal{R}[a,b], there exists \delta_\varepsilon > 0 such that if \dot P is any tagged partition with \lVert P\rVert < \delta_\varepsilon, then \left\lvert S(\alpha_\varepsilon;\dot P) - \int_a^b \alpha_\varepsilon\right\rvert < \varepsilon \quad \text{and} \quad \left\lvert S(\omega_\varepsilon;\dot P) - \int_a^b \omega_\varepsilon\right\rvert < \varepsilon. Definition 7.1.1 applied to \alpha_\varepsilon and \omega_\varepsilon, taking the minimum of the two deltas (M08).
Unpacking these two inequalities gives \int_a^b \alpha_\varepsilon - \varepsilon < S(\alpha_\varepsilon;\dot P) and S(\omega_\varepsilon;\dot P) < \int_a^b \omega_\varepsilon + \varepsilon. Since \alpha_\varepsilon(x) \le f(x) \le \omega_\varepsilon(x) on [a,b], we have S(\alpha_\varepsilon;\dot P) \le S(f;\dot P) \le S(\omega_\varepsilon;\dot P), and therefore \int_a^b \alpha_\varepsilon - \varepsilon < S(f;\dot P) < \int_a^b \omega_\varepsilon + \varepsilon. Pointwise inequality \alpha_\varepsilon \le f \le \omega_\varepsilon preserves Riemann sums (P02).
If \dot Q is any other tagged partition with \lVert Q\rVert < \delta_\varepsilon, then the same bounds hold for S(f;\dot Q): \int_a^b \alpha_\varepsilon - \varepsilon < S(f;\dot Q) < \int_a^b \omega_\varepsilon + \varepsilon. Step 2 applied to \dot Q.
Subtracting the two inequalities and using linearity (Theorem 7.1.5) together with \int_a^b(\omega_\varepsilon \alpha_\varepsilon) < \varepsilon gives \lvert S(f;\dot P) - S(f;\dot Q)\rvert < \int_a^b \omega_\varepsilon - \int_a^b \alpha_\varepsilon + 2\varepsilon = \int_a^b (\omega_\varepsilon - \alpha_\varepsilon) + 2\varepsilon < \varepsilon + 2\varepsilon = 3\varepsilon. Two numbers in (A-\varepsilon, B+\varepsilon) are within (B-A)+2\varepsilon of each other; Theorem 7.1.5(a),(b).
Since \varepsilon > 0 is arbitrary, the Cauchy Criterion (Theorem 7.2.1) implies that f \in \mathcal{R}[a,b]. ∎Theorem 7.2.1 (replacing \varepsilon by \varepsilon/3 if desired).
Worked example · Squeeze applied to h(x)=x on [0,1] (Bartle Example 7.2.6(b))

Partition [0,1] into n equal pieces using P_n = (0, \tfrac1n, \tfrac2n, \dots, \tfrac{n-1}{n}, 1). On [\tfrac{k-1}{n}, \tfrac{k}{n}) for k=1,\dots,n-1 (and on [\tfrac{n-1}{n},1] for k=n), define step functions \alpha_n(x) := \tfrac{k-1}{n} (the minimum of x on the piece) and \omega_n(x) := \tfrac{k}{n} (the maximum of x on the piece). By Theorem 7.2.5 and P03,

\int_0^1 \alpha_n = \frac{1}{n}\left(0 + \frac{1}{n} + \cdots + \frac{n-1}{n}\right) = \frac{1}{n^2}\cdot\frac{(n-1)n}{2} = \frac{1}{2}\left(1 - \frac{1}{n}\right),

\int_0^1 \omega_n = \frac{1}{n}\left(\frac{1}{n} + \frac{2}{n} + \cdots + \frac{n}{n}\right) = \frac{1}{n^2}\cdot\frac{n(n+1)}{2} = \frac{1}{2}\left(1 + \frac{1}{n}\right).

Since \alpha_n \le h \le \omega_n and \int_0^1(\omega_n - \alpha_n) = \tfrac1n < \varepsilon for any n > 1/\varepsilon, Theorem 7.2.3 gives h \in \mathcal{R}[0,1]. Moreover, \tfrac12(1 - \tfrac1n) \le \int_0^1 h \le \tfrac12(1 + \tfrac1n) for all n \in \mathbb{N} forces \int_0^1 x\,dx = \tfrac12.

T13

Elementary step functions \varphi_J

A single flat block of height 1 on a subinterval J with endpoints c < d has integral d - c (Bartle Lemma 7.2.4, Ex 7.1.13; PYQ MAT-21 MCQ 10).

Lemma 7.2.4 · Elementary Step Functions (Bartle p. 210) · say it word for wordIf J is a subinterval of [a,b] having endpoints c < d, and if \varphi_J(x) := 1 for x \in J and \varphi_J(x) := 0 elsewhere on [a,b], then \varphi_J \in \mathcal{R}[a,b] and \int_a^b \varphi_J = d - c. In plain words: whether the subinterval J is closed [c,d], open (c,d), or half-open [c,d) or (c,d], the indicator function \varphi_J is integrable and its integral is simply the length d - c of J.
Skeleton · prove Lemma 7.2.4First let J = [c,d]. For any \dot P with \lVert P\rVert < \delta, the union of subintervals with tag in [c,d] contains [c+\delta,d-\delta] and lies inside [c-\delta,d+\delta], so (d-c) - 2\delta \le S(\varphi_{[c,d]};\dot P) \le (d-c) + 2\delta. Choose \delta_\varepsilon = \varepsilon/4 to get \lvert S - (d-c)\rvert < \varepsilon. The other three intervals (c,d), [c,d), (c,d] differ from [c,d] at at most 2 endpoints, so Theorem 7.1.3 gives the same integral d - c. ∎
Proof of Lemma 7.2.4 & Exercise 7.1.13 (Bartle p. 210)
First suppose J = [c,d] with a \le c < d \le b. Let \dot P be any tagged partition of [a,b] with \lVert P\rVert < \delta, and let \dot P_1 be the subset of subintervals whose tags belong to [c,d].Outside \dot P_1, \varphi_{[c,d]}(t_i) = 0, so S(\varphi_{[c,d]};\dot P) = S(\varphi_{[c,d]};\dot P_1).
By M10 (Exercise 7.1.5), the union U_1 of the subintervals in \dot P_1 satisfies [c+\delta, d-\delta] \subseteq U_1 \subseteq [c-\delta, d+\delta]. Since \varphi_{[c,d]}(t_i) = 1 on \dot P_1, we have (d - c) - 2\delta \le S(\varphi_{[c,d]};\dot P) \le (d - c) + 2\delta, \quad \text{so} \quad \lvert S(\varphi_{[c,d]};\dot P) - (d - c)\rvert \le 2\delta. Length of [c+\delta,d-\delta] is (d-c)-2\delta and length of [c-\delta,d+\delta] is (d-c)+2\delta.
Given \varepsilon > 0, choose \delta_\varepsilon := \varepsilon/4 > 0; then \lVert P\rVert < \delta_\varepsilon \Rightarrow \lvert S(\varphi_{[c,d]};\dot P) - (d - c)\rvert \le 2(\varepsilon/4) = \varepsilon/2 < \varepsilon. Hence \varphi_{[c,d]} \in \mathcal{R}[a,b] and \int_a^b \varphi_{[c,d]} = d - c.Definition 7.1.1 with L = d - c.
If J is (c,d), [c,d), or (c,d], then \varphi_J differs from \varphi_{[c,d]} only at one or both of the endpoints c, d (at most two points). By Theorem 7.1.3, \varphi_J \in \mathcal{R}[a,b] and \int_a^b \varphi_J = \int_a^b \varphi_{[c,d]} = d - c. ∎Changing a function at finitely many points (Theorem 7.1.3, T06).

T14

Step functions are integrable

Every step function is a linear combination of elementary step functions \varphi_{J_j} (Bartle Theorem 7.2.5, Example 7.2.6(a); PYQ MTS-26 Q5, MAT-22 Q16).

Theorem 7.2.5 · Integrability of Step Functions (Bartle p. 210, eqs. (4)–(5))If \varphi : [a,b] \to \mathbb{R} is a step function, then \varphi \in \mathcal{R}[a,b]. Moreover, if \varphi = \sum_{j=1}^m k_j\varphi_{J_j} where J_j has endpoints c_j < d_j, then \int_a^b \varphi = \sum_{j=1}^m k_j(d_j - c_j). In plain words: every step function is integrable, and its integral is the sum of (constant height k_j) \times (interval length d_j - c_j).
Hypotheses · Theorem 7.2.5
  • \varphi is a step function on [a,b]: [a,b] is the union of finitely many non-overlapping intervals J_1,\dots,J_m on each of which \varphi is constant (Definition 5.4.9)Bartle Ex 7.2.6 non-example: taking only finitely many values is NOT enough to be a step function! Dirichlet's function C7 takes only two values (0 and 1), yet the sets \mathbb{Q}\cap[0,1] and [0,1]\setminus\mathbb{Q} are not finite unions of intervals, and f \notin \mathcal{R}[0,1].
Proof of Theorem 7.2.5 (Bartle pp. 210–211)
By Definition 5.4.9 (and Exercise 7.2.5), [a,b] is the union of finitely many non-overlapping subintervals J_1, \dots, J_m with endpoints c_j \le d_j such that \varphi(x) = k_j on J_j. Disjointness of the pieces (up to single endpoints, which can be absorbed into one piece or treated as single-point intervals) allows us to write \varphi = \sum_{j=1}^m k_j\varphi_{J_j}, where each \varphi_{J_j} is an elementary step function on [a,b].Decomposition into indicator functions (M06).
By Lemma 7.2.4, each \varphi_{J_j} belongs to \mathcal{R}[a,b] and satisfies \int_a^b \varphi_{J_j} = d_j - c_j.Lemma 7.2.4 (T13).
By Theorem 7.1.5(a) and (b) (applied inductively to the finite sum of m terms, Exercise 7.1.7), the linear combination \varphi = \sum_{j=1}^m k_j\varphi_{J_j} belongs to \mathcal{R}[a,b] and \int_a^b \varphi = \sum_{j=1}^m k_j\int_a^b \varphi_{J_j} = \sum_{j=1}^m k_j(d_j - c_j). \quad \blacksquare Linearity of the integral (Theorem 7.1.5, T07).
Worked examples · Bartle Example 7.2.6(a) & Exercise 7.2.7

1. Example 7.2.6(a): The function g(x) = 2 on [0,1] and g(x) = 3 on (1,3] of Example 7.1.4(b) is the step function 2\varphi_{[0,1]} + 3\varphi_{(1,3]}, so Theorem 7.2.5 immediately gives \int_0^3 g = 2(1 - 0) + 3(3 - 1) = 8 in one line!

2. Every Riemann sum is the integral of a step function (Bartle Ex 7.2.7): Given any f : [a,b] \to \mathbb{R} and any tagged partition \dot P = \{([x_{i-1},x_i],t_i)\}_{i=1}^n, define the step function \varphi(x) := f(t_i) on [x_{i-1},x_i) for i=1,\dots,n-1 and \varphi(x) := f(t_n) on [x_{n-1},x_n]. By Theorem 7.2.5, \int_a^b \varphi = \sum_{i=1}^n f(t_i)(x_i - x_{i-1}) = S(f;\dot P).

T15

Continuous functions on [a,b] are integrable

Uniform Continuity + Max–Min + Step functions + Squeeze = Theorem 7.2.7 (PYQ MTS-25 Q18, MAT-21 Q30, MTS-22 Q19, MAT-22 MCQ 21, 23, MAT-21 MCQ 15).

Theorem 7.2.7 · Integrability of Continuous Functions (Bartle p. 212) · say it word for wordIf f : [a,b] \to \mathbb{R} is continuous on [a,b], then f \in \mathcal{R}[a,b]. In plain words: every continuous function on a closed bounded interval is Riemann integrable.
Hypotheses & Converse · Theorem 7.2.7

Monotone functions on [a,b] are integrable

Worked example · Staircase for f(x) = x^2 on [0,1] with n=4

Their difference is 0.46875 - 0.21875 = 0.25 = \frac{1-0}{4}(f(1)-f(0)), trapping the exact value \int_0^1 x^2\,dx = \tfrac13 \approx 0.3333.

Restriction and subdivision corollaries

Restricting f \in \mathcal{R}[a,b] to [c,d] \subseteq [a,b] and splitting [a,b] at m points (Bartle Corollaries 7.2.10–7.2.11, Exercises 7.2.11–7.2.13; PYQ MAT-22 Q37b, MAT-22 MCQ 24, 25, MAT-21 MCQ 18).

Corollary 7.2.10 & Corollary 7.2.11 (Bartle p. 214) · say them word for word

Corollary 7.2.10: If f \in \mathcal{R}[a,b] and if [c,d] \subseteq [a,b], then the restriction of f to [c,d] is in \mathcal{R}[c,d].

Corollary 7.2.11: If f \in \mathcal{R}[a,b] and if a = c_0 < c_1 < \cdots < c_m = b, then the restrictions of f to each subinterval [c_{i-1},c_i] are Riemann integrable and \int_a^b f = \sum_{i=1}^m \int_{c_{i-1}}^{c_i} f.

T19

Oriented integrals and additivity for any three points

Defining \int_\beta^\alpha f := -\int_\alpha^\beta f and \int_\alpha^\alpha f := 0 so additivity holds in any order (Bartle Definition 7.2.12, Theorem 7.2.13).

Definition 7.2.12 & Theorem 7.2.13 (Bartle pp. 214–215, eq. (8)) · say them word for word

Definition 7.2.12: If f \in \mathcal{R}[a,b] and if \alpha, \beta \in [a,b] with \alpha < \beta, we define \int_\beta^\alpha f := -\int_\alpha^\beta f \qquad \text{and} \qquad \int_\alpha^\alpha f := 0.

Theorem 7.2.13: If f \in \mathcal{R}[a,b] and if \alpha, \beta, \gamma are any numbers in [a,b], then \int_\alpha^\beta f = \int_\alpha^\gamma f + \int_\gamma^\beta f, in the sense that the existence of any two of these integrals implies the existence of the third and the equality.

In plain words: integrating backwards from \beta to \alpha flips the sign, integrating from \alpha to \alpha gives 0, and with those two conventions \int_\alpha^\beta f = \int_\alpha^\gamma f + \int_\gamma^\beta f holds no matter which of \alpha, \beta, \gamma is smallest, middle, or largest.
Proof of Theorem 7.2.13 (Bartle pp. 214–215)
If any two of the numbers \alpha, \beta, \gamma are equal, the formula \int_\alpha^\beta f = \int_\alpha^\gamma f + \int_\gamma^\beta f holds immediately by Definition 7.2.12 (for instance, if \gamma = \beta, it reads \int_\alpha^\beta f = \int_\alpha^\beta f + 0; if \alpha = \beta, it reads 0 = \int_\alpha^\gamma f - \int_\alpha^\gamma f).Definition 7.2.12 handles all cases with repeated points.
Assume \alpha, \beta, \gamma are all distinct. For any triple, define the cyclic sum L(\alpha, \beta, \gamma) := \int_\alpha^\beta f + \int_\beta^\gamma f + \int_\gamma^\alpha f. Since \int_\gamma^\alpha f = -\int_\alpha^\gamma f, the desired equation \int_\alpha^\beta f = \int_\alpha^\gamma f + \int_\gamma^\beta f holds if and only if L(\alpha, \beta, \gamma) = 0.Move \int_\alpha^\gamma f + \int_\gamma^\beta f to the left-hand side using \int_\alpha^\gamma f = -\int_\gamma^\alpha f.
When \alpha < \gamma < \beta, the Additivity Theorem 7.2.9 gives \int_\alpha^\beta f = \int_\alpha^\gamma f + \int_\gamma^\beta f, so L(\alpha, \beta, \gamma) = 0.Theorem 7.2.9 (T17) for the standard ordering \alpha < \gamma < \beta.
Cycling the three letters leaves the sum unchanged: L(\beta, \gamma, \alpha) = L(\gamma, \alpha, \beta) = L(\alpha, \beta, \gamma). Swapping two adjacent letters reverses the orientation of every integral and negates the sum: L(\beta, \alpha, \gamma) = L(\alpha, \gamma, \beta) = L(\gamma, \beta, \alpha) = -L(\alpha, \beta, \gamma).Commutativity of addition and \int_u^v f = -\int_v^u f.
Every one of the 6 possible orderings of three distinct numbers is obtained from \alpha < \gamma < \beta by a cyclic shift or a swap, so L(\alpha, \beta, \gamma) = 0 for all configurations of \alpha, \beta, \gamma. ∎0 and -0 are both 0.
Worked example · Numerical check for \alpha = 3, \beta = 1, \gamma = 0 (Model Paper Q9)

Let f(x) = x on [0,3], and take \alpha = 3, \beta = 1, \gamma = 0 (so \gamma < \beta < \alpha). Using \int_a^b x\,dx = \tfrac12(b^2 - a^2) and Definition 7.2.12:

  • Left-hand side: \displaystyle\int_3^1 x\,dx = -\int_1^3 x\,dx = -\tfrac12(3^2 - 1^2) = -4.
  • Right-hand side: \displaystyle\int_3^0 x\,dx + \int_0^1 x\,dx = -\int_0^3 x\,dx + \int_0^1 x\,dx = -\tfrac92 + \tfrac12 = -4. Both sides equal -4.
