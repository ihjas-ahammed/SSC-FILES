State and prove the First Form of the Fundamental Theorem of Calculus (Theorem 7.3.1).

Know firstT20T03T18P12M05
Theorem 7.3.1 · Fundamental Theorem of Calculus, First Form (Bartle p. 216)Suppose there is a finite set E in [a,b] and functions f, F : [a,b] \to \mathbb{R} such that:

(a) F is continuous on [a,b];

(b) F'(x) = f(x) for all x \in [a,b] \setminus E;

(c) f belongs to \mathcal{R}[a,b].

Then we have \int_a^b f = F(b) - F(a).
SkeletonFor E = \{a,b\}, given \varepsilon > 0 choose \delta_\varepsilon from f \in \mathcal{R}[a,b] and a partition P with \lVert P\rVert < \delta_\varepsilon. Apply the MVT 6.2.4 to F on each [x_{i-1},x_i] to get F(x_i) F(x_{i-1}) = f(u_i)(x_i - x_{i-1}); sum to get F(b) - F(a) = S(f;\dot P_u), which is within \varepsilon of \int_a^b f.
Proof of Theorem 7.3.1 (Bartle pp. 216–217)
We first prove the case where E = \{a,b\}. Let \varepsilon > 0 be given. Since f \in \mathcal{R}[a,b] by hypothesis (c), there exists \delta_\varepsilon > 0 such that if \dot P is any tagged partition of [a,b] with \lVert P\rVert < \delta_\varepsilon, then \left\lvert S(f;\dot P) - \int_a^b f\right\rvert < \varepsilon. Definition 7.1.1 (T03).
Let P = \{[x_{i-1},x_i]\}_{i=1}^n be a partition of [a,b] with \lVert P\rVert < \delta_\varepsilon. Since F is continuous on [x_{i-1},x_i] by (a) and differentiable on (x_{i-1},x_i) \subseteq [a,b]\setminus E by (b), the Mean Value Theorem 6.2.4 (P12) applied to F on [x_{i-1},x_i] implies there exists u_i \in (x_{i-1},x_i) such that F(x_i) - F(x_{i-1}) = F'(u_i)(x_i - x_{i-1}) = f(u_i)(x_i - x_{i-1}) \quad \text{for } i = 1, \dots, n. Mean Value Theorem 6.2.4 on [x_{i-1},x_i], using u_i \notin E \Rightarrow F'(u_i) = f(u_i).
Adding these n equations and telescoping the left-hand side gives F(b) - F(a) = \sum_{i=1}^n \big(F(x_i) - F(x_{i-1})\big) = \sum_{i=1}^n f(u_i)(x_i - x_{i-1}) = S(f;\dot P_u), where \dot P_u := \{([x_{i-1},x_i],u_i)\}_{i=1}^n is a tagged partition of [a,b] with \lVert P\rVert < \delta_\varepsilon.Telescoping sum (M01, M05).
Substituting S(f;\dot P_u) = F(b) - F(a) into Step 1 gives \big\lvert F(b) - F(a) \int_a^b f\big\rvert < \varepsilon. Since \varepsilon > 0 is arbitrary, \int_a^b f = F(b) - F(a).Arbitrary \varepsilon rule (P05).
General finite set E (Exercise 7.3.1): Let a = c_0 < c_1 < \cdots < c_m = b be the points of E \cup \{a,b\} in increasing order. On each [c_{k-1},c_k], F is continuous, F'(x) = f(x) on (c_{k-1},c_k), and f|_{[c_{k-1},c_k]} \in \mathcal{R}[c_{k-1},c_k] by Corollary 7.2.10. Applying the first part on each subinterval and summing via Corollary 7.2.11 gives \int_a^b f = \sum_{k=1}^m \big(F(c_k) F(c_{k-1})\big) = F(b) - F(a). ∎Corollaries 7.2.10 and 7.2.11 (T18).

Theorem 7.3.12 · Lebesgue's Integrability Criterion (Bartle p. 221)A bounded function f : [a,b] \to \mathbb{R} is Riemann integrable if and only if it is continuous almost everywhere on [a,b] (equivalently, the set D(f) of points of discontinuity of f on [a,b] is a null set).
SkeletonFor each function on [0,1], check (1) whether it is bounded, and (2) whether its discontinuity set D is a null set.

Applications (Bartle Examples 7.3.13(a)–(e)):

  • (a) Any step function \varphi on [0,1]: \varphi takes finitely many values, so it is bounded, and it is discontinuous at most at the finitely many endpoints of its constant intervals. Since every finite set is a null set, \varphi \in \mathcal{R}[0,1].
  • (b) Any monotone function f on [0,1]: f is bounded between f(0) and f(1), and by Theorem 5.6.4 (P10) its set of discontinuities is at most countable, hence a null set (T26). By Theorem 7.3.12, f \in \mathcal{R}[0,1].
  • (c) G(1/n) = 1/n (n \in \mathbb{N}), G(x) = 0 elsewhere on [0,1] (Example 7.1.4(d)): G is bounded (0 \le G(x) \le 1), continuous at x = 0 (since \lim_{x\to 0} G(x) = 0 = G(0)) and at every point outside \{1/n : n\in\mathbb{N}\}, and discontinuous precisely on the countable set D = \{1, \tfrac12, \tfrac13, \dots, \tfrac1n, \dots\}. Since every countable set is a null set, G \in \mathcal{R}[0,1].
  • (d) Dirichlet's function f on [0,1] C7: f is bounded (0 \le f \le 1), but f is discontinuous at every point of [0,1]. Since D = [0,1] is not a null set, f \notin \mathcal{R}[0,1].
  • (e) Thomae's function h on [0,1] C8: h is bounded (0 \le h \le 1), continuous at every irrational in [0,1], and discontinuous precisely on D = \mathbb{Q} \cap [0,1]. By Example 7.3.11, \mathbb{Q}\cap[0,1] is a null set, so h \in \mathcal{R}[0,1].
