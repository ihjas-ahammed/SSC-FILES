Fundamental Theorem of Calculus (First Form)

Evaluating \int_a^b f = F(b) F(a) using the Mean Value Theorem (Bartle Theorem 7.3.1; PYQ MTS-26 Q8, MAT-22 MCQ 27, MAT-21 MCQ 19).

Theorem 7.3.1 · Fundamental Theorem of Calculus, First Form (Bartle p. 216, eq. (1)) · say it word for wordSuppose there is a finite set E in [a,b] and functions f, F : [a,b] \to \mathbb{R} such that:

(a) F is continuous on [a,b];

(b) F'(x) = f(x) for all x \in [a,b] \setminus E;

(c) f belongs to \mathcal{R}[a,b].

Then we have \int_a^b f = F(b) - F(a). In plain words: if F is continuous on the whole closed interval [a,b], its derivative F' equals f except possibly at finitely many corner/endpoint exceptions E, and f is Riemann integrable, then the integral of f is simply F(b) - F(a).
Hypotheses · Theorem 7.3.1 (each one is essential!)
  • (a) F is continuous on all of [a,b] (even at points of E)let F(x) = \operatorname{sgn}(x) on [-1,1] and f(x) = 0; then F'(x) = 0 = f(x) on [-1,1]\setminus\{0\} (E=\{0\}) and f \in \mathcal{R}[-1,1], but F jumps at 0 and \int_{-1}^1 0 = 0 \ne 2 = F(1)-F(-1)
  • (b) F'(x) = f(x) for all x \in [a,b] \setminus E where E is finiteif E is uncountable (e.g. the Cantor function F on [0,1], which is continuous with F'=0 off the Cantor set), \int_0^1 0 = 0 \ne 1 = F(1)-F(0)
  • (c) f belongs to \mathcal{R}[a,b] (not automatic even when E = \varnothing!)K(x) = x^2\cos(1/x^2), K(0)=0 C19 is differentiable at every point of [0,1] (E=\varnothing), yet f = K' is unbounded near 0, so K' \notin \mathcal{R}[0,1]. Likewise H(x) = 2\sqrt x has H'(x) = 1/\sqrt x \notin \mathcal{R}[0,b]

Proof of Theorem 7.3.1 (Bartle pp. 216–217)
We first prove the case where E = \{a,b\}. Let \varepsilon > 0 be given. Since f \in \mathcal{R}[a,b] by hypothesis (c), there exists \delta_\varepsilon > 0 such that if \dot P is any tagged partition of [a,b] with \lVert P\rVert < \delta_\varepsilon, then \left\lvert S(f;\dot P) - \int_a^b f\right\rvert < \varepsilon. Definition 7.1.1 (T03) applied to f \in \mathcal{R}[a,b].
Let P = \{[x_{i-1},x_i]\}_{i=1}^n be a partition of [a,b] with \lVert P\rVert < \delta_\varepsilon. Since F is continuous on [x_{i-1},x_i] by (a) and differentiable on (x_{i-1},x_i) \subseteq [a,b]\setminus E by (b), the Mean Value Theorem 6.2.4 (P12) applied to F on [x_{i-1},x_i] provides a point u_i \in (x_{i-1},x_i) such that F(x_i) - F(x_{i-1}) = F'(u_i)(x_i - x_{i-1}) = f(u_i)(x_i - x_{i-1}) \quad \text{for } i = 1, \dots, n. Mean Value Theorem 6.2.4 on each [x_{i-1},x_i]; since u_i \in (x_{i-1},x_i) \subseteq (a,b), u_i \notin E, so F'(u_i) = f(u_i).
Adding these n equations and telescoping the left-hand side gives F(b) - F(a) = \sum_{i=1}^n \big(F(x_i) - F(x_{i-1})\big) = \sum_{i=1}^n f(u_i)(x_i - x_{i-1}) = S(f;\dot P_u), where \dot P_u := \{([x_{i-1},x_i],u_i)\}_{i=1}^n is a tagged partition of [a,b] with norm \lVert P\rVert < \delta_\varepsilon.Telescoping sum (M01, M05) and definition of Riemann sum (T02).
Substituting S(f;\dot P_u) = F(b) - F(a) into the inequality of Step 1 yields \left\lvert F(b) - F(a) - \int_a^b f\right\rvert < \varepsilon. Since \varepsilon > 0 is arbitrary, we conclude that \int_a^b f = F(b) - F(a).Arbitrary \varepsilon rule (P05).
General finite set E (Exercise 7.3.1): Let a = c_0 < c_1 < \cdots < c_m = b be the points of E \cup \{a,b\} in increasing order. On each subinterval [c_{k-1},c_k], F is continuous, F'(x) = f(x) on (c_{k-1},c_k), and f|_{[c_{k-1},c_k]} \in \mathcal{R}[c_{k-1},c_k] by Corollary 7.2.10. Applying the case just proved on each [c_{k-1},c_k] and summing via Corollary 7.2.11 gives \int_a^b f = \sum_{k=1}^m \big(F(c_k) - F(c_{k-1})\big) = F(b) - F(a). ∎Corollaries 7.2.10 and 7.2.11 (T18) plus telescoping over the m pieces.

Examples and limits of FTC 1: when it works and when it fails

Checking all three hypotheses (a), (b), (c) in practice (Bartle Examples 7.3.2(a)–(e), Exercises 7.3.2–7.3.4, 7.3.8; PYQ MAT-22 Q35, MAT-22 MCQ 28, 29, MAT-21 MCQ 20).

Examples 7.3.2(a)–(e) (Bartle pp. 217–218)

(a) \int_a^b x\,dx = \tfrac12(b^2 - a^2): F(x) := \tfrac12 x^2 has F'(x) = x for all x \in [a,b] (E = \varnothing), and f(x) = x is continuous so f \in \mathcal{R}[a,b] (7.2.7). More generally (Ex 7.3.2), H_n(x) = \frac{x^{n+1}}{n+1} gives \int_a^b x^n\,dx = \frac{b^{n+1}-a^{n+1}}{n+1} with E = \varnothing.

(b) \int_a^b \frac{1}{x^2+1}\,dx = \operatorname{Arctan} b - \operatorname{Arctan} a: G(x) := \operatorname{Arctan} x has G'(x) = \frac{1}{x^2+1} on [a,b] (E = \varnothing), which is continuous and hence in \mathcal{R}[a,b].

(c) \int_{-10}^{10} \operatorname{sgn}(x)\,dx = 0: A(x) := \lvert x\rvert is continuous on [-10,10], A'(x) = \operatorname{sgn}(x) on [-10,10]\setminus\{0\} (E = \{0\}), and \operatorname{sgn} is a step function so \operatorname{sgn} \in \mathcal{R}[-10,10] (7.2.5). FTC 1 gives A(10) - A(-10) = 10 10 = 0.

(d) Failure for H(x) := 2\sqrt x on [0,b]: H is continuous on [0,b] and H'(x) = 1/\sqrt x on (0,b) (E = \{0\}), but h = H' is unbounded on (0,b), so h \notin \mathcal{R}[0,b] (Theorem 7.1.6) no matter how h(0) is defined. Hypothesis (c) fails; FTC 1 does not apply.

(e) Failure for K(x) := x^2\cos(1/x^2) (x \in (0,1]), K(0) := 0 C19: By the Product and Chain Rules, K'(x) = 2x\cos(1/x^2) + (2/x)\sin(1/x^2) for x > 0, and at 0, \lim_{x\to 0}\frac{K(x)-K(0)}{x} = \lim_{x\to 0} x\cos(1/x^2) = 0, so K'(0) = 0. Thus K is continuous and differentiable at every point of [0,1] (E = \varnothing)! However, K' is unbounded on [0,1] (at x_m = (\frac{\pi}{2} + 2m\pi)^{-1/2} \to 0, the second term is 2/x_m \to \infty), so K' \notin \mathcal{R}[0,1] by Theorem 7.1.6 and FTC 1 does not apply.

In plain words: having an antiderivative F is never enough by itself—you must always check that F is continuous on [a,b] and that f = F' is bounded and integrable!

The indefinite integral is Lipschitz, hence continuous

Accumulating area from a to z smooths out any integrable function f \in \mathcal{R}[a,b] into a Lipschitz function F(z) = \int_a^z f (Bartle Definition 7.3.3, Theorem 7.3.4; PYQ MAT-21 Q6).

Definition 7.3.3 & Theorem 7.3.4 (Bartle p. 218, eq. (3)) · say them word for word

Definition 7.3.3: If f \in \mathcal{R}[a,b], the function defined by F(z) := \int_a^z f \quad \text{for } z \in [a,b] is called the indefinite integral of f with basepoint a.

Theorem 7.3.4: The indefinite integral F defined by F(z) := \int_a^z f is continuous on [a,b]. In fact, if \lvert f(x)\rvert \le M for all x \in [a,b], then \lvert F(z) - F(w)\rvert \le M\lvert z - w\rvert \quad \text{for all } z, w \in [a,b].

In plain words: because f \in \mathcal{R}[a,b] is bounded by M, the area added between w and z is at most height M times width \lvert z - w\rvert, so F is Lipschitz (and therefore uniformly continuous) on [a,b]—even if f itself is discontinuous!
Hypotheses · Theorem 7.3.4
  • f \in \mathcal{R}[a,b] (which by Theorem 7.1.6 automatically supplies M > 0 with \lvert f(x)\rvert \le M)no continuity of f is required here: even for Thomae C8 or \operatorname{sgn} C9, the indefinite integral F is continuous on [a,b]
Proof of Theorem 7.3.4 (Bartle p. 218)
By Corollary 7.2.10, for each z \in [a,b] the restriction of f to [a,z] is in \mathcal{R}[a,z], so F(z) = \int_a^z f is well-defined (with F(a) = \int_a^a f = 0). By Theorem 7.1.6, f is bounded on [a,b], say \lvert f(x)\rvert \le M for all x \in [a,b].Corollary 7.2.10 (T18) and Boundedness Theorem 7.1.6 (T08).
Assume w, z \in [a,b] with w \le z. By the Additivity Theorem 7.2.9, F(z) = \int_a^z f = \int_a^w f + \int_w^z f = F(w) + \int_w^z f, \quad \text{so} \quad F(z) - F(w) = \int_w^z f. Additivity Theorem 7.2.9 (T17) applied on [a,z] split at w.
Since -M \le f(x) \le M for all x \in [w,z], Theorem 7.1.5(c) and Example 7.1.4(a) give -M(z - w) \le \int_w^z f \le M(z - w), whence \lvert F(z) - F(w)\rvert = \left\lvert\int_w^z f\right\rvert \le M\lvert z - w\rvert (and by symmetry the same holds if z < w).Monotonicity of the integral (7.1.5c) and constant integral (7.1.4a).
Thus F satisfies a Lipschitz condition with constant M on [a,b], and hence F is continuous on [a,b] (given \varepsilon > 0, take \delta := \varepsilon/(M+1)). ∎Every Lipschitz function is continuous (P09).
Worked example · Changing the basepoint (Bartle Exercises 7.3.6, 7.3.9)

If c \in [a,b] and F_c(z) := \int_c^z f is the indefinite integral with basepoint c, Theorem 7.2.13 gives F_a(z) = \int_a^z f = \int_a^c f + \int_c^z f = F_a(c) + F_c(z), so F_c(z) = F_a(z) - F_a(c): changing the basepoint simply shifts F by the constant -F_a(c). Similarly, \int_x^b f = F_a(b) - F_a(x) and \int_x^{\sin x} f = F_a(\sin x) - F_a(x).

Fundamental Theorem of Calculus (Second Form)

Differentiating the area accumulator F(z) = \int_a^z f at a point c where f is continuous gives F'(c) = f(c) (Bartle Theorems 7.3.5–7.3.6; PYQ MTS-25 Q25, MAT-21 Q37a, MAT-22 Q33, MAT-22 MCQ 30, MTS-22 Q14).

Theorem 7.3.5 & Theorem 7.3.6 · FTC Second Form (Bartle p. 219) · say them word for word

Theorem 7.3.5 (Fundamental Theorem of Calculus, Second Form): Let f \in \mathcal{R}[a,b] and let f be continuous at a point c \in [a,b]. Then the indefinite integral F(z) := \int_a^z f is differentiable at c and F'(c) = f(c).

Theorem 7.3.6: If f is continuous on [a,b], then the indefinite integral F(z) := \int_a^z f is differentiable on [a,b] and F'(x) = f(x) for all x \in [a,b].

In plain words: at every point c where an integrable function f is continuous, the rate of change of the accumulated area F(z) = \int_a^z f equals the height f(c) of the curve at c. If f is continuous on the whole interval [a,b], then F is an antiderivative of f on [a,b].

The indefinite integral need not be an antiderivative

What happens to F(z) = \int_a^z f when f is not continuous: corners and ignored spikes (Bartle Examples 7.3.7(a),(b), Exercises 7.3.12–7.3.13).

Examples 7.3.7(a), (b) · When F is Not an Antiderivative (Bartle p. 219)

(a) F'(c) fails to exist at a jump C20: Let f(x) := \operatorname{sgn} x on [-1,1]. Then f \in \mathcal{R}[-1,1] and its indefinite integral with basepoint -1 is F(x) = \int_{-1}^x \operatorname{sgn} = \lvert x\rvert - 1 for x \in [-1,1] (for x < 0, \int_{-1}^x (-1) = -(x+1) = \lvert x\rvert - 1; for x \ge 0, \int_{-1}^0 (-1) + \int_0^x 1 = -1 + x = \lvert x\rvert - 1). However, since F'(0) does not exist, F is not an antiderivative of f on [-1,1].

(b) F'(c) exists everywhere but does not equal f(c) C8: Let h be Thomae's function (Example 7.1.7) and let H(x) := \int_0^x h. Since \int_0^1 h = 0 and h \ge 0, we have H(x) = 0 for all x \in [0,1]. Thus H'(x) = 0 exists at every point of [0,1], but H'(x) = 0 \ne h(x) at every rational x \in \mathbb{Q}\cap[0,1], so H is not an antiderivative of h on [0,1].

In plain words: an antiderivative of f on [a,b] must satisfy F'(x) = f(x) at every point of [a,b]. If f jumps at c, F has a corner at c; if f has isolated spikes, F ignores them so F'(c) \ne f(c) at the spikes.
Worked example · Bartle Exercise 7.3.12

Let f : [0,3] \to \mathbb{R} be f(x) = x on [0,1), f(x) = 1 on [1,2), and f(x) = x on [2,3]. Find F(x) = \int_0^x f and determine where F is differentiable:

  • For 0 \le x \le 1: F(x) = \int_0^x t\,dt = \tfrac12 x^2.
  • For 1 \le x \le 2: F(x) = \int_0^1 t\,dt + \int_1^x 1\,dt = \tfrac12 + (x - 1) = x - \tfrac12.
  • For 2 \le x \le 3: F(x) = F(2) + \int_2^x t\,dt = \tfrac32 + \tfrac12(x^2 - 4) = \tfrac12(x^2 - 1).

Notice that f is continuous at x = 1 (\lim_{x\to 1^-} x = 1 = f(1)), so by Theorem 7.3.5, F is differentiable at x = 1 with F'(1) = 1. At x = 2, f jumps from 1 to 2, so F'_-(2) = 1 \ne 2 = F'_+(2): F is differentiable on [0,3]\setminus\{2\} with F'(x) = f(x) there, and not differentiable at x = 2.

The Substitution Theorem

Reversing the Chain Rule to change variables in a definite integral (Bartle Theorem 7.3.8, Examples 7.3.9(a),(b), Exercises 7.3.17–7.3.19; PYQ MTS-25 Q6, MAT-22 Q18, MAT-21 Q19, MAT-22 MCQ 19, 26).

Theorem 7.3.8 · Substitution Theorem (Bartle p. 220, eq. (5)) · say it word for wordLet J := [\alpha,\beta] and let \varphi : J \to \mathbb{R} have a continuous derivative on J. If f : I \to \mathbb{R} is continuous on an interval I containing \varphi(J), then \int_\alpha^\beta f(\varphi(t))\,\varphi'(t)\,dt = \int_{\varphi(\alpha)}^{\varphi(\beta)} f(x)\,dx. Null sets and "almost everywhere"

When is a set of bad points small enough for the Riemann integral to ignore? (Bartle Definition 7.3.10, Example 7.3.11; PYQ MTS-25 Q7, MTS-26 Q7, MTS-22 MCQ 10).

Definition 7.3.10 · Null Set and Almost Everywhere (Bartle p. 220, eq. (6)) · say it word for word

(a) A set Z \subseteq \mathbb{R} is said to be a null set if for every \varepsilon > 0 there exists a countable collection \{(a_k,b_k)\}_{k=1}^\infty of open intervals such that Z \subseteq \bigcup_{k=1}^\infty (a_k,b_k) \qquad \text{and} \qquad \sum_{k=1}^\infty (b_k a_k) \le \varepsilon.

(b) If Q(x) is a statement about the point x \in I, we say that Q(x) holds almost everywhere on I (or for almost every x \in I), written Q(x) for a.e. x \in I, if there exists a null set Z \subseteq I such that Q(x) holds for all x \in I \setminus Z.

In plain words: a set Z is a null set (has "length zero") if, whatever tiny total length \varepsilon > 0 you are handed, you can cover all of Z with a sequence of open intervals whose lengths add up to at most \varepsilon.
Proof of Example 7.3.11 · \mathbb{Q}\cap[0,1] is a null set (Bartle p. 221; PYQ MTS-25 Q7)
The set \mathbb{Q}_1 := \mathbb{Q} \cap [0,1] is countable (P13), so its elements can be enumerated as a sequence r_1, r_2, \dots, r_k, \dots.Countability of the rationals (P13).
Let \varepsilon > 0 be given. For each k \in \mathbb{N}, let J_k be the open interval J_k := \left(r_k - \frac{\varepsilon}{2^{k+1}},\, r_k + \frac{\varepsilon}{2^{k+1}}\right). Then J_k contains r_k and has length b_k - a_k = 2\cdot\dfrac{\varepsilon}{2^{k+1}} = \dfrac{\varepsilon}{2^k}.The \varepsilon/2^k geometric covering trick (M07).
The union \bigcup_{k=1}^\infty J_k of this countable collection of open intervals contains every point of \mathbb{Q}_1, and the sum of the lengths is \sum_{k=1}^\infty (b_k - a_k) = \sum_{k=1}^\infty \frac{\varepsilon}{2^k} = \varepsilon\sum_{k=1}^\infty \frac{1}{2^k} = \varepsilon\cdot 1 = \varepsilon. Since \varepsilon > 0 is arbitrary, \mathbb{Q}_1 = \mathbb{Q} \cap [0,1] is a null set. ∎Geometric series \sum_{k=1}^\infty 1/2^k = 1 (P03) and Definition 7.3.10(a).
Result · Four key properties of null sets (Bartle p. 221; PYQ MTS-22 MCQ 10)
  • 1. Subsets: Every subset A \subseteq Z of a null set Z is a null set (any open cover of Z also covers A).
  • 2. Unions: The union Z_1 \cup Z_2 of two null sets (or countably many null sets) is a null set (cover Z_1 with total length \le \varepsilon/2 and Z_2 with total length \le \varepsilon/2).
  • 3. Every countable set is null: The exact same \varepsilon/2^k argument of Example 7.3.11 shows that every finite or countably infinite set in \mathbb{R} is a null set.
  • 4. Not every null set is countable (MTS-22 MCQ 10 trap!): The Cantor set (Bartle Definition 11.1.10) is an uncountable null set in [0,1]. On the other hand, a non-degenerate interval [a,b] (a < b) is never a null set (its length is b - a > 0).

Theorem 7.3.18 · Taylor's Theorem with the Remainder (Bartle p. 223, eqs. (8)–(9)) · say it word for wordSuppose that f', \dots, f^{(n)}, f^{(n+1)} exist on [a,b] and that f^{(n+1)} \in \mathcal{R}[a,b]. Then we have f(b) = f(a) + \frac{f'(a)}{1!}(b - a) + \cdots + \frac{f^{(n)}(a)}{n!}(b - a)^n + R_n, where the remainder is given by R_n = \frac{1}{n!}\int_a^b f^{(n+1)}(t)\,(b - t)^n\,dt. In plain words: if you integrate R_n = \frac{1}{n!}\int_a^b f^{(n+1)}(t)(b-t)^n\,dt by parts n times, each step peels off one Taylor term -\frac{f^{(k)}(a)}{k!}(b-a)^k until only R_0 = \int_a^b f'(t)\,dt = f(b) - f(a) remains.
Hypotheses · Theorem 7.3.18
  • f', f'', \dots, f^{(n+1)} exist at every point of [a,b] and f^{(n+1)} \in \mathcal{R}[a,b]for k \le n, f^{(k)} is differentiable on [a,b] (since f^{(k+1)} exists), hence continuous on [a,b] (Theorem 6.1.2) and in \mathcal{R}[a,b] (Theorem 7.2.7); only the top derivative f^{(n+1)} needs the extra assumption f^{(n+1)} \in \mathcal{R}[a,b]
Proof of Theorem 7.3.18 (Bartle p. 223, with misprint corrected)
Since f^{(n)} and t \mapsto (b-t)^n/n! are differentiable on [a,b] with derivatives f^{(n+1)} \in \mathcal{R}[a,b] and -(b-t)^{n-1}/(n-1)! \in \mathcal{R}[a,b] (continuous), we apply Integration by Parts (Theorem 7.3.17) to R_n with F(t) := f^{(n)}(t) (f(t) = F'(t) = f^{(n+1)}(t)) and G(t) := (b-t)^n/n! (g(t) = G'(t) = -(b-t)^{n-1}/(n-1)!).Check hypotheses of Theorem 7.3.17 (T31) for F(t) = f^{(n)}(t) and G(t) = (b-t)^n/n!.
Since G(b) = (b-b)^n/n! = 0 and G(a) = (b-a)^n/n!, Theorem 7.3.17 gives R_n = \left[\frac{f^{(n)}(t)(b-t)^n}{n!}\right]_{t=a}^{t=b} - \int_a^b f^{(n)}(t)\left(-\frac{(b-t)^{n-1}}{(n-1)!}\right)dt = -\frac{f^{(n)}(a)}{n!}(b-a)^n + \frac{1}{(n-1)!}\int_a^b f^{(n)}(t)(b-t)^{n-1}\,dt. That is, R_n = -\dfrac{f^{(n)}(a)}{n!}(b-a)^n + R_{n-1}, where R_{n-1} = \dfrac{1}{(n-1)!}\int_a^b f^{(n)}(t)(b-t)^{n-1}\,dt.Evaluate the boundary term at t=b and t=a. (Bartle misprint note: the first displayed integral on p. 223 prints (b-a)^{n-1} by mistake; the variable of integration is t, so it must be (b-t)^{n-1}, as Bartle's next line confirms.)
For each k = n, n-1, \dots, 1, f^{(k)} is continuous on [a,b] (since f^{(k+1)} exists) and therefore belongs to \mathcal{R}[a,b]. Repeating this integration by parts n times yields R_{k} = -\frac{f^{(k)}(a)}{k!}(b-a)^k + R_{k-1} \quad \text{for } k = n, n-1, \dots, 1, down to R_0 = \int_a^b f'(t)\,dt = f(b) - f(a) by the First Form of the Fundamental Theorem 7.3.1.Induction backwards from k=n to k=1, ending with FTC 1 (T20) for R_0 = \int_a^b f'(t)\,dt.
Rearranging R_{k-1} = \frac{f^{(k)}(a)}{k!}(b-a)^k + R_k from k=1 to k=n gives f(b) - f(a) = R_0 = \frac{f'(a)}{1!}(b-a) + R_1 = \cdots = \sum_{k=1}^n \frac{f^{(k)}(a)}{k!}(b-a)^k + R_n, which is Taylor's formula (8). ∎Back-substitute R_1, R_2, \dots, R_n into f(b) = f(a) + R_0.
Check yourself · Verify Theorem 7.3.18 for f(x) = e^x, a = 0, b = 1, n = 1 (Q36)
Compute the Taylor polynomial f(0) + f'(0)(1-0) and the integral remainder R_1 = \int_0^1 e^t(1-t)\,dt, and check their sum.
f(0) + f'(0)(1) = 1 + 1 = 2. By parts with F(t)=e^t, G(t)=1-t: R_1 = \big[e^t(1-t)\big]_0^1 - \int_0^1 e^t(-1)\,dt = (0 - 1) + (e - 1) = e - 2. Sum: 2 + (e - 2) = e = f(1).

INTERLEAVED DRILL · WHICH TOOL?

"Which tool?" mixed recognition drill

In the exam, questions are not labelled by section. Read each prompt, name the exact theorem/tool and the hypotheses to check, then uncover the answer.

Drill 1 · Integrability of a messy bounded function
Show that g(x) = \sin(1/x) (x \in (0,1]), g(0) = 0 is in \mathcal{R}[0,1]. Which two tools work?
Tool A (Lebesgue's Criterion 7.3.12, T27): \lvert g(x)\rvert \le 1 (bounded) and g is discontinuous only at \{0\} (a 1-point null set). Tool B (Bartle Ex 7.2.11, T18): \lvert g\rvert \le 1 on [0,1] and g is continuous (hence integrable by 7.2.7) on [c,1] for every c \in (0,1).
Drill 2 · Disproving integrability
Show that H(1/k) = k (k \in \mathbb{N}), 0 elsewhere on [0,1] is not in \mathcal{R}[0,1]; then show h(x) = x + 1 on \mathbb{Q}, 0 on irrationals is not in \mathcal{R}[0,1].
For H: Boundedness Theorem 7.1.6 (T08)—H is unbounded (H(1/k)=k\to\infty), so H\notin\mathcal{R}[0,1] in one line! For h: h is bounded (0\le h\le 2), so 7.1.6 does not apply; use the Cauchy Criterion negation (7.2.1, T11) with \varepsilon_0 = 1 (rational tags give S \ge 1, irrational tags give S = 0), or Lebesgue 7.3.12 (T27) (D = [0,1], not null).
Drill 3 · FTC 1 vs Substitution at a singular endpoint
Compare \int_1^4 \frac{\sin\sqrt t}{\sqrt t}\,dt and \int_0^4 \frac{\sin\sqrt t}{\sqrt t}\,dt. Why do they need different theorems?
On [1,4], \varphi(t) = \sqrt t has \varphi'(t) = \frac{1}{2\sqrt t} continuous on [1,4], so Substitution (Theorem 7.3.8, T25) works directly. On [0,4], \varphi'(0) does not exist, so 7.3.8 fails; instead use Ex 7.2.11 (T18) for integrability (\lvert\sin\sqrt t/\sqrt t\rvert \le 1) and FTC 1 (Theorem 7.3.1, T20) with F(t) = -2\cos\sqrt t and exceptional set E = \{0\}.
Drill 4 · Derivative of an integral with variable limits
Find F'(x) for F(x) = \int_{x^2}^x \sqrt{1+t^2}\,dt. Which theorems do you cite?
Split via Theorem 7.2.13 (T19) as F(x) = G(x) G(x^2) where G(u) = \int_0^u \sqrt{1+t^2}\,dt. Cite FTC 2 (Theorem 7.3.6, T23) (since \sqrt{1+t^2} is continuous) to get G'(u) = \sqrt{1+u^2}, and the Chain Rule 6.1.6 (P11) on G(x^2) to get F'(x) = \sqrt{1+x^2} - 2x\sqrt{1+x^4}.
Drill 5 · Integral equals zero on all subintervals
If f : [0,1] \to \mathbb{R} is continuous and \int_0^x f = \int_x^1 f for all x \in [0,1], how do you prove f \equiv 0? What if instead f \ge 0 is continuous and \int_a^b f = 0?
First prompt: put F(x) = \int_0^x f; by Additivity 7.2.9 (T17), F(x) = F(1) - F(x) \Rightarrow F(x) = \tfrac12 F(1) constant, then differentiate via FTC 2 (7.3.6, T23) to get f(x) = F'(x) = 0. Second prompt: only one integral \int_a^b f = 0 is given, so use continuity at c + Monotonicity 7.1.5(c) + Lemma 7.2.4 (T15, Ex 7.2.8): if f(c) > 0, then f > \tfrac12 f(c) on some interval J of length \ell > 0, giving \int_a^b f \ge \tfrac12 f(c)\ell > 0.
