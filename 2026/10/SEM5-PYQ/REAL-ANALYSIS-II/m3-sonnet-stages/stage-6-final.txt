math">M05</span></div> <div class="box def"><span class="lab">Theorem 7.3.1 ·
Fundamental Theorem of Calculus, First Form (Bartle p. 216)</span>Suppose there is a finite
set E in [a,b] and functions f, F : [a,b] \to \mathbb{R} such that: <p>(a) F is continuous on
[a,b];</p> <p>(b) F'(x) = f(x) for all x \in [a,b] \setminus E;</p> <p>(c) f belongs to
\mathcal{R}[a,b].</p> Then we have
\int_a^b f = F(b) - F(a).
</div> <div class="box skel"><span class="lab">Skeleton</span>For E = \{a,b\}, given
\varepsilon > 0 choose \delta_\varepsilon from f \in \mathcal{R}[a,b] and a partition P with \lVert
P\rVert < \delta_\varepsilon. Apply the MVT 6.2.4 to F on each [x_{i-1},x_i] to get F(x_i) -
F(x_{i-1}) = f(u_i)(x_i - x_{i-1}); sum to get F(b) - F(a) = S(f;\dot P_u), which is within \varepsilon
of \int_a^b f.</div> <div class="box proof"><span class="lab">Proof of Theorem 7.3.1 (Bartle
pp. 216–217)</span> <div class="steps"> <div class="step">We first prove the case where E =
\{a,b\}. Let \varepsilon > 0 be given. Since f \in \mathcal{R}[a,b] by hypothesis (c), there exists
\delta_\varepsilon > 0 such that if \dot P is any tagged partition of [a,b] with \lVert P\rVert <
\delta_\varepsilon, then
\left\lvert S(f;\dot P) - \int_a^b f\right\rvert < \varepsilon.
<span class="why">Definition 7.1.1 (T03).</span></div> <div class="step">Let P =
\{[x_{i-1},x_i]\}_{i=1}^n be a partition of [a,b] with \lVert P\rVert < \delta_\varepsilon. Since F is
continuous on [x_{i-1},x_i] by (a) and differentiable on (x_{i-1},x_i) \subseteq [a,b]\setminus E by
(b), the Mean Value Theorem 6.2.4 (P12) applied to F on [x_{i-1},x_i] implies there exists u_i \in
(x_{i-1},x_i) such that
F(x_i) - F(x_{i-1}) = F'(u_i)(x_i - x_{i-1}) = f(u_i)(x_i - x_{i-1}) \quad \text{for } i = 1, \dots, n.
<span class="why">Mean Value Theorem 6.2.4 on [x_{i-1},x_i], using u_i \notin E \Rightarrow
F'(u_i) = f(u_i).</span></div> <div class="step">Adding these n equations and telescoping the
left-hand side gives
F(b) - F(a) = \sum_{i=1}^n \big(F(x_i) - F(x_{i-1})\big) = \sum_{i=1}^n f(u_i)(x_i - x_{i-1}) =
S(f;\dot P_u),
where \dot P_u := \{([x_{i-1},x_i],u_i)\}_{i=1}^n is a tagged partition of [a,b] with \lVert P\rVert <
\delta_\varepsilon.<span class="why">Telescoping sum (M01, M05).</span></div> <div
class="step">Substituting S(f;\dot P_u) = F(b) - F(a) into Step 1 gives \big\lvert F(b) - F(a) -
\int_a^b f\big\rvert < \varepsilon. Since \varepsilon > 0 is arbitrary, \int_a^b f = F(b) - F(a).<span
class="why">Arbitrary \varepsilon rule (P05).</span></div> <div class="step"><b>General finite
set E (Exercise 7.3.1):</b> Let a = c_0 < c_1 < \cdots < c_m = b be the points of E \cup \{a,b\} in
increasing order. On each [c_{k-1},c_k], F is continuous, F'(x) = f(x) on (c_{k-1},c_k), and
f|_{[c_{k-1},c_k]} \in \mathcal{R}[c_{k-1},c_k] by Corollary 7.2.10. Applying the first part on each
subinterval and summing via Corollary 7.2.11 gives \int_a^b f = \sum_{k=1}^m \big(F(c_k) -
F(c_{k-1})\big) = F(b) - F(a). <span class="qed">∎</span><span class="why">Corollaries 7.2.10
and 7.2.11 (T18).</span></div> </div> </div> <p class="marking">Marks: statement with
(a),(b),(c) 1.5 · MVT step on [x_{i-1},x_i] 2 · telescoping to S(f;\dot P_u) and conclusion 1.5 ·
general finite E 1.</p> </section>

class="lab">Theorem 7.3.12 · Lebesgue's Integrability Criterion (Bartle p. 221)</span>A
bounded function f : [a,b] \to \mathbb{R} is Riemann integrable if and only if it is continuous
almost everywhere on [a,b] (equivalently, the set D(f) of points of discontinuity of f on [a,b] is a
null set).</div> <div class="box skel"><span class="lab">Skeleton</span>For each function on
[0,1], check (1) whether it is bounded, and (2) whether its discontinuity set D is a null set.</div>
<p><b>Applications (Bartle Examples 7.3.13(a)–(e)):</b></p> <ul> <li><b>(a) Any step function
\varphi on [0,1]:</b> \varphi takes finitely many values, so it is bounded, and it is discontinuous
at most at the finitely many endpoints of its constant intervals. Since every finite set is a null set,
\varphi \in \mathcal{R}[0,1].</li> <li><b>(b) Any monotone function f on [0,1]:</b> f is bounded
between f(0) and f(1), and by Theorem 5.6.4 (P10) its set of discontinuities is at most countable,
hence a null set (T26). By Theorem 7.3.12, f \in \mathcal{R}[0,1].</li> <li><b>(c) G(1/n) = 1/n (n
\in \mathbb{N}), G(x) = 0 elsewhere on [0,1] (Example 7.1.4(d)):</b> G is bounded (0 \le G(x) \le
1), continuous at x = 0 (since \lim_{x\to 0} G(x) = 0 = G(0)) and at every point outside \{1/n :
n\in\mathbb{N}\}, and discontinuous precisely on the countable set D = \{1, \tfrac12, \tfrac13,
\dots, \tfrac1n, \dots\}. Since every countable set is a null set, G \in \mathcal{R}[0,1].</li>
<li><b>(d) Dirichlet's function f on [0,1] <span class="cx">C7</span>:</b> f is bounded (0 \le f
\le 1), but f is discontinuous at <b>every</b> point of [0,1]. Since D = [0,1] is not a null set, f
\notin \mathcal{R}[0,1].</li> <li><b>(e) Thomae's function h on [0,1] <span
class="cx">C8</span>:</b> h is bounded (0 \le h \le 1), continuous at every irrational in [0,1],
and discontinuous precisely on D = \mathbb{Q} \cap [0,1]. By Example 7.3.11,
\mathbb{Q}\cap[0,1] is a null set, so h \in \mathcal{R}[0,1].</li> </ul> <p class="marking">Marks:

<p><b>Theorem 7.3.5:</b> Let f \in \mathcal{R}[a,b] and let f be continuous at a point c \in [a,b].
Then the indefinite integral F(z) := \int_a^z f (z \in [a,b]) is differentiable at c and F'(c) = f(c).</p>
<p><b>Theorem 7.3.6:</b> If f is continuous on [a,b], then the indefinite integral F(z) := \int_a^z
f is differentiable on [a,b] and F'(x) = f(x) for all x \in [a,b].</p></div> <div class="box
skel"><span class="lab">Skeleton</span>For c \in [a,b), given \varepsilon > 0 use continuity of f
at c to find \eta_\varepsilon > 0 so c \le x < c + \eta_\varepsilon \Rightarrow f(c) - \varepsilon <
f(x) < f(c) + \varepsilon. For 0 < h < \eta_\varepsilon, write F(c+h) - F(c) = \int_c^{c+h} f,
sandwich between (f(c)-\varepsilon)h and (f(c)+\varepsilon)h, divide by h, and repeat for h <
0.</div> <div class="box proof"><span class="lab">Proof of Theorems 7.3.5 and 7.3.6 (Bartle
pp. 219–220)</span> <div class="steps"> <div class="step">Suppose first that c \in [a,b) and
consider the right-hand derivative of F at c. Since f is continuous at c, given \varepsilon > 0
there exists \eta_\varepsilon > 0 such that if c \le x < c + \eta_\varepsilon (x \in [a,b]), then
f(c) - \varepsilon < f(x) < f(c) + \varepsilon.
<span class="why">Definition 5.1.1 of continuity of f at c.</span></div> <div class="step">Let h
satisfy 0 < h < \eta_\varepsilon (with c + h \le b). By the Additivity Theorem 7.2.9 (and Corollary
7.2.10), f is integrable on [a,c], [a,c+h], and [c,c+h], and
F(c + h) - F(c) = \int_a^{c+h} f - \int_a^c f = \int_c^{c+h} f.
<span class="why">Additivity Theorem 7.2.9 (T17).</span></div> <div class="step">On the
interval [c, c+h], the inequality of Step 1 holds, so Theorem 7.1.5(c) and Example 7.1.4(a) yield
(f(c) - \varepsilon)\cdot h \le F(c + h) - F(c) = \int_c^{c+h} f \le (f(c) + \varepsilon)\cdot h.
<span class="why">Monotonicity of the integral (Theorem 7.1.5(c), T07) and constant integral
\int_c^{c+h} k = kh (T05).</span></div> <div class="step">Dividing this inequality by h > 0 and
subtracting f(c) gives
\left\lvert\frac{F(c + h) - F(c)}{h} - f(c)\right\rvert \le \varepsilon.
Since \varepsilon > 0 is arbitrary, the right-hand limit is \lim_{h\to 0^+} \dfrac{F(c+h) - F(c)}{h} =
f(c).<span class="why">Definition of right-hand derivative.</span></div> <div class="step">If c
\in (a,b], the left-hand limit is proved identically: for -\eta_\varepsilon < h < 0 (where
f(c)-\varepsilon < f(x) < f(c)+\varepsilon on (c-\eta_\varepsilon,c]), on [c+h,c] of length -h > 0 we
have (f(c)-\varepsilon)(-h) \le \int_{c+h}^c f = F(c) - F(c+h) \le (f(c)+\varepsilon)(-h); dividing by -h
> 0 gives \left\lvert\frac{F(c+h)-F(c)}{h} - f(c)\right\rvert \le \varepsilon, so \lim_{h\to 0^-}
\frac{F(c+h)-F(c)}{h} = f(c). Hence F is differentiable at c and F'(c) = f(c).<span

every point of [a,b], then f \in \mathcal{R}[a,b] by Theorem 7.2.7, and applying Theorem 7.3.5 at
each x \in [a,b] shows that F is differentiable on [a,b] with F'(x) = f(x) for all x \in [a,b]. <span
class="qed">∎</span><span class="why">Pointwise application of Theorem 7.3.5 across [a,b].
(Note: MAT-22 Q33 states Theorem 7.3.5 in full.)</span></div> </div> </div> <p><b>Example
where F fails to be differentiable at 0 (Example 7.3.7(a), <span class="cx">C20</span>):</b>

indefinite integral with basepoint -1 is F(x) = \int_{-1}^x \operatorname{sgn} = \lvert x\rvert - 1. At
c = 0 (where f is discontinuous), F'_-(0) = -1 \ne +1 = F'_+(0), so F is not differentiable at 0.</p>
