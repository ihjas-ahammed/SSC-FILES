How this paper works

The syllabus gives this module 8 marks. This paper gives twice that (16 marks). Every file format named in unit 17 (csv, xls, tab, dat) is tested.

No past paper of this exact course was found, so the questions use similar CUFYUGP papers. PYQ = adapted from a similar paper, named with its code, term and question number. Instructor = written from the syllabus, with no close match.

Similar papers used: MAT4CJ205 Python and SageMath (Apr 2026); CSC1MN106 Computer Fundamentals with MS Excel, SPSS (Nov 2024).
