Four trig identities

Plus One Maths Ch 3. These are the only identities the module uses.

Maths tool
(a)$\cos(A+B) = \cos A\cos B - \sin A\sin B$ (b)$\cos A + \cos B = 2\cos\dfrac{A+B}{2}\cos\dfrac{A-B}{2}$ (c)$2\cos A\cos B = \cos(A-B) + \cos(A+B)$ (d)$1 + \cos\delta = 2\cos^2\dfrac{\delta}{2}$, $\;1-\cos\delta = 2\sin^2\dfrac\delta2$
Where each one is used

(a) splits $\cos(\omega t + \theta)$ into a $\cos\omega t$ part and a $\sin\omega t$ part (T1).

(b) adds two equal waves in one line (T4).

(c) turns a product of two waves into a sum, so we can average it (T4).

(d) turns $2I_0(1+\cos\delta)$ into $4I_0\cos^2(\delta/2)$ (T4).

Check yourself
Use (b): $\cos\omega t + \cos(\omega t + \pi/2) = ?$
$2\cos\frac{\pi}{4}\cos(\omega t + \frac\pi4) = \sqrt2\cos(\omega t + \frac\pi4)$: amplitude √2, not 2.
M2

Waves as arrows (phasors)

A picture that gives the T1 result without algebra.

{{fig:phasor_add}}
The ideaDraw each wave as an arrow: length = amplitude, angle = phase. Two waves of the same frequency add like arrows placed head to tail. The resultant arrow gives the amplitude (its length) and the phase (its angle) of the sum.
Arrows $a_1$ and $a_2$ with angle δ between their directions. The triangle has the outside angle δ, so the inside angle is $\pi - \delta$Angles on a straight line add to π.
Cosine rule: $A^2 = a_1^2 + a_2^2 - 2a_1a_2\cos(\pi - \delta) = a_1^2 + a_2^2 + 2a_1a_2\cos\delta$$\cos(\pi - \delta) = -\cos\delta$.
Check yourself
$a_1 = a_2 = a$, δ = 90°. Resultant?
$A^2 = a^2 + a^2 + 0 = 2a^2$, so $A = \sqrt2\,a$ (same as M1 check).

M4

Units and powers of ten

Most wrong answers in numericals are unit mistakes.

1 Å$10^{-10}$ m $= 10^{-8}$ cm 1 nm$10^{-9}$ m $= 10$ Å 1 μm$10^{-6}$ m $= 10^{-4}$ cm 5000 Å$= 500$ nm $= 5\times10^{-7}$ m $= 5\times10^{-5}$ cm 589 nm$= 5890$ Å $= 5.89\times10^{-7}$ m
How to do every numerical

1. Write the formula in symbols. 2. Convert every length to the same unit (all m, or all cm). 3. Put in numbers. 4. Ask: is the size sensible? (Fringe widths: fractions of a mm. Film thicknesses: about $10^{-5}$ cm.)

Check yourself
$\lambda = 6\times10^{-5}$ cm, $D = 100$ cm, $d = 0.1$ cm. β?
$6\times10^{-5}\times100/0.1 = 0.06$ cm $= 0.6$ mm. Sensible.
