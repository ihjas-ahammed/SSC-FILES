MODULE 3: MODEL ANSWERS
Key steps for checking your work

Section A. 1. No. $(1, 2)(2, 3) = (1, 2, 3)$ and $(2, 3)(1, 2) = (1, 3, 2)$ (Table 4.15). 2. True. Each left coset has $|H|$ elements and the cosets partition $G$ (Definition 10.10; Theorem 10.7). 3. $\{3, 4, 5\}$ (Section 8, orbits before Example 8.18; the cycle $(3, 4, 5)$ contains $3$). 4. $3$. $A_3 = \{\iota, (1, 2, 3), (1, 3, 2)\}$ (Theorem 8.24).

Section B. 5. $(1, 2, 3, 4, 5) = (1, 5)(1, 4)(1, 3)(1, 2)$, read right to left (8.14). 6. The orbits are $\{1, 4\}$ and $\{2, 3, 5\}$ (orbits in Section 8 and Section 4). 7. $aH = \{ah \mid h \in H\}$ (Definition 10.2). 8. $\langle 4 \rangle = \{0, 4, 8\}$ has $3$ elements, so the index is $12/3 = 4$ (Definition 10.10; Theorem 10.7). 9. $(1, 2, 3)$ is even and $(4, 5)$ is odd, so the product is odd: $(1, 2, 3)$ is a product of two transpositions, $(4, 5)$ is one transposition (Definition 8.22).

Section C. 10. $a \sim_L b$ if and only if $a^{-1}b \in H$ is reflexive, symmetric and transitive (Theorem 10.1). Each class is $aH$, and each $x$ lies in $xH$, so the classes cover $G$ and are disjoint. 11. $f(h) = ah$ is one-to-one by left cancellation and onto $aH$ by definition (Theorem 10.6). 12. If $a^{-1}b \in K$ then $\phi(a) = \phi(b)$ because $\phi(a^{-1}b) = e$. If $\phi(a) = \phi(b)$ then $\phi(a^{-1}b) = \phi(a)^{-1}\phi(b) = e$, so $a^{-1}b \in K$ (Theorem 10.17). 13. $\operatorname{sgn}(\sigma\mu) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\mu)$: if $\sigma$ and $\mu$ are products of $p$ and $q$ transpositions, $\sigma\mu$ is a product of $p + q$ transpositions (Section 8, sign of a permutation; Theorem 8.24). 14. A $k$-cycle is a product of $k - 1$ transpositions (8.14), so it is even exactly when $k - 1$ is even, that is when $k$ is odd.

Section D. 15. Let $n = |G|$ and $m = |H|$. The cosets of $H$ partition $G$ and each has $m$ elements (Theorem 10.6), so $n = rm$ where $r$ is the number of cosets (Theorem 10.7). For $a \in G$, $\langle a \rangle$ has order $m$ and $m \mid n$ (Theorem 10.9). 16. Write $\sigma$ as cycles of lengths $\ell_1, \dots, \ell_r$. A cycle of length $\ell$ is a product of $\ell - 1$ transpositions (8.14), so $\operatorname{sgn}(\sigma) = (-1)^{\sum(\ell_i - 1)}$, and $(-1)^{\ell_i - 1} = -1$ exactly when $\ell_i$ is even. So $\sigma$ is odd exactly when the number of even-length cycles is odd (Theorems 8.19 and 8.24).
