# Day 8 maths exam runtime

Read skills/00-START-HERE.md and ../source/prompt.md first.
The two canonical data files are under ../data/, with exact mirrors in
../source/data/. Author educational content directly, never with a generator.

This is an isolated copy of the updated exam runtime. The explicit exam
scope selects only 3-mark original question cards for editable flip recall.
Higher-mark questions, model answers and maths/figures keep the reading layout.
The always-visible /70 meter is computed from rubric eval states, with section
ceilings 24/36/10 and best-one Section C. It is separate from match goals.
Mathematics inside options uses MathJax, with TeX comparisons protected before
HTML parsing. Android starts with the same notch controls as desktop.
Real Analysis uses Model Paper 5; Algebra uses Model Paper 4. The full proofs
are authored in info/math steps, with one animated equality calculation each.

Run from the parent folder using README.md commands. Pass --app for each paper's
separate hosted directory. Builds in dist/ are additional distributable copies,
not an editable content source. Keep source/skills and this skills folder equal.
