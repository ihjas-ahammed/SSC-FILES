# Mathematical figures

Use a figure only when it clarifies an argument. It never substitutes for the
proof. The shrinking-spike graph is piecewise linear, so exact polylines suffice;
no physics-only 100-point sampling quota applies to a mathematical triangle.
Keep analytic formulas in MathJax and group tables in a scrollable math card.

SVG: one svg element with viewBox "0 0 260 180", role img and a descriptive
aria-label. Use palette classes f,s,ok,lk,gk,h,hk,t,i, no hardcoded colors,
scripts, links, images, event handlers or external fonts. Keep labels inside
the viewBox and distinguish axes/parameters. Verify XML and visible geometry.
Write the diagram directly yourself; do not generate educational SVG data.
