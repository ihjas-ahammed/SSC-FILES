# sent-optics: Optics PYQ generation bundle

Give this whole folder to one model. Every file it needs is inside this folder.
The model returns ONE file: `optics-pyq.json`. The rules are in PROMPT.md.

## Contents

- PROMPT.md: the task, the card format and the rules. Read it first.
- originals/: the Optics previous-year papers as downloaded (PDF). Papers from 2018,
  Nov 2019 and Nov 2022 have no text layer: read those PDFs directly.
- textbook/: textbook cutouts for units 1–4 and 17–22. Units 5–16 are not in this bundle.
- syllabus/syllabus.pdf: the Optics syllabus (scope check).
- reference/units-optics.json: the 22 Optics units (u = unit number, module = 1–4).
- text/: text extracted from originals/ (only the papers that have a text layer).
