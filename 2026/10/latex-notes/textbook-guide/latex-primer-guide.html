1. The basics

Syllabus unit 1 · Primer pages 1–14

1.1 What is LaTeX?

In plain words. LaTeX is a typesetting program. You do not type into a page and see the result at once, as in Word. You write plain text with a few commands (words that start with \), then compile the file. The compiler produces the finished PDF. The program underneath is TeX, written by Donald Knuth. LaTeX is a large set of ready-made commands built on TeX.

Word processors do all four steps (typing, formatting, screen display, printing) in one program. TeX does only the formatting step, which is the step that decides line breaks, page breaks and spacing. This is why TeX is so good at mathematics: it spends its effort on exactly that job.

The workflow is always the same:

  1. Type the text and commands in a plain text editor (the primer uses Emacs on GNU/Linux).
  2. Compile it with latex myfile (or pdflatex myfile to get a PDF directly).
  3. View the result in a previewer, and print it if needed.

1.2 Your first document

\documentclass{article}
\begin{document}
This is my \emph{first} document prepared in \LaTeX.
\end{document}
You type
This is my \emph{first} document
prepared in \LaTeX.
You get
This is my first document prepared in LaTeX.

Read the example line by line:

  • \documentclass{article} says what kind of document this is. Every file must start with it.
  • \begin{document} and \end{document} enclose the text to be printed.
  • \emph{first} asks for emphasis. The word comes out in italics.
  • \LaTeX prints the name of the program. Other commands give special output, such as \today, which prints today's date.

1.3 Paragraphs and spaces

LaTeX ignores how many spaces you type between words, and it ignores line breaks inside a paragraph. It sets every line to the same length by adjusting the spaces between words. A blank line starts a new paragraph.

A paragraph starts with an indent. To stop that indent, put \noindent at the start of the paragraph.

Two special spacing cases:

  • After a full stop that follows a capital letter, such as "Vitamin A.", LaTeX thinks the sentence has ended and adds extra space. Type A\@. to stop this. Write \@ before the full stop.
  • After a full stop that ends an abbreviation such as "etc.", you want a normal space. Type etc.\ are. The \ (backslash and space) forces a normal word space.

Also, TeX gobbles every space after a command word. So \LaTeX is fun loses the space before "is". Write \LaTeX\ is fun instead.

1.4 Quotes and dashes

Opening and closing quotes are different in typeset text. Use a backtick for the opening quote and an apostrophe for the closing one:

`single quotes'  and  ``double quotes''

The commands \lq and \rq give the same quotes if your keyboard lacks a backtick.

There are three kinds of dash, and the number of dash characters in the source decides which you get:

You typeYou getName and use
--hyphen, as in "hyphen-ated"
--–en dash, for ranges such as pages 221–225
---—em dash, for a parenthetical remark

1.5 Accents and foreign letters

Accents are added with a command and the letter. Some examples:

CommandResultCommandResult
\'oó\"oö
\^oô\c cç
\=oō\v sš
\d oo with dot below\u oo with breve
\oe, \ae, \ssœ, æ, ß\o, \lø, ł

The letters i and j must lose their dot before an accent goes on them. Use \i and \j for the dotless forms, as in \'{\i}, which gives í.

\'{E}l est\'{a} aqu\'{\i}

This gives Él está aquí (Spanish).

1.6 Special characters that must be escaped

Ten characters have a special job for TeX: # $ % & ~ _ ^ \ { }. To print one of them, put a backslash in front of it:

You typeYou getYou typeYou get
\%%\&&
\$$\##
\__\{, \}{ and }
\textbackslash\\textasciitilde~
\textasciicircum^

The percent sign deserves a note. % starts a comment: everything after it on that line is ignored. Comments are useful for notes to yourself, such as a "to do" list.

1.7 Line breaks

\\ forces a new line. \\[10pt] also adds 10 points of extra space between the lines. (One point is about 1/72 of an inch.)

1.8 Positioning text: center, flushleft, flushright

\begin{center}
  The \TeX nical Institute\\[.75cm]
    Certificate
\end{center}
\begin{flushright}
  The Director\\
  The \TeX nical Institute
\end{flushright}

center centres the text, flushright pushes it against the right margin, and flushleft against the left. These are environments: a \begin{name} and a matching \end{name} enclose the part they affect.

1.9 Type style: family, series and shape

A type style is a mix of three things: a family (roman, sans serif, typewriter), a series (medium, bold) and a shape (upright, italic, slanted, small caps). The commands:

StyleCommandDeclaration form
roman (family)\textrm{roman}{\rmfamily roman}
sans serif (family)\textsf{sans serif}{\sffamily sans serif}
typewriter (family)\texttt{typewriter}{\ttfamily typewriter}
medium (series)\textmd{medium}{\mdseries medium}
boldface (series)\textbf{boldface}{\bfseries boldface}
upright (shape)\textup{upright}{\upshape upright}
italic (shape)\textit{italic}{\itshape italic}
slanted (shape)\textsl{slanted}{\slshape slanted}
small caps (shape)\textsc{small cap}{\scshape small cap}

Command or declaration? \textbf{...} works on exactly the text in its braces. A declaration such as \bfseries stays on until the end of the group it sits in, which is the closing brace or the end of the paragraph. Compare:

By a \bfseries{triangle}, we mean a polygon of three sides.
By a {\bfseries triangle}, we mean a polygon of three sides.

In the first line, everything after \bfseries is bold. In the second, the braces around the declaration and its text limit the bold to "triangle". So wrap a declaration and the text it should affect in braces.

The emphasis rule. \emph switches to italics in normal text, but switches to upright text when it is already inside italics. So in \textit{A triangle is called a \emph{triangle}}, the word "triangle" comes out upright. This is deliberate: it stands out from italic text.

1.10 Type size

The default size is 10 points. The ten size commands, from smallest to largest, are \tiny, \scriptsize, \footnotesize, \small, \normalsize, \large, \Large, \LARGE, \huge, \Huge. They are declarations, so use them in braces:

{\bfseries\huge The \TeX nical Institute}\\[1cm]
{\scshape\LARGE Certificate}

Style and size commands can be combined, as above.

Remember (Part 1)
  • Spaces and line breaks in the source do not change the output. A blank line starts a paragraph.
  • A command eats the spaces after it. Use \ to keep one.
  • Ten characters are reserved. Escape them with a backslash.
  • % starts a comment, so it does not print.

2. The document

Syllabus unit 2 · Primer pages 15–26

2.1 Document class and options

In plain words. The document class decides the overall shape of the document: its page size, its sectioning, and whether it has chapters. Options adjust that shape. Options go in square brackets, and the class name goes in braces. 
\documentclass[options]{class}
  • Classes: article (papers, assignments; no chapters), report (long documents with chapters), book (chapters, odd-page starts), letter.
  • Font size: 10pt (default), 11pt, 12pt. Example: \documentclass[11pt]{article}.
  • Paper: a4paper, letterpaper (default), a5paper, legalpaper, b5paper. The primer's table lists sizes for each; for India, use a4paper.
  • Columns: onecolumn (default) or twocolumn, like a dictionary.
  • Sides: oneside (default for article) or twoside (page numbers on the outside edge, for double-sided printing; default for book).
  • Chapter starts: openany (report default) or openright (book default: chapters start on odd pages).
  • Title page: titlepage or notitlepage. Report and book put the title on its own page; article does not.
\documentclass[11pt,a4paper]{article}

LaTeX has no default class, so you must always name one.

2.2 Page style: headers and footers

Each page has a "head" and a "foot". The \pagestyle command chooses what goes there:

StyleWhat it shows
plainEmpty head, page number centred in the foot (article default)
emptyNothing, so no page numbers
headingsPage number and chapter/section names in the head (book default)
myheadingsSame as headings, but you choose the text with \markboth{left}{right} or \markright{right}

To change one page only, use \thispagestyle{empty}. For full control of headers, the fancyhdr package is better; the primer points to it.

2.3 Page numbering

\pagenumbering{roman}    % i, ii, iii ...
\pagenumbering{arabic}   % 1, 2, 3 ... (the default)
\setcounter{page}{5}     % the current page is numbered 5

Other styles: Roman (I, II), alph (a, b), Alph (A, B). A common pattern: roman numbers for the preface, arabic numbers for the body.

2.4 Lengths

Page layout uses lengths such as the width of the text. You change them with \setlength:

\setlength{\textwidth}{15cm}

The geometry package is easier: \usepackage[margin=2.5cm]{geometry} sets all margins in one line.

2.5 Title, author and date

\title{Document name}
\author{Author names}
\date{Date text}
\maketitle
  • \maketitle prints the title block. Without it, nothing is printed.
  • Use \\ to break a long title or to print several lines of address in the author field.
  • Use \and between authors to set them side by side.
  • \date{} (empty braces) prints no date. Omitting \date prints today's date.
  • \thanks{...} adds a footnote mark to the title, author or date.

2.6 Abstract

\begin{abstract}
  Abstract text.
\end{abstract}

Works in article and report, but not book. In an article, it appears under the title on the first page.

2.7 Dividing the document: sectioning

The hierarchy in book and report is:

\chapter   \section   \subsection   \subsubsection   \paragraph   \subparagraph

article has no \chapter; its top level is \section.

  • Numbering: a chapter prints "Chapter 2", a section "2.1", a subsection "2.1.1". Subsubsections and below have no numbers in book and report. In article, subsubsections are numbered.
  • \paragraph and \subparagraph have no numbers and use run-in headings.
  • Add a star to remove the number and the table-of-contents entry: \section*{Introduction}.
  • \part{...} sits above chapters in long documents. It does not change the numbering below it.
Remember (Part 2)
  • Every file starts with \documentclass.
  • The title block needs \maketitle in the body.
  • Chapters exist only in book and report.
  • Starred sectioning (\section*) removes numbers and table-of-contents entries.

3. Bibliography

Syllabus unit 3 · Primer pages 27–34

In plain words. A bibliography is the list of sources at the end of a document. In the text, you refer to a source by a short key (for example lamport). LaTeX turns the key into a number, such as [1], and prints the full entry at the end under the same number. You can change the numbering style without touching the entries.

3.1 Writing a list by hand: thebibliography

\begin{thebibliography}{99}
  \bibitem{les85} Leslie Lamport, 1985. \emph{\LaTeX---A
   Document Preparation System---User's Guide and
   Reference Manual}, Addison-Wesley, Reading.
  \bibitem{don89} Donald E. Knuth, 1989. \emph{Typesetting
   Concrete Mathematics}, TUGBoat, 10(1):31-36.
\end{thebibliography}
  • The argument {99} is the width of the widest label. Use a two-digit number for 10 to 99 entries. For custom labels, use the longest label, such as {Long-name}.
  • Each entry starts with \bibitem{key}. The key is any string without a comma, for example ale91.
  • Cite an entry with \cite{key}. Cite several with commas: \cite{key1,key2}.
  • Add a note with an optional argument: \cite[page~25]{key1} prints "[1, page 25]".
  • The first compilation writes the keys to a file; the second replaces the citations with numbers. So compile twice.

Example from the primer. The input

It is hard to write unstructured documents using \LaTeX~\cite{les85}.
It is interesting to typeset one equation~\cite[Sec 3.3]{les85}
rather than setting ten pages of running matter~\cite{don89,rondon89}.

prints "It is hard to write unstructured documents using LaTeX [1]. It is interesting to typeset one equation [1, Sec 3.3] rather than setting ten pages of running matter [2,3]." The ~ is a non-breaking space, so the citation never starts a new line on its own.

3.2 Author and year citations: natbib

The natbib package gives you control over the citation style. Load it with \usepackage[options]{natbib}.

OptionEffect
round (default), square, curly, angleBrackets around citations
authoryear (default), numbers, superAuthor and year, numbers in brackets, or superscript numbers (as in Nature)
sort, sort&compressOrder multiple citations by list position; compress 3–6, 15

The main commands and what they print for a key ale91 (Alex et al., 1991):

CommandPrints
\citet{ale91}Alex et al. (1991)
\citep{ale91}(Alex et al., 1991)
\citep[chap.~4]{ale91}(Alex et al., 1991, chap. 4)
\citealt{ale91}Alex et al. 1991 (no brackets)
\citet*{ale91}Alex, Mathew and Ravi (1991): the starred form prints all authors
\citet{ale91,rav92}Alex et al. (1991); Ravi et al. (1992)
\citeauthor{ale91}, \citeyear{ale91}Alex et al.; 1991 (for partial citations)

In numerical mode, the same citation prints as [5] or Alex et al. [5].

3.3 Bibliography entries with natbib

With author-year citations, each \bibitem gets a label with the author and year in square brackets:

\begin{thebibliography}{widest-label}
  \bibitem[Lamport(1985)]{les85} Leslie Lamport, 1985.
    \emph{\LaTeX---A Document Preparation}...
\end{thebibliography}
Careful. The year in parentheses inside the optional argument is required. If one entry lacks a year, the whole list silently switches to numbers. Use (0000) when a year is unknown and cite with \citeauthor in the text.

3.4 Changing the punctuation

\bibpunct sets the brackets, separators and mode. Example from the primer:

\bibpunct{[}{]}{,}{a}{}{;}
\citep{jon90,jon91,jam92}     % prints [Jones et al. 1990; 1991, James et al. 1992]
Remember (Part 3)
  • A key is a short name; \cite prints the number or author-year.
  • Compile twice (or more) for the citations to be correct.
  • Use ~ before a citation so it does not break across lines.
  • Use natbib for author-year lists; its \citet and \citep are the commands to learn.

4. Bibliographic databases (BibTeX)

Syllabus unit 3 · Primer pages 35–42

In plain words. Typing the same reference into every paper is tedious. BibTeX lets you keep references once, in a .bib database file. BibTeX then formats them in whatever style a journal wants. You never retype a reference.

4.1 The database entry

@BOOK{knuth:86a,
  AUTHOR    = "Donald E. Knuth",
  TITLE     = {The \TeX{}book},
  EDITION   = "third",
  PUBLISHER = "Addison-Wesley",
  ADDRESS   = {Reading, MA},
  YEAR      = 1986 }
  • @BOOK is the entry type. Capitals or small letters both work.
  • knuth:86a is the key you use with \cite.
  • Each field is NAME = {text}, or "text". A plain number such as 1986 needs neither.
  • Fields are separated by commas. Fields that the style does not need are ignored, so you can store notes or abstracts there too.

4.2 Common entry types

TypeUse forRequired fields
@articleArticle in a journal or magazineauthor, title, journal, year
@bookBook with a publisherauthor or editor, title, publisher, year
@inbookPart of a book (chapter or pages)author or editor, title, chapter and/or pages, publisher, year
@incollectionPart of a book with its own titleauthor, title, booktitle, publisher, year
@inproceedings, @conferencePaper in conference proceedingsauthor, title, booktitle, year
@phdthesis, @masterthesisThesisauthor, title, school, year
@manualTechnical documentationtitle

@unpublishedUnpublished workauthor, title, note

Optional fields such as volume, number, pages, month and note are printed when present. If a required field is missing, BibTeX shows an error in its log.

4.3 Using the database in a document

\documentclass{article}
\pagestyle{empty}
\begin{document}
Citation of a normal book~\cite{Eijkhout:1991}. A reference to
a manual~\cite{Dynatext} and a PhD thesis \cite{Liang:1983}.
\bibliographystyle{plain}   % the layout of the list
\bibliography{bsample}      % the file bsample.bib
\end{document}

The command \bibliographystyle chooses the format. The common styles:

StyleBehaviour
plainSorted alphabetically, numeric labels
unsrtLike plain, but in order of first citation
alphaLabels made from author and year, such as Knu86
abbrvLike plain, but names of months and journals shortened
acm, apalikeHouse styles of ACM and APA journals

4.4 The four-step procedure

BibTeX does not read the .tex file. It reads the .aux file that LaTeX wrote, then looks up the keys in the database and writes a .bbl file. Run the commands in this order:

$ latex sample     # 1st run: writes the citation keys to sample.aux
$ bibtex sample    # reads sample.aux and bsample.bib, writes sample.bbl
$ latex sample     # 2nd run: reads sample.bbl
$ latex sample     # 3rd run: resolves all references

Warnings and errors from BibTeX go to sample.blg.

\nocite{key} puts an entry in the list without printing a citation. \nocite{*} puts every entry from every database in the list, which is useful for checking a database.

Remember (Part 4)
  • References live in a .bib file once. The document only says which file (\bibliography{name}) and which style (\bibliographystyle{...}).
  • Run latex, bibtex, latex, latex. If a citation still shows "?", run latex once more.
  • Check the .blg file when something is missing.

5. Table of contents and index

Syllabus unit 4 · Primer pages 43–51 (glossary, 5.3, is omitted by the syllabus)

5.1 Table of contents, lists of figures and tables

In plain words. LaTeX writes down every heading, figure caption and table caption as it goes, along with its page number. Then \tableofcontents prints them all in a list. You only type the command where the list should appear. 
\tableofcontents    % the contents page
\listoffigures     % list of figures
\listoftables      % list of tables
  • The contents list needs two compilations. The first run saves the headings to a .toc file; the second run reads them back and prints the list.
  • Figure and table lists use the caption text, saved to .lof and .lot.
  • Starred headings (\section*) are not listed. To list one anyway, add it by hand: \addcontentsline{toc}{section}{Preface}.
  • \addtocontents{toc}{\protect\vspace{2ex}} adds a gap in the middle of the contents.
  • Use the optional argument of a caption to shorten its entry in the lists: \caption[Short]{Long caption text}.

5.2 Index

In plain words. An index lists important words with the pages where they appear. You mark each word in the text with \index{word}. A program called makeindex sorts them, and \printindex prints the sorted list.

Steps (from the primer):

  1. Mark terms in the text: \index{index entry}.
  2. In the preamble, load the package and turn on indexing: \usepackage{makeidx} then \makeindex.
  3. Put \printindex where the index should appear, normally before \end{document}.
  4. Compile with latex. This writes a raw index file (file.idx).
  5. Run makeindex file. This writes file.ind (the sorted index) and file.ilg (a log).
  6. Compile with latex again to see the index.

Sub-entries

\index{dimensions!rule!width}   % main ! sub ! subsub
\index{animal!mammal!cat}

The ! character separates the levels. The output is an indented list: dimensions, then rule, then width, with the page number after it.

Page ranges and cross-references

\index{fonts!PostScript|(}     % start of a range
\index{fonts!PostScript|)}     % end of the range
\index{animalism|see{animal}}   % "animalism, see animal" (no page number)

Showing the entry differently

\index{delta@$\delta$}                  % sorted under "delta", printed as delta
\index{tabular@\texttt{tabular} environment}
\index{animal@\emph{animal}}           % page number printed in italics

The part before @ decides where the entry is sorted. The part after it is what is printed.

Special characters

The characters !, @, " and | have jobs in the index. To print one of them, put " in front: \index{exclamation ("!)} prints "exclamation (!)".

No index file? Nothing is produced unless \makeindex is in the preamble. The primer notes this in the text: without it, \index writes nothing.

5.3 Glossary (omitted in the syllabus)

The primer describes \makeglossary and \glossary{entry} for a glossary. The syllabus leaves this out, so it is not needed for the exam.

Remember (Part 5)
  • The contents list needs two runs. The index needs latex, makeindex, latex.
  • \index does nothing without \makeindex in the preamble.
  • ! makes sub-entries; | makes page ranges and "see" cross-references; @ sets the sort key.

6. Displayed text and lists

Syllabus unit 5 · Primer pages 55–68

In plain words. "Displaying" means setting a passage apart from the main text, for example an indented quotation, a poem, or a list. LaTeX does this with environments: a \begin{name} and an \end{name} around the passage.

6.1 Quotations

EnvironmentUseLook
quoteA quotation that is one paragraphIndented on both sides
quotationA quotation of several paragraphsIndented on both sides, and the first line of each paragraph is indented too
 
\begin{quote}
  The true spirit of delight ... from which all great work springs.
\end{quote}

Paragraphs inside quotation are separated by blank lines, as in ordinary text.

6.2 Poetry: verse

\begin{verse}
A mathematician once confided\\
That a M\"obius band is one sided\\
You'll get quite a laugh\\
If you cut it in half\\
For it stays in one piece when divided
\end{verse}
  • \\ forces a line break. Stanzas are separated by a blank line.
  • \\* forces the break but forbids a page break there, so a rhyming couplet stays together.
  • \\[5pt] adds 5 points of extra space after the line.

6.3 Lists

In plain words. LaTeX has three list environments. Each item is marked with \item. Lists can be nested up to four levels deep.
EnvironmentLabelsUse for
itemizeBullets: •, –, *, · at the four levelsUnordered points
enumerateNumbers: 1., (a), i., A.Steps, or points you refer to by number
descriptionWhatever you give in square brackets after \item, in boldTerms and their meanings

Bullets

One should keep the following in mind when using \TeX
\begin{itemize}
\item \TeX\ is a typesetting language and not a word processor
\item \TeX\ is a program and not an application
\end{itemize}
Being a program, \TeX\ offers a high degree of flexibility.

A list inside a list is nested. The second level uses dashes, the third an asterisk, the fourth a dot.

Changing the bullet

{\renewcommand{\labelitemi}{$\triangleright$}
\begin{itemize}
\item First item of a new list
\item Second item
\end{itemize}}

The braces keep the change local to this list. The first-level bullet is \labelitemi, the second-level \labelitemii, and so on. Remove the braces to change the bullet for the whole document.

Numbered lists

\begin{enumerate}
  \item Prepare a source file with the extension "tex"
  \item Compile it with \LaTeX to produce a "dvi" file
  \item Print the document using a "dvi" driver
\end{enumerate}

The numbering is 1, 2, 3 at the first level, (a), (b) at the second, i, ii at the third, and A, B at the fourth.

Custom labels with the enumerate package

\usepackage{enumerate}   % in the preamble, by David Carlisle
\begin{enumerate}[\hspace{0.5cm}Step 1.]
\item Prepare a source file with the extension "tex"
\item Compile it with \LaTeX to produce a "dvi" file
  \begin{enumerate}[i.]
  \item Use a previewer to view the output
  \item Edit the source if needed
  \end{enumerate}
\item Print the document using a "dvi" driver
\end{enumerate}

The text in square brackets after \begin{enumerate} becomes the label of the first item. The \hspace adds an indent. The letters A, a, I, i and 1 inside the brackets are read as numbering styles. To keep one as plain text, wrap it in braces, as in [\hspace{1cm}({A}1)]. The primer's example then shows (A1), (A2), (A3), (A4).

Pitfall (from the primer). Writing \begin{enumerate}[\hspace{1cm}(A1)] without braces gives (11), (22), (33). The letter A is read as an instruction to number with capitals. Braces around the A fix it.

Overriding one label

\begin{enumerate}
  \item[(1)] $l$ is an upper bound of $A$
  \item[(2)] if $u$ is an upper bound of $A$, then $l\le u$
\end{enumerate}

Any list can use a custom label in square brackets right after \item.

Pitfall: square brackets. Write \item (0,1) is an open interval and it works. But \item [0,1] is a closed interval loses the [0,1], because LaTeX reads it as a label. Put the maths in dollar signs: \item $[0,1]$ is a closed interval.

Descriptions

\begin{description}
  \item[\TeX] A typesetting program
  \item[Emacs] A text editor and also
  \item[AbiWord] A word processor
\end{description}

The label is whatever is in the brackets, typeset in bold roman. There is no indent at the first level by default.

Remember (Part 6)
  • Use quote for one paragraph and quotation for several.
  • Inside verse, the line break is \\. A blank line starts a new stanza.
  • Lists nest up to four levels. Each item starts with \item.
  • Braces keep a change of label local. Put maths and brackets in $...$ inside an item.

7. Rows and columns

Syllabus units 6 and 7 · Primer pages 69–94

In plain words. A list gives you rows. When the rows need columns that line up, use tabbing (for simple aligned text) or tabular (for a real table with rules and cells). tabular is the one you will use most.

7.1 Tabbing: setting tab stops

In tabbing, you set tab stops with \= and jump to them with \>. A line ends with \\.

\begin{tabbing}
\hspace{1cm}\= \textbf{AbiWord}\quad\= word processor\\[5pt]
            \> \textbf{Emacs}                  \> text editor\\[5pt]
            \> \textbf{\TeX}                   \> typesetting program
\end{tabbing}

Line by line: the first \= sets a tab 1 cm from the margin; the second sets a tab after the word "AbiWord" plus a quad (a space the width of the letter M). Every later \> goes to those tab stops.

Pitfall. A tab is set by the first line that uses \=. If that line is wide (for example the word "TEX" above), the later lines jump too far. The fix is a dummy line that sets the tabs and is removed with \kill: 
\begin{tabbing}
  \textbf{AbiWord}\quad\= A word processor\kill
  \textbf{\TeX}\quad \> A typesetting program\\[5pt]
  \textbf{Emacs}\quad \> A text editor\\[5pt]
  \textbf{AbiWord}\quad\> A word processor
\end{tabbing}

The line ending in \kill sets the tab stops but is not printed.

7.2 Tabular: the table environment

In plain words. A tabular is a grid. The argument in braces after \begin{tabular} gives one letter per column: l left, c centred, r right. Cells are separated by &, and each row ends with \\.

Mercury &amp; 4878\\
Venus   &amp; 12104\\
Earth   &amp; 12756
\end{tabular}
\end{center}

The center environment centres the table on the page. The \\[5pt] adds a little space after the heading row.

Column letters
  • l, c, r: left, centre, right
  • p{6cm}: a paragraph cell 6 cm wide, wrapping its text
  • |: a vertical line

Rules: \hline and \cline

\begin{tabular}{|l|r|}
\hline
Planet &amp; Diameter(km)\\
\hline

\hline
\end{tabular}
  • | in the column letters draws a vertical line. Two bars give a double line.
  • \hline draws a horizontal line across the whole table. It must come at the start of a row or right after \\.
  • \cline{i-j} draws a line only under columns i to j.
  • Because a final \hline follows the last row, that last row still needs its \\.

Spanning columns: \multicolumn

\begin{tabular}{lrr}
Planet &amp; \multicolumn{2}{c}{Distance from sun (km)}\\
       &amp; Maximum   &amp; Minimum\\
Mercury &amp; 69400000 &amp; 46800000\\
\end{tabular}

\multicolumn{2}{c}{text} makes one cell that spans two columns, centred. The general form is \multicolumn{num}{pos}{item}. The empty first cell of the second row begins with &, because the row has no entry in column one.

Careful with the last column. When a \multicolumn covers the last column and you want a vertical line on its right, put the line in its position argument: \multicolumn{2}{c|}{...}. The primer shows that the final | is reset by \multicolumn and must be repeated.

Spacing: \arraystretch and @{}

\renewcommand{\arraystretch}{1.2}   % 20% more space between rows
\begin{tabular}{|c|r@{--}l|}          % a dash between the two numbers
  \hline
  Height &amp; \multicolumn{2}{c|}{Ideal weight}\\
  (cm)   &amp; \multicolumn{2}{c|}{(kg)}\\
  \hline
  155 &amp; 53.5 &amp; 64\\
  \hline
\end{tabular}

r@{--}l means: right-aligned, then a dash, then left-aligned, with no normal gap between them. The result is "53.5–64". The @{...} form removes the usual column space; you can add space back with \hspace inside the braces.

Cleaner rules: booktabs

The primer's tables use \hline, but for a cleaner look, the booktabs package gives \toprule, \midrule and \bottomrule, with no vertical lines. Use \cmidrule{2-3} for a partial rule. This is an extension beyond the primer, but it is standard practice.

8. Typesetting mathematics

Syllabus units 8–11 · Primer pages 95–136

In plain words. TeX was written to typeset mathematics well. Inside a formula, LaTeX spaces the symbols itself, so you write the meaning and let it place the spaces. Maths has two modes: in-text (inside a sentence, with $...$) and display (a formula on its own line, with \[...\] or equation).

8.1 The basics

In-text and displayed maths

The equation representing a straight line in the Cartesian plane is
of the form $ax+by+c=0$, where $a$, $b$, $c$ are constants.

$$
  ax+by+c=0
$$
  • $...$ keeps maths in the sentence. The letters are in math italic.
  • $$...$$ (TeX) and \[...\] (LaTeX) put the formula on its own centred line.
  • \(...\) and \begin{math}...\end{math} are the LaTeX forms of in-text maths.
Spaces in maths. TeX ignores the spaces you type inside maths and places its own. $ax+by+c=0$ and $ax + by + c = 0$ print the same. Do not type spaces to make the result look right.

Superscripts and subscripts

$x^2$      $x_n$      $x_n^2$      % x squared, x sub n, both together
$x^{mn}$    $x_{n-1}$                       % braces group several symbols
$(x^m)^n = x^{mn}$

Without braces, only the next character is affected. So x^mn prints "xmn", but x^{mn} prints xmn. For a superscript and a subscript together on the same letter, the order and braces change the output: x_m^n, x^n_m and {x_m}^n come out differently. Use braces to say what you mean.

$$ x_m^n \qquad x^n_m \qquad {x_m}^n \qquad {x^n}_m $$

Roots and fractions

$\sqrt{2}$          % square root
$\sqrt[4]{5}$      % fourth root
$\sqrt{x+y}$       % the top bar stretches over the whole expression
$\sqrt{2+\sqrt{2}}$ % nested roots

The square root's horizontal bar stretches to cover its contents. Use \frac{numerator}{denominator} for fractions (covered in Part 8.4 below).

Spacing inside maths

Binary operators and relations

TeX adds extra space around binary operators (such as +, -, \circ) and around relations (such as =, \le). Symbols that are not in either class do not get that space. To force a symbol to behave as one of these:

x\circ y = x+y-xy          % \circ is a binary operator: spaces on both sides
x\mathbin\Box y           % force \Box (from amssymb) to act as a binary operator
x\mathrel\rho y           % force \rho to act as a relation

Some symbols (for example \Box) are only available after loading amssymb or latexsym.

8.2 Custom commands

In plain words. If you type the same expression many times, give it a short name with \newcommand. Put the definitions in the preamble, so they can be used anywhere. 
\newcommand{\vect}{(x_1,x_2,\dots,x_n)}
We often write $x$ to denote the vector $\vect$.

With an argument, the same command can produce many vectors:

\newcommand{\vect}[1]{(#1_1,#1_2,\dots,#1_n)}
$\vect{x}$ gives $(x_1,x_2,\dots,x_n)$ and $\vect{a}$ gives $(a_1,a_2,\dots,a_n)$.

\newcommand{\vect}[2]{(#1_1,#1_2,\dots,#1_#2)}
$\vect{x}{m}$ gives $(x_1,x_2,\dots,x_m)$.

[1] says the command takes one argument. #1 is replaced by that argument. A command can take up to nine arguments.

\end{equation*}

  x\le|x|\quad\text{for all $x$ in $R$}.
\end{equation*}

Long equations: split and multline

When an equation is too long for one line, split inside an equation* lines it up at the & character, with the = signs aligned:

\begin{equation*}
  \begin{split}
    (a+b)^2 &amp; = (a+b)(a+b)\\
            &amp; = a^2+ab+ba+b^2\\
            &amp; = a^2+2ab+b^2
  \end{split}
\end{equation*}

multline is simpler to type, but for more than two lines its output is less neat. The primer recommends split for long expansions.

Groups of equations: gather and align

\begin{gather*}
  (a,b)+(c,d)=(a+c,b+d)\\
  (a,b)(c,d)=(ac-bd,ad+bc)
\end{gather*}

Thus $x$, $y$ and $z$ satisfy the equations
\begin{align*}
  x+y-z &amp; = 1\\
  x-y+z &amp; = 1
\end{align*}
  • gather: each line centred on its own.
  • align: lines aligned at each &. Put the & before the = to line up the equals signs.
  • \intertext{and by hypothesis} puts a short piece of text between aligned lines without breaking the alignment.
  • Extra & signs make side-by-side columns. Use \qquad to space the columns apart.
  • aligned, gathered and alignedat take only the width they need, so they can sit inside an equation* beside other text.

Cases

\begin{equation*}
  |x| =
  \begin{cases}
    x      &amp; \text{if $x\ge 0$}\\
    -x     &amp; \text{if $x\le 0$}
  \end{cases}
\end{equation*}

Equation numbers and labels

\numberwithin{equation}{section}   % equation numbers now carry the section number
\begin{equation}\tag{L}
  ax+by+c=0
\end{equation}
\begin{align}
  x+y-z &amp; = 1 \notag \\
  x-y+z &amp; = 1 \tag{H}
\end{align}
  • Numbers are added to the unstarred environments automatically. In a book or report, the chapter number comes first: the second numbered equation of Chapter 8 prints as (8.2), as in the primer.
  • \numberwithin{equation}{section} adds the section number as well, in the style (section.equation).
  • \tag{name} replaces the automatic number with your own label.
  • \notag removes the number from one row of an align.
  • Put \tag before the \\ at the end of the row, not after it.
Remember (Part 8.1–8.3)
  • Use $...$ for in-text maths and \[...\] or equation for displays.
  • Braces group the superscript or subscript. x^{mn}, not x^mn.
  • TeX sets the spaces in maths. Do not add spaces by hand.
  • Use align for several lines that must line up, and split inside an equation for one long formula.
  • The starred environment is unnumbered; the plain one is numbered.

9. Typesetting theorems

Syllabus units 12 and 13 · Primer pages 137–150 (syllabus omits 9.2.2 and 9.2.3)

In plain words. Mathematics has special statements: theorems, lemmas, definitions, remarks. Each has a name and a number, and the statement is set apart from the text. You define the kinds once in the preamble with \newtheorem, then use them as environments.

9.1 Theorems in LaTeX

\newtheorem{thm}{Theorem}       % preamble: name of environment, then printed name

\begin{thm}
  The sum of the angles of a triangle is $180^\circ$.
\end{thm}

This prints "Theorem 1. The sum of the angles of a triangle is 180°." Keep all \newtheorem commands together in the preamble.

Numbering

DefinitionResult
\newtheorem{thm}{Theorem}Theorem 1, Theorem 2, ...
\newtheorem{thm}{Theorem}[section]Theorem 9.1.1, 9.1.2, ... (section number first)
\newtheorem{cor}[thm]{Corollary}Shares the numbering of thm: Corollary 9.1.3 follows Theorem 9.1.2

The optional argument in square brackets, [thm] or [section], says which counter to share or to nest in. The primer's example: after \newtheorem{thm}{Theorem}[section] and \newtheorem{cor}[thm]{Corollary}, Theorem and Corollary share one sequence.

  The sum of the angles of a triangle is $180^\circ$.
\end{thm}

The note appears after the number: "Theorem 9.1.5 (Euclid)."

Proofs

\begin{proof}
  Let $\{p_1,p_2,\dotsc p_k\}$ be a finite set of primes.
  Define $n=p_1p_2\dotsm p_k+1$. Then either $n$ itself is a prime
  or has a prime factor. Thus no finite set of primes can include
  all the primes.
\end{proof}
  • The end of a proof is marked automatically with a box (the "qed" symbol). Change the symbol with \renewcommand{\qedsymbol}{\halmos} if you define your own.
  • When the last line of a proof is a display, the box can land in an awkward place. The primer's fix: put \tag*{\qed} at the end of that equation, and add \renewcommand{\qed}{} at the end of the proof so the box is not printed twice. This needs amsmath loaded without the leqno option.
  • \begin{proof}[\textsc{Proof\,(Euclid)}:] changes the proof heading.

Custom styles (the rest of 9.2)

The syllabus omits sections 9.2.2 and 9.2.3 (\newtheoremstyle with nine parameters, and \swapnumbers). They are not needed for the exam, but the primer's examples show what you can do.

Remember (Part 9)
  • Define theorem-like environments with \newtheorem{name}{Printed name} in the preamble.
  • Use the optional argument to share a counter ([thm]) or to number within sections ([section]).
  • Set \theoremstyle before each group of definitions.
  • \begin{proof}...\end{proof} adds the heading and the end-of-proof box.

10. Boxes

Syllabus unit 14 (sections 10.1 and 10.2 only) · Primer pages 151–166

In plain words. TeX builds every line from boxes. A character is a box. A word is a box of boxes. You can make your own boxes, with or without a frame, and place them where you want. A box is never broken across lines unless you use a paragraph box.

10.1 Boxes with frames: \fbox

\fbox{Boxed text}

This draws a frame around the text. The gap between the text and the frame is \fboxsep (default 3 pt). The thickness of the frame line is \fboxrule (default 0.4 pt).

an \fbox{ordinary box} and a
\setlength{\fboxrule}{5pt}
\setlength{\fboxsep}{15pt}
\fbox{custom box} with extra-thick walls and extra padding

Use \phantom{text} to make an empty box exactly the size of the text. This is how the primer draws "boxes of letters" with no letters showing.

Boxes that are a fixed width: \framebox

\framebox[6cm]{6\,cm}          % a box 6 cm wide (plus the padding)
\framebox[3cm][l]{flushleft text}
\framebox[3cm][c]{centered text}
\framebox[3cm][r]{flushright text}
\framebox[3cm][s]{stretched text}
  • The position letter: l left, c centre (default), r right, s stretched to fill the box.
  • The width includes the padding on both sides. To make a box exactly 6 cm, subtract the padding, as the primer does with calc: \framebox[\dimexpr(6cm - 6pt)]{...}.
  • If the text is wider than the box, it spills out.

Lengths that refer to the text: \width, \height, \depth

\framebox{Text}\\
\framebox[2\width][l]{Text}      % twice the width of the text (inside the box)

\width, \height, \depth and \totalheight mean the size of the text inside the box. They work only inside a width specification like this one. The width of the box also includes the padding and rules, so the primer adds 4\fboxsep + 4\fboxrule when it needs an exact doubling.

What boxes cannot do

A \fbox is an LR box: it is one indivisible unit. Its text stays on one line, even if it is longer than the text width. This is why \fbox cannot hold a paragraph. Use \parbox or minipage for that (Section 10.5 in the primer, outside the syllabus).

10.2 Boxes without frames: \mbox and \makebox

\mbox{text}                    % an LR box of the text's own width
\makebox[width][pos]{text}    % a box of a set width, no frame

A box without a frame is useful to keep text together. The primer's example: "3 : 2 : 1" wrapped in \mbox{$3:2:1$} is never split across two lines, even when the paragraph is very narrow.

Zero-width boxes stick out of the margin

\makebox[0cm][r]{\textit{median}$\rightarrow$\hspace{\tabcolsep}}

A zero-width box prints its text on top of the surrounding space, so the word hangs out to the left. The primer uses this to put "median" beside a row of a table.

Notes on the rest of Chapter 10 (outside the syllabus)

Chapter 10 also covers \parbox and minipage (multi-line boxes), \rule (black boxes and struts), and \raisebox (moving boxes up or down). They are not in the syllabus units 14, but they are useful. In brief:

  • \parbox[pos]{width}{text}: a paragraph in a line. pos is t, b or the middle (default) to align with the line of text.
  • \rule[lift]{width}{height}: a solid black rectangle. A zero-width rule is an invisible strut that makes a box taller.
  • \raisebox{lift}{text}: moves text up (positive) or down (negative) from the baseline.
Remember (Part 10)
  • \fbox draws a frame; \fboxsep sets the padding and \fboxrule the line thickness.
  • \framebox[width][l|c|r|s]{text} gives a frame with a fixed width and alignment.
  • \mbox keeps text on one line without a frame.
  • A box never breaks across lines. Use \parbox or minipage for paragraphs.

11. Floats: figures and tables

Syllabus unit 15 · Primer pages 167–177

In plain words. A figure or table is too big to split across pages, so LaTeX treats it as a float. It moves the figure to a good place, often the top or bottom of a page, and numbers it. You put the picture and caption inside a figure (or table) environment. You do not place it by hand.

11.1 The figure environment

\begin{figure}
  \centering
  \includegraphics{figure.eps}
  \caption{This is an inserted EPS graphic}
  \label{fig1}
\end{figure}
  • \caption sets the caption and the number.
  • \label must come after \caption. Then \ref{fig1} gives the number and \pageref{fig1} the page.
  • A figure with no caption is an unnumbered float.
  • Several captions in one figure environment give several figures that float together.
  • \caption[Short]{Long text}: the short version appears in the list of figures.
  • \listoffigures prints the list of figures.

Placement

The optional argument in square brackets says where the float may go:

LetterMeaning
hHere, where the command is, if there is room
tTop of a page
bBottom of a page
pOn a page of its own (a float page)

With no option, the default is [tbp]. A common choice is \begin{figure}[htbp].

Forcing floats out

  • \clearpage places all waiting floats and starts a new page.
  • \FloatBarrier (package placeins) places waiting floats without starting a new page. \usepackage[section]{placeins} puts a barrier before each section.
  • \afterpage{\clearpage} (package afterpage) clears floats at the next page break.

Controlling how many floats

\setcounter{totalnumber}{2}      % at most 2 floats on any text page
\renewcommand{\textfraction}{0.3}  % at least 30% of a text page must be text
SettingDefaultMeaning
topnumber2Max floats at the top of a text page
bottomnumber1Max floats at the bottom
totalnumber3Max floats on any text page
textfraction0.2Min fraction of a text page that must be text
topfraction0.7Max fraction of a text page used by floats at the top
bottomfraction0.3Max fraction used by floats at the bottom
floatpagefraction0.5Min fraction of a float page that must be filled

A ! in the placement options makes LaTeX ignore the first three settings.

11.2 The table environment

A table environment works the same way as figure, but holds a tabular. It has a caption and a label.

\begin{table}[htbp]
  \centering
  \caption{Marks awarded in the LaTeX internal examination}
  \label{tab:marks}
  \begin{tabular}{lcc}
    \hline
    Student &amp; Assignment &amp; Viva \\
    \hline
    Student A &amp; 9 &amp; 8 \\
    Student B &amp; 7 &amp; 9 \\
    \hline
  \end{tabular}
\end{table}

Refer to it as Table~\ref{tab:marks}. The tilde is a non-breaking space, so "Table" and the number stay together.

Tabular and tabular*

\begin{tabular}[pos]{cols} rows \end{tabular}
\begin{tabular*}{width}[pos]{cols} rows \end{tabular*}
  • pos: t aligns the top row with the text baseline, b the bottom row. Default: centred.
  • tabular* sets a fixed total width. Its columns need @{\extracolsep{\fill}} to stretch.
  • Column letters: l, c, r, {wd} (a paragraph of width wd), *{n}{cols} (repeat n times), | (vertical line), @{text} (insert text between columns, removing the normal gap).

Table style parameters

ParameterControls
\tabcolsepHalf the gap between columns
\arrayrulewidthThickness of table lines
\doublerulesepGap between the two lines of a double rule
\arraystretchMultiplier for the row spacing (default 1; 1.5 adds 50%)

Set them with \setlength (for lengths) or \renewcommand (for \arraystretch). Do not change them inside the tabular itself.

Remember (Part 11)
  • Put every figure in a figure environment and every table in a table environment.
  • \label goes after \caption.
  • Let LaTeX place floats. Use [htbp] to give it options, and \clearpage to force them out.

12. Graphics inclusion

Not a numbered syllabus unit · Primer pages 179–185 · relevant to figures (unit 15) and to Module V

In plain words. Some pictures come from other programs: graphs of data, photographs. The graphicx package includes such a file in your document and can scale, rotate and crop it. LaTeX only reserves the space; the driver (dvips, xdvi, pdflatex) draws the picture.

12.1 Loading and including

\usepackage{graphicx}
\usepackage[dvips]{graphicx}     % if the output is made with dvips
\usepackage[xetex]{graphicx}     % if the engine is xelatex
\includegraphics{ellipse}                     % the file's own size
\includegraphics[scale=0.5]{ellann.eps}      % half the size
\includegraphics[width=4cm,height=0.5cm]{ellann.eps}   % fit a box
\includegraphics[angle=60]{ellann.pdf}       % rotated, counter-clockwise
Order matters. The keys are applied from left to right. [width=4cm,height=1cm,angle=60] scales the picture first and then rotates it. [angle=60,width=4cm,height=1cm] rotates first and then scales the rotated picture into the box. The results are different.

12.2 Clipping a picture

An EPS file has a bounding box line, such as %%BoundingBox: 249 604 362 689, giving the lower-left and upper-right corners in points. To show only part of the picture, give a new bounding box with bb= and add clip:

\includegraphics[bb=249 604 362 646.5,clip]{ellann.eps}   % lower half only

Stacking two clipped halves with \\[-1.253pt] between them rebuilds the whole picture.

12.3 Finding files

\graphicspath{{dir1/}{dir2/}}          % look in these folders too
\DeclareGraphicsExtensions{.eps,.ps}  % extensions to try when none is given

With the extensions set, \includegraphics{file} looks for file.eps, then file.ps, and so on.

Note on modern use. The primer was written for EPS files and the dvips driver. With pdflatex today, PNG, JPG and PDF files are normal, and you write the file name with its extension, for example \includegraphics[width=0.6\textwidth]{plot.png}. The keys (width, scale, angle) are the same.

12.4 Drawing in LaTeX

The primer draws its elliptic annulus with pstricks, a package for drawing inside TeX. It is an extra topic, not part of the syllabus.

13. Cross references

Syllabus unit 16 (sections 13.1 and 13.2 only) · Primer pages 187–196

In plain words. A cross reference is a pointer to another part of the same document: "see Section 2", "by Theorem 3.1". Writing the numbers by hand breaks when you add a section. Instead, give the target a label with \label{key}, and point to it with \ref{key}. LaTeX fills in the right number.

13.1 Labels and references

\section{Why cross references}\label{intro}
...
(see Section \ref{intro} for details)
  • The label can go anywhere inside the section, not only right after the heading.
  • The key can be any mix of letters, digits and punctuation. Use a memorable one, such as limcon for "Limits and Continuity".
  • Type ~\ref{limcon} with a tilde, so the number never starts a new line on its own.
  • The first run writes the references to the .aux file and prints "There were undefined references". A second run fixes them. Run again after any change.

13.2 Other kinds of target

TargetHow to label it
Section, chapter\section{...}\label{key}
Item in an enumerated list\item All men are mortal.\label{pre1}, then (\ref{pre1})
Figure or table\caption{...}\label{tabxy}: the label comes after the caption
Theorem\begin{theorem}\label{diffcon}
Equation\begin{equation}\label{sumsq}, then \eqref{sumsq}

Equations with amsmath

Equation~\eqref{sumsq} gives the following.      % prints "Equation (13.1)"

\begin{align}
  (x+y)^2 &amp;= x^2+2xy+y^2 \label{sum}\\
  (x-y)^2 &amp;= x^2-2xy+y^2 \tag{\ref{sum}a}
\end{align}

\eqref adds the brackets around the number. In an align, the second line's tag can reuse the first line's number with a letter, as shown: (13.2) and (13.2a).

Forward references

You can refer to a label that comes later in the document, in the same way. The second run then gets it right.

13.3 Page numbers: \pageref and varioref

see Table~\ref{tabxy} in page~\pageref{tabxy}

The package varioref adds smart page references with \vref{key}. If the target is on the same page, it prints only the number. If it is on the next page, it adds "on the following page". Its page phrases can be changed with \reftextbefore and \reftextafter.

\usepackage{varioref}
see the \vpageref[above table][table~]{tabxy}   % "above table" if same page

13.4 Other documents: xr, and the key list

The xr package lets one document refer to labels in another file: \usepackage{xr} and \externaldocument{other} in the preamble. Two external files with the same key can be told apart with a prefix: \externaldocument[a-]{other}, then \ref{a-key}.

Remember (Part 13)
  • Label after the thing being labelled (after \caption for floats).
  • Reference with \ref, or \eqref for equations.
  • Compile twice after adding or moving labels.
  • Use ~ before a reference so "Table 1" stays together.

14. Footnotes, margin notes and endnotes

Syllabus unit 17 (section 14.1 only) · Primer pages 197–205

14.1 Footnotes

In plain words. A footnote is a note at the bottom of the page, linked to a number in the text. LaTeX numbers it and places it for you. 
A footnote is written with \footnote{footnote text}.

The footnote text is set smaller, below a short rule. The first line of the footnote is indented and carries the same mark as the text.

Footnotes in a minipage or table

Inside a minipage, a plain \footnote is set at the bottom of that minipage, and it uses its own counter. To put a footnote mark in the minipage but print the note at the bottom of the page, use \footnotemark in the text and \footnotetext after the minipage:

\begin{minipage}{5cm}
  This text references a footnote at the bottom of the page.\footnotemark
\end{minipage}
\footnotetext{At bottom of page}
Tables. A plain \footnote inside tabular does not print correctly. Use longtable or tabularx, or put the table in a minipage. The threeparttable package is the cleanest way to set table notes, with \tnote{a} marks and a tablenotes list.

Changing the look

\setcounter{footnote}{0}           % restart numbering (before a section)
\renewcommand{\thefootnote}{\fnsymbol{footnote}}   % * \dagger \ddagger ...
\footnote[7]{Marker shown as 7.}  % a footnote with a set number
  • \thefootnote sets the style: \arabic, \roman, \alph, \fnsymbol (symbols for 1 to 9).
  • Restore the normal numbers with \renewcommand{\thefootnote}{\arabic{footnote}} after using symbols.
  • Style parameters: \footnotesize (font), \footnotesep (strut at the start), \footnoterule (the line above the notes).

14.2 Marginal notes

text\marginpar{This is a marginal note}

The note prints in the margin, starting at the height of the line where the command sits. With one argument it goes to the right margin (one-sided) or the outside margin (two-sided). With two arguments, \marginpar[left]{right}, the first is for the left margin.

  • \reversemarginpar and \normalmarginpar switch the margin.
  • \marginparwidth, \marginparsep and \marginparpush set the size and spacing.
  • \marginpar does not start a paragraph. If it sits before the first word of a paragraph, the alignment can be off.

14.3 Endnotes

Endnotes are collected at the end of a chapter or document. They are not in standard LaTeX; the endnotes package adds them.

\usepackage{endnotes}
This is simple text.\endnote{The first endnote.}
\theendnotes     % prints all the endnotes collected so far

Writing \renewcommand{\footnote}{\endnote} turns every footnote into an endnote.

Remember (Part 14)
  • \footnote{text} goes right after the word it explains.
  • Footnotes do not work inside tabular; use longtable, threeparttable, or a minipage.
  • Use \footnotemark and \footnotetext to keep a minipage footnote in the page sequence.
