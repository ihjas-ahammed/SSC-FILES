9. Typesetting theorems

Syllabus units 12 and 13 · Primer pages 137–150 (syllabus omits 9.2.2 and 9.2.3)

In plain words. Mathematics has special statements: theorems, lemmas, definitions, remarks. Each has a name and a number, and the statement is set apart from the text. You define the kinds once in the preamble with \newtheorem, then use them as environments.

9.1 Theorems in LaTeX

\newtheorem{thm}{Theorem}       % preamble: name of environment, then printed name

\begin{thm}
  The sum of the angles of a triangle is $180^\circ$.
\end{thm}

This prints "Theorem 1. The sum of the angles of a triangle is 180°." Keep all \newtheorem commands together in the preamble.

Numbering

DefinitionResult
\newtheorem{thm}{Theorem}Theorem 1, Theorem 2, ...
\newtheorem{thm}{Theorem}[section]Theorem 9.1.1, 9.1.2, ... (section number first)
\newtheorem{cor}[thm]{Corollary}Shares the numbering of thm: Corollary 9.1.3 follows Theorem 9.1.2

The optional argument in square brackets, [thm] or [section], says which counter to share or to nest in. The primer's example: after \newtheorem{thm}{Theorem}[section] and \newtheorem{cor}[thm]{Corollary}, Theorem and Corollary share one sequence.

Optional note

\begin{thm}[Euclid]
  The sum of the angles of a triangle is $180^\circ$.
\end{thm}

The note appears after the number: "Theorem 9.1.5 (Euclid)."

Pitfall: square brackets again. \begin{thm}[0,1] is a compact subset... treats "0,1" as the note. The fix is to put the maths in dollar signs: \begin{thm} $[0,1]$ is a compact subset of $\mathbb{R}$. \end{thm}.

9.2 Designer theorems: the amsthm package

The amsthm package gives you styles and control. Load it with \usepackage{amsthm}.

Ready-made styles

StyleHeading (name and number)Body textTypical use
plain (default)bolditalictheorem, lemma, proposition, corollary
definitionboldromandefinition, example, exercise
remarkitalicromanremark, note
 
\usepackage{amsthm}
\newtheorem{thm}{Theorem}[section]
\theoremstyle{definition}
\newtheorem{dfn}{Definition}[section]
\theoremstyle{remark}
\newtheorem{note}{Note}[section]
\theoremstyle{plain}
\newtheorem{lem}[thm]{Lemma}

Each \theoremstyle applies to the \newtheorem commands after it. Without \theoremstyle{plain} before lem, the lemma would be set in remark style. Always switch styles before you define a new group.

Proofs

\begin{proof}
  Let $\{p_1,p_2,\dotsc p_k\}$ be a finite set of primes.
  Define $n=p_1p_2\dotsm p_k+1$. Then either $n$ itself is a prime
  or has a prime factor. Thus no finite set of primes can include
  all the primes.
\end{proof}
  • The end of a proof is marked automatically with a box (the "qed" symbol). Change the symbol with \renewcommand{\qedsymbol}{\halmos} if you define your own.
  • When the last line of a proof is a display, the box can land in an awkward place. The primer's fix: put \tag*{\qed} at the end of that equation, and add \renewcommand{\qed}{} at the end of the proof so the box is not printed twice. This needs amsmath loaded without the leqno option.
  • \begin{proof}[\textsc{Proof\,(Euclid)}:] changes the proof heading.

Custom styles (the rest of 9.2)

The syllabus omits sections 9.2.2 and 9.2.3 (\newtheoremstyle with nine parameters, and \swapnumbers). They are not needed for the exam, but the primer's examples show what you can do.

Remember (Part 9)
  • Define theorem-like environments with \newtheorem{name}{Printed name} in the preamble.
  • Use the optional argument to share a counter ([thm]) or to number within sections ([section]).
  • Set \theoremstyle before each group of definitions.
  • \begin{proof}...\end{proof} adds the heading and the end-of-proof box.

10. Boxes

Syllabus unit 14 (sections 10.1 and 10.2 only) · Primer pages 151–166

In plain words. TeX builds every line from boxes. A character is a box. A word is a box of boxes. You can make your own boxes, with or without a frame, and place them where you want. A box is never broken across lines unless you use a paragraph box.

10.1 Boxes with frames: \fbox

\fbox{Boxed text}

This draws a frame around the text. The gap between the text and the frame is \fboxsep (default 3 pt). The thickness of the frame line is \fboxrule (default 0.4 pt).

an \fbox{ordinary box} and a
\setlength{\fboxrule}{5pt}
\setlength{\fboxsep}{15pt}
\fbox{custom box} with extra-thick walls and extra padding

Use \phantom{text} to make an empty box exactly the size of the text. This is how the primer draws "boxes of letters" with no letters showing.

Boxes that are a fixed width: \framebox

\framebox[6cm]{6\,cm}          % a box 6 cm wide (plus the padding)
\framebox[3cm][l]{flushleft text}
\framebox[3cm][c]{centered text}
\framebox[3cm][r]{flushright text}
\framebox[3cm][s]{stretched text}
  • The position letter: l left, c centre (default), r right, s stretched to fill the box.
  • The width includes the padding on both sides. To make a box exactly 6 cm, subtract the padding, as the primer does with calc: \framebox[\dimexpr(6cm - 6pt)]{...}.
  • If the text is wider than the box, it spills out.

Lengths that refer to the text: \width, \height, \depth

\framebox{Text}\\
\framebox[2\width][l]{Text}      % twice the width of the text (inside the box)

\width, \height, \depth and \totalheight mean the size of the text inside the box. They work only inside a width specification like this one. The width of the box also includes the padding and rules, so the primer adds 4\fboxsep + 4\fboxrule when it needs an exact doubling.

What boxes cannot do

A \fbox is an LR box: it is one indivisible unit. Its text stays on one line, even if it is longer than the text width. This is why \fbox cannot hold a paragraph. Use \parbox or minipage for that (Section 10.5 in the primer, outside the syllabus).

10.2 Boxes without frames: \mbox and \makebox

\mbox{text}                    % an LR box of the text's own width
\makebox[width][pos]{text}    % a box of a set width, no frame

A box without a frame is useful to keep text together. The primer's example: "3 : 2 : 1" wrapped in \mbox{$3:2:1$} is never split across two lines, even when the paragraph is very narrow.

Zero-width boxes stick out of the margin

\makebox[0cm][r]{\textit{median}$\rightarrow$\hspace{\tabcolsep}}

A zero-width box prints its text on top of the surrounding space, so the word hangs out to the left. The primer uses this to put "median" beside a row of a table.

Notes on the rest of Chapter 10 (outside the syllabus)

Chapter 10 also covers \parbox and minipage (multi-line boxes), \rule (black boxes and struts), and \raisebox (moving boxes up or down). They are not in the syllabus units 14, but they are useful. In brief:

  • \parbox[pos]{width}{text}: a paragraph in a line. pos is t, b or the middle (default) to align with the line of text.
  • \rule[lift]{width}{height}: a solid black rectangle. A zero-width rule is an invisible strut that makes a box taller.
  • \raisebox{lift}{text}: moves text up (positive) or down (negative) from the baseline.
Remember (Part 10)
  • \fbox draws a frame; \fboxsep sets the padding and \fboxrule the line thickness.
  • \framebox[width][l|c|r|s]{text} gives a frame with a fixed width and alignment.
  • \mbox keeps text on one line without a frame.
  • A box never breaks across lines. Use \parbox or minipage for paragraphs.

11. Floats: figures and tables

Syllabus unit 15 · Primer pages 167–177

In plain words. A figure or table is too big to split across pages, so LaTeX treats it as a float. It moves the figure to a good place, often the top or bottom of a page, and numbers it. You put the picture and caption inside a figure (or table) environment. You do not place it by hand.

11.1 The figure environment

\begin{figure}
  \centering
  \includegraphics{figure.eps}
  \caption{This is an inserted EPS graphic}
  \label{fig1}
\end{figure}
  • \caption sets the caption and the number.
  • \label must come after \caption. Then \ref{fig1} gives the number and \pageref{fig1} the page.
  • A figure with no caption is an unnumbered float.
  • Several captions in one figure environment give several figures that float together.
  • \caption[Short]{Long text}: the short version appears in the list of figures.
  • \listoffigures prints the list of figures.

Placement

The optional argument in square brackets says where the float may go:

LetterMeaning
hHere, where the command is, if there is room
tTop of a page
bBottom of a page
pOn a page of its own (a float page)

With no option, the default is [tbp]. A common choice is \begin{figure}[htbp].

Forcing floats out

  • \clearpage places all waiting floats and starts a new page.
  • \FloatBarrier (package placeins) places waiting floats without starting a new page. \usepackage[section]{placeins} puts a barrier before each section.
  • \afterpage{\clearpage} (package afterpage) clears floats at the next page break.

Controlling how many floats

\setcounter{totalnumber}{2}      % at most 2 floats on any text page
\renewcommand{\textfraction}{0.3}  % at least 30% of a text page must be text
SettingDefaultMeaning
topnumber2Max floats at the top of a text page
bottomnumber1Max floats at the bottom
totalnumber3Max floats on any text page
textfraction0.2Min fraction of a text page that must be text
topfraction0.7Max fraction of a text page used by floats at the top
bottomfraction0.3Max fraction used by floats at the bottom
floatpagefraction0.5Min fraction of a float page that must be filled

A ! in the placement options makes LaTeX ignore the first three settings.

11.2 The table environment

A table environment works the same way as figure, but holds a tabular. It has a caption and a label.

\begin{table}[htbp]
  \centering
  \caption{Marks awarded in the LaTeX internal examination}
  \label{tab:marks}
  \begin{tabular}{lcc}
    \hline
    Student &amp; Assignment &amp; Viva \\
    \hline
    Student A &amp; 9 &amp; 8 \\
    Student B &amp; 7 &amp; 9 \\
    \hline
  \end{tabular}
\end{table}

Refer to it as Table~\ref{tab:marks}. The tilde is a non-breaking space, so "Table" and the number stay together.

Tabular and tabular*

\begin{tabular}[pos]{cols} rows \end{tabular}
\begin{tabular*}{width}[pos]{cols} rows \end{tabular*}
  • pos: t aligns the top row with the text baseline, b the bottom row. Default: centred.
  • tabular* sets a fixed total width. Its columns need @{\extracolsep{\fill}} to stretch.
  • Column letters: l, c, r, {wd} (a paragraph of width wd), *{n}{cols} (repeat n times), | (vertical line), @{text} (insert text between columns, removing the normal gap).

Table style parameters

ParameterControls
\tabcolsepHalf the gap between columns
\arrayrulewidthThickness of table lines
\doublerulesepGap between the two lines of a double rule
\arraystretchMultiplier for the row spacing (default 1; 1.5 adds 50%)

Set them with \setlength (for lengths) or \renewcommand (for \arraystretch). Do not change them inside the tabular itself.

Remember (Part 11)
  • Put every figure in a figure environment and every table in a table environment.
  • \label goes after \caption.
  • Let LaTeX place floats. Use [htbp] to give it options, and \clearpage to force them out.

12. Graphics inclusion

Not a numbered syllabus unit · Primer pages 179–185 · relevant to figures (unit 15) and to Module V

In plain words. Some pictures come from other programs: graphs of data, photographs. The graphicx package includes such a file in your document and can scale, rotate and crop it. LaTeX only reserves the space; the driver (dvips, xdvi, pdflatex) draws the picture.

12.1 Loading and including

\usepackage{graphicx}
\usepackage[dvips]{graphicx}     % if the output is made with dvips
\usepackage[xetex]{graphicx}     % if the engine is xelatex
\includegraphics{ellipse}                     % the file's own size
\includegraphics[scale=0.5]{ellann.eps}      % half the size
\includegraphics[width=4cm,height=0.5cm]{ellann.eps}   % fit a box
\includegraphics[angle=60]{ellann.pdf}       % rotated, counter-clockwise
Order matters. The keys are applied from left to right. [width=4cm,height=1cm,angle=60] scales the picture first and then rotates it. [angle=60,width=4cm,height=1cm] rotates first and then scales the rotated picture into the box. The results are different.

12.2 Clipping a picture

An EPS file has a bounding box line, such as %%BoundingBox: 249 604 362 689, giving the lower-left and upper-right corners in points. To show only part of the picture, give a new bounding box with bb= and add clip:

\includegraphics[bb=249 604 362 646.5,clip]{ellann.eps}   % lower half only

Stacking two clipped halves with \\[-1.253pt] between them rebuilds the whole picture.

12.3 Finding files

\graphicspath{{dir1/}{dir2/}}          % look in these folders too
\DeclareGraphicsExtensions{.eps,.ps}  % extensions to try when none is given

With the extensions set, \includegraphics{file} looks for file.eps, then file.ps, and so on.

Note on modern use. The primer was written for EPS files and the dvips driver. With pdflatex today, PNG, JPG and PDF files are normal, and you write the file name with its extension, for example \includegraphics[width=0.6\textwidth]{plot.png}. The keys (width, scale, angle) are the same.

12.4 Drawing in LaTeX

The primer draws its elliptic annulus with pstricks, a package for drawing inside TeX. It is an extra topic, not part of the syllabus.

13. Cross references

Syllabus unit 16 (sections 13.1 and 13.2 only) · Primer pages 187–196

In plain words. A cross reference is a pointer to another part of the same document: "see Section 2", "by Theorem 3.1". Writing the numbers by hand breaks when you add a section. Instead, give the target a label with \label{key}, and point to it with \ref{key}. LaTeX fills in the right number.

13.1 Labels and references

\section{Why cross references}\label{intro}
...
(see Section \ref{intro} for details)
  • The label can go anywhere inside the section, not only right after the heading.
  • The key can be any mix of letters, digits and punctuation. Use a memorable one, such as limcon for "Limits and Continuity".
  • Type ~\ref{limcon} with a tilde, so the number never starts a new line on its own.
  • The first run writes the references to the .aux file and prints "There were undefined references". A second run fixes them. Run again after any change.

13.2 Other kinds of target

TargetHow to label it
Section, chapter\section{...}\label{key}
Item in an enumerated list\item All men are mortal.\label{pre1}, then (\ref{pre1})
Figure or table\caption{...}\label{tabxy}: the label comes after the caption
Theorem\begin{theorem}\label{diffcon}
Equation\begin{equation}\label{sumsq}, then \eqref{sumsq}

Equations with amsmath

Equation~\eqref{sumsq} gives the following.      % prints "Equation (13.1)"

\begin{align}
  (x+y)^2 &amp;= x^2+2xy+y^2 \label{sum}\\
  (x-y)^2 &amp;= x^2-2xy+y^2 \tag{\ref{sum}a}
\end{align}

\eqref adds the brackets around the number. In an align, the second line's tag can reuse the first line's number with a letter, as shown: (13.2) and (13.2a).

Forward references

You can refer to a label that comes later in the document, in the same way. The second run then gets it right.

13.3 Page numbers: \pageref and varioref

see Table~\ref{tabxy} in page~\pageref{tabxy}

The package varioref adds smart page references with \vref{key}. If the target is on the same page, it prints only the number. If it is on the next page, it adds "on the following page". Its page phrases can be changed with \reftextbefore and \reftextafter.

\usepackage{varioref}
see the \vpageref[above table][table~]{tabxy}   % "above table" if same page

13.4 Other documents: xr, and the key list

The xr package lets one document refer to labels in another file: \usepackage{xr} and \externaldocument{other} in the preamble. Two external files with the same key can be told apart with a prefix: \externaldocument[a-]{other}, then \ref{a-key}.

Remember (Part 13)
  • Label after the thing being labelled (after \caption for floats).
  • Reference with \ref, or \eqref for equations.
  • Compile twice after adding or moving labels.
  • Use ~ before a reference so "Table 1" stays together.

14. Footnotes, margin notes and endnotes

Syllabus unit 17 (section 14.1 only) · Primer pages 197–205

14.1 Footnotes

In plain words. A footnote is a note at the bottom of the page, linked to a number in the text. LaTeX numbers it and places it for you. 
A footnote is written with \footnote{footnote text}.

The footnote text is set smaller, below a short rule. The first line of the footnote is indented and carries the same mark as the text.

Footnotes in a minipage or table

Inside a minipage, a plain \footnote is set at the bottom of that minipage, and it uses its own counter. To put a footnote mark in the minipage but print the note at the bottom of the page, use \footnotemark in the text and \footnotetext after the minipage:

\begin{minipage}{5cm}
  This text references a footnote at the bottom of the page.\footnotemark
\end{minipage}
\footnotetext{At bottom of page}
Tables. A plain \footnote inside tabular does not print correctly. Use longtable or tabularx, or put the table in a minipage. The threeparttable package is the cleanest way to set table notes, with \tnote{a} marks and a tablenotes list.

Changing the look

\setcounter{footnote}{0}           % restart numbering (before a section)
\renewcommand{\thefootnote}{\fnsymbol{footnote}}   % * \dagger \ddagger ...
\footnote[7]{Marker shown as 7.}  % a footnote with a set number
  • \thefootnote sets the style: \arabic, \roman, \alph, \fnsymbol (symbols for 1 to 9).
  • Restore the normal numbers with \renewcommand{\thefootnote}{\arabic{footnote}} after using symbols.
  • Style parameters: \footnotesize (font), \footnotesep (strut at the start), \footnoterule (the line above the notes).

14.2 Marginal notes

text\marginpar{This is a marginal note}

The note prints in the margin, starting at the height of the line where the command sits. With one argument it goes to the right margin (one-sided) or the outside margin (two-sided). With two arguments, \marginpar[left]{right}, the first is for the left margin.

  • \reversemarginpar and \normalmarginpar switch the margin.
  • \marginparwidth, \marginparsep and \marginparpush set the size and spacing.
  • \marginpar does not start a paragraph. If it sits before the first word of a paragraph, the alignment can be off.

14.3 Endnotes

Endnotes are collected at the end of a chapter or document. They are not in standard LaTeX; the endnotes package adds them.

\usepackage{endnotes}
This is simple text.\endnote{The first endnote.}
\theendnotes     % prints all the endnotes collected so far

Writing \renewcommand{\footnote}{\endnote} turns every footnote into an endnote.

Remember (Part 14)
  • \footnote{text} goes right after the word it explains.
  • Footnotes do not work inside tabular; use longtable, threeparttable, or a minipage.
  • Use \footnotemark and \footnotetext to keep a minipage footnote in the page sequence.

Appendix B. Common mistakes

SymptomLikely cause and fix
Extra spaces disappear after a command wordTeX eats spaces after a command. Write \LaTeX\ is.
Whole rest of the page is bold, or in one fontA declaration such as \bfseries lasts until the end of its group. Wrap it in braces with its text: {\bfseries text}.
A % removes the end of a lineA % starts a comment. Write \% to print it.
Superscript or subscript shows the wrong lettersMissing braces: x^{mn}, not x^mn.
A list item loses its text inside square bracketsThe brackets are read as an item label. Put the maths in $...$.
Enumerate labels show (11), (22)A letter in the label argument is a numbering code. Wrap it in braces.
Theorem note is wrong, e.g. "(0,1)"The same square-bracket trap. Use $[0,1]$ at the start of the theorem.
Table columns misalignedCount the & signs: each row needs one fewer than the number of columns. Check that every row ends with \\.
"?" in place of a citation or referenceRun LaTeX again. For citations, run the bibtex step first.
\index gives no indexAdd \makeindex in the preamble, and run makeindex between two LaTeX runs.
Error "Missing $ inserted"A maths symbol (such as _, ^) is used outside maths. Wrap it in $...$.
Error at \rightEvery \left needs a matching \right (use \right. to hide one).
Error "Undefined control sequence"A command is misspelt, or its package is not loaded (for example \mathbb needs amssymb).
Overfull box warningA line is wider than the text. Reword or allow a break; an \fbox never breaks.
First error wins. When compilation fails, read the log file. The first error message is the real one; later messages are often side effects.

The primer's workflow, with the commands it uses (on GNU/Linux, typed in a terminal):

The primer also shows the viewing step: xdvi file opens a DVI file in X Window. With pdflatex the output is a PDF, which any PDF viewer opens.

Why twice? LaTeX writes the page numbers and labels to auxiliary files during one run and reads them in the next. Until the second run, the numbers may be out of date. When in doubt, run it again until the log says "Rerun" no more.
