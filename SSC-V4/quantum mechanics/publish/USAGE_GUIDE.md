## 1. Color Palette & Typography Specifications

- **Background Canvas**: `#0c0e12` (Obsidian Onyx)
- **Primary Accent**: `#4e8cff` (Electric Royal Blue)
- **Secondary Accent**: `#2ce89b` (Emerald Mastery Green)
- **Attention / Trap Warning**: `#ff5370` (Coral Laser Red)
- **Muted Structural Lines**: `rgba(255, 255, 255, 0.08)`
- **Header Font**: Inter, Plus Jakarta Sans, or Cabinet Grotesk (700 Bold / 800 Extra Bold)
- **Math / Technical Font**: JetBrains Mono, Fira Code, or KaTeX Serif

## 3. Step-by-Step Production Process

1. **Step 1: Generate Mockup Background**
   - Run the prompt from `IMAGE_PROMPT.md` in Midjourney, FLUX.1, or Google Imagen.
   - Alternatively, use a clean 3-phone device mockup template in Figma / Canva.
2. **Step 2: Place True Mobile Screenshots**
   - Replace the screen frames with:
     - Phone 1: `screenshots/01_qm_mobile_dashboard_dark.png`
     - Phone 2 (Hero): `screenshots/04_qm_mobile_concept_bloch_sphere.png`
     - Phone 3: `screenshots/06_qm_mobile_interactive_omr_quiz.png`
3. **Step 3: Overlay Badges & Callout Lines**
   - Add glowing gradient pill badges pointing to key screen areas (Bloch Sphere, OMR lock button, Progress rings).
4. **Step 4: Generate Scannable QR Code**
   - Encode: `https://ssc-data-science-qm.web.app/phy/quantum-mechanics`
   - Place in the bottom right corner.
5. **Step 5: Export for Distribution**
   - Export as high-quality PNG (1080×1920 for Mobile Status / Reels / Shorts / WhatsApp Stories, 1200×675 for Twitter / LinkedIn / Telegram channels).
