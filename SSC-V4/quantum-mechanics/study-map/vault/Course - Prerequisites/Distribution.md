# Distribution

**One-line meaning:** An object defined by how it acts on smooth functions rather than by pointwise values.

**Formal definition:** A distribution is a linear, [[Continuity|continuous]] rule on [[Test Function|smooth test functions]] with [[Compact Support|compact support]]. The delta distribution acts as $\delta[f]=f(0)$. [[Compact Support|Compact support]] means the [[Function|function]] vanishes outside some finite interval; [[Continuity|continuity]] means small test-[[Function|function]] changes give small output changes in this setting.

**Why it matters here:** Supports 10 Module 3 questions.

**Tiny example:** $\delta[x^2+1]=1$ when evaluated locally with a suitable test function.
