# Test Function

**One-line meaning:** A smooth input function used to probe a distribution.

**Formal definition:** A test function here has derivatives of all orders and vanishes outside some bounded interval. Distributions act on such functions.

**Why it matters here:** Supports 10 Module 3 questions.

**Tiny example:** A smooth bump that is zero outside $[-1,1]$ is a test function.
