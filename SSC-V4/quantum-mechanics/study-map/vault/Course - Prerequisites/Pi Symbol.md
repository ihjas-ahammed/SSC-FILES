# Pi Symbol

**One-line meaning:** π denotes a fixed real number, approximately 3.14159.

**Formal definition:** $\pi=3.14159\ldots$ is a [[Real Number]]. In this module $2\pi$ occurs in the [[Fourier Transform]] normalization.

**Why it matters here:** Supports 4 Module 3 questions.

**Tiny example:** $2\pi\approx6.28318$.
