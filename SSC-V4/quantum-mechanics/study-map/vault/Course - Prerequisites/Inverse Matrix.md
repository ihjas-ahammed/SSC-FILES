# Inverse Matrix

**One-line meaning:** A matrix that reverses another matrix’s action.

**Formal definition:** For a square [[Matrix|matrix]], $A^{-1}A=AA^{-1}=I$. An inverse exists exactly when the [[Determinant|determinant]] is nonzero.

**Why it matters here:** Supports 8 Module 3 questions.

**Tiny example:** $\operatorname{diag}(2,3)^{-1}=\operatorname{diag}(1/2,1/3)$.
