# Eigenvalue

**One-line meaning:** The factor by which an operator scales an eigenvector.

**Formal definition:** If $A|v\rangle=\lambda|v\rangle$ for nonzero $|v\rangle$, then $\lambda$ is its eigenvalue.

**Why it matters here:** Supports 12 Module 3 questions.

**Tiny example:** $A\begin{pmatrix}1\\0\end{pmatrix}=2\begin{pmatrix}1\\0\end{pmatrix}$ gives eigenvalue $2$.
