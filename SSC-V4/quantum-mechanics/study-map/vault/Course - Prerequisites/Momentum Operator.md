# Momentum Operator

**One-line meaning:** The operator that differentiates a position wave function with a quantum scale factor.

**Formal definition:** $(\hat p\psi)(x)=-i\hbar\,d\psi/dx$ on a suitable domain. A plane wave $e^{ipx/\hbar}$ satisfies $\hat p e^{ipx/\hbar}=p e^{ipx/\hbar}$.

**Why it matters here:** Supports 3 Module 3 questions.

**Tiny example:** $\hat p e^{ikx}=\hbar k e^{ikx}$.
