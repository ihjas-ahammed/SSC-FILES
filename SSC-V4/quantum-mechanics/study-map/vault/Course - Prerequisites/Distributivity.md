# Distributivity

**One-line meaning:** Multiplication spreads across a sum.

**Formal definition:** $a(b+c)=ab+ac$. [[Vector|Vector]]-[[Mathematical Space|space]] [[Scalar|scalar multiplication]] obeys $a(u+v)=au+av$ and $(a+b)v=av+bv$.

**Why it matters here:** Supports 32 Module 3 questions.

**Tiny example:** $2(3+4)=2\cdot3+2\cdot4=14$.
