# Function

**One-line meaning:** A rule that assigns one output to each allowed input.

**Formal definition:** A function $f$ sends an input $x$ to a single output $f(x)$.

**Why it matters here:** Supports 31 Module 3 questions.

**Tiny example:** $f(x)=x^2$ sends $3$ to $9$.
