# Absolute-Value Bars

**One-line meaning:** Single bars around a number give its nonnegative size.

**Formal definition:** For $z=a+ib$, $|z|=\sqrt{a^2+b^2}$ is the [[Absolute Value]] of a [[Complex Number Arithmetic|complex number]]. It is not the same notation as the [[Ket]] $|\psi\rangle$.

**Why it matters here:** Supports 12 Module 3 questions.

**Tiny example:** $|3+4i|=5$.
