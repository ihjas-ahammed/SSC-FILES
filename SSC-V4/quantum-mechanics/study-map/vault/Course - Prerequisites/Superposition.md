# Superposition

**One-line meaning:** A quantum state made by adding scaled state vectors.

**Formal definition:** $a|u\rangle+b|v\rangle$ is a superposition; it is [[Normalization|normalized]] separately when needed.

**Why it matters here:** Supports 18 Module 3 questions.

**Tiny example:** $(|1\rangle+|2\rangle)/\sqrt2$ is normalized for orthonormal basis states.
