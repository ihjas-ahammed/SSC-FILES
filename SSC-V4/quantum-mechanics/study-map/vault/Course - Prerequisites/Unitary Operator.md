# Unitary Operator

**One-line meaning:** An invertible operator that preserves overlaps and lengths.

**Formal definition:** $U^\dagger U=UU^\dagger=I$; hence $U^{-1}=U^\dagger$ and $\langle Uu|Uv\rangle=\langle u|v\rangle$.

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** A real rotation matrix is unitary.
