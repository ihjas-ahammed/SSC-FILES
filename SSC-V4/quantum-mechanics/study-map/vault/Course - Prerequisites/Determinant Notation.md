# Determinant Notation

**One-line meaning:** det asks for the determinant of a square matrix.

**Formal definition:** $\det(A-\lambda I)=0$ is a [[Secular Equation]] using the [[Determinant]] of a [[Matrix]]. It is different from the [[Trace]].

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** $\det\begin{pmatrix}2&0\\0&3\end{pmatrix}=6$.
