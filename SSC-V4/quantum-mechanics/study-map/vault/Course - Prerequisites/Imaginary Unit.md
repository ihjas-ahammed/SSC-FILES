# Imaginary Unit

**One-line meaning:** i is the number whose square is −1.

**Formal definition:** The imaginary unit satisfies $i^2=-1$ in [[Complex Number Arithmetic]]. In sums, the same letter can instead be an [[Integer]] index; context distinguishes them.

**Why it matters here:** Supports 11 Module 3 questions.

**Tiny example:** $(-i)i=1$.
