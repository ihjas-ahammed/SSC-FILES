# Quantum State

**One-line meaning:** The mathematical description of a system’s preparation used to predict measurement outcomes.

**Formal definition:** A pure state is represented by a [[Normalization|normalized]] [[Vector|vector]] in a [[Hilbert Space|Hilbert space]], with [[Vector|vectors]] differing by a common factor $e^{i\theta}$ representing the same pure state. This module uses pure-state [[Vector|vectors]]; more general mixed states require a different representation.

**Why it matters here:** Supports 29 Module 3 questions.

**Tiny example:** $\begin{pmatrix}1\\0\end{pmatrix}$ and $i\begin{pmatrix}1\\0\end{pmatrix}$ represent the same pure state.
