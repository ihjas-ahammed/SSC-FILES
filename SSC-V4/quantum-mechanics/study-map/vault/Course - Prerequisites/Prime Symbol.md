# Prime Symbol

**One-line meaning:** A prime marks a related object whose definition is stated nearby.

**Formal definition:** A prime does not have one universal meaning. In a [[Change of Basis]], $A'=U^\dagger AU$; in an [[Uncertainty Relation]], $A'=A-\langle A\rangle I$. Read its local definition.

**Why it matters here:** Supports 3 Module 3 questions.

**Tiny example:** $c'=U^\dagger c$ labels the new [[Coordinate|coordinates]].
