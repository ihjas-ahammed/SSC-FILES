# Square-Integrable Function

**One-line meaning:** A function whose squared size has a finite integral.

**Formal definition:** $f$ is square-integrable if $\int_{-\infty}^{\infty}|f(x)|^2dx<\infty$. Functions differing only on a [[Set|set]] of zero length are identified. The resulting $L^2$ [[Mathematical Space|space]] is complete with $\langle f|g\rangle=\int f^*(x)g(x)dx$.

**Why it matters here:** Supports 18 Module 3 questions.

**Tiny example:** $e^{-|x|}$ is square-integrable; the constant function 1 on the whole line is not.
