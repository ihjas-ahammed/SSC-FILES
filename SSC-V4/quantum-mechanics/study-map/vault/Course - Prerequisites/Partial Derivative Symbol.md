# Partial Derivative Symbol

**One-line meaning:** ∂ measures change in one input while keeping other inputs fixed.

**Formal definition:** For a [[Function]] of several [[Coordinate|coordinates]], $\partial f/\partial x$ is a [[Derivative]] with respect to $x$ while the other coordinates are fixed.

**Why it matters here:** Supports 1 Module 3 questions.

**Tiny example:** $f(x,y)=x^2+y$ gives $\partial f/\partial x=2x$.
