# Polynomial Root

**One-line meaning:** An input making a polynomial’s output zero.

**Formal definition:** $\lambda$ is a root of $p$ if $p(\lambda)=0$.

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** 2 and 3 are roots of $(x-2)(x-3)$.
