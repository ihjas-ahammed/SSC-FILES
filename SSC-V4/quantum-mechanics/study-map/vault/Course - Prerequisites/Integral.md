# Integral

**One-line meaning:** A way to add continuously varying small contributions.

**Formal definition:** $\int_a^b f(x)\,dx$ adds the contributions $f(x)\,dx$ between $a$ and $b$.

**Why it matters here:** Supports 18 Module 3 questions.

**Tiny example:** $\int_0^1 x\,dx=1/2$.
