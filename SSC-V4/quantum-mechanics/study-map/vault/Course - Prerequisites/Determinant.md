# Determinant

**One-line meaning:** A number that detects whether a square matrix can be inverted.

**Formal definition:** For $A=\begin{pmatrix}a&b\\c&d\end{pmatrix}$, $\det A=ad-bc$. More generally, it is the signed sum over all permutations of column choices. $\det A=0$ exactly when a finite square [[Matrix|matrix]] has a nonzero [[Vector|vector]] sent to zero.

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** $\det\begin{pmatrix}2&1\\1&3\end{pmatrix}=5$.
