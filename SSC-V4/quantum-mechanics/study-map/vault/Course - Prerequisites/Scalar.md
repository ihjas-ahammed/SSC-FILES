# Scalar

**One-line meaning:** A number used to scale an object.

**Formal definition:** A scalar is an element of the [[Field|field]] of numbers used for the [[Vector Space|vector space]].

**Why it matters here:** Supports 32 Module 3 questions.

**Tiny example:** In $3(1,2)=(3,6)$, $3$ is the scalar.
