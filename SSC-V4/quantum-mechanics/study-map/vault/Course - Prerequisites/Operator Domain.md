# Operator Domain

**One-line meaning:** The set of vectors on which an operator is defined.

**Formal definition:** $D(A)$ is the [[Set|set]] of allowed inputs of $A$. For a [[Derivative|derivative]] on square-integrable functions, extra [[Derivative|differentiability]] and boundary conditions are required.

**Why it matters here:** Supports 11 Module 3 questions.

**Tiny example:** Not every square-integrable function has a square-integrable derivative.
