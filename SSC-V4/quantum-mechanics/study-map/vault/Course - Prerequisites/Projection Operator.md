# Projection Operator

**One-line meaning:** An operator that keeps a selected component of a vector.

**Formal definition:** For [[Normalization|normalized]] $|n\rangle$, $P_n=|n\rangle\langle n|$ and $P_n^2=P_n=P_n^\dagger$.

**Why it matters here:** Supports 12 Module 3 questions.

**Tiny example:** $P_1\begin{pmatrix}a\\b\end{pmatrix}=\begin{pmatrix}a\\0\end{pmatrix}$.
