# Null Space

**One-line meaning:** All vectors that a linear map sends to zero.

**Formal definition:** $\ker A=\{v:Av=0\}$. A square finite [[Matrix|matrix]] is singular when its null space contains a nonzero [[Vector|vector]].

**Why it matters here:** Supports 1 Module 3 questions.

**Tiny example:** $\operatorname{diag}(1,0)$ sends every $\begin{pmatrix}0\\b\end{pmatrix}$ to zero.
