# Commutativity

**One-line meaning:** Swapping the order of two inputs leaves an operation unchanged.

**Formal definition:** [[Basic Algebra|Addition]] is commutative when $a+b=b+a$; multiplication is commutative when $ab=ba$. [[Matrix|Matrix]] multiplication need not be commutative.

**Why it matters here:** Supports 32 Module 3 questions.

**Tiny example:** $2+3=3+2$.
