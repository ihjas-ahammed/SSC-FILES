# Phi Symbol

**One-line meaning:** φ names a state or wave function whose meaning is defined in the question.

**Formal definition:** $|\phi\rangle$ may label a second [[Ket]]. In a [[Momentum Representation]], $\phi(p)=\langle p|\psi\rangle$ is a momentum [[Wave Function]]. Capital $\Phi$ often labels a [[Basis]] state.

**Why it matters here:** Supports 11 Module 3 questions.

**Tiny example:** $\langle\phi|\psi\rangle$ compares two states.
