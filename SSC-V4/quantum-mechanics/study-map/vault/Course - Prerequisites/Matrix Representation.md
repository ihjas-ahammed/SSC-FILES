# Matrix Representation

**One-line meaning:** Numbers describing a state or operator in a chosen basis.

**Formal definition:** [[Quantum State|State]] [[Coordinate|coordinates]] are $c_i=\langle i|\psi\rangle$. [[Linear Operator|Operator]] entries are $A_{ij}=\langle i|A|j\rangle$, so column $j$ contains the [[Coordinate|coordinates]] of $A|j\rangle$.

**Why it matters here:** Supports 5 Module 3 questions.

**Tiny example:** $A|1\rangle=2|1\rangle+i|2\rangle$ gives first column $\begin{pmatrix}2\\i\end{pmatrix}$.
