# Operator Product

**One-line meaning:** Apply one operator and then another.

**Formal definition:** $(AB)|v\rangle=A(B|v\rangle)$ wherever both applications are defined. The rightmost [[Linear Operator|operator]] acts first.

**Why it matters here:** Supports 17 Module 3 questions.

**Tiny example:** If $B(x)=2x$ and $A(x)=3x$, then $AB(x)=6x$.
