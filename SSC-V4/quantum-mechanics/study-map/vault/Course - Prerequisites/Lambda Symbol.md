# Lambda Symbol

**One-line meaning:** λ is a common label for the number produced by acting on an eigenvector.

**Formal definition:** In $Av=\lambda v$, $\lambda$ labels an [[Eigenvalue]] and $v$ is an [[Eigenvector]]. The letter itself can denote other quantities in other contexts.

**Why it matters here:** Supports 4 Module 3 questions.

**Tiny example:** $A(1,0)=2(1,0)$ has $\lambda=2$.
