# Change of Basis

**One-line meaning:** Describe the same object using different reference vectors.

**Formal definition:** If $|e_j\rangle=\sum_i|i\rangle U_{ij}$, with columns the new [[Orthonormal Basis|orthonormal basis]] in old [[Coordinate|coordinates]], then $c_{new}=U^\dagger c_{old}$ and $A_{new}=U^\dagger A_{old}U$.

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** Taking new basis vectors to be eigenvectors produces a diagonal operator matrix.
