# Negligible Set

**One-line meaning:** A set of points whose total length can be made smaller than any positive number.

**Formal definition:** A [[Set]] $N$ has zero length if, for every [[Real Number]] $\epsilon>0$, intervals can cover $N$ with total length less than $\epsilon$. Such sets do not change an [[Integral]] when an integrable [[Function]] is changed only on them.

**Why it matters here:** Supports 1 Module 3 questions.

**Tiny example:** A single point can be covered by an interval of length $\epsilon/2$, however small $\epsilon$ is.
