# Spectral Theorem

**One-line meaning:** A finite Hermitian matrix has a complete orthonormal set of eigenvectors.

**Formal definition:** For an $n\times n$ [[Hermitian Operator|Hermitian matrix]], there is an [[Orthonormal Basis|orthonormal eigenbasis]] with real [[Eigenvalue|eigenvalues]] and $A=\sum_j\lambda_j|j\rangle\langle j|$. In infinite dimensions a [[Self-adjoint Operator|self-adjoint operator]] has a spectral measure; [[Normalization|normalizable]] [[Eigenvector|eigenvectors]] need not form a discrete [[Basis|basis]].

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** $\operatorname{diag}(2,3)=2P_1+3P_2$.
