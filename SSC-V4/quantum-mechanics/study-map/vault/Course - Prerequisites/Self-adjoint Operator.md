# Self-adjoint Operator

**One-line meaning:** An operator matching its adjoint in both action and allowed inputs.

**Formal definition:** $A=A^\dagger$ and $D(A)=D(A^\dagger)$. In finite dimensions this is the same as being [[Hermitian Operator|Hermitian]].

**Why it matters here:** Supports 6 Module 3 questions.

**Tiny example:** The momentum derivative requires a suitable domain and boundary conditions to be self-adjoint.
