# Compact Support

**One-line meaning:** A function is zero beyond a finite region.

**Formal definition:** On the real line, a [[Function|function]] has compact support when it vanishes outside some closed bounded interval.

**Why it matters here:** Supports 10 Module 3 questions.

**Tiny example:** A function zero for $|x|>1$ has compact support.
