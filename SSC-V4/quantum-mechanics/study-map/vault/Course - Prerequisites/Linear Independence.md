# Linear Independence

**One-line meaning:** No vector in the collection can be made from the others.

**Formal definition:** $v_1,\ldots,v_n$ are linearly independent if $\sum_i a_iv_i=0$ implies every $a_i=0$.

**Why it matters here:** Supports 19 Module 3 questions.

**Tiny example:** $(1,0)$ and $(0,1)$ are independent; $(1,0)$ and $(2,0)$ are not.
