# Diagonal Matrix

**One-line meaning:** A square matrix whose entries outside the main diagonal are zero.

**Formal definition:** $D_{ij}=0$ whenever $i\ne j$; its diagonal entries are $D_{ii}$.

**Why it matters here:** Supports 3 Module 3 questions.

**Tiny example:** $\begin{pmatrix}2&0\\0&3\end{pmatrix}$ is diagonal.
