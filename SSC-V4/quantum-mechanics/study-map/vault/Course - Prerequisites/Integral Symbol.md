# Integral Symbol

**One-line meaning:** ∫ adds continuously varying contributions over a range.

**Formal definition:** $\int_a^b f(x)\,dx$ is an [[Integral]] over the input $x$ from $a$ to $b$. The $dx$ states which input varies. Infinite bounds denote suitable [[Limit|limits]].

**Why it matters here:** Supports 6 Module 3 questions.

**Tiny example:** $\int_0^1x\,dx=1/2$.
