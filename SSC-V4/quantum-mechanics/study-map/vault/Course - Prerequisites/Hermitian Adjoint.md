# Hermitian Adjoint

**One-line meaning:** The operator obtained by moving an operation across an inner product.

**Formal definition:** $\langle u|Av\rangle=\langle A^\dagger u|v\rangle$ for allowed [[Vector|vectors]]. For matrices, $(A^\dagger)_{ij}=A_{ji}^*$.

**Why it matters here:** Supports 13 Module 3 questions.

**Tiny example:** For $A=\begin{pmatrix}1&i\\2&3\end{pmatrix}$, $A^\dagger=\begin{pmatrix}1&2\\-i&3\end{pmatrix}$.
