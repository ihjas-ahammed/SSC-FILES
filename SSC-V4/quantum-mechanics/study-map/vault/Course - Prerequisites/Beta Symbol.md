# Beta Symbol

**One-line meaning:** β is another Greek-letter label defined for the calculation.

**Formal definition:** In the [[Uncertainty Relation]] proof, $|\beta\rangle=(B-\langle B\rangle I)|\psi\rangle$ is a [[Ket]]. The letter can have other roles elsewhere.

**Why it matters here:** Supports 2 Module 3 questions.

**Tiny example:** $\langle\beta|\beta\rangle=(\Delta B)^2$.
