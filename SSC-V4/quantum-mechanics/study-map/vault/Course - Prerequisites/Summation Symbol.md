# Summation Symbol

**One-line meaning:** Σ asks you to add the listed contributions.

**Formal definition:** $\sum_{j=1}^n c_j=c_1+\cdots+c_n$, with [[Integer]] labels $j$. [[Linear Combination|Linear combinations]] use this notation to add scaled [[Vector|vectors]].

**Why it matters here:** Supports 5 Module 3 questions.

**Tiny example:** $\sum_{j=1}^3j=1+2+3=6$.
