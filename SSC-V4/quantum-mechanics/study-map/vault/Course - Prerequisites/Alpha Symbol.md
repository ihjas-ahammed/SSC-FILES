# Alpha Symbol

**One-line meaning:** α is a Greek-letter label defined for the current calculation.

**Formal definition:** $\alpha$ can label an [[Eigenvalue]] in $A|\alpha\rangle=\alpha|\alpha\rangle$, or $|\alpha\rangle$ can name the centered [[Ket]] $(A-\langle A\rangle I)|\psi\rangle$. Use the stated definition.

**Why it matters here:** Supports 3 Module 3 questions.

**Tiny example:** In the uncertainty proof, $|\alpha\rangle=A'|\psi\rangle$.
