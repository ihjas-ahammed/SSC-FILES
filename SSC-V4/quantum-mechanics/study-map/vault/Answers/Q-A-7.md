# Question
Using basic commutation relation [x, p] = iℏ evaluate [x, p²] and [x², p]

# Formal Answer
Use the product rules $[A,BC]=[A,B]C+B[A,C]$ and $[AB,C]=A[B,C]+[A,C]B$, with $[x,p]=i\hbar I$.

Then $[x,p^2]=[x,p]p+p[x,p]=i\hbar p+pi\hbar=2i\hbar p$.

Likewise $[x^2,p]=x[x,p]+[x,p]x=xi\hbar+i\hbar x=2i\hbar x$.
