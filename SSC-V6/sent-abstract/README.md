# sent-abstract: Abstract Algebra I PYQ generation bundle

Give this whole folder to one model. Every file it needs is inside this folder.
The model returns ONE file: `abstract-pyq.json` (or one file per paper, see PROMPT.md section 6).
The rules, the card formats and the derivation format are in PROMPT.md. Read it first.

## Contents

- PROMPT.md: the task, the card formats, the derivation format (with a worked example
  that passes the study app's builder), and the checks before returning.
- originals/: the Abstract Algebra papers, Nov 2018 to Nov 2025, as HTML transcriptions
  (12 files). Theory-of-equations papers carry algebra questions only; the rest is skipped.
- textbook/: Fraleigh, *A First Course in Abstract Algebra*, 8th ed., excerpts for
  printed pages of Modules 1–4 (4 files).
- syllabus/syllabus.pdf: MAT5CJ302 syllabus (scope check; the syllabus names the 7th ed.).
- reference/units-abstract.json: the 22 syllabus items (u = 1–22, module I–IV) and unit 0
  for the open-ended Module V.

The module PYQ files and model papers are not in this bundle.
