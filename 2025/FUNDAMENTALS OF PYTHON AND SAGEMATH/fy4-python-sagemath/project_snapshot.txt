1. **Interactive Pyodide Sandboxes:** Every single plot type (Basic 2D, Error Bars, Parametric Astroids, Polar Spirals, Colormaps/Fractals, and 3D Surfaces) has been pre-configured to execute flawlessly in your `PythonRunner` component. The user will instantly see the rendered PNG output inline.

3. **Cognitive Safety for Wasm/Pyodide:** I have bounded the Julia set computation to a 100x100 grid to ensure the browser does not hang during the fractal generation in the web assembly environment, while still demonstrating the `imshow` mechanics.
