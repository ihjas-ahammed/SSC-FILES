Fourier Analysis of Vibrating String

1. Aim & Principle

Aim: To analyze the frequency spectrum of a stretched string (like a guitar) using Fast Fourier Transform (FFT).

Principle: A vibrating string produces a sound composed of a Fundamental Frequency (f1) and several Harmonics (multiples of f1).

The FFT (Fast Fourier Transform) is an algorithm that breaks a complex time-domain signal into its constituent frequencies.

Frequency of nth mode: fn=n2LTm

Where: n = Harmonic number (1, 2, 3...), L = Length, T = Tension, m = Linear Density.

3. Real Lab Procedure (Python)

In the physical lab, you record a guitar sound as a .wav file. Use the following Python code to perform the FFT and plot the spectrum.

import numpy as np
import matplotlib.pyplot as plt
from scipy.io import wavfile
from scipy.fft import fft, fftfreq

# 1. Load the sound file
sampling_rate, data = wavfile.read('guitar_string_sound.wav')

# 2. Pre-process (Convert stereo to mono if needed)
if len(data.shape) > 1:
    data = data.mean(axis=1)

# 3. Perform the FFT
n = len(data)
yf = fft(data)
xf = fftfreq(n, 1 / sampling_rate)

# 4. Filter for positive frequencies only
xf_positive = xf[:n // 2]
yf_magnitude = np.abs(yf[:n // 2])

# 5. Plot
plt.figure(figsize=(10, 4))
plt.plot(xf_positive, yf_magnitude)
plt.title("Frequency Spectrum")
plt.xlabel("Frequency (Hz)")
plt.ylabel("Magnitude")
plt.grid()
plt.show()
