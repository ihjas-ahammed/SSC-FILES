MODULE 1: MODEL ANSWERS
For checking your work. Each answer shows the key step and the result.

Section A. 1. A translation vector is T = n1a + n2b + n3c. It is primitive when the coefficients n1, n2, n3 are integers (book §1.2). 2. 32 point groups (book §1.6). 3. 14 Bravais lattices (book §1.7). 4. 6 (book §1.10.2: each atom touches six neighbours along the cube edges). 5. 12 members (book §1.8). 6. 8 members (book §1.8).

Section B. 7. n = 1, 2, 3, 4 or 6 (book §1.5, Eqs. 1.3 and 1.4). 8. 1m and 2mm (book Table 1.1). 9. N = Ni + Nf/2 + Nc/8 = 1 + 0 + 8/8 = 2 (book §1.7, Eq. 1.5: the body-centre point is inside the cell and counts 1; each of the eight corners counts 1/8). 10. Na+ at (0, 0, 0) and Cl− at (a/2, 0, 0) of an fcc lattice (book §1.13).

Section C. 11. Normal to (100) is [100]; normal to (110) is [110]. cosθ = 1/√2, so θ = 45° (book §1.8, Eq. 1.6). 12. Reciprocal lattice of a simple cubic lattice is simple cubic: a* = (2π/a)i, b* = (2π/a)j, c* = (2π/a)k (book §2.4.2, Eq. 2.21). 13. Simple cubic: a = 2r, one atom per cell, so f = (4/3)πr3/a3 = π/6 ≈ 0.52 (book §1.10.2). 14. An fcc lattice with a two-atom basis: one atom at (0, 0, 0) and one at (a/4)(1, 1, 1). Coordination number 4; nearest-neighbour distance √3a/4 (book §1.11 and §1.12). 15. The condition from the Ewald-type relation (Eq. 2.31) for h = ±1, k = 0 gives kx = ±π/a, and for h = 0, k = ±1 gives ky = ±π/a. These four lines bound a square of side 2π/a (book §2.7, Fig. 2.14). 16. 6 nearest neighbours at distance a (book Problem 5 of chapter 1, printed answer 6, a).

Section D. 17. Na+ at (0,0,0), (½,½,0), (½,0,½), (0,½,½); Cl− at (½,½,½), (0,0,½), (0,½,0), (½,0,0). Four molecules per cell. Along a cube edge the ions touch: a = 2(r+ + r−) (book §1.13 and Example 1.5). 18. Lattice translation requires cosθ = (m − 1)/2 with |cosθ| ≤ 1, so m = 3, 2, 1, 0, −1. This gives θ = 0°, 60°, 90°, 120°, 180°, and n = 1, 6, 4, 3, 2 (book §1.5, Eq. 1.4). Five is not allowed. The five two-dimensional Bravais lattices are oblique, rectangular primitive, rectangular centred, square and hexagonal (book §1.7 and Table 1.1).
