Section 4: Permutations and Disjoint Cycles (4.8–4.15)
Printed pp. 43–46 (4.8–4.15; Table 4.15)

Before you start

  • The group axioms (Module 1, Definition 2.1) and the notion of isomorphism (Section 2).
  • Functions: composition, one-to-one and onto maps, and inverse functions. A permutation of a set $A$ is a one-to-one function from $A$ onto $A$; the product of two permutations is their composition.
  • Two-row notation for a permutation: the top row lists the elements of $A$ and the bottom row lists where each one goes. The examples below use it. The book introduces it in Section 4 (printed pages 39–42), which is not reproduced here.

1. Permutations form a group

Theorem 4.8 Let $A$ be a nonempty set, and let $S_A$ be the collection of all permutations of $A$. Then $S_A$ is a group under permutation multiplication.

Why. Composing two permutations gives a permutation, so $S_A$ is closed. Permutation multiplication is function composition, which is associative. The identity map $\iota$ with $\iota(a) = a$ is the identity. A permutation $\sigma$ is one-to-one and onto, so it has an inverse function $\sigma^{-1}$, which is again a permutation, and $\sigma^{-1}\sigma = \sigma\sigma^{-1} = \iota$. ◆

Warning. Some texts multiply permutations from left to right, so that $(\sigma\mu)(a) = \mu(\sigma(a))$. Their product $\sigma\mu$ is the one we get by computing $\mu\sigma$. Check the order used in any other text. Exercise 34 asks you to check that both orders still give a group. Its text is printed directly below.

Exercise 34. (See the warning following Theorem 4.8.) Let $G$ be a group with binary operation $\ast$. Let $G'$ be the same set as $G$, and define a binary operation $\ast'$ on $G'$ by $x \ast' y = y \ast x$ for all $x, y \in G'$.

a. (Intuitive argument that $G'$ under $\ast'$ is a group.) Suppose the front wall of your classroom were made of transparent glass, and that all possible products $a \ast b = c$ and all possible instances $a \ast (b \ast c) = (a \ast b) \ast c$ of the associative property for $G$ under $\ast$ were written on the wall with a magic marker. What would a person see when looking at the other side of the wall from the next room in front of yours?
b. Show from the mathematical definition of $\ast'$ that $G'$ is a group under $\ast'$.

The structure of $S_A$ depends only on how many elements $A$ has. If $A$ and $B$ have the same number of elements, then $S_A \simeq S_B$. To see this, take a one-to-one map $f$ of $A$ onto $B$. For a permutation $\sigma$ of $A$, define $\bar\sigma$ on $B$ by $\bar\sigma(f(a)) = f(\sigma(a))$. Then $\sigma \mapsto \bar\sigma$ is an isomorphism. Renaming the elements of $A$ by elements of $B$ in two-row notation is exactly this map. So $\{1, 2, \dots, n\}$ can stand for any finite set of $n$ elements.

Example in the book: with $A = \{1, 2, 3\}$, $B = \{\#, \$, \%\}$, $f(1) = \#$, $f(2) = \$$, $f(3) = \%$, the permutation $\begin{pmatrix}1&2&3\\3&2&1\end{pmatrix}$ of $A$ becomes $\begin{pmatrix}\#&\$&\%\\\%&\$&\#\end{pmatrix}$ of $B$.

Definition 4.9 Let $A = \{1, 2, \dots, n\}$. The group of all permutations of $A$ is the symmetric group on $n$ letters, written $S_n$.

$S_n$ has $n!$ elements, where $n! = n(n-1)(n-2)\cdots(3)(2)(1)$.

$S_3$ is not abelian. Take $\sigma = \begin{pmatrix}1&2&3\\2&1&3\end{pmatrix}$ and $\tau = \begin{pmatrix}1&2&3\\1&3&2\end{pmatrix}$. Then $\sigma\tau(1) = \sigma(1) = 2$, but $\tau\sigma(1) = \tau(2) = 3$. Groups with at most four elements are abelian, and the abelian group $\mathbb{Z}_5$ is the only group of order $5$ up to isomorphism. So $S_3$ is the smallest group that is not abelian.

Example 4.10. To invert a permutation, swap the top and bottom rows and sort the columns so the top row is in order. For $\sigma = \begin{pmatrix}1&2&3&4&5&6\\3&2&6&1&4&5\end{pmatrix}$:

2. Disjoint cycle notation

Two-row notation lists every number twice. Disjoint cycle notation lists each number once. Take $\sigma = \begin{pmatrix}1&2&3&4&5&6\\3&4&6&2&5&1\end{pmatrix}$. Start with $1$. Since $\sigma(1) = 3$, write $(1, 3$. Since $\sigma(3) = 6$, write $(1, 3, 6$. Since $\sigma(6) = 1$, close the cycle: $(1, 3, 6)$. This is a cycle, and a cycle with $k$ entries is a $k$-cycle. Next, $\sigma(2) = 4$ and $\sigma(4) = 2$, so $(2, 4)$ is a $2$-cycle. The number $5$ is fixed, and 1-cycles are usually left out. So

$$\sigma = (1, 3, 6)(2, 4).$$

A $2$-cycle is also called a transposition. Cycles are disjoint if no entry is in more than one cycle. Disjoint cycles can be written in any order, and each cycle can start at any of its entries, as long as the cyclic order is kept. Every permutation of $S_n$ can be written in disjoint cycle form, and that form is unique up to these choices.

Example 4.11. In $S_9$, $\sigma = (1, 5, 2, 7)(3, 4, 9)$. Reading off the cycles: $\sigma(1) = 5$, $\sigma(5) = 2$, $\sigma(2) = 7$, $\sigma(7) = 1$, $\sigma(3) = 4$, $\sigma(4) = 9$, $\sigma(9) = 3$. Since $6$ and $8$ are not in any cycle, $\sigma(6) = 6$ and $\sigma(8) = 8$. So

$$\sigma = \begin{pmatrix}1&2&3&4&5&6&7&8&9\\5&7&4&9&2&6&1&8&3\end{pmatrix}.$$

Since the operation in $S_n$ is composition, the cycles on the right are applied first. Multiplying in disjoint cycle form is the usual way to work with permutations.

Example 4.12. In $S_6$ let $\sigma = (1, 5, 3, 2, 6)$ and $\tau = (1, 2, 4, 3, 6)$. We find $\sigma\tau$ without two-row notation. Start with $1$: $\tau$ sends $1$ to $2$, and then $\sigma$ sends $2$ to $6$, so $\sigma\tau(1) = 6$. Begin the cycle $(1, 6$. Next $\tau(6) = 1$ and $\sigma(1) = 5$, so the cycle is $(1, 6, 5$. Since $\tau(5) = 5$ and $\sigma(5) = 3$, $\sigma\tau(5) = 3$; the cycle is $(1, 6, 5, 3$. Then $3$ maps to $1$, so the first cycle is $(1, 6, 5, 3)$. The number $2$ has not been placed. Since $\sigma\tau(2) = 4$ and $\sigma\tau(4) = 2$, the second cycle is $(2, 4)$. So

$$\sigma\tau = (1, 5, 3, 2, 6)(1, 2, 4, 3, 6) = (1, 6, 5, 3)(2, 4).$$

Move from right to left between the cycles, and from left to right inside each cycle.

Example 4.13. Compute $\sigma = (1, 5)(2, 4)(1, 4, 3)(2, 5)(4, 2, 1)$ in disjoint cycle form. The first cycle on the right sends $1$ to $4$; then $(2, 5)$ does not move $4$, $(1, 4, 3)$ sends $4$ to $3$, $(2, 4)$ does not move $3$, and $(1, 5)$ does not move $3$. So $\sigma(1) = 3$. Continuing gives $\sigma = (1, 3, 5, 4)(2) = (1, 3, 5, 4)$. The group was never named. The same calculation works in $S_5$, $S_6$, or $S_n$ for any $n \ge 5$.

Example 4.14. Take $\sigma = (1, 5, 7)(3, 8, 2, 4, 6)$. Since $(ab)^{-1} = b^{-1}a^{-1}$, we get $\sigma^{-1} = (3, 8, 2, 4, 6)^{-1}(1, 5, 7)^{-1}$. The inverse of a cycle is the same cycle written backward, so $\sigma^{-1} = (6, 4, 2, 8, 3)(7, 5, 1)$. Because disjoint cycles commute and each can start at any entry, this can also be written $\sigma^{-1} = (1, 7, 5)(2, 8, 3, 6, 4)$.

1. Even and odd permutations

Every permutation of a finite set with at least two elements is a product of transpositions (Theorem 8.15), but the product is not unique: $(1, 2)(1, 2)$ is the identity. The number of transpositions can be changed, but only by an even number. The next theorem says the parity cannot be changed.

Theorem 8.19 No permutation in $S_n$ can be expressed both as a product of an even number of transpositions and as a product of an odd number of transpositions.

Proof in outline. Fix $\sigma \in S_n$ and a transposition $\tau = (i, j)$. The claim is that the number of orbits of $\sigma$ and of $\tau\sigma$ differ by exactly $1$.

Case I: $i$ and $j$ lie in different orbits of $\sigma$. Write $\sigma$ as disjoint cycles, one containing $j$ and one containing $i$. Figure 8.20 shows these two orbits as two circles, labelled with $j$, $a$, $b$ and $i$. Symbolically the two cycles are $(b, j, \times, \times, \times)(a, i, \times, \times)$, where $\times$ stands for other elements of the orbits. Multiplying by $(i, j)$ on the left joins the two orbits into one. The product of the first three cycles is

$$(i, j)(b, j, \times, \times, \times)(a, i, \times, \times) = (a, j, \times, \times, \times, b, i, \times, \times).$$

So two orbits become one.

Exercise 42 asks you to repeat this computation for the case where one or both of $i$ and $j$ is the only element of its orbit. It is printed directly below.

Exercise 42. a. Draw a figure like Fig. 8.20 to illustrate that if $i$ and $j$ are in different orbits of $\sigma$ and $\sigma(i) = i$, then the number of orbits of $(i, j)\sigma$ is one less than the number of orbits of $\sigma$.
b. Repeat part (a) if $\sigma(j) = j$ also.

Case II: $i$ and $j$ lie in the same orbit of $\sigma$. Write $\sigma$ as disjoint cycles with the first of the form $(a, i, \times, \times, \times, b, j, \times, \times)$. Multiplying by $(i, j)$ splits this orbit into two, as Figure 8.21 shows: the product of the first two cycles is

$$(i, j)(a, i, \times, \times, \times, b, j, \times, \times) = (a, j, \times, \times, \times)(b, i, \times, \times, \times).$$

So one orbit becomes two.

In both cases the number of orbits changes by $1$. The identity $\iota$ has $n$ orbits, since each element is alone in its orbit. A permutation $\sigma$ then has a number of orbits that differs from $n$ by an even number, or by an odd number, but not both. If $\sigma = \tau_1\tau_2\cdots\tau_m\iota$ with $m$ even and also with $m$ odd, this would be impossible. ◆

Definition 8.22 A permutation of a finite set is even or odd according as it can be written as a product of an even number of transpositions, or as a product of an odd number of transpositions.

Example 8.23. The identity $\iota$ in $S_n$ is even, since $\iota = (1, 2)(1, 2)$. For $n = 1$ the identity cannot be written as such a product, and we define it to be even. The permutation $(1, 4, 5, 6)(2, 1, 5)$ in $S_6$ can be written

$$(1, 4, 5, 6)(2, 1, 5) = (1, 6)(1, 5)(1, 4)(2, 5)(2, 1),$$

which has five transpositions, so it is odd.

2. The alternating groups

For $n \ge 2$ the even and odd permutations of $S_n$ are equally many. Let $A_n$ be the set of even permutations and $B_n$ the set of odd ones. Fix a transposition $\tau = (1, 2)$. Define $\lambda_\tau : A_n \to B_n$ by $\lambda_\tau(\sigma) = \tau\sigma$. This lands in $B_n$, since $\tau\sigma$ is a product of one more transposition than $\sigma$, so it is odd. It is one-to-one, because $\tau\sigma = \tau\mu$ gives $\sigma = \mu$. It is onto $B_n$, because for $\rho \in B_n$ the element $\tau^{-1}\rho$ is even and maps to $\rho$. So $A_n$ and $B_n$ have the same number of elements, $n!/2$ each.

The product of two even permutations is even, the identity is even, and the inverse of an even permutation is even: if $\sigma$ is a product of transpositions in one order, $\sigma^{-1}$ is the same transpositions in the opposite order. So the even permutations form a subgroup.

Theorem 8.24 If $n \ge 2$, the even permutations of $\{1, 2, \dots, n\}$ form a subgroup of $S_n$ of order $n!/2$.

The sign of a permutation is the map $\operatorname{sgn} : S_n \to \{1, -1\}$ with $\operatorname{sgn}(\sigma) = 1$ if $\sigma$ is even and $-1$ if $\sigma$ is odd. The set $\{1, -1\}$ is a group under multiplication, and $\operatorname{sgn}$ is a homomorphism. Its kernel $\operatorname{Ker}(\operatorname{sgn})$ is the set of even permutations, which is the subgroup of Theorem 8.24. The sign map is the standard way of defining the determinant of a square matrix.

Exercise 52 asks you to prove some standard facts about determinants from this definition. It is printed directly below.

Exercise 52. The usual definition for the determinant of an $n \times n$ matrix $A = (a_{ij})$ is

$$\det(A) = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma)\, a_{1,\sigma(1)}a_{2,\sigma(2)}a_{3,\sigma(3)}\cdots a_{n,\sigma(n)},$$

where $\operatorname{sgn}(\sigma)$ is the sign of $\sigma$. Using this definition, prove the following properties of determinants.
a. If a row of matrix $A$ has all zero entries, then $\det(A) = 0$.
b. If two different rows of $A$ are switched to obtain $B$, then $\det(B) = -\det(A)$.
c. If $r$ times one row of $A$ is added to another row of $A$ to obtain a matrix $B$, then $\det(A) = \det(B)$.
d. If a row of $A$ is multiplied by $r$ to obtain the matrix $B$, then $\det(B) = r\det(A)$.

Definition 8.25 The subgroup of $S_n$ consisting of the even permutations of $n$ letters is the alternating group $A_n$ on $n$ letters.

The groups $S_n$ and $A_n$ are important. Cayley’s theorem shows that every finite group of order $n$ is isomorphic to a subgroup of $S_n$. There are no formulas using only radicals for solving polynomial equations of degree $n \ge 5$, and this fact is due to the structure of $A_n$.

1. Cosets

Let $H$ be a subgroup of $G$, finite or infinite. We split $G$ into pieces of equal size by an equivalence relation.

Theorem 10.1 Let $H \le G$. Define $a \sim_L b$ if and only if $a^{-1}b \in H$. Then $\sim_L$ is an equivalence relation on $G$.

Proof. Reflexive. $a^{-1}a = e \in H$, so $a \sim_L a$. Symmetric. If $a^{-1}b \in H$, then $(a^{-1}b)^{-1} = b^{-1}a \in H$, so $b \sim_L a$. Transitive. If $a^{-1}b \in H$ and $b^{-1}c \in H$, then $(a^{-1}b)(b^{-1}c) = a^{-1}c \in H$, so $a \sim_L c$. ◆

The cells of this partition are easy to describe. The cell containing $a$ is all $x$ with $a^{-1}x \in H$, that is all $x = ah$ with $h \in H$. This cell is written $aH$.

Definition 10.2 For $H \le G$ and $a \in G$, the subset $aH = \{ah \mid h \in H\}$ is the left coset of $H$ containing $a$.

Example 10.3. The left cosets of $3\mathbb{Z}$ in $\mathbb{Z}$ are $3\mathbb{Z}$ itself, $1 + 3\mathbb{Z} = \{\dots, -8, -5, -2, 1, 4, 7, 10, \dots\}$, and $2 + 3\mathbb{Z} = \{\dots, -7, -4, -1, 2, 5, 8, 11, \dots\}$. These three exhaust $\mathbb{Z}$.

Example 10.4. In $\mathbb{Z}_{12}$ with $H = \langle 3 \rangle$: $0 + H = \{0, 3, 6, 9\}$, $1 + H = \{1, 4, 7, 10\}$, $2 + H = \{2, 5, 8, 11\}$. These are all the left cosets.

Example 10.5. In the nonabelian group $D_4 = \{\iota, \rho, \rho^2, \rho^3, \mu, \mu\rho, \mu\rho^2, \mu\rho^3\}$, the left cosets of $H = \langle \mu \rangle = \{\iota, \mu\}$ are

$$\iota\{\iota, \mu\} = \{\iota, \mu\},\quad \rho\{\iota, \mu\} = \{\rho, \mu\rho^3\},\quad \rho^2\{\iota, \mu\} = \{\rho^2, \mu\rho^2\},\quad \rho^3\{\iota, \mu\} = \{\rho^3, \mu\rho\}.$$

Every element of $D_4$ appears in exactly one of these sets, so the list is complete.

2. The theorem of Lagrange

In Example 10.4 each coset of $\langle 3 \rangle$ has four elements; in Example 10.5 each has two. Theorem 10.6 says this always happens.

Theorem 10.6 Let $H \le G$. For any $a \in G$, the coset $aH$ has the same cardinality as $H$.

Proof. Define $f : H \to aH$ by $f(h) = ah$. If $f(b) = f(c)$, then $ab = ac$ and left cancellation gives $b = c$, so $f$ is one-to-one. Every element of $aH$ has the form $ah = f(h)$, so $f$ is onto. ◆

For a finite subgroup $H$ this says each coset has $|H|$ elements, which is what is needed for Lagrange’s theorem.

Theorem 10.7 (Theorem of Lagrange) Let $H$ be a subgroup of a finite group $G$. Then the order of $H$ divides the order of $G$.

Proof. Let $|G| = n$ and $|H| = m$. Each coset of $H$ has $m$ elements, and the cosets partition $G$. If there are $r$ cosets, then $n = rm$. ◆

Theorem 10.7 is a counting theorem: it follows from counting cosets and the number of elements in each.

Corollary 10.8 Every group of prime order is cyclic.

Proof. Let $|G| = p$ and $a \ne e$. Then $\langle a \rangle$ has at least two elements, and its order divides $p$ by Theorem 10.7. So $|\langle a \rangle| = p$ and $\langle a \rangle = G$. ◆

So up to isomorphism there is only one group of each prime order.

Theorem 10.9 The order of an element of a finite group divides the order of the group.

Proof. The order of an element is the order of the cyclic subgroup it generates. Apply Theorem 10.7. ◆

Definition 10.10 The number of left cosets of $H$ in $G$ is the index $(G : H)$.

The index may be finite or infinite. If $G$ is finite, $(G : H) = |G|/|H|$. The next theorem is about indices. The book leaves its proof to the exercises; Exercise 40 is printed directly below.

Exercise 40. Lagrange’s theorem says the order of a subgroup of a finite group divides the group order. The converse is false in general: a group need not have a subgroup of every order that divides its order. Section 13 of the book shows this, and the complete answer for abelian groups is in Section 9.

Right cosets

Everything above works with right cosets. Let $\sim_R$ be defined by $a \sim_R b$ if and only if $ab^{-1} \in H$. Its classes are the right cosets $Ha = \{ha \mid h \in H\}$. Each right coset has the same cardinality as $H$, so left and right cosets have the same size. In an abelian group they coincide. In general they need not coincide.

Example 10.12. For $H = \{\iota, \mu\}$ in $D_4$ the right cosets are $\{\iota, \mu\}\iota = \{\iota, \mu\}$, $\{\iota, \mu\}\rho = \{\rho, \mu\rho\}$, $\{\iota, \mu\}\rho^2 = \{\rho^2, \mu\rho^2\}$, and $\{\iota, \mu\}\rho^3 = \{\rho^3, \mu\rho^3\}$. These differ from the left cosets: $\rho H = \{\rho, \mu\rho^3\}$ while $H\rho = \{\rho, \mu\rho\}$.

Left and right cosets are not the same here. The book points out that when they are the same, a curious thing happens, which is illustrated next.

Example 10.13. $\mathbb{Z}_6$ is abelian. The cosets of $H = \{0, 3\}$ are $\{0, 3\}$, $1 + \{0, 3\} = \{1, 4\}$, and $2 + \{0, 3\} = \{2, 5\}$. They exhaust $\mathbb{Z}_6$.

3. Kernels and cosets

If $G$ is abelian, left and right cosets coincide. The next theorem gives another case.

Theorem 10.17 Let $\phi : G \to G'$ be a homomorphism. The left and right cosets of $\operatorname{Ker}(\phi)$ are identical. Moreover $a, b \in G$ lie in the same coset of $\operatorname{Ker}(\phi)$ if and only if $\phi(a) = \phi(b)$.

Proof. Suppose $a$ and $b$ lie in the same left coset, so $a^{-1}b \in \operatorname{Ker}(\phi)$. Then $\phi(a)^{-1}\phi(b) = e$, so $\phi(a) = \phi(b)$. Hence $\phi(ab^{-1}) = \phi(a)\phi(b)^{-1} = e$, so $ab^{-1} \in \operatorname{Ker}(\phi)$ and $a, b$ lie in the same right coset. Conversely, if $\phi(a) = \phi(b)$ then $\phi(b^{-1}a) = e$, so $a, b$ lie in the same left coset. The argument for right cosets is the same, and is left to the reader. ◆

Example 10.18. The determinant $\det : GL(2, \mathbb{R}) \to \mathbb{R}^*$ is a homomorphism. Two matrices lie in the same left coset of its kernel if and only if they lie in the same right coset, which happens if and only if they have the same determinant. For example $\begin{bmatrix}2&0\\0&1\end{bmatrix}$ and $\begin{bmatrix}3&2\\2&2\end{bmatrix}$ both have determinant $2$.

Corollary 10.19 A homomorphism $\phi : G \to G'$ is one-to-one if and only if $\operatorname{Ker}(\phi)$ is the trivial subgroup of $G$.

Proof. If $\operatorname{Ker}(\phi) = \{e\}$, each coset has one element, and $\phi(a) = \phi(b)$ puts $a, b$ in one coset by Theorem 10.17, so $a = b$. Conversely, if $\phi$ is one-to-one, only $e$ maps to $e'$, so $\operatorname{Ker}(\phi) = \{e\}$. ◆

To test whether $\phi$ is one-to-one, it is enough to show that $\phi(x) = e'$ has only the solution $x = e$.

Example 10.20. $\phi : \mathbb{R} \to \mathbb{R}^+$, $\phi(x) = 2^x$, is a homomorphism. The equation $2^x = 1$ has only the solution $x = 0$, since $2^x > 1$ for $x > 0$ and $2^x < 1$ for $x < 0$. So $\phi$ is one-to-one.
