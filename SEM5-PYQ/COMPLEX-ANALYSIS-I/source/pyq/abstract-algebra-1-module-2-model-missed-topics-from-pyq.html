MODULE 2: MODEL ANSWERS
Key steps for checking your work

Section A. 1. An improper subgroup of $G$ is $G$ itself. All other subgroups are proper (Definition 5.2). 2. True. $\{e\}$ is a subgroup (Definition 5.1), and it differs from $G$ when $G$ has more than one element. 3. True. $\langle a \rangle = \{a^n \mid n \in \mathbb{Z}\}$ is a subgroup containing $a$ (Theorem 5.19). Every subgroup containing $a$ contains all $a^n$, so it contains $\langle a \rangle$. 4. $-7 = 3(-3) + 2$. Quotient $-3$, remainder $2$ (Theorem 6.2).

Section B. 5. For a positive integer $m$ and any integer $n$ there are unique integers $q$ and $r$ with $n = mq + r$ and $0 \le r < m$ (Theorem 6.2). 6. $(1, 2, 3, 4) = (1, 4)(1, 3)(1, 2)$, read right to left (the formula before Theorem 8.15). 7. The orbits are $\{1, 2, 6\}$, $\{3, 5\}$ and $\{4\}$ (Section 8, orbits before Example 8.18). 8. $\tau : G \to S_G$ with $\tau(x) = \sigma_{x^{-1}}$, where $\sigma_y(g) = gy$ (Definition 8.13). So $\tau(x)(g) = gx^{-1}$. 9. $6$. Since $\gcd(42, 72) = 6$ and $6 = 3(72) - 5(42)$, the positive generator of $H$ is $6$ (Definition 6.8, Example 6.9).

Section C. 10. For $a \in H$ every power $a^k$ with $k \ge 1$ lies in $H$. Since $H$ is finite, $a^i = a^j$ for some $i < j$, so $a^{j-i} = e \in H$. Then $a^{-1} = a^{j-i-1} \in H$. So $H$ meets the three conditions of Theorem 5.12, and $H$ is a subgroup (Theorem 5.16). 11. $\langle a \rangle$ is a subgroup containing $a$ (Theorem 5.19). If $K$ is any subgroup containing $a$, then $K$ contains $a^n$ for every $n \in \mathbb{Z}$, so $\langle a \rangle \subseteq K$. 12. $0 = 0r + 0s \in H$. $(nr + ms) + (n'r + m's) = (n + n')r + (m + m')s \in H$. $-(nr + ms) = (-n)r + (-m)s \in H$. So $H$ is a subgroup (Theorem 5.12). By Corollary 6.7 it is $d\mathbb{Z}$ with $d = \gcd(r, s)$ (Definition 6.8). 13. $\phi(a)\phi(a^{-1}) = \phi(aa^{-1}) = \phi(e) = e'$ (Theorem 8.5, part 1). Multiplying on the left by $\phi(a)^{-1}$ gives $\phi(a^{-1}) = \phi(a)^{-1}$ (Theorem 8.5, part 2). 14. If $\lambda_g(x) = \lambda_g(y)$ then $gx = gy$, so $x = y$ by left cancellation: $\lambda_g$ is one-to-one. For $b \in G$, $\lambda_g(g^{-1}b) = b$, so $\lambda_g$ is onto $G$ (Definition 8.10). 15. Let $d = \gcd(n, s)$. The order of $a^s$ is the least $m > 0$ with $n \mid sm$, that is $\frac{n}{d} \mid \frac{s}{d}m$. Since $\gcd(\frac{n}{d}, \frac{s}{d}) = 1$, this holds exactly when $\frac{n}{d} \mid m$. So the order is $\frac{n}{d}$, and $\langle a^s \rangle$ has $\frac{n}{\gcd(n,s)}$ elements (Theorems 5.19, 6.10 and 6.15). 16. For $y \in G$ let $\sigma_y(g) = gy$. Each $\sigma_y$ is a bijection with inverse $\sigma_{y^{-1}}$. Let $\tau(x) = \sigma_{x^{-1}}$. Then $\tau(xy)(g) = g(xy)^{-1} = gy^{-1}x^{-1} = \tau(x)(\tau(y)(g))$, so $\tau$ is a homomorphism into $S_G$. If $\tau(x) = \tau(y)$, then $x^{-1} = y^{-1}$ (take $g = e$), so $x = y$: $\tau$ is one-to-one. Hence $G \cong \tau[G] \le S_G$ (Definition 8.13, Theorem 8.5, Exercise 54).
