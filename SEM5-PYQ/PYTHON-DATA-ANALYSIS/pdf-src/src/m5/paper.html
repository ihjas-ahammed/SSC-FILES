How this paper works

The syllabus gives the open-ended module 5 marks. This paper gives twice that (10 marks). Each example from the syllabus appears once. You answer one example from each part.

No past paper of this exact course was found, so the questions use similar CUFYUGP papers. PYQ = adapted from a similar paper, named with its code, term and question number. Instructor = written from the syllabus, with no close match.

Similar papers used: CSC1MN106 Computer Fundamentals with MS Excel, SPSS (Nov 2024); STA2MN101 Probability Theory I (Apr 2025).
