How this paper works

The syllabus gives this module 12 marks. This paper gives twice that (24 marks), so every unit is tested with more questions than a real paper would use.

No past paper of this exact course was found, so the questions use similar CUFYUGP papers. PYQ = adapted from a similar paper, named with its code, term and question number. Instructor = written from the syllabus, with no close match. Each question also shows its unit (U1 to U5). Every concept of units 1–5 is the main point of at least one question.

Similar papers used: CSC3MN206 Programming using Python, Nov 2025, versions A and B (N25-A, N25-B); MAT4CJ205 Fundamentals of Python and SageMath, Apr 2026 (A26).
