How this paper works

The syllabus gives this module 15 marks. This paper gives twice that (30 marks). The questions use the physics data named in the syllabus: capacitor charging, phone-sensor readings, and pendulum and spring experiments.

No past paper of this exact course was found, so the questions use similar CUFYUGP papers. PYQ = adapted from a similar paper, named with its code, term and question number. Instructor = written from the syllabus, with no close match.

Similar papers used: CSC1MN106 Computer Fundamentals with MS Excel, SPSS (Nov 2024); STA2MN101 Probability Theory I (Apr 2025); STA3MN201 Statistical Inference using R (Nov 2025); MAT4CJ205 Python and SageMath (Apr 2026).
