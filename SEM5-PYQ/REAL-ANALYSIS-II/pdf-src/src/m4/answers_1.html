1PYQ MTS-25 Q9

Uniform norm; $\lVert\sin\rVert_{\mathbb R}$.

Know firstT5P3

Let $A \subseteq \mathbb R$ and $\varphi : A \to \mathbb R$. φ is bounded on A if $\varphi(A)$ is a bounded set. For bounded φ the uniform norm of φ on A is $$\lVert\varphi\rVert_A := \sup\{|\varphi(x)| : x \in A\}.$$ It satisfies $\lVert\varphi\rVert_A \le \varepsilon \iff |\varphi(x)| \le \varepsilon$ for all $x \in A$.

Since $|\sin x| \le 1$ for all x and $\sin(\pi/2) = 1$, $\lVert \sin\rVert_{\mathbb R} = 1$.

Marks: bounded 1 · definition of norm 1 · example 1.

2PYQ MTS-22 Q8

Define pointwise convergence.

Know firstT1P1

Let $(f_n)$ be a sequence of functions on $A \subseteq \mathbb R$, $A_0 \subseteq A$ and $f : A_0 \to \mathbb R$. $(f_n)$ converges (pointwise) on $A_0$ to f if for each $x \in A_0$ the sequence of numbers $(f_n(x))$ converges to $f(x)$. Equivalently: for each $\varepsilon>0$ and each $x \in A_0$ there is $K(\varepsilon, x) \in \mathbb N$ with $|f_n(x) - f(x)| < \varepsilon$ for all $n \ge K(\varepsilon, x)$. f is then unique (a sequence has at most one limit).

Marks: definition 2 · ε–K form or uniqueness 1.

3PYQ MTS-26 Q9

Define uniform convergence; compare.

Know firstT3M3

$(f_n)$ converges uniformly on $A_0$ to $f : A_0 \to \mathbb R$ if for each $\varepsilon>0$ there is $K(\varepsilon) \in \mathbb N$, depending on ε but not on x, such that $n \ge K(\varepsilon)$ implies $|f_n(x) - f(x)| < \varepsilon$ for all $x \in A_0$.

Difference: in pointwise convergence K may depend on both ε and x ($\forall\varepsilon\,\forall x\,\exists K$); in uniform convergence one K serves every x ($\forall\varepsilon\,\exists K\,\forall x$). Uniform ⇒ pointwise, not conversely (e.g. $x/n$ on ℝ).

Marks: definition 2 · difference with example 1.

4PYQ MTS-25 Q10

$\lim e^{-nx}$, $x \ge 0$.

Know firstT2P1

If $x = 0$: $e^{-n\cdot 0} = 1$ for all n, so the limit is 1. If $x>0$: $e^{-nx} = (e^{-x})^n$ with $0 < e^{-x} < 1$, so $(e^{-x})^n \to 0$.

$\lim e^{-nx} = 1$ if $x = 0$, and $= 0$ if $x > 0$.

Marks: x = 0 case 1 · x > 0 case 1 · limit function stated 1.

5PYQ MTS-26 Q10

$\lim \frac{nx}{1+nx}$, $x \ge 0$.

Know firstT2P2

x = 0: every term is 0, limit 0. x > 0: dividing by $nx$, $\dfrac{nx}{1+nx} = \dfrac{1}{\frac{1}{nx} + 1} \to \dfrac{1}{0+1} = 1$.

$f(0) = 0$, $f(x) = 1$ for $x>0$.

Note: each $f_n$ is continuous on $[0,\infty)$, the limit jumps at 0, so the convergence is not uniform there (T14).

Marks: two cases 2 · answer 1.

6PYQ MAT-22 Q8

$\lim \frac{x^2+nx}{n}$.

Know firstT2P2

$\dfrac{x^2+nx}{n} = \dfrac{x^2}{n} + x$. For fixed x, $x^2/n \to 0$, so the limit is $x$.

$\lim \dfrac{x^2+nx}{n} = x$ for every $x \in \mathbb R$.

Marks: rewrite 1 · limit 2.

7PYQ MAT-21 Q10

$\lim \frac{\cos(nx+n)}{n}$.

Know firstT2P2

$|\cos(nx+n)| \le 1$, so $0 \le \left|\dfrac{\cos(nx+n)}{n}\right| \le \dfrac1n \to 0$. By the squeeze theorem the limit is 0.

0, for every $x \in \mathbb R$.

8PYQ MTS-22 MCQ 12 · adapted

$F_n = \frac1n\sin(nx+n) \to 0$ uniformly on ℝ; find $\lVert F_n\rVert$.

Know firstT8T6

For every $x \in \mathbb R$: $|F_n(x) - 0| \le \frac1n$. The bound does not depend on x, so $\lVert F_n\rVert_{\mathbb R} \le \frac1n$. It is attained: at $x = \frac{\pi}{2n} - 1$, $nx + n = \pi/2$ and $F_n(x) = \frac1n$. Hence $\lVert F_n\rVert_{\mathbb R} = \frac1n \to 0$, so $F_n \to 0$ uniformly on ℝ (Lemma 8.1.8). (MCQ answer: limit 0, option B.)

$\lVert F_n\rVert_{\mathbb R} = 1/n \to 0$: uniform.

Marks: bound 1 · norm 1 · conclusion 1.

9PYQ MTS-22 Q9

Uniform convergence of $x^n$ on (−1, 1].

Know firstT2T4M5

Pointwise limit: $g(x) = 0$ for $-1<x<1$, $g(1) = 1$. Take $\varepsilon_0 = \frac12$, $n_k = k$, $x_k = (1/2)^{1/k} \in (0,1)$. Then $|x_k^k - g(x_k)| = \frac12 - 0 = \frac12 \ge \varepsilon_0$ for every k. By Lemma 8.1.5 the convergence is not uniform on (−1, 1].

Converges pointwise to g; not uniformly.

Marks: limit 1 · choice of $x_k$, ε₀ 1 · conclusion 1.

10PYQ MTS-22 Q10

$h_n = 2nxe^{-nx^2}$: $\lim\int_0^1 h_n \ne \int_0^1 h$.

Know firstT12P6

$H_n(x) = -e^{-nx^2}$ satisfies $H_n'(x) = 2nx\,e^{-nx^2} = h_n(x)$. By the Fundamental Theorem, $\int_0^1 h_n = H_n(1) - H_n(0) = -e^{-n} + 1 \to 1$. But $\int_0^1 h = 0$. Since $1 \ne 0$, $\lim \int_0^1 h_n \ne \int_0^1 h$. (Moreover $h_n(x) \to 0$ for every x, so h is the pointwise limit: for x > 0, $0 < h_n(x) < 4/(nx^3)$.)

$\lim \int_0^1 h_n = 1 \ne 0 = \int_0^1 h$.

Marks: antiderivative 1 · value $1 - e^{-n}$ 1 · comparison 1.

12PYQ MTS-22 MCQ 13 · adapted

$f_n \to f$ uniformly on ℝ. $2f_n$? $f_n^2$?

Know firstT15T6

$(2f_n)$: yes, $|2f_n(x) - 2f(x)| = 2|f_n(x) - f(x)|$, so $\lVert 2f_n - 2f\rVert = 2\lVert f_n - f\rVert \to 0$.

$(f_n^2)$: not necessarily. $f_n(x) = x + \frac1n \to x$ uniformly on ℝ (norm $1/n$), but $f_n^2(x) - x^2 = \frac{2x}{n} + \frac{1}{n^2}$, which at $x = n$ is $2 + \frac1{n^2} \ge 2$. So $f_n^2 \not\to x^2$ uniformly. (Same for $f_n^3$.) It is true if all $f_n$ are bounded.

$2f_n$: always uniform. $f_n^2$, $f_n^3$: not necessarily (MCQ: option D).

Marks: $2f_n$ 1 · counterexample 2.

13

$K(\varepsilon, x)$ for $x/n$.

Know firstT1M3

$|x/n - 0| < \varepsilon \iff n > |x|/\varepsilon$. So $K(\varepsilon, x) = \lfloor |x|/\varepsilon\rfloor + 1$ works. Any valid K must exceed $|x|/\varepsilon$ (at $n = K$ we need $K > |x|/\varepsilon$); as $|x| \to \infty$ this grows without bound, so no single K works for all x ∈ ℝ. The convergence is pointwise, not uniform, on ℝ.

Marks: K found 2 · why not uniform 1.

14

$x/(x+n)$ on $[0,a]$ and $[0,\infty)$.

Know firstT7P3

For $x \ge 0$: $0 \le \frac{x}{x+n} \le \frac xn \to 0$, so the limit is 0. $\frac{x}{x+n} = 1 - \frac{n}{x+n}$ increases with x. On $[0,a]$: $\lVert f_n\rVert = \frac{a}{a+n} \to 0$, uniform. On $[0,\infty)$: the values approach 1 as $x \to \infty$ and never reach it, so $\lVert f_n\rVert = 1$ for every n: not uniform.

$\lVert f_n\rVert_{[0,a]} = \frac{a}{a+n}$ (uniform); $\lVert f_n\rVert_{[0,\infty)} = 1$ (not uniform).
15

$\arctan(nx) \to \frac\pi2\operatorname{sgn}x$; not uniform on ℝ.

Know firstT2T14

x > 0: $nx \to +\infty$, $\arctan(nx) \to \pi/2$. x < 0: $\to -\pi/2$. x = 0: $\arctan 0 = 0$. So the limit is $\frac\pi2\operatorname{sgn}x$. Each $\arctan(nx)$ is continuous on ℝ, but the limit is discontinuous at 0. If the convergence were uniform, Theorem 8.2.2 would make the limit continuous. Hence not uniform on ℝ.

Marks: limit 1.5 · argument 1.5.

16

$\lim(\cos\pi x)^{2n}$.

Know firstT2P1

Let $t = \cos^2 \pi x \in [0,1]$; the term is $t^n$. If $x \in \mathbb Z$, $\cos\pi x = \pm1$, $t = 1$, limit 1. Otherwise $0 \le t < 1$, limit 0.

The limit exists for all x: $f(x) = 1$ if x is an integer, $0$ otherwise.
17

$x/n$: uniform on [0, 1], not on ℝ.

Know firstT9T4

On [0, 1]: $|x/n| \le 1/n$, attained at x = 1, so $\lVert x/n\rVert_{[0,1]} = 1/n \to 0$: uniform (Lemma 8.1.8). On ℝ: take $\varepsilon_0 = 1$, $x_k = k$: $|f_k(k) - 0| = 1 \ge \varepsilon_0$, so not uniform (Lemma 8.1.5).

18

$xe^{-nx} \to 0$ uniformly on $[0,\infty)$.

Know firstT7M4

Pointwise limit 0 (exponentials beat powers). $\frac{d}{dx}(xe^{-nx}) = e^{-nx}(1 - nx) = 0$ at $x = 1/n$: positive before, negative after, so a maximum. Value $\frac1n e^{-1}$. At 0 the value is 0 and as $x\to\infty$ it tends to 0.

$\lVert xe^{-nx}\rVert = \frac{1}{en} \to 0$: uniform.
19

$x^n$ on $[0, \frac12]$.

Know firstT9

$x^n$ increases on $[0, \frac12]$, so $\lVert x^n\rVert_{[0,1/2]} = (\frac12)^n = 2^{-n} \to 0$. By Lemma 8.1.8, $x^n \to 0$ uniformly on $[0, \frac12]$.

$\lVert x^n\rVert_{[0,1/2]} = 2^{-n}$.
20

Theorem 8.2.2 and its converse.

Know firstT13T14

Theorem. Let $(f_n)$ be a sequence of continuous functions on $A \subseteq \mathbb R$ that converges uniformly on A to $f : A \to \mathbb R$. Then f is continuous on A.

Converse false. $f_n(x) = x/n$ are continuous on ℝ and converge to $f = 0$, which is continuous, but the convergence is not uniform on ℝ ($x_k = k$ gives gap 1). So a continuous limit does not imply uniform convergence.

Marks: statement 1.5 · counterexample 1.5.
