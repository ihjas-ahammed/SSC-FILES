UNIT 19 · BARTLE §8.1.1–8.1.3

Watching one point at a time

T1

Pointwise convergence

The first definition (PYQ MTS-22 Q8, MAT-21 Q21).

The ideaStand at one point x. Watch the heights $f_1(x), f_2(x), f_3(x), \ldots$ If they settle to a number, call it $f(x)$. Do this at every point of a set $A_0$: the numbers $f(x)$ make a new function f, the limit function.
Definition 8.1.1 · say it word for wordLet $(f_n)$ be a sequence of functions on $A \subseteq \mathbb R$ to $\mathbb R$, let $A_0 \subseteq A$, and let $f : A_0 \to \mathbb R$. We say that the sequence $(f_n)$ converges on $A_0$ to f if, for each $x \in A_0$, the sequence $(f_n(x))$ converges to $f(x)$ in ℝ. Then f is called the limit on $A_0$ of $(f_n)$, and $(f_n)$ is said to converge pointwise on $A_0$. In plain words: at every single point, the numbers $f_n(x)$ tend to $f(x)$.
Lemma 8.1.3 · the ε–K form$(f_n)$ converges on $A_0$ to f if and only if for each $\varepsilon>0$ and each $x \in A_0$ there is a natural number $K(\varepsilon, x)$ such that if $n \ge K(\varepsilon, x)$, then $|f_n(x) - f(x)| < \varepsilon$. Note the label $K(\varepsilon, x)$: the stage K is allowed to depend on x as well as ε (M3).
Worked example · finding K(ε, x)

$f_n(x) = x/n$, $f = 0$ on ℝ. We need $|x/n - 0| < \varepsilon$, i.e. $n > |x|/\varepsilon$.

So $K(\varepsilon, x)$ = any whole number bigger than $|x|/\varepsilon$ works. At $x = 1$, $\varepsilon = 0.1$: $K = 11$. At $x = 100$: $K = 1001$.

The further out x is, the longer we wait. No single K works for all x: we will see this means "not uniform" (T3).

Result · uniquenessA sequence of numbers has at most one limit (P1). So the limit function f, if it exists, is unique.
Check yourself
For $f_n(x) = x/n$ and $\varepsilon = 0.01$, find a K that works at x = 3.
Need $n > 3/0.01 = 300$. K = 301.

T2

Finding the limit function

The most frequent past question in this module (asked six times).

Skeleton · find the pointwise limit
  1. Fix $x \in A$. (Now $f_n(x)$ is a sequence of numbers.)
  2. Split into cases where the behaviour changes (often $x = 0$, $x = 1$, $x = -1$, $|x|<1$, $|x|>1$).
  3. In each case compute $\lim_n f_n(x)$ with P1 and P2.
  4. Write f piecewise, and state $A_0$, the set where the limit exists.
Worked example · Bartle 8.1.2(b): $g_n(x) = x^n$ on ℝ
$x = 1$$1^n = 1 \to 1$ $|x| < 1$$x^n \to 0$ (P1) $x = -1$$(-1)^n$ = −1, 1, −1, …: no limit $|x| > 1$unbounded: no limit

So $A_0 = (-1, 1]$, with $g(x) = 0$ for $-1 < x < 1$ and $g(1) = 1$.

Three more, the way past papers ask them

$\lim e^{-nx}$, $x \ge 0$ (PYQ MTS-25 Q10)At $x = 0$: $e^{0} = 1$, limit 1. For $x>0$: $e^{-nx} = (e^{-x})^n$ with $0 < e^{-x} < 1$, so the limit is 0. Limit: $f(0) = 1$, $f(x) = 0$ for $x>0$.
$\lim \dfrac{nx}{1+nx}$, $x \ge 0$ (PYQ MTS-26 Q10)At $x = 0$: every term is 0. For $x>0$: $\dfrac{1}{1 + 1/(nx)} \to 1$. Limit: $f(0) = 0$, $f(x) = 1$ for $x>0$.
$\lim \dfrac{x^2+nx}{n}$ (PYQ MAT-22 Q8; Bartle 8.1.2(c))$\dfrac{x^2+nx}{n} = \dfrac{x^2}{n} + x \to 0 + x = x$ for every $x \in \mathbb R$.
Exam trapThe exceptional points ($x = 0$ above) are where marks are lost. Before writing "the limit is 0", test the end points and the points where a base equals 1.
Check yourself
Find $\lim (\cos \pi x)^{2n}$ for $x \in \mathbb R$.
Put $t = \cos^2 \pi x \in [0,1]$, so the term is $t^n$. If x is an integer, $t = 1$ and the limit is 1; otherwise $0 \le t < 1$ and the limit is 0.

T3

Uniform convergence

The central definition of the module (PYQ MTS-26 Q9).

Definition 8.1.4 · say it word for wordA sequence $(f_n)$ of functions on $A \subseteq \mathbb R$ to $\mathbb R$ converges uniformly on $A_0 \subseteq A$ to a function $f : A_0 \to \mathbb R$ if for each $\varepsilon > 0$ there is a natural number $K(\varepsilon)$ (depending on ε but not on $x \in A_0$) such that if $n \ge K(\varepsilon)$, then $|f_n(x) - f(x)| < \varepsilon$ for all $x \in A_0$. In plain words: one stage K, chosen from ε alone, after which every point x is within ε. Picture: the whole graph of $f_n$ sits in the ε-tube round f.
Skeleton · prove $f_n \to f$ uniformly on $A_0$Let $\varepsilon > 0$. Choose $K = $ ? (built from ε only). Let $n \ge K$ and $x \in A_0$. Then $|f_n(x) - f(x)| \le$ ? $< \varepsilon$. Since K does not depend on x, $f_n \to f$ uniformly on $A_0$. ∎

Exam trapWriting $K = |x|/\varepsilon$ and calling it uniform. Before writing "uniform", circle every letter in your K: only ε and fixed numbers are allowed.
Check yourself
Show $\frac1n \sin(nx + n) \to 0$ uniformly on ℝ.
Let $\varepsilon>0$; take $K > 1/\varepsilon$. For $n \ge K$ and every x: $|\frac1n \sin(nx+n)| \le \frac1n \le \frac1K < \varepsilon$. K uses ε only. ∎

T4

Proving "NOT uniform"

Find points where $f_n$ stays far away (Lemma 8.1.5; PYQ MTS-22 Q9).

Lemma 8.1.5 · say it word for wordA sequence $(f_n)$ of functions on $A \subseteq \mathbb R$ to $\mathbb R$ does not converge uniformly on $A_0 \subseteq A$ to a function $f : A_0 \to \mathbb R$ if and only if for some $\varepsilon_0 > 0$ there is a subsequence $(f_{n_k})$ of $(f_n)$ and a sequence $(x_k)$ in $A_0$ such that $|f_{n_k}(x_k) - f(x_k)| \ge \varepsilon_0$ for all $k \in \mathbb N$. In plain words: a fixed distance $\varepsilon_0$, and for frames as late as you like, a point $x_k$ where the frame is still at least $\varepsilon_0$ away.
Skeleton · prove NOT uniform on $A_0$Take $\varepsilon_0 = $ ?, $n_k = k$ and $x_k = $ ? $\in A_0$. Then $|f_k(x_k) - f(x_k)| = $ ? $\ge \varepsilon_0$ for all k. By Lemma 8.1.5, $(f_n)$ does not converge uniformly on $A_0$. ∎
Scratch · how to choose $x_k$Look for where $f_k$ is still big: at its peak, far out towards ∞, or near the bad end point. Good recipes: solve $f_k(x) = \frac12$; or try $x_k = k$, $x_k = 1/k$, $x_k = -k$.

Bartle's three examples (8.1.6)

(a) $x/n$ on ℝ, limit 0$x_k = k$: $|f_k(k) - 0| = k/k = 1$. Take $\varepsilon_0 = 1$. Not uniform on ℝ.
{{fig:x_over_n}}
(b) $x^n$ on (−1, 1], limit g$x_k = (1/2)^{1/k}$, so $x_k^k = \frac12$ and $g(x_k) = 0$ (since $x_k < 1$). Gap $\frac12 = \varepsilon_0$. Not uniform.
{{fig:xn_tube}}
(c) $(x^2+nx)/n$ on ℝ, limit x$x_k = -k$: $h_k(-k) = (k^2 - k^2)/k = 0$ and $h(-k) = -k$, so the gap is $k \ge 1 = \varepsilon_0$. Not uniform on ℝ.
Proof · the lemma itself (5 marks)
"Uniform" says: for all ε there is K with $|f_n(x) - f(x)| < \varepsilon$ for all $n \ge K$, all $x \in A_0$.Definition 8.1.4.
Its negation: there is $\varepsilon_0>0$ such that for every K some $n \ge K$ and some $x \in A_0$ have $|f_n(x) - f(x)| \ge \varepsilon_0$.Flip each quantifier and the inequality (M5).
K = 1 gives $n_1$, $x_1$. K = $n_1 + 1$ gives $n_2 > n_1$, $x_2$. Continue.Builds an increasing $n_k$: a subsequence.
Conversely, given such $n_k, x_k$: for any K pick k with $n_k \ge K$; that pair breaks uniformity.$n_k \to \infty$, so late enough frames always exist.
Exam trap$\varepsilon_0$ must be one fixed number. "Gap $= 1/k$" proves nothing; "gap $= \frac12$ for every k" proves it.

T5

Bounded functions and the uniform norm

One number that measures the worst gap (PYQ MTS-25 Q9).

Definition 8.1.7 · say it word for wordIf $A \subseteq \mathbb R$ and $\varphi : A \to \mathbb R$ is a function, we say that φ is bounded on A if the set $\varphi(A)$ is a bounded subset of ℝ. If φ is bounded we define the uniform norm of φ on A by $$\lVert\varphi\rVert_A := \sup\{|\varphi(x)| : x \in A\}.$$ In plain words: the height of the highest point of the graph of |φ|.
Result · the key property$$\lVert\varphi\rVert_A \le \varepsilon \iff |\varphi(x)| \le \varepsilon \text{ for all } x \in A.$$ (A sup is ≤ ε exactly when every element is ≤ ε, P3.)
Check yourself
Find $\lVert \sin \rVert_{\mathbb R}$, $\lVert x \rVert_{[-2,1]}$ and $\lVert x^n \rVert_{[0,1)}$.
1 (attained at π/2). 2 (at x = −2). 1 (sup, not attained).

T6

The norm test (Lemma 8.1.8)

Uniform convergence ⇔ worst gap → 0 (PYQ MTS-26 Q20, MAT-22 Q19).

Lemma 8.1.8 · say it word for wordA sequence $(f_n)$ of bounded functions on $A \subseteq \mathbb R$ converges uniformly on A to f if and only if $\lVert f_n - f \rVert_A \to 0$.
Know$f_n$ bounded on A; T3 definition; T5 key property.Wantuniform ⇔ the real sequence $\lVert f_n - f\rVert_A$ tends to 0.
Proof (⇒)
Let $\varepsilon>0$. By uniformity there is $K(\varepsilon)$ with $|f_n(x) - f(x)| \le \varepsilon$ for all $x \in A$, $n \ge K(\varepsilon)$.Definition 8.1.4 (we only need ≤).
So ε is an upper bound of $\{|f_n(x) - f(x)| : x \in A\}$, hence $\lVert f_n - f\rVert_A \le \varepsilon$ for $n \ge K(\varepsilon)$.The sup is the least upper bound (P3).
ε was arbitrary, so $\lVert f_n - f\rVert_A \to 0$.This is the ε–K definition of a limit of numbers (P1).
Proof (⇐)
Let $\varepsilon>0$. Since $\lVert f_n - f\rVert_A \to 0$, there is $H(\varepsilon)$ with $\lVert f_n - f\rVert_A \le \varepsilon$ for $n \ge H(\varepsilon)$.Definition of limit (P1).
For every $x \in A$: $|f_n(x) - f(x)| \le \lVert f_n - f\rVert_A \le \varepsilon$ when $n \ge H(\varepsilon)$.Each element of a set is ≤ its sup.
H depends on ε only, so $f_n \to f$ uniformly on A. ∎Matches Definition 8.1.4 (use ε/2 if you want strict <).
Hypotheses checklist
  • $f_n - f$ bounded on Aotherwise the "sup" is +∞ and the norm is not a real number. Example: $x/n$ on ℝ: $f_n - f$ is unbounded, so automatically not uniform C15.
Why this lemma is so usefulIt turns a question about functions (for all ε, all x …) into a question about one sequence of numbers $\lVert f_n - f\rVert$, which you can compute with calculus (T7).

T7

Computing ‖fn − f‖

The standard 6–9 mark problem (PYQ MAT-21 Q32).

Skeleton · "discuss the convergence of $f_n$ on A"
  1. Pointwise: fix x, find f (T2).
  2. Gap: write $d_n(x) = |f_n(x) - f(x)|$.
  3. Worst gap: $\lVert f_n - f\rVert_A = \sup d_n$ by calculus (M4).
  4. Verdict: if it → 0, uniform (Lemma 8.1.8); if not, not uniform.
Worked example · Bartle 8.1.9(e): $G_n(x) = x^n(1-x)$ on [0, 1]

1. At $x = 0, 1$: $G_n = 0$. For $0<x<1$: $x^n \to 0$. So $G = 0$.

2–3. $G_n'(x) = x^{n-1}\big(n - (n+1)x\big) = 0$ at $x = \frac{n}{n+1}$, a maximum. $$\lVert G_n\rVert = \left(\frac{n}{n+1}\right)^n \frac{1}{n+1} = \frac{n^n}{(n+1)^{n+1}}.$$

4. $\left(\frac{n}{n+1}\right)^n \le 1$, so $\lVert G_n\rVert \le \frac{1}{n+1} \to 0$: uniform on [0, 1].

{{fig:norm_gap}}
Worked example · the moving bump $f_n(x) = \dfrac{nx}{1+n^2x^2}$ on $[0,\infty)$

Pointwise: $f_n(0) = 0$; for $x>0$, $0 \le f_n(x) \le \frac{nx}{n^2x^2} = \frac{1}{nx} \to 0$. So $f = 0$.

Worst gap: by AM–GM (M4), $f_n \le \frac12$ with equality at $x = 1/n$. So $\lVert f_n\rVert = \frac12$ for every n: not uniform on $[0,\infty)$.

Exam trapA sup can be a limit that is never reached: $\sup\{x/(x+n) : x \ge 0\} = 1$. Check the ends and ∞, not just the critical points.
Check yourself
Find $\lVert x e^{-nx}\rVert_{[0,\infty)}$. Uniform to 0?
Max at $x = 1/n$: value $\frac{1}{en} \to 0$. Uniform.

T8

The shortcut: a bound free of x

When you can bound the gap by something with no x in it, you are done.

ResultIf $|f_n(x) - f(x)| \le a_n$ for all $x \in A$, and $a_n \to 0$, then $\lVert f_n - f\rVert_A \le a_n \to 0$, so $f_n \to f$ uniformly on A.
Worked example · Bartle 8.1.9(d)$F_n(x) = \frac1n \sin(nx+n)$: $|F_n(x)| \le \frac1n$ for every real x. So $\lVert F_n\rVert_{\mathbb R} \le \frac1n \to 0$: uniform on ℝ. (In fact $\lVert F_n \rVert = \frac1n$, reached when $nx + n = \pi/2$.)
{{fig:sin_env}}
Exam trapThe bound must not contain x. $|x/n| \le |x|/n$ is useless on ℝ (it grows with x), but on [0, 1] it gives $\le 1/n$.
