P1

Limits of sequences

Every pointwise limit in this module is an ordinary sequence limit.

Remind me · Real Analysis I, Bartle 3.1

$x_n \to x$ means: for every $\varepsilon>0$ there is a natural number $K$ such that $|x_n - x| < \varepsilon$ for all $n \ge K$.

A sequence has at most one limit.

Standard limits to know by heart
$1/n \to 0$and $c/n \to 0$ for any fixed number $c$ $b^n \to 0$when $|b| < 1$; $b^n = 1$ when $b = 1$ $b^n$unbounded when $|b|>1$; $(-1)^n$ has no limit $n^{1/n} \to 1$$(1+\frac1n)^n \to e$ $n\,e^{-na} \to 0$for each fixed $a>0$ (exponentials beat powers)
Check yourself
Find $\lim (0.9)^n$ and $\lim (1.1)^n$.
$0.9^n \to 0$ (|0.9| < 1). $1.1^n$ grows without bound: no limit.
P2

Algebra of limits and the squeeze

The two tools that do most pointwise limits.

Remind me · Bartle 3.2.3, 3.2.7
  • If $a_n \to a$ and $b_n \to b$ then $a_n + b_n \to a+b$, $a_n b_n \to ab$, and $a_n/b_n \to a/b$ when $b \ne 0$.
  • Squeeze: if $|a_n| \le b_n$ and $b_n \to 0$, then $a_n \to 0$.
  • Order limit (3.2.6): if $a_n \le c$ for all $n$ and $a_n \to a$, then $a \le c$. Limits keep "≤" (but not "<").
Example$\dfrac{\cos(nx+n)}{n}$: since $|\cos| \le 1$, we have $\left|\dfrac{\cos(nx+n)}{n}\right| \le \dfrac1n \to 0$. By the squeeze the limit is 0, for every x.
Check yourself
Find $\lim \dfrac{nx}{1+nx}$ for a fixed $x>0$.
Divide top and bottom by $nx$: $\dfrac{1}{1/(nx) + 1} \to \dfrac{1}{0+1} = 1$.
P3

Supremum (least upper bound)

The uniform norm is a supremum, so we need this exactly.

Remind me · Bartle 2.3
  • $u = \sup S$ means: $u$ is an upper bound of S ($s \le u$ for all $s \in S$), and no smaller number is an upper bound.
  • So: $\sup S \le c$ ⇔ every $s \in S$ has $s \le c$.
  • A sup need not be attained: $\sup\{x^n : 0 \le x < 1\} = 1$, but no $x$ in $[0,1)$ gives $x^n = 1$.
Exam trap"$x^n < 1$ for every $x<1$, so the sup is less than 1." Wrong. Each value is below 1, but they come as close to 1 as we like, so the sup is exactly 1.
Check yourself
Find $\sup\{x/(x+5) : x \ge 0\}$. Is it attained?
$x/(x+5) = 1 - 5/(x+5)$ increases towards 1 as $x \to \infty$. Sup = 1, never attained.
P4

Cauchy sequences

Used in the Cauchy criterion (T10).

Remind me · Bartle 3.5.1, 3.5.5

$(a_n)$ is Cauchy if for every $\varepsilon>0$ there is $H$ such that $|a_m - a_n| < \varepsilon$ for all $m, n \ge H$: late terms are close to each other.

Cauchy Convergence Criterion (3.5.5): a sequence of real numbers converges if and only if it is Cauchy.

The ideaWith a Cauchy sequence you can prove convergence without knowing the limit. ℝ has no holes, so a sequence whose terms bunch together must bunch round some real number.
P5

Continuity at a point (from Module 1)

Needed for T11–T14.

Remind me · Bartle 5.1.1

$f$ is continuous at $c \in A$ if for every $\varepsilon>0$ there is $\delta>0$ such that $|f(x) - f(c)| < \varepsilon$ whenever $x \in A$ and $|x - c| < \delta$.

Polynomials, $\sin$, $\cos$, $e^x$, $\arctan$ and their sums, products and (non-zero denominator) quotients are continuous.

M1

Inequality kit: |·|, ε/2 and ε/3

Three moves that appear in every proof of this module.

Maths tool
  • $|a| < \varepsilon$ means $-\varepsilon < a < \varepsilon$: "a is within ε of 0".
  • Triangle inequality: $|a + b| \le |a| + |b|$.
  • Add and subtract: to compare $p$ and $r$ through a middle point $q$, write $p - r = (p - q) + (q - r)$, so $|p - r| \le |p - q| + |q - r|$.
  • Split ε: if each piece is less than $\varepsilon/2$, two pieces add to less than ε. With three pieces use $\varepsilon/3$.
ExampleIf $|f_m(x) - f(x)| < \varepsilon/2$ and $|f_n(x) - f(x)| < \varepsilon/2$, then $|f_m(x) - f_n(x)| \le |f_m(x) - f(x)| + |f(x) - f_n(x)| < \varepsilon$.
M2

A function is one object; freeze x first

How to read $f_n(x)$ with two letters moving.

Maths tool

$f_n(x)$ has two inputs: the frame number n and the point x.

  • Freeze x, let n run → a sequence of numbers $f_1(x), f_2(x), \ldots$ (P1). Its limit is $f(x)$.
  • Freeze n, let x run → one whole function $f_n$, a graph.

Pointwise convergence uses the first view. Uniform convergence compares whole graphs, the second view.

Example$f_n(x) = x/n$. Freeze $x = 6$: the numbers $6, 3, 2, 1.5, \ldots \to 0$. Freeze $n = 3$: the line $y = x/3$.
Exam trapAlways say which set you work on. A is where the $f_n$ are defined, and the limit may exist only on a smaller set $A_0$. "Uniform" is always "uniform on some set".
M3

The order of quantifiers (a game)

The whole difference between pointwise and uniform is the order of three words.

Maths tool · the game

An opponent names a small $\varepsilon>0$. You must answer with a stage K after which $|f_n(x) - f(x)| < \varepsilon$.

ConvergenceOrder of playK may depend on
pointwiseopponent picks ε and x, then you pick Kε and x
uniformopponent picks ε, you pick K, then opponent picks any xε only

In symbols: pointwise is $\forall \varepsilon\ \forall x\ \exists K$; uniform is $\forall \varepsilon\ \exists K\ \forall x$. Only "for all x" has moved.

ExampleFor $x/n$ on ℝ: given ε and x, $K > |x|/\varepsilon$ works. As $|x|$ grows, K must grow: no single K serves every x. Pointwise yes, uniform no.
M4

Finding a supremum with calculus

How to compute ‖fn − f‖ in T7.

Maths tool · four steps
  1. Write the gap $d_n(x) = |f_n(x) - f(x)|$ on the set.
  2. Differentiate (in x, with n fixed) and solve $d_n'(x) = 0$: the critical points.
  3. List the candidates: values at the critical points, at the end points, and the limits at open ends or at ∞.
  4. The largest candidate is the sup. It may be a limit that is never reached.
Example$d_n(x) = x\,e^{-nx}$ on $[0,\infty)$. $d_n'(x) = e^{-nx}(1 - nx) = 0$ at $x = 1/n$. Candidates: $d_n(0) = 0$, $d_n(1/n) = \frac{1}{en}$, limit at ∞ = 0. So $\sup = \frac{1}{en}$.
Short cut · AM–GM$1 + n^2x^2 \ge 2nx$ (because $(1 - nx)^2 \ge 0$), so $\dfrac{nx}{1+n^2x^2} \le \dfrac12$, with equality at $x = 1/n$.
M5

Negating a statement

To prove "not uniform" you must know exactly what "not uniform" says.

Maths tool · flip each word

"for all" ↔ "there is", and the final inequality flips ($<$ becomes $\ge$).

Uniform: for every ε there is K such that for every $n \ge K$ and every x, $|f_n(x) - f(x)| < \varepsilon$.

Not uniform: there is an $\varepsilon_0$ such that for every K there are some $n \ge K$ and some x with $|f_n(x) - f(x)| \ge \varepsilon_0$.

Exam trap$\varepsilon_0$ is one fixed number (like ½). It must not shrink as n grows.
