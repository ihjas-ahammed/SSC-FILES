P01

The derivative in Plus Two

Slope of the tangent, speed, and the difference quotient.

Remind me · Plus Two Ch 5
  • Slope of a line through two points = rise ÷ run $=\dfrac{y_2-y_1}{x_2-x_1}$.
  • For a function f and a point c, the line joining $(c,f(c))$ to $(x,f(x))$ has slope $\dfrac{f(x)-f(c)}{x-c}$. This is the difference quotient (the "chord slope").
  • The derivative $f'(c)$ is the number these slopes approach as x comes close to c. It is the slope of the tangent, and the instantaneous rate of change.
  • Plus Two writes $\dfrac{f(c+h)-f(c)}{h}$ with $h\to0$. Bartle writes $x\to c$. They are the same thing with $h=x-c$.
  • Tangent line at c: $y-f(c)=f'(c)\,(x-c)$ (a line through $(c,f(c))$ with slope $f'(c)$).
Check yourself
For $f(x)=x^2$ and $c=3$, simplify the chord slope and find the tangent line.
$\frac{x^2-9}{x-3}=x+3\to6$. So $f'(3)=6$ and the tangent is $y-9=6(x-3)$.

Plus Two rules you may quote

Bartle proves the rules; the standard derivatives are assumed known.

Remind me · Plus Two Ch 5

For functions f, g and a constant α:

  • Sum, constant multiple: $(f+g)'=f'+g'$, $(\alpha f)'=\alpha f'$.
  • Product: $(fg)'=f'g+fg'$. Quotient (where $g\ne0$): $\left(\frac fg\right)'=\frac{f'g-fg'}{g^2}$.
  • Chain: $(g\circ f)'(x)=g'(f(x))\,f'(x)$.

P04

Limits of functions (Real Analysis I)

The derivative is a limit, so we need these results in exact form.

Remind me · Bartle 4.1, 4.2
  • A point c is a cluster point of a set A if every interval round c contains points of A other than c.
  • Definition 4.1.4. Let $A\subseteq\mathbb R$ and let c be a cluster point of A. For a function $f:A\to\mathbb R$, a real number L is said to be a limit of f at c if, given any $\varepsilon>0$ there exists $\delta(\varepsilon)>0$ such that if $x\in A$ and $0<|x-c|<\delta(\varepsilon)$, then $|f(x)-L|<\varepsilon$.
  • Limit laws (4.2.4): limits of sums, products and quotients (non-zero limit in the denominator) are the sum, product and quotient of the limits, when each limit exists.
  • Order (4.2.6): if $f(x)\ge0$ near c (for $x\ne c$) and $\lim_{x\to c}f$ exists, then $\lim_{x\to c}f\ge0$. A strict "$>$" can become "$\ge$" in the limit.
  • Local sign (4.2.9): if $\lim_{x\to c}f=L>0$, there is a neighbourhood of c on which $f(x)>0$ for $x\ne c$ (and similarly for $L<0$).
  • Sequential criterion (4.1.8): $\lim_{x\to c}f=L$ iff $f(x_n)\to L$ for every sequence $x_n\to c$ with $x_n\ne c$.
  • Squeeze: $g\le f\le h$ near c and $\lim g=\lim h=L$ ⇒ $\lim f=L$.
Why we need local sign and orderLocal sign ("limit positive ⇒ function positive near c") is how a derivative's sign is turned into a statement about values (T10, T22). Order ("f ≥ 0 ⇒ limit ≥ 0") is how $f$ increasing gives $f'\ge0$ (T14).

P06

Continuity (Module 1)

Differentiability sits on top of continuity.

Definition 5.1.1 · say it word for word Let $A\subseteq\mathbb R$, let $f:A\to\mathbb R$, and let $c\in A$. We say that f is continuous at c if, given any number $\varepsilon>0$ there exists $\delta>0$ such that if x is any point of A satisfying $|x-c|<\delta$, then $|f(x)-f(c)|<\varepsilon$. In words: whatever band of half-height ε you are handed round f(c), there is a window of half-width δ round c whose points all land in the band. Equivalent: $\lim_{x\to c}f(x)=f(c)$.
Remind me · Module 1
  • Sums, products, constant multiples and quotients (denominator $\ne0$) of continuous functions are continuous.
  • Composition (5.2.6): if f is continuous at c and g is continuous at $f(c)$, then $g\circ f$ is continuous at c.
  • Polynomials, $\sin$, $\cos$, $e^x$, $|x|$ are continuous everywhere.
  • Details: Module 1 prepare file, topics T01–T07.
Exam trap"Continuous" is a statement about values, "differentiable" about slopes. Every differentiable function is continuous (T02), but not the other way: $|x|$ at 0.
P07

The big theorems of Module 1

Rolle and Darboux are built on these. Know the statements.

Maximum–Minimum Theorem 5.3.4 Let $I=[a,b]$ be a closed bounded interval and let $f:I\to\mathbb R$ be continuous on I. Then f has an absolute maximum and an absolute minimum on I. So there is a point $x^*\in I$ with $f(x)\le f(x^*)$ for every $x\in I$. This is what makes Rolle and Darboux work.
Bolzano's Intermediate Value Theorem 5.3.7 Let I be an interval and let $f:I\to\mathbb R$ be continuous on I. If $a,b\in I$ and if $k\in\mathbb R$ satisfies $f(a)<k<f(b)$, then there exists a point $c\in I$ between a and b such that $f(c)=k$.
Remind me · Module 1
  • Location of Roots (5.3.5): f continuous on $[a,b]$ with $f(a)<0<f(b)$ (or the reverse) ⇒ a root in $(a,b)$.
  • Lipschitz (Definition 5.4.4): there is $K>0$ with $|f(x)-f(u)|\le K|x-u|$ for all $x,u\in A$. (T19 shows that a bounded derivative gives this.)
  • Details: Module 1 prepare file, topics T08–T22.

  • the interval is closed$x$ on $(0,1)$ has no maximum
  • and bounded$x$ on $[0,\infty)$ has no maximum
P08

Intervals, neighbourhoods and interior points

The words "interior" and "relative" are everywhere in §6.2.

Remind me · Bartle 2.2, 2.5
  • $V_\delta(c)=(c-\delta,c+\delta)$ is the δ-neighbourhood of c: all x with $|x-c|<\delta$.
  • A point c of an interval I is interior if some neighbourhood $V_\delta(c)$ lies inside I. So an interior point is any point of I except an endpoint.
  • $[a,b]$: interior is $(a,b)$. $(a,b)$: every point is interior. $[0,\infty)$: interior is $(0,\infty)$.
  • "Relative" (or "local") means: compared only with nearby points, inside some neighbourhood.
Why interior mattersThe derivative needs x to approach c from both sides. At an endpoint only one side exists, so a peak there need not have slope 0: $f(x)=x$ on $[0,1]$ peaks at 1 with slope 1 N7.
Check yourself
Is 0 an interior point of $[0,1]$? Of $(-1,1)$?
No: every neighbourhood of 0 contains negative numbers, which are not in $[0,1]$. Yes for $(-1,1)$ (take $\delta=1$).
P09

Inequalities and absolute value

The rules you use on every inequality line. More practice: Module 1 inequality gym.

Remind me · Plus One, Bartle 2.2
  • $|ab|=|a||b|$. $|a|<\varepsilon\iff-\varepsilon<a<\varepsilon$.
  • Triangle inequality: $|a+b|\le|a|+|b|$.
  • Multiplying: by a positive number keeps the direction ($2<3\Rightarrow10<15$). By a negative number it flips ($2<3\Rightarrow-4>-6$).
  • Signs of products: positive × positive = positive; negative × negative = positive; mixed = negative.
  • Strict and non-strict: "$<$" says "strictly less". If one step in a chain is strict, the whole chain is strict.
Maths tool · the sign of a quotient

If $q>0$ then $(x-c)\,q$ has the same sign as $x-c$. So $x>c$ gives a positive product and $x<c$ a negative one. We use this in T10 and T22.

Check yourself
If $f(x)-f(c)=(x-c)\cdot q$ with $q>0$ and $x<c$, is $f(x)>f(c)$ or $f(x)<f(c)$?
$x-c<0$ and $q>0$, so the product is negative: $f(x)<f(c)$.
P10

Piecewise functions and the signum

Differentiability at a join is the commonest short question.

Remind me · Plus One Ch 2
  • A piecewise function uses different formulas on different parts of the domain, such as $f(x)=x^2$ for $x\le1$ and $2x-1$ for $x>1$.
  • The point where the formulas change is the join. The value there is given by the piece whose condition includes the join (here $f(1)=1$).
  • Signum: $\operatorname{sgn}x=1$ for $x>0$, $0$ for $x=0$, $-1$ for $x<0$. Then $|x|=x\operatorname{sgn}x$.
Check yourself
For the $f$ above, are the two pieces equal at 1? Do they have the same slope there?
Values: $1^2=1$ and $2(1)-1=1$, so yes. Slopes: $2x=2$ and $2$, so yes. The join is smooth: $f$ is differentiable at 1 with $f'(1)=2$.
P11

Trigonometry values you need

Angles in radians. Used in the $x^2\sin(1/x)$ examples.

Remind me · Plus Two Ch 2
  • For every real x: $|\sin x|\le1$ and $|\cos x|\le1$.
  • For each whole number n: $\sin n\pi=0$, $\cos2n\pi=1$, $\cos(2n+1)\pi=-1$.
  • $\sin\frac\pi2=1$, $\cos\frac\pi2=0$, $\cos0=1$, $\sin0=0$.
  • $\tan x=\frac{\sin x}{\cos x}$, $\sec x=\frac1{\cos x}$, $\cot x=\frac{\cos x}{\sin x}$, $\csc x=\frac1{\sin x}$. $\sin^2x+\cos^2x=1$.
Check yourself
Evaluate $\cos\frac1x$ at $x=\frac1{3\pi}$ and at $x=\frac1{4\pi}$.
$\frac1x=3\pi$: $\cos3\pi=-1$. $\frac1x=4\pi$: $\cos4\pi=1$.
P12

Exponential and logarithm

Used in the MVT inequalities of T18.

Remind me · Plus Two Ch 1, 5
  • $e^0=1$, $e\approx2.718$. $e^x>0$ for every x. $e^x>1$ for $x>0$ and $e^x<1$ for $x<0$. $e^x$ is increasing.
  • $\ln x$ is defined only for $x>0$. $\ln1=0$, and $\ln x$ is increasing. $\ln x$ and $e^x$ undo each other.
  • $\dfrac{d}{dx}e^x=e^x$ and $\dfrac{d}{dx}\ln x=\dfrac1x$.
Check yourself
Is $e^c>1$ or $<1$ for $c$ between $-1$ and $0$?
$c<0$, so $e^c<1$ (and $e^c>e^{-1}>0$).
P13

Quadratics and sign charts

Needed to decide where $f'$ is positive or negative.

Remind me · Class 10, Plus One
  • $ax^2+bx+c=0$ has roots $x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$. The number $D=b^2-4ac$ is the discriminant.
  • If $D<0$ there are no real roots, so the quadratic never crosses zero and keeps the sign of a for all x.
  • Sign chart: mark the roots of each factor on a number line, then test one point in each interval. A factor changes sign only at its own root.
Check yourself
What is the sign of $x(x-1)(x-2)$ on $(1,2)$? And is $4x^2-15x+18$ ever zero?
Test $x=1.5$: $1.5\times0.5\times(-0.5)<0$, so negative. $D=225-288=-63<0$ and $a=4>0$: always positive, never zero.
M01

Limit of a difference quotient

Three steps, in this order.

Maths tool
  1. Write the quotient $\dfrac{f(x)-f(c)}{x-c}$ with the actual formulas.
  2. Simplify until the factor $x-c$ cancels top and bottom. (You may cancel it because $x\ne c$ in a limit.)
  3. Put $x=c$ in what is left.

Micro-example. $f(x)=x^2$: $\dfrac{x^2-c^2}{x-c}=\dfrac{(x-c)(x+c)}{x-c}=x+c\to2c$.

Micro-example. $f(x)=3x$: $\dfrac{3x-3c}{x-c}=3$ for every $x\ne c$, so the limit is 3.

Exam trapDo not put $x=c$ at the start: you get $\frac00$. The whole point is to cancel the zero factor first.
Check yourself
Find $f'(-1)$ for $f(x)=x^2$ by this method.
Quotient $=x+c$ with $c=-1$: tends to $-2$.
M02

Factorising and rationalising

How to make the factor $x-c$ appear.

Maths tool
  1. Powers: $x^n-c^n=(x-c)(x^{n-1}+x^{n-2}c+\cdots+c^{n-1})$. For $n=3$: $x^3-c^3=(x-c)(x^2+xc+c^2)$.
  2. Square roots: multiply top and bottom by the "conjugate": $\sqrt x-\sqrt c=\dfrac{(\sqrt x-\sqrt c)(\sqrt x+\sqrt c)}{\sqrt x+\sqrt c}=\dfrac{x-c}{\sqrt x+\sqrt c}$.
  3. Fractions: put over a common denominator: $\dfrac1x-\dfrac1c=\dfrac{c-x}{xc}=-\dfrac{x-c}{xc}$.

Micro-example: $\dfrac{\sqrt x-\sqrt c}{x-c}=\dfrac1{\sqrt x+\sqrt c}\to\dfrac1{2\sqrt c}$ $(c>0)$.

Micro-example: $\dfrac{1/x-1/c}{x-c}=\dfrac{-1}{xc}\to-\dfrac1{c^2}$.

Check yourself
Find $\lim_{x\to c}\dfrac{x^{-2}-c^{-2}}{x-c}$ for $c\ne0$.
$\frac1{x^2}-\frac1{c^2}=\frac{c^2-x^2}{x^2c^2}=\frac{-(x-c)(x+c)}{x^2c^2}$. Divide by $x-c$: $\frac{-(x+c)}{x^2c^2}\to\frac{-2c}{c^4}=-\frac2{c^3}$.
M03

One-sided limits and one-sided derivatives

At a corner or a join, compute both sides.

Maths tool
  • $x\to c^+$ means x approaches c from the right ($x>c$). $x\to c^-$ means from the left ($x<c$).
  • A limit exists iff the left limit and the right limit exist and are equal.
  • So $f'(c)$ exists iff the right quotient limit and the left quotient limit both exist and are equal.

Micro-example. $f(x)=|x|$ at 0: $\dfrac{|x|-0}{x-0}=\dfrac{|x|}x$, which is $+1$ for $x>0$ and $-1$ for $x<0$. The one-sided limits are $+1$ and $-1$: no derivative.

At a join of a piecewise function, check in order
  • the two pieces have the same value at the join (continuity)$x^2$ then $4\sqrt x$ at 1: values 1 and 4, stop, not differentiable N3
  • the two one-sided derivatives agree$2x+|x|$ at 0: slopes 3 and 1 N3
Check yourself
Is $h(x)=2x+|x|$ differentiable at 0?
$h=3x$ for $x\ge0$ and $x$ for $x\le0$. Right slope 3, left slope 1: not equal. No.
M04

Limit laws and the squeeze

When a factor has no limit, use the squeeze, not the product law.

Maths tool
  • Product law: $\lim(fg)=\lim f\cdot\lim g$ only when both limits exist.
  • Bounded times zero is zero: if $|g(x)|\le B$ and $f(x)\to0$, then $f(x)g(x)\to0$. Write $0\le|fg|\le B|f|\to0$ and squeeze.

Micro-example. $\sin\frac1x$ has no limit at 0, so we cannot split $x\sin\frac1x$. But $\left|x\sin\frac1x\right|\le|x|\to0$, so $x\sin\frac1x\to0$.

Check yourself
Find $\lim_{x\to0}x^2\cos\frac1x$.
$\left|x^2\cos\frac1x\right|\le x^2\to0$, so the limit is 0.
M05

Sign analysis of the derivative

The routine behind "find the intervals of increase" and "find the extrema".

Maths tool · four steps
  1. Find $f'$ and factorise it.
  2. Solve $f'=0$ (and note where $f'$ does not exist). Mark these points on a number line.
  3. Test one point in each interval and record the sign of $f'$.
  4. Read off: $f'>0$ means rising, $f'<0$ means falling. Include the end points of each interval (Bartle's "increasing" is non-strict).

Micro-example. $f(x)=x^3-3x$: $f'=3(x-1)(x+1)$, zeros $\pm1$. Test: $x=-2$ gives $+9$; $x=0$ gives $-3$; $x=2$ gives $+9$. So increasing on $(-\infty,-1]$, decreasing on $[-1,1]$, increasing on $[1,\infty)$.

Why this is allowed"Sign of $f'$ gives rising or falling" is proved in T14, and "sign change gives extremum" in T15. For now, learn the routine; those topics supply the reasons.
Check yourself
Where is $f(x)=x^2-3x+5$ decreasing?
$f'=2x-3$, zero at $\frac32$; $f'<0$ for $x<\frac32$. Decreasing on $(-\infty,\frac32]$.
M06

An inequality from the MVT

Five steps. This is the template for T17–T21 (compare with the gym, P09).

Maths tool

The MVT (T12) says: for some c strictly between a and b, $f(b)-f(a)=f'(c)(b-a)$. We do not know c, but we do know where it lies.

  1. Write $f(b)-f(a)=f'(c)(b-a)$ for the interval you want, with $a<c<b$.
  2. Bound $f'(c)$ using $a<c<b$ (the derivative is monotone there, or $|\cdot|\le1$).
  3. Multiply by $b-a>0$, so the direction is kept.
  4. The result is strict if the bound on $f'(c)$ is strict.
  5. Treat $x=a$ (equality) and the other side of a (a different interval) separately.

Micro-example. For $0\le x,y\le M$: $x^2-y^2=2c\,(x-y)$ for some c between y and x, and $0\le2c\le2M$, so $|x^2-y^2|\le2M|x-y|$. (A Lipschitz bound.)

Exam trapThe MVT gives some c, not the midpoint and not a number you can name. An inequality needs a bound on $f'$ over the whole open interval N12.
Check yourself
For $f(x)=x^3$, show $|x^3-y^3|\le3|x-y|$ for $x,y\in[0,1]$.
$x^3-y^3=3c^2(x-y)$ with $c\in[0,1]$, so $3c^2\le3$. Hence $|x^3-y^3|\le3|x-y|$.
M07

No limit, by two sequences

How to show a quotient or a derivative has no limit.

Maths tool
  1. Find a sequence $x_n\to c$ ($x_n\ne c$) with $f(x_n)\to A$.
  2. Find another $y_n\to c$ ($y_n\ne c$) with $f(y_n)\to B$ and $B\ne A$.
  3. By the sequential criterion (P04) the limit does not exist, since a limit would force $A=B$.

Micro-example. $\cos\frac1x$ at 0: $x_n=\frac1{2n\pi}$ gives $\cos2n\pi=1$; $y_n=\frac1{(2n+1)\pi}$ gives $-1$. So no limit.

Check yourself
Show $\sin\frac1x$ has no limit at 0 using $x_n=\frac1{n\pi}$ and one other sequence.
$x_n=\frac1{n\pi}$ gives $\sin n\pi=0$. Take $y_n=\frac1{\pi/2+2n\pi}$: $\sin(\pi/2+2n\pi)=1$. Limits $0\ne1$.
M08

Composite bookkeeping

Name the inside and the outside before you differentiate.

Maths tool
  1. Name the inner function f (the one applied first) and the outer function g.
  2. Differentiate g, but evaluate $g'$ at $f(x)$, not at x.
  3. Multiply by $f'(x)$: $(g\circ f)'(x)=g'(f(x))\cdot f'(x)$.

Micro-example. $\sqrt{x^2-2x+5}$: inner $f=x^2-2x+5$, outer $g(y)=\sqrt y$ with $g'(y)=\frac1{2\sqrt y}$. So the derivative is $\frac1{2\sqrt{x^2-2x+5}}\cdot(2x-2)=\dfrac{x-1}{\sqrt{x^2-2x+5}}$.

For three layers, peel from the outside: $\sin(\cos(x^2))$ gives $\cos(\cos x^2)\cdot(-\sin x^2)\cdot2x$.

Check yourself
Differentiate $\sin(x^2)$ and $(x^2+1)^3$.
$\cos(x^2)\cdot2x$. And $3(x^2+1)^2\cdot2x=6x(x^2+1)^2$.
M09

Defining a function by cases, and the join

The idea behind Carathéodory's theorem (T05).

Maths tool

For a function f and a point c, define a new function by cases:

$\varphi(x)=\dfrac{f(x)-f(c)}{x-c}$ for $x\ne c$, and $\varphi(c)=$ a number we choose.

The only question is: do the two descriptions meet at c? That is, does $\lim_{x\to c}\varphi(x)$ exist and equal the number we chose? If yes, $\varphi$ is continuous at c.

Micro-example. $f=x^2$, $c=1$: $\varphi(x)=x+1$ for $x\ne1$, and choosing $\varphi(1)=2$ makes $\varphi$ continuous. That chosen value is $f'(1)$.

Micro-example. $f=|x|$, $c=0$: $\varphi(x)=\operatorname{sgn}x$ for $x\ne0$, which jumps from $-1$ to $+1$. No value for $\varphi(0)$ can join them.

Check yourself
For $f=x^3$ and any c, find $\varphi$ (use M02) and say which value to give $\varphi(c)$.
$\varphi(x)=x^2+xc+c^2$ for $x\ne c$. It is a polynomial, so choose $\varphi(c)=3c^2$, which is $f'(c)$.
M10

"There exists c", and proof by contradiction

How to read the conclusion of Rolle, MVT and Darboux.

Maths tool
  • "There exists at least one point c" says c exists. It does not say where, or that it is the only one, or that it is the midpoint.
  • Contradiction: to show $f'(c)=0$, assume $f'(c)>0$ and derive something that is false; then do the same with $f'(c)<0$.
  • Reduction by a minus sign: a maximum of f is a minimum of $-f$. A proof for "max" gives the proof for "min" by replacing f with $-f$. Also $f'(c)=0\iff(-f)'(c)=0$.
The exam habitWhen you finish a proof of "there exists c", say where c lies: "with $a<c<b$". And when you use "by symmetry" or "similarly", write one line showing how, because the examiner marks that line.
Check yourself
Rolle gives c with $f'(c)=0$ for $f=x(x-1)(x-2)$ on $[0,2]$. Is c unique?
No. $f'=3x^2-6x+2=0$ gives $x=1\pm\frac1{\sqrt3}$, both in $(0,2)$. "At least one" allows several.
