T22

The local sign lemma

The engine inside Darboux's Theorem (Bartle Lemma 6.2.11).

PuzzleIf the slope at c is positive, are the points just to the right of c higher than f(c)? Are they higher than each other as you move right? One is true, one is not.
Picture in words
f′(c) > 0just right of c: values above f(c) ↗ (and just left: below) f′(c) < 0just left of c: values above f(c) ↖ (and just right: below)
A positive slope at c means the tangent climbs; the graph follows its tangent closely enough, for a short distance, to stay above (right) or below (left) the height f(c).
Lemma 6.2.11 · local sign lemmaLet $I$ be an interval, $f : I \to \mathbb R$, $c \in I$, and suppose $f$ has a derivative at $c$.

(a) If $f'(c) > 0$, then there is $\delta > 0$ such that $f(x) > f(c)$ for $x \in I$ with $c < x < c + \delta$.

(b) If $f'(c) < 0$, then there is $\delta > 0$ such that $f(x) > f(c)$ for $x \in I$ with $c - \delta < x < c$.

Note (b): the values are above f(c) on the left (the graph is falling through c). Darboux needs exactly this.
Skeleton · (a)The quotient $\dfrac{f(x) - f(c)}{x - c}$ tends to $f'(c) > 0$, so for $0 < |x - c| < \delta$ it is ?. For $c < x < c + \delta$: $f(x) - f(c) = (x - c) \cdot$ ? $> 0$. ∎
Proof
(a) $\displaystyle\lim_{x \to c}\frac{f(x) - f(c)}{x - c} = f'(c) > 0$. By the local sign property of limits there is $\delta > 0$ such that $\dfrac{f(x) - f(c)}{x - c} > 0$ for $x \in I$, $0 < |x - c| < \delta$.Theorem 4.2.9 (a positive limit forces positive values nearby; Module 1).
For $c < x < c + \delta$: $x - c > 0$, so $f(x) - f(c) = (x - c)\cdot\dfrac{f(x) - f(c)}{x - c} > 0$.Positive times positive.
(b) $f'(c) < 0$: choose $\delta$ so the quotient is $< 0$ for $0 < |x - c| < \delta$. For $c - \delta < x < c$: $x - c < 0$ and quotient $< 0$, so $f(x) - f(c) = (x - c)\cdot(\text{quotient}) > 0$. ∎Negative times negative is positive.
Hypotheses checklist
  • $f'(c) \ne 0$ (strict sign)$f(x) = -x^2$ at 0: $f'(0) = 0$ and $f(x) < f(0)$ on both sides
  • $f'(c)$ exists (two-sided at an interior point)$f(x) = -|x|$ at 0: left quotient is $+1$, right quotient is $-1$; the right values are below f(0), so (a)'s conclusion fails C5
  • (a) says right of c, not "everywhere near c"left of c the values are lower: $f(x) < f(c)$

Where each was used. Existence of $f'(c)$: the limit whose sign is read. $f'(c) > 0$: starts the sign argument. $x \in I$: the points compared stay in the domain, so it also works at an endpoint of I (that is how Darboux uses it).

Your intuition lies · "positive slope ⇒ increasing near c"The lemma compares $f(x)$ only with the single value $f(c)$. It does not say f is increasing on $(c - \delta, c + \delta)$. For $g(x) = x + 2x^2\sin(1/x)$, $g(0) = 0$, $g'(0) = 1 > 0$ and indeed $g(x) > 0$ just right of 0, but $g'(x) = -1$ at $x = \frac1{2n\pi}$: g goes down inside every window (T14).
Worked example 1 · full

$f(x) = 3x + x^2$ at $c = 0$. $f'(0) = 3 > 0$. The quotient is $\dfrac{3x + x^2 - 0}{x} = 3 + x$, which is $> 0$ for $-3 < x < 3$, $x \ne 0$. So $\delta = 3$ works: for $0 < x < 3$, $f(x) = x(3 + x) > 0 = f(0)$. (And for $-3 < x < 0$ the values are below.)

Worked example 2 · with gaps$f(x) = x^2 - 2x$ at $c = 0$. $f'(0) = $ ? $< 0$. Quotient $= x - 2$, which is $< 0$ for $x < $ ?. By (b), for $-\delta < x < 0$ we get $f(x) > $ ?. Here $\delta = $ ?. Answer: $-2$; $x < 2$; $f(x) > f(0) = 0$; $\delta = 2$. Check $x = -1$: $1 + 2 = 3 > 0$ ✓.
Check yourself
$f'(c) > 0$. Does the lemma let you conclude $f(x_1) < f(x_2)$ for $c < x_1 < x_2 < c + \delta$? Why or why not?
No. It only compares each x with $f(c)$. Two points both to the right of c are not compared. Counterexample: $x + 2x^2\sin(1/x)$ at 0 (in the trap box).

T23

Darboux's Theorem

A derivative has the intermediate value property, even when it is not continuous.

PuzzleYou know $f'(0) = 0$ and $f'(2) = 4$. Does f′ have to take the value 1 somewhere between? You are not told f′ is continuous. (Yes: this theorem.)
Theorem 6.2.12 · Darboux's TheoremIf $f$ is differentiable on $I = [a, b]$ and if $k$ is a number between $f'(a)$ and $f'(b)$, then there is at least one point $c$ in $(a, b)$ such that $f'(c) = k$. "Between" means either $f'(a) < k < f'(b)$ or $f'(a) > k > f'(b)$. Bartle writes out only the first case; the exam wants both.
Proof picture · in numbers $f(x) = x^2$ on $[0, 2]$, $f'(a) = f'(0) = 0$, $f'(b) = f'(2) = 4$, $k = 1$. The auxiliary function $g(x) = kx - f(x) = x - x^2$ has $g'(0) = 1 > 0$ (rising at the left end) and $g'(2) = -3 < 0$ (falling at the right end).
x0 · 0.5 · 1 · 2 g(x)0 · 0.25 · 0 · −2
The maximum of g on [0, 2] is at the interior point $x = \frac12$, where $g' = 0$, i.e. $f'(\frac12) = 1 = k$.
Skeleton · case $f'(a) < k < f'(b)$Let $g(x) = kx - f(x)$. g is continuous on [a, b], so it has a maximum at some $c \in [a, b]$ (Max–Min). Since $g'(a) = k - f'(a) > 0$, the maximum is not at ? (Lemma 6.2.11(a)). Since $g'(b) = k - f'(b) < 0$, it is not at ? (Lemma (b)). So c is interior and $g'(c) = 0$, i.e. ?. ∎
Scratch · how to find g (never copied into the exam) Want a point where $f'(c) = k$, i.e. $k - f'(c) = 0$.
"derivative equals 0" is what happens at an interior extremum. So we need a function whose derivative is $k - f'$: that is $g(x) = kx - f(x)$.
Is there an extremum? g is continuous on [a, b], so yes, a maximum exists. Is it inside? The signs of $g'$ at the ends say the graph climbs away from a and falls into b, so the top is not at the ends.
Proof (Bartle, with the missing case written out)
Case 1: $f'(a) < k < f'(b)$. Let $g(x) = kx - f(x)$ on $[a, b]$.$g' = k - f'$, so $f'(c) = k$ iff $g'(c) = 0$.
g is continuous on [a, b], so g attains a maximum at some $c \in [a, b]$.Differentiable ⇒ continuous; Max–Min Theorem 5.3.4.
$g'(a) = k - f'(a) > 0$, so by Lemma 6.2.11(a) there are x just to the right of a with $g(x) > g(a)$. Hence the maximum is not at a: $c \ne a$.A maximum value cannot be exceeded.
$g'(b) = k - f'(b) < 0$, so by Lemma 6.2.11(b) there are x just to the left of b with $g(x) > g(b)$. Hence $c \ne b$.Lemma (b): values above g(b) on the left. This is why (b) is stated that way.
So $c \in (a, b)$ is an interior maximum of g, and $g'(c)$ exists. By the Interior Extremum Theorem, $0 = g'(c) = k - f'(c)$, so $f'(c) = k$.Theorem 6.2.1 (T10).
Case 2: $f'(a) > k > f'(b)$. Put $F = -f$ and $K = -k$. Then $F'(a) = -f'(a) < -k = K$ and $K < -f'(b) = F'(b)$, which is Case 1 for F and K. So there is $c \in (a, b)$ with $F'(c) = K$, i.e. $f'(c) = k$. ∎Multiplying by −1 reverses the order, turning case 2 into case 1. (Equivalently, maximise $f(x) - kx$.) The case Bartle omits.
Hypotheses checklist
  • f differentiable at every point of [a, b] (one-sided at the ends)$f(x) = |x|$ on $[-1, 1]$: $f'(-1) = -1 < 0 < 1 = f'(1)$ but $f' = \pm 1$ never 0, since f′(0) does not exist C5
  • the domain is an interval$f(x) = -|x|$ on $[-1, 0) \cup (0, 1]$ (the point 0 removed): $f'(-1) = 1$, $f'(1) = -1$, and $f' = \pm 1$ never 0
  • f′ continuous: not needed$f(x) = x^2\sin(1/x)$, $f(0) = 0$: $f'$ is discontinuous at 0 yet has the property C6

Where each was used. Differentiable on [a, b]: g continuous (Max–Min), and $g'(a)$, $g'(b)$ exist for the lemma. Interval: all of [a, b] is the domain, so the maximum exists. Interior Extremum: converts "max at interior c" into $g'(c) = 0$.

Your intuition lies · "no continuity of f′, so no IVP"The Intermediate Value Theorem for continuous functions (Module 1) is one reason a function can have the IVP, not the only one. Derivatives can wiggle ($\cos\frac1x$ terms in f′ of $x^2\sin\frac1x$ near 0 C6) but cannot jump. Darboux is one-way: it can rule a function out as a derivative; it does not by itself prove a function is a derivative.
Worked example 1 · full

$f(x) = x^2$ on $[0, 2]$, $k = 1$. $f'(0) = 0 < 1 < 4 = f'(2)$. $g(x) = x - x^2$, $g'(x) = 1 - 2x$. $g(0) = 0$, $g(\frac12) = \frac14$, $g(2) = -2$. The maximum is at $c = \frac12 \in (0, 2)$, and $f'(\frac12) = 1 = k$ ✓.

Worked example 2 · with gaps$f(x) = x^3$ on $[0, 2]$, $k = 3$. $f'(0) = $ ?, $f'(2) = $ ?, so $k$ is between. $g(x) = 3x - x^3$, $g' = $ ? $= 0$ at $x = $ ?. Check $g(0), g(1), g(2)$: ?. So $c = $ ?. Answer: $0$; $12$; $3 - 3x^2$; $x = 1$; $0, 2, -2$ (max at 1); $c = 1$, and $f'(1) = 3$ ✓.
Check yourself · the second ordering
$f(x) = \sin x$ on $[0, \pi]$, $k = \frac12$. Here $f'(0) = 1 > \frac12 > -1 = f'(\pi)$. Which function do you maximise, and what c do you get?

T24

A function that is not a derivative

Jumps are impossible for derivatives (Bartle 6.2.13, Ex 6.2.12).

PuzzleThe function that is $-1$ left of 0 and $+1$ right of 0 is perfectly simple. Is there any function whose derivative is it? Darboux says no, with no calculation at all.
{{fig:darboux_jump}}
Bartle 6.2.13 and Ex 6.2.12The function $g : [-1, 1] \to \mathbb R$ defined by $g(x) = -1$ for $-1 \le x < 0$, $g(0) = 0$, $g(x) = 1$ for $0 < x \le 1$ is not the derivative on $[-1, 1]$ of any function. The test: a derivative must take every value between any two of its values (Darboux). g takes −1 and 1 but never $\frac12$.
Skeleton · "show g is not a derivative"Suppose $g = F'$ on $[a, b]$ for some differentiable F. Pick two values $g(p) < g(q)$ and a number $k$ strictly between them. By Darboux there is $c$ between p and q with $g(c) = k$. But ?. Contradiction. ∎
Proof
Suppose $g = F'$ for a function F differentiable on $[-1, 1]$.Contradiction method (M10).
$F'(-1) = g(-1) = -1$ and $F'(1) = g(1) = 1$, and $-1 < \frac12 < 1$.Read the values off g.
By Darboux there is $c \in (-1, 1)$ with $F'(c) = g(c) = \frac12$.Theorem 6.2.12 (T23); F is differentiable on [−1, 1].
But g takes only the values $-1, 0, 1$. Contradiction. ∎$\frac12$ is not one of them.
Hypotheses checklist (what the argument needs)
  • F differentiable on the whole interval$F(x) = |x|$ has $F' = \operatorname{sgn} x$ for $x \ne 0$ but is not differentiable at 0, so sgn is not "$F'$ on [−1, 1]" C9
  • a value $k$ strictly between two values of g, never taken$\sin(1/x)$ with value 0 at 0 takes every value between any two of its values: Darboux gives no contradiction C10
Your intuition lies · "it fails continuity, so it is not a derivative"Wrong reason. Many derivatives are discontinuous: f′ for $x^2\sin(1/x)$ C6. The right test is the intermediate value property. And $h(x) = \sin(1/x)$, $h(0) = 0$, is discontinuous at 0 but does have the IVP on [0, 1]; Darboux does not rule it out. It is in fact a derivative (it is $F' - 2x\cos\frac1x$ with $F = x^2\cos\frac1x$, and $2x\cos\frac1x$ is continuous, so has an antiderivative: Module 3) C10.
Same derivative, different functions (Ex 6.2.12) $h(x) = 0$ for $x < 0$ and $h(x) = 1$ for $x \ge 0$. By Darboux no F has $F' = h$ everywhere (h takes 0 and 1 but not $\frac12$). Yet $f_1(x) = \max(x, 0)$ and $f_2(x) = 0$ for $x \le 0$, $f_2(x) = x + 1$ for $x > 0$ both have derivative $h(x)$ for every $x \ne 0$ ($0$ on the left, $1$ on the right), and $f_2 - f_1 = 0$ for $x \le 0$, $= 1$ for $x > 0$: not a constant. The corollary "equal derivatives ⇒ differ by a constant" needs one interval and differentiability at every point (T13).
Worked example 1 · full

Heaviside: $H(x) = 0$ ($x < 0$), $H(x) = 1$ ($x \ge 0$) on $[-1, 1]$. $H(-1) = 0$, $H(1) = 1$. Take $k = \frac12$. $H$ never equals $\frac12$ (values 0, 1 only). By Darboux, H is not the derivative of any function on $[-1, 1]$.

Worked example 2 · with gaps$g(x) = \lfloor x \rfloor$ (greatest integer) on $[0, 2]$. $g(0) = $ ?, $g(2) = $ ?. Take $k = $ ?. The values of g are only ?, so $k$ is skipped: not a derivative. Answer: $0$; $2$; $k = \frac12$ (or $\frac32$); $\{0, 1, 2\}$.
Check yourself
$f$ is differentiable on $[0, 1]$ and $f'(x) \ne 0$ for every x. Why must $f'$ have the same sign throughout, and what follows for f?
If $f'(p) < 0 < f'(q)$ for some p, q, Darboux (on [p, q] or [q, p]) gives a point where $f' = 0$: contradiction. So $f' > 0$ everywhere or $f' < 0$ everywhere, and f is strictly monotone (T14).
