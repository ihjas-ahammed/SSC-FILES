State and prove the Location of Roots Theorem.

Know firstT10P10T3P6M7

Theorem 5.3.5. Let I = [a, b] and let $f : I \to \mathbb R$ be continuous on I. If $f(a) < 0 < f(b)$, or if $f(a) > 0 > f(b)$, then there exists $c \in (a,b)$ such that $f(c) = 0$.

Proof (case $f(a) < 0 < f(b)$).

Let $I_1 = [a_1, b_1] = [a, b]$ and $p_1 = \frac{a_1 + b_1}{2}$. If $f(p_1) = 0$, take $c = p_1$. If $f(p_1) > 0$ put $I_2 = [a_1, p_1]$; if $f(p_1) < 0$ put $I_2 = [p_1, b_1]$. In both cases $f(a_2) < 0 < f(b_2)$.Bisection keeps the sign change.
Continue. Either we reach some $p_n$ with $f(p_n) = 0$, or we get nested intervals $I_n = [a_n, b_n]$ with $f(a_n) < 0 < f(b_n)$ and $b_n - a_n = \dfrac{b - a}{2^{n-1}}$.Induction; each step halves the length.
By the Nested Intervals Property there is c in every $I_n$. Since $a_n \le c \le b_n$ and $b_n - a_n \to 0$, we get $a_n \to c$ and $b_n \to c$.2.5.2; $|a_n - c| \le b_n - a_n$.
f is continuous at $c \in I$, so $f(a_n) \to f(c)$ and $f(b_n) \to f(c)$.Sequential criterion 5.1.3.
$f(a_n) < 0$ for all n gives $f(c) \le 0$; $f(b_n) > 0$ gives $f(c) \ge 0$. Hence $f(c) = 0$.Order theorem 3.2.6.
Since $f(a) < 0$ and $f(b) > 0$, c is neither a nor b: $c \in (a,b)$.f(c) = 0.
If $f(a) > 0 > f(b)$, apply the above to $g = -f$, which is continuous with $g(a) < 0 < g(b)$. ∎A zero of −f is a zero of f.

Error estimate: the midpoint $p_n$ is within $(b-a)/2^n$ of c.

Marks: statement 2 · construction 3 · nested intervals and limits 2 · continuity and sign 2 · conclusion 1.

State and prove the Maximum–Minimum Theorem.

Know firstT9T8P5P7T3

Theorem 5.3.4. Let I = [a, b] be a closed bounded interval and let $f : I \to \mathbb R$ be continuous on I. Then f has an absolute maximum and an absolute minimum on I. (MCQ: this needs I closed and bounded.)

Lemma used. Boundedness Theorem 5.3.2: f is bounded on I.

$f(I) = \{f(x) : x \in I\}$ is non-empty and bounded, so $s^* = \sup f(I)$ and $s_* = \inf f(I)$ exist.5.3.2 and Completeness.
For each n, $s^* - \frac1n$ is not an upper bound of f(I): choose $x_n \in I$ with $s^* - \frac1n < f(x_n) \le s^*$.Definition of supremum.
$(x_n)$ is bounded, so by Bolzano–Weierstrass some subsequence $x_{n_r} \to x^*$; since $a \le x_{n_r} \le b$, $x^* \in I$.I bounded and closed.
f is continuous at $x^*$: $f(x_{n_r}) \to f(x^*)$.Sequential criterion.
From $s^* - \frac{1}{n_r} < f(x_{n_r}) \le s^*$, the Squeeze Theorem gives $f(x_{n_r}) \to s^*$.$1/n_r \to 0$.
By uniqueness of limits $f(x^*) = s^*$, so $f(x^*) \ge f(x)$ for all $x \in I$: an absolute maximum at $x^*$.$s^*$ is an upper bound.
For the minimum, choose $x_n$ with $s_* \le f(x_n) < s_* + \frac1n$ and repeat steps 3–6 (or apply the result to −f). ∎Symmetry.

Hypotheses. Not closed: $f(x) = x$ on (0, 1) has no max or min. Not bounded: x on [0, ∞) has no max. Not continuous: $h(x) = x$ on [0, 1), $h(1) = 0$ has no max.

Marks: statement 1 · sup exists 1 · approximating $x_n$ 2 · BW and $x^* \in I$ 2 · continuity and squeeze 2 · max 1 · min 1.

State and prove the Uniform Continuity Theorem.

Know firstT15T14P7T3

Theorem 5.4.3. Let I be a closed bounded interval and let $f : I \to \mathbb R$ be continuous on I. Then f is uniformly continuous on I.

Suppose f is not uniformly continuous on I. By 5.4.2 there are $\varepsilon_0>0$ and sequences $(x_n), (u_n)$ in I with $|x_n - u_n| < \frac1n$ and $|f(x_n) - f(u_n)| \ge \varepsilon_0$ for all n.Nonuniform Continuity Criteria with δ = 1/n.
$(x_n)$ is bounded, so by Bolzano–Weierstrass a subsequence $x_{n_k} \to z$. Since I is closed, $z \in I$.I bounded and closed.
$|u_{n_k} - z| \le |u_{n_k} - x_{n_k}| + |x_{n_k} - z| < \frac{1}{n_k} + |x_{n_k} - z| \to 0$, so $u_{n_k} \to z$.Triangle inequality.
f is continuous at z, so $f(x_{n_k}) \to f(z)$ and $f(u_{n_k}) \to f(z)$.Sequential criterion.
Hence $|f(x_{n_k}) - f(u_{n_k})| \to |f(z) - f(z)| = 0$, contradicting $|f(x_{n_k}) - f(u_{n_k})| \ge \varepsilon_0$ for all k.Limit of a difference.
Therefore f is uniformly continuous on I. ∎

Hypotheses. 1/x on (0, 1] (not closed) and x² on [0, ∞) (not bounded) are continuous but not uniformly continuous.

Marks: statement 1 · negation and sequences 3 · BW and z ∈ I 2 · second sequence 2 · continuity and contradiction 2.

State and prove the Continuous Extension Theorem.

Theorem 5.4.8. A function f is uniformly continuous on the interval (a, b) if and only if it can be defined at the endpoints a and b such that the extended function is continuous on [a, b].

(⇐) If the extension is continuous on [a, b], it is uniformly continuous there (Theorem 5.4.3), and the same δ works on the subset (a, b).

(⇒) We show $\lim_{x\to a} f(x)$ exists; the end b is similar.

Let $(x_n)$ in (a, b) converge to a. It is a Cauchy sequence.Convergent ⇒ Cauchy (3.5.3).
By Theorem 5.4.7, $(f(x_n))$ is Cauchy, hence converges to some L.Uniform continuity; Cauchy ⇒ convergent (3.5.5).
If $(u_n)$ is another sequence in (a, b) converging to a, then $u_n - x_n \to 0$, so by uniform continuity $f(u_n) - f(x_n) \to 0$, hence $f(u_n) \to L$.Given ε, take δ; eventually $|u_n - x_n| < \delta$.
Every sequence tending to a gives the same limit L, so $\lim_{x\to a} f(x) = L$ by the sequential criterion for limits (4.1.8). Define $f(a) := L$.P9.
Similarly define f(b). The extended f is continuous at a and b (limit = value), and at every interior point as before; so it is continuous on [a, b]. ∎Remark 5.1.7.

Use. $\sin(1/x)$: no limit at 0, so not UC on (0, 1); $x\sin(1/x)$: limit 0, so UC.
