UNIT 1 · BARTLE §5.1

Continuity at a point

T1

The ε–δ definition

The definition everything else rests on (PYQ MTS-22 Q1).

Definition 5.1.1 · say it word for wordLet $A \subseteq \mathbb R$, let $f : A \to \mathbb R$, and let $c \in A$. We say that f is continuous at c if, given any number $\varepsilon>0$, there exists $\delta>0$ such that if x is any point of A satisfying $|x - c| < \delta$, then $|f(x) - f(c)| < \varepsilon$. If f fails to be continuous at c, then we say that f is discontinuous at c. In plain words: you can force f(x) as close to f(c) as anyone demands, just by taking x close enough to c.
Definition 5.1.5 · continuous on a setIf $B \subseteq A$, f is continuous on B if f is continuous at every point of B.
Skeleton · prove f is continuous at cLet $\varepsilon>0$. Choose $\delta = $ ?. Let $x \in A$ with $|x - c| < \delta$. Then $|f(x) - f(c)| \le$ ? $< \varepsilon$. Hence f is continuous at c. ∎
Two easiest examples (Bartle 5.1.6(a), (b))

Constant $f(x) = b$: $|f(x) - f(c)| = |b - b| = 0 < \varepsilon$ for every x, so any δ works (say δ = 1).

Identity $g(x) = x$: $|g(x) - g(c)| = |x - c|$, so $\delta = \varepsilon$ works.

Your intuition will lie to you here"Continuous = can be drawn without lifting the pen." The pen rule cannot prove anything, and it is wrong for $1/x$: that graph has two pieces, yet $1/x$ is continuous at every point of its domain $x \ne 0$. Continuity is only ever about points in the domain.
Check yourself
For $f(x) = 3x + 1$, which δ works for a given ε?
$|f(x) - f(c)| = 3|x - c| < \varepsilon$ when $|x - c| < \varepsilon/3$. So $\delta = \varepsilon/3$ (the same at every c).

T2

Neighbourhoods, limits and isolated points

Two other ways to say the same thing (Theorem 5.1.2).

Theorem 5.1.2 · neighbourhood formf is continuous at $c \in A$ iff given any ε-neighbourhood $V_\varepsilon(f(c))$ of f(c) there exists a δ-neighbourhood $V_\delta(c)$ of c such that if x is any point of $A \cap V_\delta(c)$, then f(x) belongs to $V_\varepsilon(f(c))$; that is, $f(A \cap V_\delta(c)) \subseteq V_\varepsilon(f(c))$. $V_\delta(c) = (c - \delta, c + \delta)$. This is Definition 5.1.1 written with sets.
Result · limit form (Remarks 5.1.2)

If c is a cluster point of A: f is continuous at c ⇔ (i) f(c) is defined, (ii) $\lim_{x\to c} f(x)$ exists, (iii) the two are equal.

If c is not a cluster point (an isolated point of A), f is automatically continuous at c: a small window round c contains no other point of A.

Check yourself
$A = [0,1] \cup \{2\}$, f any function on A. Is f continuous at 2?
Yes. With δ = ½ the only point of A in the window is 2 itself, so $|f(x) - f(2)| = 0 < \varepsilon$.

T3

The sequential criterion

Continuity through sequences: the tool for disproving continuity (PYQ MTS-26 Q1).

Theorem 5.1.3 · Sequential Criterion for ContinuityA function $f : A \to \mathbb R$ is continuous at the point $c \in A$ if and only if for every sequence $(x_n)$ in A that converges to c, the sequence $(f(x_n))$ converges to f(c).
Theorem 5.1.4 · Discontinuity CriterionLet $A \subseteq \mathbb R$, let $f : A \to \mathbb R$, and let $c \in A$. Then f is discontinuous at c if and only if there exists a sequence $(x_n)$ in A such that $(x_n)$ converges to c, but the sequence $(f(x_n))$ does not converge to f(c).
{{fig:seq_criterion}}
Proof of 5.1.3 (Bartle leaves it to you)

(⇒)

Let $x_n \to c$, $x_n \in A$, and let $\varepsilon>0$. Take δ from the continuity of f at c.Definition 5.1.1.
Since $x_n \to c$, there is K with $|x_n - c| < \delta$ for $n \ge K$.Definition of convergence, used with the number δ in place of ε.
So $|f(x_n) - f(c)| < \varepsilon$ for $n \ge K$: $f(x_n) \to f(c)$.Step 1 applied to $x = x_n$.

(⇐) by contrapositive

Suppose f is not continuous at c: some $\varepsilon_0>0$ has, for every δ, a point $x \in A$ with $|x - c| < \delta$, $|f(x) - f(c)| \ge \varepsilon_0$.Negation (M3).
With δ = 1/n get $x_n \in A$, $|x_n - c| < 1/n$, $|f(x_n) - f(c)| \ge \varepsilon_0$.One point for each n (M5).
Then $x_n \to c$ but $f(x_n) \not\to f(c)$: the sequence condition fails. ∎Squeeze for $x_n \to c$; the gap stays ≥ ε₀. Steps 4–6 also prove 5.1.4.

T4

ε–δ proofs: x², polynomials, 1/x, |x|

Finding δ in practice (PYQ MTS-25 Q1; related FYUGP CALC-24 Q12).

Know$h(x) = x^2$, c any real number, ε > 0 given.Wantδ with $|x^2 - c^2| < \varepsilon$ whenever $|x - c| < \delta$.
Scratch · Bartle 5.1.6(c)

$|x^2 - c^2| = |x - c|\,|x + c|$. Restrict $|x - c| < 1$: then $|x + c| \le |x - c| + 2|c| < 1 + 2|c|$.

Want $(1 + 2|c|)\,|x - c| < \varepsilon \Leftarrow |x - c| < \dfrac{\varepsilon}{1 + 2|c|}$.

ProofLet $\varepsilon>0$ and put $\delta = \min\left\{1, \dfrac{\varepsilon}{1 + 2|c|}\right\}$. If $|x - c| < \delta$, then $|x + c| < 1 + 2|c|$, so $$|x^2 - c^2| = |x - c||x + c| < \frac{\varepsilon}{1 + 2|c|}(1 + 2|c|) = \varepsilon.$$ So $x^2$ is continuous at every c. ∎
Check yourself
Find δ for $x^2$ at c = 3, ε = 0.01.
$\delta = \min\{1, 0.01/7\} = 1/700 \approx 0.00143$.
Result · polynomials (PYQ MTS-25 Q1)If $x_n \to c$ then $x_n^k \to c^k$ and $a_kx_n^k + \dots + a_0 \to a_kc^k + \dots + a_0$ (limits of sums and products, P6). By the sequential criterion, every polynomial is continuous on ℝ.
Scratch · $\varphi(x) = 1/x$ at $c>0$ (Bartle 5.1.6(d))

$\left|\frac1x - \frac1c\right| = \dfrac{|x - c|}{xc}$. Keep x away from 0: if $|x - c| < c/2$ then $x > c/2$, so $\frac1{xc} < \frac2{c^2}$. Want $\frac{2}{c^2}|x - c| < \varepsilon$.

ProofGiven ε > 0 put $\delta = \min\left\{\dfrac c2, \dfrac{c^2\varepsilon}{2}\right\}$. If $|x - c| < \delta$ then $\left|\frac1x - \frac1c\right| < \frac{2}{c^2}\cdot\frac{c^2\varepsilon}{2} = \varepsilon$. ∎
(c = ½, ε = 1/10: δ = min{¼, 1/80} = 1/80.)
$|x|$ is continuous everywhere (Bartle Ex 5.1.10)$\big||x| - |c|\big| \le |x - c|$ (reverse triangle inequality, M1). So $\delta = \varepsilon$ works at every c.
Exam trapForgetting the "min": $\delta = \varepsilon/(1+2|c|)$ alone is wrong, because the bound $|x + c| < 1 + 2|c|$ needs $|x - c| < 1$ too.

T5

Where functions break

1/x at 0, signum, jumps, joined pieces (old MCQs; related FYUGP CALC-24 Q3).

Bartle 5.1.6(e), (f)

1/x at 0: 0 is not in the domain, so the question "continuous at 0?" does not arise; and no value at 0 can help, since $x_n = 1/n$ gives $1/x_n = n \to \infty$.

sgn at 0: $x_n = 1/n$ gives $\operatorname{sgn} x_n = 1 \not\to 0 = \operatorname{sgn} 0$. Discontinuous at 0; continuous at every $c \ne 0$ (constant near c: δ = |c|).

{{fig:jump}}
Result · names used in old MCQs (general knowledge)
removablelimit exists but ≠ f(c) (or f(c) undefined): "a hole" jumpleft and right limits exist but differ (sgn at 0) infinitef blows up (1/x near 0)
Joining two pieces (Bartle Ex 5.1.3; CALC-24 Q3)

If f is continuous on [a, b], g on [b, c] and f(b) = g(b), the joined function is continuous on [a, c]. If the values at b differ, it jumps.

Example: $f(x) = x^2$ ($x \le 2$), $x + 10$ ($x>2$): f(2) = 4, left limit 4, right limit 12, a jump of 8. Using $x + 2$ instead makes it continuous.

Check yourself · old MCQ
Which of sin x, sin(1/x), 1/x are continuous functions on $A = \{x \ge 0\}$?
Only sin x: the other two are not even defined at 0 ∈ A.
Exam trap$[\sin x]$ jumps at every $k\pi$ and at every $\pi/2 + 2k\pi$ (where it is suddenly 1).

T6

Dirichlet and Thomae

Two famous functions you cannot draw (PYQ MTS-25 Q16; MTS-22 MCQ 1).

Dirichlet's function (Bartle 5.1.6(g))$f(x) = 1$ if x is rational, $f(x) = 0$ if x is irrational. f is not continuous at any point of ℝ.
{{fig:dirichlet}}
Proof
c rational: the irrationals $x_n = c + \sqrt2/n \to c$, and $f(x_n) = 0 \to 0 \ne 1 = f(c)$.Density of irrationals (P4).
b irrational: choose rationals $y_n \to b$ (e.g. decimal truncations); $f(y_n) = 1 \to 1 \ne 0 = f(b)$.Density of rationals.
By the Discontinuity Criterion f is discontinuous at every point. ∎Theorem 5.1.4.
Thomae's function (Bartle 5.1.6(h))On $A = \{x : x > 0\}$: $h(x) = 0$ if x is irrational; $h(m/n) = 1/n$ if $m, n \in \mathbb N$ have no common factor except 1. h is continuous at every irrational in A and discontinuous at every rational in A.
{{fig:thomae}}
Proof
Rational $a = m/n$: irrationals $x_k \to a$ give $h(x_k) = 0 \to 0 \ne 1/n = h(a)$. Discontinuous.Discontinuity Criterion.
Irrational b, ε > 0: choose $n_0$ with $1/n_0 < \varepsilon$.Archimedes (P4).
In $(b - 1, b + 1)$ only finitely many rationals have denominator $< n_0$.For each denominator q there are finitely many p with $(b-1)q < p < (b+1)q$.
Choose δ > 0 less than the distance from b to each of them.Finitely many positive distances have a smallest one; b itself is not among them.
If $|x - b| < \delta$: x is irrational (h = 0) or has denominator ≥ $n_0$ (h ≤ $1/n_0$). So $|h(x) - h(b)| < \varepsilon$. ∎h(b) = 0.

At $b = \sqrt2/2 \approx 0.7071$ with ε = 0.2: $n_0 = 6$; the nearest rationals with denominator ≤ 5 are 2/3 and 3/4 (distances 0.040, 0.043), so δ = 0.04 works.

T7

Filling holes: x sin(1/x) versus sin(1/x)

When can a missing value be filled in? (Bartle 5.1.7–5.1.8; MAT-22 MCQ 9.)

Result · Remark 5.1.7If f has a limit L at c (c not in the domain), defining F(c) = L gives a function continuous at c. If f has no limit at c, no value at c can make it continuous.
Examples

$\dfrac{x^2 + x - 6}{x - 2} = x + 3$ for $x \ne 2$; the limit at 2 is 5. Define f(2) = 5: continuous (a removable hole).

$F(x) = x\sin(1/x)$, F(0) = 0: $|F(x) - 0| \le |x| < \varepsilon$ when $|x| < \delta = \varepsilon$. Continuous at 0.

$\sin(1/x)$: $x_n = \frac{1}{n\pi}$ gives 0, $y_n = \frac{2}{(4n+1)\pi}$ gives 1. Two limits, so no limit: no continuous extension.
