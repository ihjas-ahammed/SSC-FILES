Which tool?

Mixed drill. Name the tool first, then check its conditions. Answers below.

  1. Show f is continuous at c.
  2. Show f is not continuous at c.
  3. Show an equation has a root in (a, b).
  4. Show f takes the value k somewhere.
  5. Show f is bounded / has a maximum.
  6. Show f is uniformly continuous on [a, b].
  7. Show f is uniformly continuous on an unbounded set.
  8. Show f is not uniformly continuous.
  9. Show f is uniformly continuous on (a, b).
Answers
1. ε–δ with scratch work (T4), or "built from continuous functions". 2. One bad sequence (Discontinuity Criterion, T3). 3. Sign change + Location of Roots (T10). 4. Bolzano (T11) or Corollary 5.3.8. 5. Boundedness / Max–Min, after checking closed, bounded, continuous (T8, T9). 6. Uniform Continuity Theorem (T15). 7. Lipschitz bound (T16), or split the set (T17). 8. Pair of sequences (5.4.2, T14). 9. Continuous extension: does f have limits at a and b? (T20).

Theorem sheet

5.1.1 Continuity at c∀ε > 0 ∃δ > 0: $x \in A$, $|x - c| < \delta$ ⇒ $|f(x) - f(c)| < \varepsilon$.
5.1.3 / 5.1.4 Sequencescontinuous at c ⇔ every $x_n \to c$ gives $f(x_n) \to f(c)$; discontinuous ⇔ some $x_n \to c$ with $f(x_n) \not\to f(c)$.
5.3.2 Boundedness · 5.3.4 Max–Minf continuous on closed bounded [a, b] ⇒ f bounded, and has an absolute max and min.
5.3.5 Location of Roots · 5.3.7 Bolzanof continuous on [a, b], f(a) < 0 < f(b) ⇒ f(c) = 0 for some c ∈ (a, b). f continuous on an interval, f(a) < k < f(b) ⇒ f(c) = k for some c between a and b.
5.3.9 · 5.3.10f([a, b]) = [m, M]; f(interval) is an interval.
5.4.1 Uniform continuity · 5.4.3 UC Theorem∀ε ∃δ(ε): $|x - u| < \delta$ ⇒ $|f(x) - f(u)| < \varepsilon$. Continuous on [a, b] ⇒ uniformly continuous.
5.4.5 · 5.4.7 · 5.4.8Lipschitz ⇒ UC. UC maps Cauchy sequences to Cauchy sequences. UC on (a, b) ⇔ continuously extendable to [a, b].
5.4.10 · 5.4.13 · 5.4.14Continuous f on [a, b] is within ε of a step function, a piecewise linear function, a polynomial.

How to attack a question

3 marksExact definition or statement, or one example with a one-line check. About 4 minutes. 6 marksStatement, then Know/Want, then the skeleton with the δ (or the sequences) filled in. 8–12 lines. 10 marksStatement word for word; numbered proof with the theorem names (Bolzano–Weierstrass, sequential criterion, nested intervals); end with where each hypothesis (closed, bounded, continuous) was used. If stuck, write the skeleton anyway.
Five-minute final checkDid I use every hypothesis? Is my δ free of x? Did "<" become "≤" when I took a limit? Did I say "closed and bounded"?
