1PYQ MTS-22 Q1

Continuity at c; constant function.

Know firstT1P2

Let $A \subseteq \mathbb R$, $f : A \to \mathbb R$, $c \in A$. f is continuous at c if, given any $\varepsilon>0$, there exists $\delta>0$ such that if x is any point of A with $|x - c| < \delta$, then $|f(x) - f(c)| < \varepsilon$.

Let $f(x) = b$ for all x. For any c and any ε > 0, take δ = 1. Then for every x, $|f(x) - f(c)| = |b - b| = 0 < \varepsilon$. So f is continuous at every c, i.e. on ℝ.

Marks: definition 1.5 · proof 1.5.

2

Neighbourhood form; limit form; isolated points.

Know firstT2P9

Neighbourhood form (5.1.2). f is continuous at c iff for every ε-neighbourhood $V_\varepsilon(f(c))$ there is a δ-neighbourhood $V_\delta(c)$ with $f(A \cap V_\delta(c)) \subseteq V_\varepsilon(f(c))$.

Limit form. If c is a cluster point of A, f is continuous at c iff $f(c)$ is defined, $\lim_{x\to c} f(x)$ exists, and they are equal.

Isolated point. If c is not a cluster point, some $V_\delta(c)$ meets A only in {c}; then for $x \in A$ with $|x - c| < \delta$ we have x = c and $|f(x) - f(c)| = 0 < \varepsilon$. (E.g. $A = [0,1] \cup \{2\}$, c = 2, δ = ½.)

Marks: each part 1.

3PYQ MTS-26 Q1

Discontinuity Criterion; [x] at 1.

Know firstT3P6

Discontinuity Criterion (5.1.4). Let $f : A \to \mathbb R$, $c \in A$. f is discontinuous at c iff there is a sequence $(x_n)$ in A with $x_n \to c$ but $(f(x_n))$ not converging to f(c).

Take $x_n = 1 - \frac{1}{n+1} \in [\frac12, 1)$. Then $x_n \to 1$ and $[x_n] = 0$, so $f(x_n) \to 0 \ne 1 = f(1)$. Hence [x] is discontinuous at 1.

Marks: statement 1 · sequence 1 · conclusion 1.

4CALC-24 Q12 · related FYUGP

|x| is continuous everywhere.

Know firstT4M1

By the reverse triangle inequality, $\big||x| - |c|\big| \le |x - c|$ for all x, c. Let $c \in \mathbb R$ and ε > 0; take δ = ε. If $|x - c| < \delta$ then $\big||x| - |c|\big| \le |x - c| < \varepsilon$. So |x| is continuous at c; c was arbitrary.

Marks: inequality 1 · δ 1 · conclusion 1.

5

Continuity on a set; g(x) = x.

Know firstT1

f is continuous on $B \subseteq A$ if f is continuous at every point of B.

For g(x) = x, any c and ε > 0: take δ = ε. If $|x - c| < \delta$ then $|g(x) - g(c)| = |x - c| < \varepsilon$. So g is continuous at every c, i.e. on ℝ.

6CALC-24 Q3 · related FYUGP

$x^2$ ($x \le 2$), $x + 10$ ($x > 2$) at 2.

Know firstT5T3

$f(2) = 4$. Left limit: $\lim_{x\to2^-} x^2 = 4$. Right limit: $\lim_{x\to2^+}(x + 10) = 12$. Since $12 \ne 4$, f is not continuous at 2 (a jump of 8). Sequence form: $x_n = 2 + \frac1n \to 2$ but $f(x_n) = 12 + \frac1n \to 12 \ne 4$.

Replacing $x + 10$ by $x + 2$ (value 4 at 2) makes the two pieces meet, and f becomes continuous.

Marks: limits 1.5 · conclusion 0.5 · fix 1.

$|F(x) - F(0)| = |x\sin(1/x)| \le |x|$. Given ε, take δ = ε: if $|x| < \delta$ then $|F(x) - F(0)| < \varepsilon$. So F is continuous at 0.

9PYQ MTS-26 Q2also MAT-22 MCQ 6

Bounded function; continuous but unbounded.

Know firstT8M3T4

$f : A \to \mathbb R$ is bounded on A if there is $M>0$ with $|f(x)| \le M$ for all $x \in A$.

$f(x) = 1/x$ on $A = (0,\infty)$ is continuous (T4). It is unbounded: for any $M>0$, $x_M = \frac{1}{M+1} \in A$ gives $f(x_M) = M + 1 > M$. (Similarly $\frac{1}{2x}$, the MCQ's function: continuous, not bounded.)

11PYQ MAT-22 MCQ 10 · adapted

Absolute max/min.

Know firstT9P5

f has an absolute maximum on A if some $x^* \in A$ has $f(x^*) \ge f(x)$ for all $x \in A$; an absolute minimum if some $x_* \in A$ has $f(x_*) \le f(x)$ for all $x \in A$.

$1/x$ on $(0,\infty)$: unbounded above, so no maximum; inf = 0 is never reached, so no minimum. $x^2$ on [−1, 1]: maximum 1 at x = ±1, minimum 0 at x = 0.

12PYQ MAT-21 Q17balso MAT-22 MCQ 12, MAT-21 MCQ 7

Roots of $xe^x - 2$ and $6x^3 - 3x^2 + 2$.

Know firstT10

(a) $f(x) = xe^x - 2$ is continuous on [0, 1]; $f(0) = -2 < 0$ and $f(1) = e - 2 \approx 0.718 > 0$. By the Location of Roots Theorem there is $c \in (0,1)$ with $f(c) = 0$ (in fact c ≈ 0.8526).

(b) $q(x) = 6x^3 - 3x^2 + 2$ is continuous; $q(-1) = -7 < 0 < 2 = q(0)$. So q has a zero in $(-1, 0) \subset (-1, 1)$ (≈ −0.5606). MCQ answer: "a zero in (−1, 1)".

13PYQ MAT-21 Q1

Bolzano's IVT; $c^2 = 2$.

Know firstT11

Theorem 5.3.7. Let I be an interval and $f : I \to \mathbb R$ continuous on I. If $a, b \in I$ and $k \in \mathbb R$ satisfies $f(a) < k < f(b)$, then there exists $c \in I$ between a and b with $f(c) = k$.

$f(x) = x^2$ is continuous on [1, 2], and $f(1) = 1 < 2 < 4 = f(2)$. So some $c \in (1,2)$ has $c^2 = 2$.

14PYQ MAT-22 Q1also MAT-21 Q2, MCQs

Uniform continuity; continuous vs UC.

Know firstT13M2

f is uniformly continuous on A if for each $\varepsilon>0$ there is $\delta(\varepsilon)>0$ such that if $x, u \in A$ and $|x - u| < \delta(\varepsilon)$, then $|f(x) - f(u)| < \varepsilon$.

Every uniformly continuous function is continuous (fix u = c: the same δ works at c). Not every continuous function is uniformly continuous: $1/x$ on $(0,\infty)$ is continuous but not UC ($x_n = \frac1n$, $u_n = \frac1{n+1}$ get closer, values stay 1 apart). MCQ answer: "every uniformly continuous function is continuous".

15PYQ MTS-26 Q3also MAT-21 Q28a

Lipschitz function.

Know firstT16

$f : A \to \mathbb R$ is Lipschitz on A if there is a constant $K>0$ with $|f(x) - f(u)| \le K|x - u|$ for all $x, u \in A$. Geometrically (on an interval): every chord of the graph has slope between −K and K.

$|(3x + 1) - (3u + 1)| = 3|x - u|$, so $3x + 1$ is Lipschitz with K = 3.

16PYQ MTS-25 Q2also MAT-22 Q15

UC but not Lipschitz.

Know firstT16T15

$g(x) = \sqrt x$ on I = [0, 2]. It is continuous on a closed bounded interval, so uniformly continuous (Theorem 5.4.3). It is not Lipschitz: given any K > 0 put $x = \frac{1}{(K+1)^2} \in I$. Then $$|g(x) - g(0)| = \frac{1}{K+1} > \frac{K}{(K+1)^2} = K|x - 0|.$$ (E.g. K = 5: $\frac16 \approx 0.167 > \frac{5}{36} \approx 0.139$.)

Marks: example 1 · UC 1 · not Lipschitz 1.

17PYQ MTS-22 MCQ 3 · adapted

f + g Lipschitz; f² need not be.

Know firstT16M1

If $|f(x) - f(u)| \le K_1|x - u|$ and $|g(x) - g(u)| \le K_2|x - u|$, then $|(f+g)(x) - (f+g)(u)| \le (K_1 + K_2)|x - u|$. So f + g is Lipschitz.

$f(x) = x$ on $[0,\infty)$ is Lipschitz (K = 1). But $|x^2 - u^2| = (x + u)|x - u|$; with $x = n + 1$, $u = n$ the ratio is $2n + 1$, unbounded. So $f^2$ is not Lipschitz. (MCQ: the false statement is the one about $f^2$.)

18PYQ MTS-22 MCQ 4 · adapted

$1/(1+x^2)$ is UC on ℝ.

Know firstT16M1

$f(x) - f(u) = \dfrac{(1+u^2) - (1+x^2)}{(1+x^2)(1+u^2)} = \dfrac{(u - x)(u + x)}{(1+x^2)(1+u^2)}$. Since $\frac{|x|}{1+x^2} \le \frac12$ and $\frac{1}{1+u^2} \le 1$ (and the same with x, u swapped), $$\frac{|u + x|}{(1+x^2)(1+u^2)} \le \frac{|x|}{1+x^2} + \frac{|u|}{1+u^2} \le 1.$$ So $|f(x) - f(u)| \le |x - u|$: Lipschitz with K = 1, hence uniformly continuous (δ = ε).

19PYQ MAT-22 Q5also MAT-21 Q3

Step function.

Know firstT21

$s : [a,b] \to \mathbb R$ is a step function if [a, b] is the union of finitely many nonoverlapping intervals $I_1, \dots, I_n$ with s constant on each $I_k$.

The given s: the six intervals [−2, −1), [−1, 0], (0, ½), [½, 1), [1, 3], (3, 4] do not overlap and cover [−2, 4], and s is constant on each. So s is a step function (6 distinct values: 0, 1, ½, 3, −2, 2). $f(x) = x$ on [0, 1] takes infinitely many values, so it is not a step function.

20PYQ MTS-25 Q3also MAT-22 Q2

Weierstrass Approximation Theorem.

Know firstT22T8

Theorem 5.4.14. Let $I = [a,b]$ and $f : I \to \mathbb R$ continuous. If ε > 0 is given, there is a polynomial $p_\varepsilon$ with $|f(x) - p_\varepsilon(x)| < \varepsilon$ for all $x \in I$.

For 1/x on (0, 1]: any polynomial p is bounded on [0, 1], say $|p| \le B$. If $|1/x - p(x)| < 1$ on (0, 1] then $1/x < B + 1$ there, false near 0. The interval (0, 1] is not closed.
