State and prove the Sequential Criterion.

Know firstT3P6M3

Theorem 5.1.3. $f : A \to \mathbb R$ is continuous at $c \in A$ iff for every sequence $(x_n)$ in A converging to c, $(f(x_n))$ converges to f(c).

(⇒) Let $x_n \to c$ in A and ε > 0. Continuity gives δ with $|f(x) - f(c)| < \varepsilon$ for $x \in A$, $|x - c| < \delta$. Since $x_n \to c$ there is K with $|x_n - c| < \delta$ for $n \ge K$. Then $|f(x_n) - f(c)| < \varepsilon$ for $n \ge K$, so $f(x_n) \to f(c)$.

(⇐) Suppose f is not continuous at c. Then there is $\varepsilon_0>0$ such that for every δ > 0 some $x \in A$ has $|x - c| < \delta$ and $|f(x) - f(c)| \ge \varepsilon_0$. Taking δ = 1/n gives $x_n \in A$ with $|x_n - c| < 1/n$ and $|f(x_n) - f(c)| \ge \varepsilon_0$. Then $x_n \to c$ but $f(x_n) \not\to f(c)$, so the sequence condition fails. By contrapositive, the condition implies continuity. ∎

Marks: statement 1 · (⇒) 2 · (⇐) negation and $x_n$ 3.

22PYQ MTS-25 Q1

ε–δ for x²; polynomials continuous.

Know firstT4M1M4T3

Scratch. $|x^2 - c^2| = |x - c||x + c|$, and if $|x - c| < 1$ then $|x + c| \le |x - c| + 2|c| < 1 + 2|c|$.

Proof. Let ε > 0 and $\delta = \min\{1, \frac{\varepsilon}{1 + 2|c|}\}$. If $|x - c| < \delta$ then $|x^2 - c^2| < (1 + 2|c|)\cdot\frac{\varepsilon}{1 + 2|c|} = \varepsilon$. So $x^2$ is continuous at every c. (E.g. c = 3, ε = 0.01: δ = 1/700.)

Polynomials. Let $p(x) = a_kx^k + \dots + a_1x + a_0$ and $x_n \to c$. By the limit theorems for sums and products, $x_n^j \to c^j$ and $p(x_n) \to p(c)$. By the Sequential Criterion, p is continuous at every c. ∎

Marks: scratch 1 · δ and proof 3 · polynomials 2.

1/x continuous on (0, ∞); δ for c = ½, ε = 1/10.

Know firstT4M1

Let c > 0, ε > 0. $\left|\frac1x - \frac1c\right| = \frac{|x - c|}{xc}$. If $|x - c| < c/2$ then $x > c/2$, so $\frac{1}{xc} < \frac{2}{c^2}$. Put $\delta = \min\{\frac c2, \frac{c^2\varepsilon}{2}\}$. If $x > 0$ and $|x - c| < \delta$: $$\left|\frac1x - \frac1c\right| < \frac{2}{c^2}|x - c| < \frac{2}{c^2}\cdot\frac{c^2\varepsilon}{2} = \varepsilon.$$ So 1/x is continuous at every c > 0.

c = ½, ε = 1/10: δ = min{¼, 1/80} = 1/80.

Dirichlet's function is discontinuous everywhere.

Know firstT6T3P4

f(x) = 1 for rational x, 0 for irrational x.

c rational. $x_n = c + \frac{\sqrt2}{n}$ is irrational and $x_n \to c$. So $f(x_n) = 0 \to 0 \ne 1 = f(c)$.

25PYQ MTS-22 MCQ 1 · adapted

Thomae's function.

Know firstT6P4

On $A = \{x > 0\}$: h(x) = 0 for irrational x; $h(m/n) = 1/n$ for $m, n \in \mathbb N$ with no common factor.

Rational a = m/n. Irrationals $x_k \to a$ (density) give $h(x_k) = 0 \to 0 \ne 1/n = h(a)$: discontinuous.

Irrational b. Let ε > 0; by Archimedes pick $n_0$ with $1/n_0 < \varepsilon$. In $(b - 1, b + 1)$ there are only finitely many rationals with denominator less than $n_0$, and b is not one of them. Choose δ > 0 smaller than the distance from b to each (and ≤ 1). If $x \in A$, $|x - b| < \delta$, then x is irrational (h(x) = 0) or a rational with denominator ≥ $n_0$ ($h(x) \le 1/n_0$). So $|h(x) - h(b)| < \varepsilon$: continuous at b. ∎ (MCQ: continuous only at irrationals.)

Theorem 5.3.2. Let I = [a, b] be a closed bounded interval and $f : I \to \mathbb R$ continuous on I. Then f is bounded on I.

27PYQ MAT-22 Q13

inf ≤ k ≤ sup ⇒ k is a value; x³ − 3x, k = 1.

Know firstT11T9

By the Max–Min Theorem there are $c_*, c^* \in I$ with $f(c_*) = \inf f(I)$ and $f(c^*) = \sup f(I)$. If k equals one of these, take c = $c_*$ or $c^*$. Otherwise $f(c_*) < k < f(c^*)$, and Bolzano's theorem on the interval between $c_*$ and $c^*$ gives c with $f(c) = k$. ∎

Illustration. $f(x) = x^3 - 3x$ on [−1.5, 1.5]: inf = −2 (at 1), sup = 2 (at −1), so k = 1 is taken. Indeed $c^3 - 3c = 1$ has the root $c = 2\cos 100° \approx -0.347$ in I.

28PYQ MAT-21 Q15

f([a, b]) is a closed bounded interval.

Know firstT12T9T11

Theorem 5.3.9. If I is a closed bounded interval and $f : I \to \mathbb R$ is continuous, then f(I) is a closed bounded interval.

Proof. Let $m = \inf f(I)$, $M = \sup f(I)$ (they exist: f is bounded by 5.3.2). By Max–Min both are values of f, and every value lies between them: $f(I) \subseteq [m, M]$. By Corollary 5.3.8 every $k \in [m, M]$ is a value: $[m, M] \subseteq f(I)$. So $f(I) = [m, M]$. ∎

Example. $f(x) = x^3 - 3x$ on [−1.5, 1.5]: f(a) = 1.125, f(b) = −1.125, but $f(I) = [-2, 2]$ (max 2 at −1, min −2 at 1), not $[f(b), f(a)] = [-1.125, 1.125]$.

29PYQ MTS-25 Q17also MAT-22 Q14

Preservation of Intervals.

Know firstT12T11P10

Theorem 5.3.10. Let I be an interval and $f : I \to \mathbb R$ continuous on I. Then f(I) is an interval.

Proof. Let $\alpha < \beta$ be in f(I), say $\alpha = f(a)$, $\beta = f(b)$ with $a, b \in I$. If $\alpha < k < \beta$, Bolzano's theorem gives c between a and b (so c ∈ I) with $f(c) = k$, i.e. $k \in f(I)$. Thus $[\alpha, \beta] \subseteq f(I)$ for all $\alpha < \beta$ in f(I), and by the characterisation 2.5.1, f(I) is an interval (a single point if f is constant). ∎

Images. For $f(x) = \frac{1}{x^2+1}$: $f((-1,1)) = (\frac12, 1]$ and $f([0,\infty)) = (0, 1]$. Intervals, but "open" and "closed" are not preserved.

Marks: statement 1 · proof 3 · two images 2.

Nonuniform Continuity Criteria; 1/x.

Know firstT14T16M6

5.4.2. For $f : A \to \mathbb R$ the following are equivalent: (i) f is not uniformly continuous on A; (ii) there is $\varepsilon_0>0$ such that for every δ > 0 there are $x_\delta, u_\delta \in A$ with $|x_\delta - u_\delta| < \delta$ and $|f(x_\delta) - f(u_\delta)| \ge \varepsilon_0$; (iii) there are $\varepsilon_0>0$ and sequences $(x_n), (u_n)$ in A with $\lim(x_n - u_n) = 0$ and $|f(x_n) - f(u_n)| \ge \varepsilon_0$ for all n.

1/x on (0, ∞). $x_n = \frac1n$, $u_n = \frac1{n+1}$: $x_n - u_n = \frac{1}{n(n+1)} \to 0$ and $|f(x_n) - f(u_n)| = |n - (n+1)| = 1$. With $\varepsilon_0 = 1$, (iii) holds: not uniformly continuous.

On [a, 1), a > 0. $\left|\frac1x - \frac1u\right| = \frac{|x - u|}{xu} \le \frac{1}{a^2}|x - u|$: Lipschitz with $K = 1/a^2$, hence uniformly continuous (δ = εa²). (MCQ: uniformly continuous on [a, 1).)

31PYQ MAT-21 Q28b

Lipschitz ⇒ uniformly continuous; sin x.

Know firstT16T13

Theorem 5.4.5. If f is Lipschitz on A with constant K, it is uniformly continuous on A.

Proof. Given ε > 0 let δ = ε/K. If $x, u \in A$ and $|x - u| < \delta$, then $|f(x) - f(u)| \le K|x - u| < K\delta = \varepsilon$. δ depends only on ε (and the fixed K). ∎

sin x. $|\sin x - \sin u| = 2\left|\cos\frac{x+u}{2}\right|\left|\sin\frac{x-u}{2}\right| \le 2\cdot 1\cdot\frac{|x - u|}{2} = |x - u|$ (using $|\sin t| \le |t|$). So K = 1 and δ = ε.

32PYQ MTS-26 Q24balso MAT-22 Q36b

√x is uniformly continuous on [0, ∞).

Know firstT17T15T16

On I = [0, 2] (MAT-22 Q36b): $\sqrt x$ is continuous on a closed bounded interval, so uniformly continuous (5.4.3); call its δ $\delta_I(\varepsilon)$.

On J = [1, ∞): $|\sqrt x - \sqrt u| = \frac{|x - u|}{\sqrt x + \sqrt u} \le \frac12|x - u|$, Lipschitz with $K = \frac12$; $\delta_J = 2\varepsilon$.

Together. Let $\delta = \min\{1, \delta_I(\varepsilon), \delta_J(\varepsilon)\}$. If $x, u \ge 0$ and $|x - u| < \delta$: if both are ≥ 1 they lie in J; otherwise one is < 1 and the other < 2, so both lie in I. Either way $|\sqrt x - \sqrt u| < \varepsilon$. ∎

Direct alternative. $|\sqrt x - \sqrt u| \le \sqrt{|x - u|}$, so δ = ε² works everywhere.

33PYQ MAT-21 Q22

Sum of UC functions is UC; product need not be.

Know firstT18T14

Sum. Given ε, take $\delta = \min\{\delta_f(\varepsilon/2), \delta_g(\varepsilon/2)\}$. If $|x - u| < \delta$: $|(f+g)(x) - (f+g)(u)| \le |f(x) - f(u)| + |g(x) - g(u)| < \frac\varepsilon2 + \frac\varepsilon2 = \varepsilon$.

Product. $f(x) = g(x) = x$ are uniformly continuous on ℝ (δ = ε). Their product $x^2$ is not: $x_n = n$, $u_n = n + \frac1n$ give $x_n - u_n \to 0$ but $|x_n^2 - u_n^2| = 2 + \frac{1}{n^2} \ge 2$ (5.4.2 with $\varepsilon_0 = 2$).

UC maps Cauchy sequences to Cauchy sequences.

Know firstT19P8

Theorem 5.4.7. Let $(x_n)$ be Cauchy in A and ε > 0. By uniform continuity choose δ with $|f(x) - f(u)| < \varepsilon$ whenever $x, u \in A$, $|x - u| < \delta$. Step-function approximation; f(x) = x, ε = 0.1.

Know firstT21T15

Theorem 5.4.10. f is uniformly continuous on [a, b] (5.4.3); let δ = δ(ε). Choose m ∈ ℕ with $h = \frac{b-a}{m} < \delta$. Let $I_1 = [a, a + h]$, $I_k = (a + (k-1)h, a + kh]$ for k = 2, …, m. Define $s_\varepsilon(x) = f(a + kh)$ for $x \in I_k$. This is a step function, and for $x \in I_k$, $|x - (a + kh)| \le h < \delta$, so $|f(x) - s_\varepsilon(x)| < \varepsilon$. ∎

Piecewise linear approximation; x² with four pieces.

Know firstT21T15

Definition. $g : [a,b] \to \mathbb R$ is piecewise linear if [a, b] is a union of finitely many disjoint intervals on each of which g is linear.

Proof. Choose δ from uniform continuity and nodes $x_k = a + kh$ with $h < \delta$. Let $g_\varepsilon$ be the chord through $(x_{k-1}, f(x_{k-1}))$ and $(x_k, f(x_k))$ on each $[x_{k-1}, x_k]$; it is continuous since neighbouring chords meet at the nodes. For $x = (1-\lambda)x_{k-1} + \lambda x_k$ ($0 \le \lambda \le 1$), $$f(x) - g_\varepsilon(x) = (1-\lambda)[f(x) - f(x_{k-1})] + \lambda[f(x) - f(x_k)],$$ and both brackets are less than ε in size, so $|f(x) - g_\varepsilon(x)| < \varepsilon$. ∎

Example. On a piece $[p, p + h]$ the chord of $x^2$ minus $x^2$ is $(x - p)(p + h - x)$, largest at the midpoint: $h^2/4$. With h = ¼:

largest error $= \frac{1}{64} \approx 0.0156$.
