One idea for the whole module
THE Ε-TUBE

A sequence of functions is a film: f1, f2, f3, …
are frames, each a whole graph.
Pointwise: stand at one x and watch the
height fn(x) settle down. Every x settles, but
some may take much longer than others.
Uniform: draw a thin tube round the final
graph f. From some frame on, the whole
graph of fn lies inside the tube, however thin
the tube.
Every question in this module asks: which of
these two happens, and what does it buy us?

Supremum (least upper bound)

The uniform norm is a supremum, so we need this
exactly.
REMIND ME · BARTLE 2.3

u = sup S means: u is an upper bound of S
(s ≤ u for all s ∈ S ), and no smaller number

is an upper bound.
So: sup S ≤ c ⇔ every s ∈ S has s ≤ c.
A sup need not be attained: sup{xn : 0 ≤
x < 1} = 1, but no x in [0, 1) gives xn = 1.
EXAM TRAP

"xn < 1 for every x < 1, so the sup is less than
1." Wrong. Each value is below 1, but they
come as close to 1 as we like, so the sup is
exactly 1.
CHECK YOURSELF

Find sup{x/(x + 5) : x ≥ 0}. Is it attained?
x/(x + 5) = 1 − 5/(x + 5) increases towards 1 as
x → ∞. Sup = 1, never attained.

THE IDEA

Stand at one point x. Watch the heights

DEFINITION 8.1.1 · SAY IT WORD FOR WORD

Let (fn ) be a sequence of functions on A ⊆ R
to R, let A0 ⊆ A, and let f : A0 → R. We say
that the sequence (fn ) converges on A0 to f
if, for each x ∈ A0 , the sequence (fn (x))
converges to f (x) in ℝ. Then f is called the
limit on A0 of (fn ), and (fn ) is said to
converge pointwise on A0 .
