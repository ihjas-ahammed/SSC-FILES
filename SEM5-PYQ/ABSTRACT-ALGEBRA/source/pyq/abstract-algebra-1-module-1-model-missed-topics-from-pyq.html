Key steps for checking your work

Section A. 1. No. The sum of two odd integers is even, so $H$ is not closed under addition. 2. Condition 1: $a/b$ is undefined when $b = 0$, so $\ast$ is not everywhere defined. 3. No. If $e$ and $e'$ are identities then $e = e \ast e' = e'$ (Theorem 1.15). 4. $\begin{array}{c|cc} \ast & e & a \\ \hline e & e & a \\ a & a & e \end{array}$ 5. No. $1$ is an identity ($\max\{a, 1\} = a$), but $2$ has no inverse, since $\max\{2, x\} = 1$ is impossible. 6. Exactly once: for fixed $a$, the equation $a \ast x = b$ has exactly one solution for each $b$ (Theorem 2.17). 7. True. This is the one-sided form of the identity axiom; it follows from the other one-sided axioms. 8. True. The left inverse is also a right inverse, by the one-sided argument in Section 2.

Section B. 9. Let $a'$ and $a''$ be inverses of $a$. Then $a' = a' \ast e = a' \ast (a \ast a'') = (a' \ast a) \ast a'' = e \ast a'' = a''$. 10. $\langle \mathbb{Z}^+, \max \rangle$ has identity $1$, but $2$ has no inverse. Each element needs an inverse, so it is not a group. 11. If $a \ast x = a \ast y$ with $x \neq y$, then left cancellation (Theorem 2.16) gives $x = y$. So no element can repeat in a row. 12. (1) $f$ is one-to-one and onto $G_2$. (2) $f(a \ast_1 b) = f(a) \ast_2 f(b)$ for all $a, b \in G_1$. 13. Bijective: its inverse is $\exp$. Homomorphism: $\ln(xy) = \ln x + \ln y$.

Section C. 14. Composition: $f_{a,b}(f_{c,d}(x)) = a(cx + d) + b = (ac)x + (ad + b)$, with $ac \neq 0$. Inverse: $f_{a,b}^{-1} = f_{1/a,\,-b/a}$. Identity: $f_{1,0}$. Associativity: Theorem 1.13. 15. Row $e$ and column $e$ are forced by the identity. Then $a \ast a \in \{b, e\}$; $a \ast a = e$ leads to a repeated $b$ in row $b$, so $a \ast a = b$, and the rest follows. The completed table is the group of order 3. 16. Injective: $a \ast x = a \ast y$ implies $x = y$ (cancellation). Onto: $x = a' \ast b$ solves $a \ast x = b$ (Theorem 2.17). So $b$ occurs once in the row of $a$.

Section D. 17. Klein group: $a \ast a = b \ast b = c \ast c = e$, with $a \ast b = c$. Cyclic group $\mathbb{Z}_4$ (with $e = 0$, $a = 1$, $b = 2$, $c = 3$): $a \ast a = b$. An isomorphism preserves $x \ast x = e$, so the two cannot be isomorphic. 18. Let $u = a \ast a'$. Then $u \ast u = a \ast (a' \ast a) \ast a' = a \ast a' = u$. If $v \ast u = e$, then $u = e \ast u = (v \ast u) \ast u = v \ast (u \ast u) = v \ast u = e$. So $a \ast a' = e$, and $a \ast e = a \ast (a' \ast a) = (a \ast a') \ast a = a$. Hence $e$ is an identity and $a'$ is an inverse.
