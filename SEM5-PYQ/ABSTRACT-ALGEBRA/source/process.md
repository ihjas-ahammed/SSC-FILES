# process.md: the source folder (overview)

This folder holds everything the notes and papers for Abstract Algebra I are built from. Use this file to find the right process for a task. Each process file below says how to do its task in detail.

## What is here
| Path | What it holds | Which process applies |
|---|---|---|
| `books/` | Book excerpts (none yet) | `books/process.md` (PDF to HTML excerpts) |
| `books/prepare/` | One folder per module with its notes, pre files and PDFs (none yet) | `books/prepare/process.md` (overview), then the module's own process file |
| `pyq/` | Past papers and model papers (none yet) | `pyq/process.md` (exam papers) |

## Which process to use
1. **Converting a book page range to HTML** (sheets, transcription, checks): `books/process.md`.
2. **Writing notes for a module** (book sources, study and structured bodies, combined PDFs): `books/prepare/process.md`. The module's own process file is created with the first module.
3. **Making a PYQ or a model question paper**: `pyq/process.md`.
4. **Anything about the whole folder structure, rules, or module status**: `../CLAUDE.md`.

## Rules that apply everywhere in `source/`
- Put working files in the session scratchpad, not here.
- Do not delete a source PDF or an excerpt unless the user asks.
- Nothing is mailed before its checks have run.
- A file that is superseded is kept, listed in its module's `process.md`, and deleted only when the user asks.
