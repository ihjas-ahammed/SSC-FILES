1. The group of permutations

Theorem 4.8 Let $A$ be a nonempty set and $S_A$ the set of all permutations of $A$. Then $S_A$ is a group under permutation multiplication.

Proof. Composition of permutations is a permutation, so $S_A$ is closed. Composition is associative, so $\mathcal{G}_1$ holds. The identity map $\iota$ satisfies $\mathcal{G}_2$. A permutation $\sigma$ is one-to-one and onto, so it has an inverse function $\sigma^{-1}$, a permutation with $\sigma^{-1}\sigma = \sigma\sigma^{-1} = \iota$; this gives $\mathcal{G}_3$. ◆

Warning. Some texts multiply permutations left to right, so that $(\sigma\mu)(a) = \mu(\sigma(a))$. Exercise 34 asks the reader to check that both conventions give a group. The text of Exercise 34 follows.

Exercise 34. (See the warning following Theorem 4.8.) Let $G$ be a group with binary operation $\ast$. Let $G'$ be the same set as $G$, and define a binary operation $\ast'$ on $G'$ by $x \ast' y = y \ast x$ for all $x, y \in G'$. (a) Intuitive argument that $G'$ under $\ast'$ is a group: suppose the front wall of your classroom were made of transparent glass, and that all possible products $a \ast b = c$ and all possible instances $a \ast (b \ast c) = (a \ast b) \ast c$ of the associative property for $G$ under $\ast$ were written on the wall with a magic marker. What would a person see when looking at the other side of the wall from the next room in front of yours? (b) Show from the mathematical definition of $\ast'$ that $G'$ is a group under $\ast'$.

If $|A| = |B|$, then $S_A \simeq S_B$. A one-to-one map $f : A \to B$ onto gives the isomorphism $\phi(\sigma) = \bar\sigma$, where $\bar\sigma(f(a)) = f(\sigma(a))$. So the structure of $S_A$ depends only on $|A|$, and $\{1, \dots, n\}$ is a prototype for any set of $n$ elements. The book’s example: $A = \{1, 2, 3\}$, $B = \{\#, \$, \%\}$, $f(1) = \#$, $f(2) = \$$, $f(3) = \%$ sends $\begin{pmatrix}1&2&3\\3&2&1\end{pmatrix}$ to $\begin{pmatrix}\#&\$&\%\\\%&\$&\#\end{pmatrix}$.

Definition 4.9 For $A = \{1, \dots, n\}$, the group of all permutations of $A$ is the symmetric group on $n$ letters, $S_n$. It has $n!$ elements.

Remark (not numbered). $S_3$ is not abelian: with $\sigma = \begin{pmatrix}1&2&3\\2&1&3\end{pmatrix}$ and $\tau = \begin{pmatrix}1&2&3\\1&3&2\end{pmatrix}$, $\sigma\tau(1) = 2 \ne 3 = \tau\sigma(1)$. Since every group of order at most $4$ is abelian and $\mathbb{Z}_5$ is the only group of order $5$, $S_3$ is the smallest nonabelian group.

Plus Two recall: inverse functions (status OPEN, check against the Kerala text)

Recall. A function is one-to-one and onto exactly when it has an inverse function. The inverse reverses each arrow: if $\sigma(a) = b$ then $\sigma^{-1}(b) = a$.

Re-derive.

  1. For $\sigma = \begin{pmatrix}1&2&3\\3&2&1\end{pmatrix}$: $\sigma(1) = 3$, so $\sigma^{-1}(3) = 1$; reading the columns backward gives $\sigma^{-1} = \begin{pmatrix}1&2&3\\3&2&1\end{pmatrix}$.
  2. Composing: $\sigma^{-1}(\sigma(a)) = a$ for every $a$.

Saved. Example 4.10 (inverting a permutation by swapping the rows).

Example 4.10. The inverse of $\sigma = \begin{pmatrix}1&2&3&4&5&6\\3&2&6&1&4&5\end{pmatrix}$ is $\sigma^{-1} = \begin{pmatrix}1&2&3&4&5&6\\4&2&1&5&6&3\end{pmatrix}$, obtained by interchanging the rows and sorting the columns.

2. Disjoint cycles

For $\sigma = \begin{pmatrix}1&2&3&4&5&6\\3&4&6&2&5&1\end{pmatrix}$ we write $(1, 3, 6)(2, 4)$: the cycle $(1, 3, 6)$ is a $3$-cycle, and $(2, 4)$ is a $2$-cycle. Entries that are fixed are omitted. A $2$-cycle is a transposition. Cycles are disjoint if no entry lies in two of them. Every permutation of $S_n$ has a disjoint cycle form, unique up to order and cyclic rotation.

Example 4.11. $(1, 5, 2, 7)(3, 4, 9) = \begin{pmatrix}1&2&3&4&5&6&7&8&9\\5&7&4&9&2&6&1&8&3\end{pmatrix}$.

The operation is composition, so the rightmost cycle acts first.

Example 4.12. In $S_6$, $(1, 5, 3, 2, 6)(1, 2, 4, 3, 6) = (1, 6, 5, 3)(2, 4)$.

Example 4.13. $(1, 5)(2, 4)(1, 4, 3)(2, 5)(4, 2, 1) = (1, 3, 5, 4)$. The calculation does not use the value of $n$ and holds in $S_n$ for every $n \ge 5$.

Example 4.14. $(1, 5, 7)(3, 8, 2, 4, 6)$ has inverse $(6, 4, 2, 8, 3)(7, 5, 1)$, since $(ab)^{-1} = b^{-1}a^{-1}$ and the inverse of a cycle is the cycle backward; this also equals $(1, 7, 5)(2, 8, 3, 6, 4)$.

1. Parity of permutations

Theorem 8.19 No permutation in $S_n$ is both a product of an even number and a product of an odd number of transpositions.

Proof. Let $\sigma \in S_n$ and $\tau = (i, j)$. Claim: the number of orbits of $\tau\sigma$ and of $\sigma$ differ by $1$.

Case I ($i$, $j$ in different orbits of $\sigma$). Write $\sigma$ with cycles $(b, j, \times, \times, \times)(a, i, \times, \times)$ (Figure 8.20). Then $(i, j)(b, j, \times, \times, \times)(a, i, \times, \times) = (a, j, \times, \times, \times, b, i, \times, \times)$. Two orbits are joined into one.

Exercise 42. (named in Case I, Theorem 8.19) a. Draw a figure like Fig. 8.20 to illustrate that if $i$ and $j$ are in different orbits of $\sigma$ and $\sigma(i) = i$, then the number of orbits of $(i, j)\sigma$ is one less than the number of orbits of $\sigma$.
b. Repeat part (a) if $\sigma(j) = j$ also.

Case II ($i$, $j$ in the same orbit). Write $\sigma$ with first cycle $(a, i, \times, \times, \times, b, j, \times, \times)$ (Figure 8.21). Then $(i, j)(a, i, \times, \times, \times, b, j, \times, \times) = (a, j, \times, \times, \times)(b, i, \times, \times, \times)$. One orbit is split into two.

In both cases the orbit count changes by $1$. The identity has $n$ orbits, so the number of orbits of $\sigma$ differs from $n$ by an even number or by an odd number, not both. Hence $\sigma$ cannot be written with an even number of transpositions and also with an odd number. ◆

Figures 8.20 and 8.21 show the two cases as circles joined by a pinched middle (8.20) and as one loop split into two (8.21), with the points labelled $i, j, a, b$. Labels as printed; not redrawn.

Definition 8.22 A permutation of a finite set is even (respectively odd) if it is a product of an even (respectively odd) number of transpositions.

Example 8.23. $\iota = (1, 2)(1, 2)$ is even (and is defined to be even for $n = 1$). $(1, 4, 5, 6)(2, 1, 5) = (1, 6)(1, 5)(1, 4)(2, 5)(2, 1)$ has five transpositions, so it is odd.

2. The alternating groups

For $n \ge 2$ the sets $A_n$ (even) and $B_n$ (odd) have equal size. With $\tau = (1, 2)$, the map $\lambda_\tau(\sigma) = \tau\sigma$ takes $A_n$ into $B_n$, is one-to-one by cancellation, and is onto since $\lambda_\tau(\tau^{-1}\rho) = \rho$ for $\rho \in B_n$.

The product of two even permutations is even, $\iota$ is even, and $\sigma^{-1}$ is even when $\sigma$ is (reverse the transpositions). So the even permutations form a subgroup.

Theorem 8.24 If $n \ge 2$, the even permutations of $\{1, \dots, n\}$ form a subgroup of $S_n$ of order $n!/2$.

Sign. The book uses $\operatorname{sgn}$ in the standard definition of the determinant and asks for the facts below (Exercise 52, printed next). $\operatorname{sgn} : S_n \to \{1, -1\}$, $\operatorname{sgn}(\sigma) = 1$ if $\sigma$ is even and $-1$ if odd, is a homomorphism; $\operatorname{Ker}(\operatorname{sgn})$ is the set of even permutations. It defines the determinant.

Exercise 52. (named after Theorem 8.24, in the sign paragraph) The usual definition for the determinant of an $n \times n$ matrix $A = (a_{ij})$ is

$$\det(A) = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma)\, a_{1,\sigma(1)}a_{2,\sigma(2)}a_{3,\sigma(3)}\cdots a_{n,\sigma(n)},$$

where $\operatorname{sgn}(\sigma)$ is the sign of $\sigma$. Using this definition, prove the following properties of determinants.
a. If a row of matrix $A$ has all zero entries, then $\det(A) = 0$.
b. If two different rows of $A$ are switched to obtain $B$, then $\det(B) = -\det(A)$.
c. If $r$ times one row of $A$ is added to another row of $A$ to obtain a matrix $B$, then $\det(A) = \det(B)$.
d. If a row of $A$ is multiplied by $r$ to obtain the matrix $B$, then $\det(B) = r\det(A)$.

Definition 8.25 The subgroup of $S_n$ of even permutations of $n$ letters is the alternating group $A_n$ on $n$ letters.

Cayley’s theorem shows that every finite group of order $n$ is a subgroup of $S_n$ up to isomorphism. The absence of radical formulas for polynomial equations of degree $n \ge 5$ is due to the structure of $A_n$.

Printed pp. 97–104 (10.1–10.20; Tables 10.14, 10.15; Example 10.16)

1. Cosets

Theorem 10.1 Let $H \le G$ and define $a \sim_L b$ if and only if $a^{-1}b \in H$. Then $\sim_L$ is an equivalence relation on $G$.

Proof. Reflexive: $a^{-1}a = e \in H$. Symmetric: $(a^{-1}b)^{-1} = b^{-1}a \in H$. Transitive: $(a^{-1}b)(b^{-1}c) = a^{-1}c \in H$. ◆

The class of $a$ is $\{x \mid a^{-1}x \in H\} = \{ah \mid h \in H\}$.

Definition 10.2 For $H \le G$ and $a \in G$, $aH = \{ah \mid h \in H\}$ is the left coset of $H$ containing $a$.

Example 10.3. The left cosets of $3\mathbb{Z}$ in $\mathbb{Z}$ are $3\mathbb{Z}$, $1 + 3\mathbb{Z}$ and $2 + 3\mathbb{Z}$.

Example 10.4. The left cosets of $\langle 3 \rangle$ in $\mathbb{Z}_{12}$ are $\{0, 3, 6, 9\}$, $\{1, 4, 7, 10\}$, $\{2, 5, 8, 11\}$.

Example 10.5. The left cosets of $\langle \mu \rangle = \{\iota, \mu\}$ in $D_4$: $\{\iota, \mu\}$, $\{\rho, \mu\rho^3\}$, $\{\rho^2, \mu\rho^2\}$, $\{\rho^3, \mu\rho\}$.

2. The theorem of Lagrange

Theorem 10.6 For $H \le G$ and $a \in G$, $aH$ has the same cardinality as $H$.

Proof. $f(h) = ah$ is one-to-one by left cancellation, and onto $aH$ by definition. ◆

Theorem 10.7 (Theorem of Lagrange) If $H \le G$ and $G$ is finite, then $|H|$ divides $|G|$.

Proof. Each coset has $|H|$ elements and the cosets partition $G$; if there are $r$ of them, $|G| = r|H|$. ◆

Corollary 10.8 Every group of prime order is cyclic.

Proof. A generator $a \ne e$ gives $|\langle a \rangle|$ dividing the prime $p$ and at least $2$; so $\langle a \rangle = G$. ◆

There is therefore one group of each prime order, up to isomorphism.

Theorem 10.9 The order of an element of a finite group divides the order of the group.

Proof. The order of $a$ is $|\langle a \rangle|$; apply Theorem 10.7. ◆

Definition 10.10 The number of left cosets of $H$ in $G$ is the index $(G : H)$.

If $G$ is finite, $(G : H) = |G|/|H|$. The proof of Theorem 10.11 is left to the exercises, which the text names as Exercise 40, printed next.

The converse of Lagrange’s theorem is false in general; Section 13 of the book gives the example. For abelian groups the answer is in Section 9.

Right cosets

With $a \sim_R b$ if and only if $ab^{-1} \in H$, the classes are the right cosets $Ha = \{ha \mid h \in H\}$. Each has the cardinality of $H$. In abelian groups left and right cosets coincide; in general they need not.

Example 10.12. The right cosets of $\{\iota, \mu\}$ in $D_4$ are $\{\iota, \mu\}$, $\{\rho, \mu\rho\}$, $\{\rho^2, \mu\rho^2\}$, $\{\rho^3, \mu\rho^3\}$. Since $\rho H = \{\rho, \mu\rho^3\} \ne \{\rho, \mu\rho\} = H\rho$, they differ from the left cosets.

Example 10.13. In $\mathbb{Z}_6$ with $H = \{0, 3\}$ the cosets are $\{0, 3\}$, $\{1, 4\}$, $\{2, 5\}$.

3. Kernels and cosets

Theorem 10.17 For a homomorphism $\phi : G \to G'$, the left and right cosets of $\operatorname{Ker}(\phi)$ are identical; and $a, b$ lie in the same coset of $\operatorname{Ker}(\phi)$ if and only if $\phi(a) = \phi(b)$.

Proof. If $a^{-1}b \in \operatorname{Ker}(\phi)$ then $\phi(a) = \phi(b)$, and $\phi(ab^{-1}) = e$, so $ab^{-1} \in \operatorname{Ker}(\phi)$. If $\phi(a) = \phi(b)$ then $b^{-1}a \in \operatorname{Ker}(\phi)$. The right-coset case is left to the reader. ◆

Example 10.18. For $\det : GL(2, \mathbb{R}) \to \mathbb{R}^*$, two matrices lie in the same coset of the kernel if and only if they have the same determinant. Both $\begin{bmatrix}2&0\\0&1\end{bmatrix}$ and $\begin{bmatrix}3&2\\2&2\end{bmatrix}$ have determinant $2$.

Corollary 10.19 A homomorphism $\phi : G \to G'$ is one-to-one if and only if $\operatorname{Ker}(\phi)$ is trivial.

Proof. Apply Theorem 10.17. ◆

Example 10.20. $\phi : \mathbb{R} \to \mathbb{R}^+$, $\phi(x) = 2^x$, is one-to-one, since $2^x = 1$ only for $x = 0$.
