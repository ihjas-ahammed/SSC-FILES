1. Cosets

Let $H$ be a subgroup of $G$, finite or infinite. We split $G$ into pieces of equal size by an equivalence relation.

Theorem 10.1 Let $H \le G$. Define $a \sim_L b$ if and only if $a^{-1}b \in H$. Then $\sim_L$ is an equivalence relation on $G$.

Proof. Reflexive. $a^{-1}a = e \in H$, so $a \sim_L a$. Symmetric. If $a^{-1}b \in H$, then $(a^{-1}b)^{-1} = b^{-1}a \in H$, so $b \sim_L a$. Transitive. If $a^{-1}b \in H$ and $b^{-1}c \in H$, then $(a^{-1}b)(b^{-1}c) = a^{-1}c \in H$, so $a \sim_L c$. ◆

The cells of this partition are easy to describe. The cell containing $a$ is all $x$ with $a^{-1}x \in H$, that is all $x = ah$ with $h \in H$. This cell is written $aH$.

Definition 10.2 For $H \le G$ and $a \in G$, the subset $aH = \{ah \mid h \in H\}$ is the left coset of $H$ containing $a$.

Example 10.3. The left cosets of $3\mathbb{Z}$ in $\mathbb{Z}$ are $3\mathbb{Z}$ itself, $1 + 3\mathbb{Z} = \{\dots, -8, -5, -2, 1, 4, 7, 10, \dots\}$, and $2 + 3\mathbb{Z} = \{\dots, -7, -4, -1, 2, 5, 8, 11, \dots\}$. These three exhaust $\mathbb{Z}$.

Example 10.4. In $\mathbb{Z}_{12}$ with $H = \langle 3 \rangle$: $0 + H = \{0, 3, 6, 9\}$, $1 + H = \{1, 4, 7, 10\}$, $2 + H = \{2, 5, 8, 11\}$. These are all the left cosets.

Example 10.5. In the nonabelian group $D_4 = \{\iota, \rho, \rho^2, \rho^3, \mu, \mu\rho, \mu\rho^2, \mu\rho^3\}$, the left cosets of $H = \langle \mu \rangle = \{\iota, \mu\}$ are

$$\iota\{\iota, \mu\} = \{\iota, \mu\},\quad \rho\{\iota, \mu\} = \{\rho, \mu\rho^3\},\quad \rho^2\{\iota, \mu\} = \{\rho^2, \mu\rho^2\},\quad \rho^3\{\iota, \mu\} = \{\rho^3, \mu\rho\}.$$

Every element of $D_4$ appears in exactly one of these sets, so the list is complete.

2. The theorem of Lagrange

In Example 10.4 each coset of $\langle 3 \rangle$ has four elements; in Example 10.5 each has two. Theorem 10.6 says this always happens.

Theorem 10.6 Let $H \le G$. For any $a \in G$, the coset $aH$ has the same cardinality as $H$.

Proof. Define $f : H \to aH$ by $f(h) = ah$. If $f(b) = f(c)$, then $ab = ac$ and left cancellation gives $b = c$, so $f$ is one-to-one. Every element of $aH$ has the form $ah = f(h)$, so $f$ is onto. ◆

For a finite subgroup $H$ this says each coset has $|H|$ elements, which is what is needed for Lagrange’s theorem.

Theorem 10.7 (Theorem of Lagrange) Let $H$ be a subgroup of a finite group $G$. Then the order of $H$ divides the order of $G$.

Proof. Let $|G| = n$ and $|H| = m$. Each coset of $H$ has $m$ elements, and the cosets partition $G$. If there are $r$ cosets, then $n = rm$. ◆

Theorem 10.7 is a counting theorem: it follows from counting cosets and the number of elements in each.

Corollary 10.8 Every group of prime order is cyclic.

Proof. Let $|G| = p$ and $a \ne e$. Then $\langle a \rangle$ has at least two elements, and its order divides $p$ by Theorem 10.7. So $|\langle a \rangle| = p$ and $\langle a \rangle = G$. ◆

So up to isomorphism there is only one group of each prime order.

Theorem 10.9 The order of an element of a finite group divides the order of the group.

Proof. The order of an element is the order of the cyclic subgroup it generates. Apply Theorem 10.7. ◆

Definition 10.10 The number of left cosets of $H$ in $G$ is the index $(G : H)$.

The index may be finite or infinite. If $G$ is finite, $(G : H) = |G|/|H|$. The next theorem is about indices. The book leaves its proof to the exercises; Exercise 40 is printed directly below.

Exercise 40. Prove Theorem 10.11 [Hint: Let $\{a_iH \mid i = 1, \dots, r\}$ be the collection of distinct left cosets of $H$ in $G$ and $\{b_jK \mid j = 1, \dots, s\}$ be the collection of distinct left cosets of $K$ in $H$. Show that $\{(a_ib_j)K \mid i = 1, \dots, r;\ j = 1, \dots, s\}$ is the collection of distinct left cosets of $K$ in $G$.]

Theorem 10.11 Suppose $K \le H \le G$, and $(H : K)$ and $(G : H)$ are both finite. Then $(G : K)$ is finite and $(G : K) = (G : H)(H : K)$.

Lagrange’s theorem says the order of a subgroup of a finite group divides the group order. The converse is false in general: a group need not have a subgroup of every order that divides its order. Section 13 of the book shows this, and the complete answer for abelian groups is in Section 9.

Right cosets

Everything above works with right cosets. Let $\sim_R$ be defined by $a \sim_R b$ if and only if $ab^{-1} \in H$. Its classes are the right cosets $Ha = \{ha \mid h \in H\}$. Each right coset has the same cardinality as $H$, so left and right cosets have the same size. In an abelian group they coincide. In general they need not coincide.

Example 10.12. For $H = \{\iota, \mu\}$ in $D_4$ the right cosets are $\{\iota, \mu\}\iota = \{\iota, \mu\}$, $\{\iota, \mu\}\rho = \{\rho, \mu\rho\}$, $\{\iota, \mu\}\rho^2 = \{\rho^2, \mu\rho^2\}$, and $\{\iota, \mu\}\rho^3 = \{\rho^3, \mu\rho^3\}$. These differ from the left cosets: $\rho H = \{\rho, \mu\rho^3\}$ while $H\rho = \{\rho, \mu\rho\}$.

Left and right cosets are not the same here. The book points out that when they are the same, a curious thing happens, which is illustrated next.

Example 10.13. $\mathbb{Z}_6$ is abelian. The cosets of $H = \{0, 3\}$ are $\{0, 3\}$, $1 + \{0, 3\} = \{1, 4\}$, and $2 + \{0, 3\} = \{2, 5\}$. They exhaust $\mathbb{Z}_6$.

3. Kernels and cosets

If $G$ is abelian, left and right cosets coincide. The next theorem gives another case.

Theorem 10.17 Let $\phi : G \to G'$ be a homomorphism. The left and right cosets of $\operatorname{Ker}(\phi)$ are identical. Moreover $a, b \in G$ lie in the same coset of $\operatorname{Ker}(\phi)$ if and only if $\phi(a) = \phi(b)$.

Proof. Suppose $a$ and $b$ lie in the same left coset, so $a^{-1}b \in \operatorname{Ker}(\phi)$. Then $\phi(a)^{-1}\phi(b) = e$, so $\phi(a) = \phi(b)$. Hence $\phi(ab^{-1}) = \phi(a)\phi(b)^{-1} = e$, so $ab^{-1} \in \operatorname{Ker}(\phi)$ and $a, b$ lie in the same right coset. Conversely, if $\phi(a) = \phi(b)$ then $\phi(b^{-1}a) = e$, so $a, b$ lie in the same left coset. The argument for right cosets is the same, and is left to the reader. ◆

Example 10.18. The determinant $\det : GL(2, \mathbb{R}) \to \mathbb{R}^*$ is a homomorphism. Two matrices lie in the same left coset of its kernel if and only if they lie in the same right coset, which happens if and only if they have the same determinant. For example $\begin{bmatrix}2&0\\0&1\end{bmatrix}$ and $\begin{bmatrix}3&2\\2&2\end{bmatrix}$ both have determinant $2$.

Corollary 10.19 A homomorphism $\phi : G \to G'$ is one-to-one if and only if $\operatorname{Ker}(\phi)$ is the trivial subgroup of $G$.

Proof. If $\operatorname{Ker}(\phi) = \{e\}$, each coset has one element, and $\phi(a) = \phi(b)$ puts $a, b$ in one coset by Theorem 10.17, so $a = b$. Conversely, if $\phi$ is one-to-one, only $e$ maps to $e'$, so $\operatorname{Ker}(\phi) = \{e\}$. ◆

To test whether $\phi$ is one-to-one, it is enough to show that $\phi(x) = e'$ has only the solution $x = e$.

Example 10.20. $\phi : \mathbb{R} \to \mathbb{R}^+$, $\phi(x) = 2^x$, is a homomorphism. The equation $2^x = 1$ has only the solution $x = 0$, since $2^x > 1$ for $x > 0$ and $2^x < 1$ for $x < 0$. So $\phi$ is one-to-one.
