# process.md: the source folder (overview)

This folder holds everything the notes and papers for Convex Optimization are built from. Use this file to find the right process for a task.

## What is here
| Path | What it holds | Which process applies |
|---|---|---|
| `syllabus.html` | Syllabus transcription (MAT5EJ303 (2)) | none; check against `../CLAUDE.md` |
| `books/` | Book excerpts (none yet) | `books/process.md` (PDF to HTML excerpts, Codex method) |
| `books/prepare/` | One folder per module (`module-1` to `module-4`, book-sources only so far) | `books/prepare/process.md` (overview), then the module's own process file |
| `pyq/` | One transcribed paper (LP pool, Nov 2025) and the layout and build code | `pyq/process.md` (exam papers) |

## Which process to use
1. **Converting a book page range to HTML** (sheets, transcription, checks): `books/process.md`.
2. **Writing notes for a module**: `books/prepare/process.md`, then the module's own `module-N/process.md` (created with the first module).
3. **Making a PYQ or a model question paper**: `pyq/process.md`.
4. **Anything about the whole folder structure, rules, or module status**: `../CLAUDE.md`.

## Rules that apply everywhere in `source/`
- Put working files in the session scratchpad, not here.
- Do not delete a source PDF or an excerpt unless the user asks.
- Nothing is mailed before its checks have run.
- A file that is superseded is kept, listed in its module's `process.md`, and deleted only when the user asks.
- Copies of past papers for checking are made in the scratchpad, one subfolder per paper, and checked byte-for-byte against the original.
