അപ്പപോൾ നമുക്ക് ഇങ്ങനെ തുടങ്ങാം: (i) x ഒരു എണ്ണൽസംഖ്യ (ii) അടുത്ത എണ്ണൽസംഖ്യ x + 1 (iii) ഇവ രണ്ടും കൂട്ടിയാൽ കിട്ടുന്ന സംഖ്യ x + (x + 1)

അടുത്തതായി, ചെറിയ സംഖ്യയുടെ രണ്ടു മടങ്ങിനോോട് ഒന്നു കൂട്ടിയ സംഖ്യ നോോക്കാം: (i) ചെറിയ സംഖ്യ x (ii) അതിന്റെ രണ്ടു മടങ്ങ് 2x (iii) അതിനോോട് 1 കൂട്ടിയത് 2x + 1

ഇനി മുകളിൽ എഴുതിയ തത്വത്തിന്റെ ബീജഗണിതരൂപം എഴുതാമല്ലലോ: x ഏത് എണ്ണൽസംഖ്യ ആയാലും x + (x + 1) = 2x + 1

ഇതിൽ ഒരു കാര്യയം ശ്രദ്ധിച്ചചോ ? കണക്കിലെ ചുരുക്കെഴുത്ത് എന്ന പാഠത്തിൽ കണ്ട ഒരു കാര്യയം: x, y, z ഏതു സംഖ്യകളായാലും (x + y) + z = x + (y + z)

ഈ സമവാക്യയം തിരിച്ചു വായിച്ചാൽ x + (y + z) = (x + y) + z

ഇതിൽ, y, z എന്നിവ ഏതെങ്കിലും സംഖ്യകളായി എടുക്കുന്നതിനു പകരം x ഉം 1 ഉം ആയി എടുത്താലോോ ? x + (x + 1) = (x + x) + 1 x + x = 2x ആണല്ലലോ. മുകളിലെ സമവാക്യത്തിൽ ഇത് എഴുതിയാൽ, x + (x + 1) = 2x + 1
